返回 0（存在/无写权限检查通过）或 -1（失败/EACCES）。

★语义：**MSVC6 CRT _access 文件存在性检查（推断名——标准
C 库 `_access`）**——cdecl 2 参：
  ① GetFileAttributesA（[0x7E12E4] IAT）查路径属性；
  ② 失败（-1）→ GetLastError（[0x7E1200]）+ 0x7D161B
     （batch 008 Win32→errno 映射）→ 返 -1；
  ③ 成功 → 存在性位（al bit0）+ 模式位 2（写权限）双检：
     不满足 → errno=0xD（EACCES）+ 状态 5 → 返 -1；
  ④ 通过 → 返 0。
  = MSVC6 `_access` 标准实现（存在性 + 写权限检查），与
  batch 1150 _tmpnam 唯一化循环配合（文件不存在 → 走
  0x7CD615 递增器）。
