★语义：**MSVC6 CRT toupper/大小写转换器（推断名——_toupper/
mbctoupper 族）**——cdecl 1 参：
  ① 窄模式（[0xB782A0]==0）：ASCII 小写 0x61-0x7A 直接 -0x20
     转大写返回（fast path，无表）；
  ② 宽模式（[0xB782A0]!=0）：字符码 <0x100 → [0x87C79C] 门控
     （>1 走 0x7D1311 字符分类 / else [0x87C590] ctype 表
     and 2）判定大写类——未命中返回原值；
  ③ 命中/≥0x100 → [0x87C590] 表 lead-byte 判定（
     [edx+ecx*2+1]&0x80）：lead-byte 组 2 字节 / 否则单字节
     → 调 0x7D10C2（8 参：模式全局/0x200/源/字节数/目标/3/0/1）
     转换 → 返回 1 取低字节 / 返回 2 组字；
  ④ 转换失败返回原值。
  = CRT toupper 窄/宽双路径标准形态（ASCII fast path + DBCS
  转换 + ctype 表判定）。

★调用点（探针 E8 实测 1 处 0x7C981F）：前邻宿主 0x7C98xx
  区（字符转换调用端——与 0x7D1311 其他调用点 0x7C9920-
  0x7C9DFB 同区，toupper/tolower 分发宿主）。

★E8 被调者：0x7D1311（batch 字符分类——本批 0x7C9884 交
  叉，49 callers）+ 0x7D10C2（6 callers：0x7C98E7 本函数/
  0x7CB106/0x7D3793/0x7D37BB/0x7DD089/0x7DD0B7——字符转换
  大调用邻域，未逐一核登记）。

★原版怪癖（照抄）：
  ① 窄模式 fast path 直 -0x20（无 tolower 镜像——本函数只
     做 toupper 不做 tolower）；
  ② 宽模式 <0x100 先查 [0x87C79C] 门控（>1 走 0x7D1311 函
     数调用 / ≤1 走 [0x87C590] 表直读）——两套判定路径共
     存（门控值语义与 batch 1115 宿主同款）；
  ③ ctype 表 and 2（大写类位）判定后未命中直接返回原值

  ⑤ 8 参大调用 0x7D10C2（模式全局/0x200/…/3/0/1）参数组

----------------------------------------------------------------

   （_toupper/mbctoupper 族）——0x7C-0x7D = MSVC6 静态 CRT

   0x7D10C2 转换 = CRT 字符大小写转换标准形态（batch 1115/
   1116 同款全局族）。
2. 依赖：0x7D1311（字符分类）+ 0x7D10C2（转换大调用）——
   重写 gamemd 时用等价 std::toupper/towupper 运行时代替。
3. gamemd_replication_discipline：MSVC6 CRT 字符转换设施，
   重写时用等价运行时代替，逐字节复刻无意义——按商业库
   纪律归档，不写 C++ 模型不做 golden。
