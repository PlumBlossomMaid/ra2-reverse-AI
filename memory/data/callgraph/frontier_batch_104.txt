0x407450  双向链表摘除+自环（25 callers，25B）
================================================================================
机器码（全 25B）：
    mov eax, [ecx+4]      ; ★ node->prev
    mov edx, [ecx]        ; ★ node->next
    mov [eax], edx        ; prev->next = next
    mov eax, [ecx]        ; node->next
    mov edx, [ecx+4]      ; node->prev
    mov [eax+4], edx      ; next->prev = prev
    mov [ecx], ecx        ; ★ node->next = node（自环）
    mov [ecx+4], ecx      ; ★ node->prev = node（自环）
    ret

语义：**标准双向链表节点摘除，并把被摘节点重构成「自环空链表」**——把节点从
宿主链表解链后，让节点自身的 next/prev 都指向自己，使其成为可独立使用的空表头
（引擎「登记册」体系里节点退役后复用/重挂的惯用手法）。与 batch 088/089/091
登记的登记册设计家族（CellStruct 向量/对象指针表/哈希节点表）同属「链表/登记」
基建层。

★孪生邻域：紧随 0x407470 是**又一个安全解引用谓词**（mov eax,[ecx] / test /
