★语义：**MSVC6 CRT fopen/fdopen 家族薄包装（推断名——
_fsopen 路径三段链）**——cdecl 3 参：
  ① 0x7D2DA6 单例槽分配器拿 FILE 槽（空 → 静默返 0）；
  ② 原 3 参 + 槽共 4 参转发 0x7D2C36（fopen 标志解析器，
     模式串→_IO 标志位，实际只用前两栈参 [ebp+8]/

  ③ 0x7CB44B 对流槽做流锁 Leave 后返回解析结果。
  = fopen 展开链（壳 0x7CA845 固定传 _SH_DENYNO=0x40）中
  的「取槽+解析+解锁」中段。

★调用点（探针 E8 实测 1 处 0x7CA84F）：紧邻三参壳
  0x7CA845：push 0x40/push [esp+0xc]/push [esp+0xc]/call

  默认共享标志）→ 本壳 = fopen（宏展开 _fsopen(path,

★原版怪癖（照抄）：
  ① 四段重读 [esp+0x18]（push 各自前栈深度固定）——MSVC
     编译器「重复 push [esp+N]」惯用（每压一参栈顶前移但
