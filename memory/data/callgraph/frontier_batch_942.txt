一、链语义（全段 disasm 复核 + golden 8 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7CA405 = MSVC6 静态 CRT 宽字符
字符串长度 `wcslen`——cdecl 1 栈参、ret 无栈清理、返回长度：
  · 入口：
      mov ecx, [esp+4]   ; ecx = s（第一参）
      cmp word [ecx], 0  ; s[0] == 0?
      lea eax, [ecx+2]   ; eax = s+2（字节偏移）
      je 收尾            ; s[0]==0 → 返回 0（空串特例）
  · 循环（"读-推-测"）：
      mov dx, [eax]      ; dx = *(uint16_t*)eax
      inc eax / inc eax  ; eax += 2
      test dx, dx        ; ★dx 载入后在 eax 推进之后才 test
      jne 循环
  · 收尾：sub eax, ecx / sar eax, 1 / dec eax / ret

★batch 058 反编译歧义纠正：旧登记写 `while(s[i]==0)i++; return i-1`
（Ghidra 反编译形式），逐条汇编复核实为 **找第一个 NUL 宽字符的索引
并返回它**（= 字符串长度）：
  · s[0]==0 → 返回 0（空串）；
  · s[0]!=0 → 从 s[1] 起逐字找第一个 0，返回其索引（= 长度）。
  实现用字节地址差 /2（sar 算术右移）再定位，正数等价除法。

★原版怪癖（golden 实证，C++ 侧逐条复刻）：
  ① s[0]==0 走独立分支返回 0（空串特例）；
  ② 非空串从 s[1] 起找 NUL，返回 NUL 索引 = 字符串长度
     （sar /2 + dec）；
  ③ 无溢出防护，宽字符 16 位逐字扫描；
  ④ 无任何外部全局/子调用——纯内存扫描，整函数可真身模拟
     （本批零桩边界）。
