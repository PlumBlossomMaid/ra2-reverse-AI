0x735060  窄串→宽串转换（14 callers，0x2C 全读完）
================================================================================
机器码（全 0x2C）：
    mov al, [edx]                   ; ★ 源窄串（edx）
    test al / je 写终止符           ; 空 → 直接写 word 0
    mov esi, [esp+8]                ; ★ arg2（长度上限，-1 或计数）
    test esi / je 写终止符
  loop:
    movzx ax, al / mov [ecx], ax    ; ★ 窄字符 → word 写入目标
    add ecx, 2 / inc edx            ; 目标 +2B / 源 +1B
    cmp esi, -1 / je 继续           ; 无上限 → 继续
    dec esi                         ; 有上限 → 计数递减
  继续:
    mov al, [edx] / test al / jne loop   ; 源遇 '\0' 停
  写终止符:
    mov word [ecx], 0               ; ★ 写宽串终止符
    ret 4

语义：**窄串→宽串转换器（char* → wchar_t*）**——逐字节把窄字符扩成 word
写入目标，遇源 '\0' 或长度上限（arg2，-1=无限）停，末尾写 word 0。紧邻
0x735090 是反向宽→窄版（cmp word [edx],0）。⚠️ 原版怪癖：arg2 上限
「-1=无限」用 cmp esi,-1 判定，其余值逐次递减。

⚠️ partial：宿主类（0x735xxx 区，转换工具）与调用方用途。
