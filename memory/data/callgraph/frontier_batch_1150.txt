一、链语义（disasm 全 126B + 七依赖交叉 + 两未登记依赖定性，
0x7CD460-0x7CD4DD）
--------------------------------------------------------------
签名（推断）：cdecl 1 参（[esp+0x10]=输出缓冲 string 或
NULL），返回 char* 临时文件名 / NULL。per-thread 槽
[ptd+0x28] 惰性分配 0xE 字节缓冲。

★语义：**MSVC6 CRT _tmpnam 主实现（标准 C 库 tmpnam 族，推
断名）**——cdecl 1 参（string 可空）：
  ① 锁 key=3 保护 namebuf 全局 [0xB78208]；
  ② 懒初始化 namebuf（0x7CD5B4 batch 1022 _init_namebuf）；
  ③ 唯一化重试循环：_access 存在检查（0x7D53C2 未登记）
     + 后缀递增（0x7CD615 未登记）——已存在则递增重试；
  ④ 唯一名就绪：输出缓冲为 NULL → per-thread 槽 [ptd+
     0x28] 惰性 malloc 0xE 字节（0x7C9430）→ 复用之；
  ⑤ strcpy 词级变体（0x7D4BF0 batch 008）拷 namebuf 入
     缓冲 → 返回缓冲指针。
  = MSVC6 `_tmpnam` 标准实现（namebuf 初始化 → 唯一化 →
  返回），与 VC6 CRT 源码行为逐行吻合。

★调用点（探针 E8 实测 1 处 0x77DCA3）：宿主 0x77DCxx 区
  调用者（cdecl 1 参，返指针后接线）。

★E8 被调者：0x7CD9F5（★★TSV:238 锁 Enter）+ 0x7CDA56

★两未登记依赖定性（disasm 实测）：
  ① 0x7D53C2 = CRT `_access` 存在检查族：`push [esp+4];
     call [0x7E12E4]`（IAT=GetFileAttributesA）→ eax==-1
     失败 → call [0x7E1200]（GetLastError）+ errno=0xD
     （EACCES）+ or eax,-1；成功 → `test al,1` + 次参位 2
     组合判定（存在性+写权限双检）——callers=1 0x7CD483；
  ② 0x7CD615 = tmpnam 后缀递增/唯一化器：`push 0x2e('.');`
     call 0x7D571F（batch 1047 DBCS 查找——strrchr 快路径）
     找 '.' → 0x7C9FD9（batch 1048 strtol 薄包装）解析后缀
     数字 → inc → 0x7FFF 上限（cmp eax,0x7fff）→ 0x7D473F
     （batch 1043 _ultoa）数字转串 → 0x7D4BF0（batch 008）
     写回——**与 batch 1022 0x7CD5B4 调用链完全同族**
     （0x7D5719/0x7D473F/0x7D571F/0x7D4BF0 复用）。

★原版怪癖（照抄）：
  ① 锁 key=3 与 batch 1036/1047 的 0x19（字符分类）区分
     ——tmpnam 族独立锁编号；
  ② namebuf 初始化标志是 [0xB78208] 首字节（`cmp byte`）
     而 batch 1022 是 mov esi+双缓冲 [0xB78208]/[0xB78218]
     二选一——初始化检查只看主槽；
  ③ 唯一化重试循环：_access 返回非 0（文件已存在/错误）
     → 出循环直接用；返回 0（不存在）→ 还要再过 0x7CD615
     递增器判定——存在检查+递增双条件顺序微妙（照抄）；
  ④ per-thread 槽 [ptd+0x28] 只 malloc **0xE 字节**（tmp
     名最长 13 字符+NUL）——固定 14 字节；分配失败 edi=
     namebuf（esi）回退语义；
  ⑤ 输出缓冲 NULL 判定用 `cmp edi,ebx/jne`（ebx 恒 0）——
     string==NULL 才走 ptd 槽，非 NULL 直接 strcpy；
  ⑥ strcpy 用 0x7D4BF0 词级变体（batch 008 四字节 NUL 检
     测）而非 CRT strcpy 本体。

   写时用等价运行时代替，逐字节复刻无意义——按商业库纪律
