**语义（推断名）**：**MSVC6 静态 CRT `_splitpath`（路径四段拆分）**——cdecl 5 参：
① **drive**：`strlen(path)>=1` 且 `path[1]==':'` → 前 2 字符 `_strncpy` 到 drive 并手动
   补 NUL（`drive[2]=0`），path += 2 跳过盘符；否则 `*drive=0`；
② **扫描**：从 path 起逐字符，`[0xB78961]&4` 命中的双字节字符整体跳过（+2，DBCS
   lead-byte 感知——batch 040 同款），遇最后一个 `/` 或 `\` 记录**分隔符后一位置**
   为 dir 起点，遇最后一个 `.` 覆盖记录；③ **dir** = `path[0..最后一个分隔符]`
   （**含尾分隔符**，len 截断 255）；④ **fname** = `[分隔符后..最后一个点)`（无点则
   = 全部剩余）；⑤ **ext** = `[最后一个点..串尾)`；各段 `_strncpy` 后手动补 NUL。
★原版怪癖（照抄）：① **dir 含尾分隔符**（len = 分隔符后一位置 - path 起点，把
   分隔符本身算进 dir）；② **各段截断 255**（0xFF 上限 + 手动 NUL，标准 _MAX_* 表
   观）；③ **drive 固定拷 2 字节 + 手动 NUL**（"C:" 形态，不查缓冲区）；④ **[0xB78961]&4
   lead-byte 整体跳过**（DBCS 感知，命中 +2——与 batch 040 的 0x7D3886 同表同位）；⑤
   **多个 '.' 只记最后一个**（覆盖写 [ebp-4]）；⑥ **'.' 在 fname 起点前 → 整体走无点
   分支**（fname 取全部、ext 空）；⑦ 无分隔符 → dir 置空；⑧ **[ebp+8]/[ebp+0xC] 参数槽
