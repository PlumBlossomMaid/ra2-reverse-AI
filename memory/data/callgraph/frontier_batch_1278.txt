    fmul dword ptr [0x7f6890] ; ×{float 0x7F6890}

语义：**浮点缩放截断器**——this+0 的 float × 常量 [0x7F6890] 后尾跳

[0x7F6890] 需读 PE 确认值（.rdata 单 float）；③★this+0 直接当 float

0x7500E0 —— 整数→浮点换算器（13B 全程读完）
================================================================================
签名：thiscall（ecx=this 指向 float）+ 1 栈参（[esp+4]=int 源值）ret 4。
机器码（全文 13 字节）：
    fild dword ptr [esp+4]    ; ST0 = (double)(int)[esp+4]
    fmul qword ptr [0x7e3808] ; ×{double 0x7E3808}
    fstp dword ptr [ecx]      ; this->+0 = (float)结果
    ret 4

语义：**整数→浮点换算器**——1 栈参 int 源值 fild 浮点化 × 常量 [0x7E3808]
（double）后存 this+0（float）。3 unique caller（30 callsite）。

★怪癖：①★fild (int→double) + fmul double + fstp float 三段式（32 位 int
→ 64 位 double → 乘 → 32 位 float 回存——精度转换链）；②★常量 [0x7E3808]
是 double（8 字节 qword）；③★与 0x7500D0 同 0x7500xx 区配对（反向换算
器——彼 float 到 int、此 int 到 float）。

⚠️ partial：常量 [0x7E3808] 值（未读）、source int 语义（坐标/计数）、
宿主类（0x7500xx 区）。

0x721290 —— 字段钳位写入器（22B 全程读完）
================================================================================
签名：thiscall（ecx=this）+ 1 栈参（[esp+4]=值）ret 4。
机器码（全文 22 字节）：
    mov eax, [esp+4]          ; eax = 值
    cmp eax, 0xff             ; 与 0xFF（255）比较
    jl 0x7212a0               ; 值 < 255 → 跳过钳制
    mov eax, 0xff             ; 否则 eax = 255
    0x7212a0:
    mov [ecx+0xc], eax        ; this->+0xC = min(值, 255)
    ret 4

语义：**字段钳位写入器**——1 栈参值钳位到 [-, 255]（上界 0xFF=255）后存
this+0xC。3 unique caller（30 callsite，functions.tsv 计数）。

★怪癖：①★钳位上界 0xFF=255（单上界无下界——负值原样写入）；②★与
batch 1277 0x752AB0（钳位写 [0x846614]）同构但目标不同——★本批写
对象字段 +0xC，彼批写全局；③★mov+ret 最简两分支。

⚠️ partial：+0xC 字段语义（计数/索引/配置）、钳位 0xFF 业务含义（字节
域上界）、宿主类（0x721xxx 区）。
