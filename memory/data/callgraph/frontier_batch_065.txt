★ **跨层连接**：`cell->[0x11B]` 与 `cell->[0x11C]` 这两个字段——前者正是
**死代码 `0x5A82E0`** 读的同一字段（见 dead-code-functions.md）。活代码的

活代码共享 CellClass 布局。`cell->[0x11C]` 应为「可用/占用」标志字节，
`cell->[0x11B]` 应为某种类型/地形字节（**未实锤**，仅由两处读取点推断）。

0x0048D080  游戏模式分发器（按全局 [0xA8B238] 分支）
================================================================================
72 callers。`and esp,0xfffffff8`（SSE 对齐）+ `sub esp,0x100` 大帧。骨架：

    call 0x406f70                          ; 前置（可能是某个 Tick）
    ; [0xB45B68]>0 时，从 [0xB45B5C] 取单例，虚调用 vtable+8
    mov eax, [0xa8b238]                    ; ★ 与 HouseClass 阵营判定同一全局
    cmp eax, 3 / je → call 0x48D1E0
    cmp eax, 4 / jne
    cmp eax, 1 / je
    cmp eax, 2 / jne
    test byte [0xa8dab8], 1
    mov ecx, 0xa8ea70 / call 0x5f1c60
    mov eax, [0xa8b230]

语义：**按全局 [0xA8B238] 的值（1/2/3/4）分发游戏模式逻辑**——这与
HouseClass::IsControlledByCurrentPlayer 用的是**同一个全局**（batch 062）。
`[0xA8B238]` 因此大概率是 **GameMode/Session.Type 枚举**（1=单机战役 /
2=单机遭遇战 / 3=联机 / 4=观察者 之类，⚠️ 各值含义未实锤）。
`[0xB45B68]`/`[0xB45B5C]` 是一个带虚表的单例管理器。

0x004CACB0 / 0x004CAD00  表驱动三角函数（sin 已实锤）
================================================================================
69 / 61 callers。紧邻已实锤的 sqrt（0x4CAC40），是 CRT 数学簇的一部分。

0x4CACB0（全部 0x42 字节）：
    fld qword [esp+4]                      ; 入参 double
    fmul dword [0x8223b0]                  ; ★ × 2607.594（= 8192/π，读字节实锤）
    call 0x7c5f00                          ; ftol
    mov cl, al / cdq / sub eax,edx / and cl,1 / sar eax,1
    and eax, 0x80001fff                    ; 取低 13 位（8191）+ 符号位
    ...（符号/象限折叠）
    fld dword [eax*4 + 0x84f084]           ; ★ 查 8192 项 float 表
    ret

**常量与表读字节实锤**：
- `0x8223B0` = 2607.594482421875 = **8192/π**（索引 = round(x · 8192/π)，
  随后 `sar 1` 折半 → 表覆盖半周 π，符号位做象限折叠）。
- 表 `0x84F084` 前 6 项：`0.0, 0.000767, 0.001534, 0.002301, 0.003068, 0.003835`，
  逐项匹配 `sin(i·2π/8192)`（误差 < 1e-7）。

**结论：0x4CACB0 = 表驱动正弦 `sin(x)`**（x 弧度，8192 项表 + 象限折叠）。

0x4CAD00 是紧邻孪生：`fld [esp+4]; fmul [0x8223b4]; call 0x7c5f00`——
**常量 0x8223B4 的值与 0x8223B0 完全相同**（都是 8192/π），故两者**不是**
靠缩放常数区分 sin/cos。⚠️ 只见到 0x4CAD00 的头两条指令，它用的是同表
加相位偏移（cos(x)=sin(x+π/2)）还是另一张首项=1.0 的 cos 表，**未实锤**。
