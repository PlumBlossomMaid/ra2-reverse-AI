## 原版怪癖（照抄）

1. a/b 同族但 ret 宽度不同（a=0x10 / b=0x1C——b 多 3 栈参）+ 模板存放位置不同（a 存栈 / b 存 ebp）+ b 路链表尾插（[esi+0x5c]/[esi+0x5d8] 双链）+ 0x4733a0 挂 [esi+0x114] 族 + [esi+0x6c9]=1；
2. b 路 `[esi+0x14]&4 → neg al → sbb eax,eax → and eax,esi` 位标志提取指针惯用法（eax=esi 或 0）；
3. 三路共享 [0xa8e7ac] **全局原子计数对**（inc 进入/dec 退出包住危险调用——batch 2110 c 同款）；
4. a/b/c 坐标惯用法：`movsx <<8 + 0x80`（半坐标）；c 路另有 `<<0xd` + `sub 0x6001` + `and 0xffffe000` 单元格对齐；
5. c 路 **16B repe cmpsd** vs 0x7e9a50 常量比较（0x34c 偏移临时区）；
6. c 路三标志多路径（[esp+0x12]/[esp+0x13]/[esp+0x84]——全 0 走简单，否则复杂）；
7. c 路 8 邻域尝试 [0x89f688] 表（8×8B 方向步长——batch 2104 提到的 8 邻域 work 索引表同址）+ 0x568300 尝试 + 失败带 -1 生命参重试；
