一、链语义（disasm 全段复核 + golden 16 用例实证）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7CA610 = MSVCRT strncmp（定长
字节串比较）——cdecl 3 栈参 (s1, s2, count)，返回比较三态 {-1,0,+1}
（无符号逐字节）。纯内存操作，无子调用无全局引用——全程可真身模拟。
  机器码（0x7CA610-0x7CA647，56B）：
    push ebp/mov ebp,esp/push edi/push esi/push ebx
    ecx=[ebp+0x10]=count → jecxz 0x7CA641（★count==0 → 返回 0）
    ebx=count / edi=[ebp+8]=s1 / esi=edi / xor eax,eax
    repne scasb（0x7CA624）：从 s1 扫 NUL，每字节 ecx--，找到
      NUL 或 ecx 耗尽停
    neg ecx → add ecx,ebx → ecx = min(count, len(s1)+1)
      （★★比较长度 = s1 到首个 NUL 的长度+1，若在 count 内；
      否则 = count——s1 被预扫、s2 不预扫）
    mov edi,esi（s1 复位）/ esi=[ebp+0xC]=s2
    repe cmpsb（0x7CA62F）：比较 ecx 个字节，停在不等或耗尽
    （★s1 的 NUL 参与比较：s1 短时提前终止、NUL=0 判序）
  收尾（0x7CA631）：al=[esi-1]（s2 最后字节）/ xor ecx,ecx /
    cmp al,[edi-1]（s1 最后字节）
    ja 0x7CA63F → not ecx(0) → eax=-1（s2>s1 → s1<s2 → 负）
    je 0x7CA641 → eax=0（相等）
    dec ecx ×2 → not ecx(-2) → eax=1（s2<s1 → s1>s2 → 正）

★原版怪癖（golden 实证，照抄）：
  ① count==0 直接返回 0（jecxz，不读任何内存）；
  ② 比较长度 = min(count, len(s1)+1)——先 scasb 扫 s1 的 NUL
     （≤count），s2 不预扫：s1 短时其 NUL 提前终止比较，NUL=0
     参与无符号判序（s1 先到 NUL 且前缀相同 → s1<s2）；
  ③ 收尾只取最后一对字节判三态（ja/je 无符号），不返回原始差值；
  ④ eax 由 ecx 经 not 得到（-1/0/+1），非直接差值。
