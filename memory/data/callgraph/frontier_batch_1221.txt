一、链语义（disasm 全 28B + 核心交叉 + Westwood 调用点交

--------------------------------------------------------------
签名（确认）：cdecl 0 参，返回核心 0x7DD20F 结果（字符或
-1 EOF）。

主体（0x7DD1D7-0x7DD1F2）：
007dd1d7  push esi
007dd1d8  push 8                           ; ★锁 key = 8
007dd1da  call 0x7cd9f5                    ; ★★TSV:238 流锁
                                           ;   Enter（key 8）
007dd1df  call 0x7dd20f                    ; ★★TSV:1973 batch
                                           ;   1129 CRT 控制台字
                                           ;   符读取器（_getch
                                           ;   类，209B）
007dd1e4  push 8                           ; 锁 key = 8
007dd1e6  mov esi, eax                     ; ★esi = 核心结果
007dd1e8  call 0x7cda56                    ; ★★TSV:239 流锁
                                           ;   Leave（key 8）
007dd1ed  pop ecx                          ; 清 Enter 的 key
007dd1ee  mov eax, esi                     ; ★返回核心结果
007dd1f0  pop ecx                          ; 清 Leave 的 key
007dd1f1  pop esi
007dd1f2  ret

★语义：**MSVC6 CRT 控制台字符读取加锁包装壳（推断名——
_getch 公开入口锁包装层）**——cdecl 0 参：
  ① 流锁 Enter（0x7CD9F5，key 8）；
  ② 调 0x7DD20F（_getch 类控制台字符读取器——缓存槽
     [0x87DD70] + CONIN$ 句柄槽 [0x87DD80] + -1/-2 双哨
     兵，batch 1129 已全量登记）；
  ③ 流锁 Leave（0x7CDA56，key 8）；
  ④ 返回核心结果（esi 中转）。
  = 控制台输入公开入口的锁包装（缓存槽 + CONIN$ 句柄全程
  串行化——键缓冲不被并发读取撕裂）。

★调用点（探针 E8 实测 1 处 0x4C85C8——**Westwood 主代码区
  0x4C85xx，非 CRT 内部**）：宿主 0x4C859A 起（启动/等待域
  ）：mov esi,[0x7E1218]/call esi（★IAT 槽，推断
  GetTickCount/timeGetTime）→ mov edi,[0x7E1210]/test
  eax,eax/jne 0x4C85B0 → call edi/call esi（★失败重试一
  次）→ push 0x821CC0（★消息串）/call 0x7DD4F4（★scan 池
  候选 printf 族）/add esp,4 → push 0xFA0（★4000ms 超时）
  /call dword[0x7E11F0]（★IAT 槽）→ **call 0x7DD1D7（★本
  批）** → call edi → pop edi/mov eax,0x481/pop esi/ret
  ——宿主为「打印提示 + 等 4 秒 + 阻塞读一键」的交互等待
  流程（Westwood 游戏启动/错误路径直接调 CRT 控制台读入
  口，经锁壳）。
