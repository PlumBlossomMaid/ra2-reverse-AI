一、链语义（disasm 全段复核 + golden 14 用例逐位实证）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7C8B48 = MSVC6 静态 CRT 迭代式
qsort——cdecl 4 栈参 base/count/size/cmp 函数指针、ret 由调用者清栈、
返回 void（比较器语义由调用方注入，这里是 int32 升序）。零外部全局，
子调用全在本段：0x7C8C9C 收缩排序、0x7C8CEA swap。
  主流程（0x7C8B48-0x7C8C9B）：
    count < 2 或 size == 0 → 直接返回（不调比较器）
    first = base；last = base + (count-1)*size
    显式区间栈（[ebp-0xF8] 存 first、[ebp-0x80] 存 last，深度 [ebp-4]）
    主循环 0x7C8B87：
      n = (last-first)/size + 1（无符号 div，eax=last-first、xor edx）
      n <= 8 → 调 0x7C8C9C(first,last,size,cmp) 收缩排序 → 出栈
               （depth<0 → 返回；否则弹 (first,last) 继续主循环）
      n > 8  → 快排分区（0x7C8BC7）：
        mid = first + (n/2)*size；swap(mid, first, size)
        （中点元素交换到 first 作枢轴）
        左扫 i（0x7C8BDE）：i 初值 first，循环 { i += size；
          i > last（ja）→ 右扫；cmp(i, first) > 0（jle 继续）→ 右扫 }
        右扫 j（0x7C8BF6）：j 初值 last + size，循环 { j -= size；
          j <= first（jbe）→ 汇合；cmp(j, first) < 0（jge 继续）→ 汇合 }
        汇合（0x7C8C08）：
          j >= i → swap(i, j, size)；回左扫（jmp 0x7C8BDE）
          j < i  → swap(first, j, size)（枢轴归位）→ 区间调度
        区间调度（0x7C8C24）：
          ecx = j - first - 1（字节）、edx = last - i（字节）
          ecx < edx（jl）→ 左区间小：右区间 [i, last] 入栈
            （i < last 时）；继续左区间 [first, j-size]
            （first+size < j 时），否则出栈
          ecx >= edx → 右区间小：左区间 [first, j-size] 入栈
            （first+size < j 时）；继续右区间 [i, last]
            （i < last 时），否则出栈
  收缩排序（0x7C8C9C-0x7C8CE9）：
    last <= first → 返回
    每轮外层：rec = first；cur = first + size
      内层 while cur <= last：cmp(cur, rec) > 0 → rec = cur；cur += size
      内层结束：swap(rec, last, size)；last -= size；last > first 继续
  swap（0x7C8CEA-0x7C8D15）：
    a == b 或 n == 0 → 直接返回；否则逐字节交换 a/b 的 n 字节

★原版怪癖（golden 实证，C++ 侧逐条复刻）：
  ① 枢轴取「中点元素」并交换到 first，不做三数取中；
  ② 左扫/右扫均先推进游标再判断边界与比较（i 先 +=size 判 i>last，
     j 先 -=size 判 j<=first）——严格按序调用比较器；
  ③ 左扫停在 cmp(i,first) > 0、右扫停在 cmp(j,first) < 0（等号继续
     推进——不稳定排序的来源之一）；
  ④ 区间调度比较 left=(j-first-1) 字节 vs right=(last-i) 字节，
     按「小区间入栈、大区间继续迭代」控制显式栈；
  ⑤ 收缩排序内层比较基准是**动态 rec**（0x7C8CC9 `mov ebx, esi`
     更新后与 cur 比），不是固定 first——最初写成 cmp(cur, first)
     导致 n=7 完全不动、n=9 从第 16 次比较分岔，golden 逐位对拍暴露；
  ⑥ 显式栈无溢出检查（原版固定栈区约 30 项）——C++ 模型用动态栈，
     正常输入（深度 O(log n)）行为等价；
  ⑦ 比较器调用序列（次数/顺序/实参值对）是可观测行为——golden 逐位
     记录，C++ 模型必须逐位复现。

  n=5 全零 / n=2 / n=7 / n=8 / n=3 重复 → 收缩排序路径（n<=8）

三、C++ 模型（code/rewrite/runtime/crt_qsort.{h,cpp}）
------------------------------------------------
namespace ra2::runtime。单函数 + 文件内私有辅助（无外部依赖）：
  qsort_legacy(base, count, size, cmp) —— 0x7C8B48：
    count < 2 || size == 0 → 直接返回
    主循环 n<=8 走 shrink_sort（动态 rec 基准）、n>8 走快排分区
    （mid 枢轴 + 双向扫描 + 显式栈区间调度）
  shrink_sort / swap_bytes —— 0x7C8C9C / 0x7C8CEA 逐条照抄
cmp 为 cdecl 函数指针 int (*)(const void*, const void*)——与调用点
push 两参 + call 的 ABI 完全对应（cdecl 参数顺序 = 原版压栈顺序）。
无失败路径、无额外校验。原版"区间栈约 30 项"限制未复刻（动态栈），
正常输入行为等价。

------------------------------------------------
