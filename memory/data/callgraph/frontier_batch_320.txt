0x58BE20 —— 随机取「已占用」格子（四级递增严格度第一级，126B）（6 callers，全 0x7E=126B 读完）
================================================================================
机器码（全 0x7E）：eax=[0x89C2DC]（边长 side）→ eax=side*side/esi=side*side-1
→ loop: v=_ftol((double)(uint32)Random()*scale*[0x7ED898])（=*total/4294967295.0）
→ if (v>side*side-1) goto loop（拒绝采样）→ p=[0xABED10]+v*0x50（lea ecx,
[eax+eax*4]; shl ecx,4——★side*0x50 索引与活代码 0x578E60 分配 side²×0x50
同套）→ if (p->x==0 && p->y==0) goto loop（空格子重抽）→ *this=*p; return
（返回值=work[v] 首 dword = x|(y<<16)）

语义：**随机取一个「已占用」的格子**——拒绝采样（>hi 重抽 + 空格子重抽），
取到非 (0,0) 的格子后整块拷出；side*0x50 索引方式与活代码同套。同地址
0x58BEA0 是同构第二份。**原 11 条 body_bytes=1 误判名单之一（实测 126B）**。

★原版怪癖（照抄）：① **拒绝采样双条件**（v>hi + (x,y)==(0,0) 均重抽）；
② **无限重抽**（无上限——后两级才有 100 次上限）；③ **side*0x50 索引**（与

★跨批次连接：**[0x89C2DC]/[0xABED10]（MapGen 边长/工作数组）**+Randomizer::
