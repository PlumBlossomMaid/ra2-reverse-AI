★语义：**CRT 字符特性表位操作器（推断名——_pctype 类写侧）**
——cdecl 2 参（param1=字符值，param2=操作标志）：
  ① [0xB78A80] 表查（param>>5 表索引 ×4 + 低5位 ×9 → 项内偏
     移 +4）读表项字节；
  ② 参2 == 0x8000 → 清 0x7F 位（and cl,0x7F）；
     参2 == 0x4000 → 置 0x80 位（or cl,0x80）；
  ③ 写回表项字节 [edx]；返回 = 0x8000 + (原标志 and 0xC000)；
  ④ 参2 非法（≠0x8000/0x4000）→ errno=0x16（EINVAL=22）+
     返回 -1。

★原版怪癖（照抄）：
  ① 表布局 [0xB78A80]：[表索引×4] 基 + 低5位×9×4 + 4 偏移——
     与 batch 1063（0x7DD434 查询器）同族但不同表（0xB78A80
     vs 0x87DA30）——查询/写入分表；
  ② 位操作双值（0x8000 清 / 0x4000 置）——非 0/1 语义；
  ③ eax 标志抽取用 neg/sbb（(flag&0x80)?0:-1 + and 0xC000 +
     0x8000）——返回值 = 特性位向量的压缩表示；
  ④ 非法参数 EINVAL=0x16 返 -1（错误码与哨兵共用）；
  ⑤ 写后返回旧标志特征值（非 void）。
