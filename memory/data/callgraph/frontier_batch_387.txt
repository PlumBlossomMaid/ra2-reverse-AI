② 0x004CADB0 —— 命名裁定（asin 表实锤 → acos；修正 batch 350 的「atan」命名）
================================================================================
**裁定依据（`.qwen/tmp/_read_tbl_up.py` 直读表项，逐点对拍）**：
```
地址        k      x       实测表项          理论 asin(x)        一致?
0x859094    k=0    x=-1    -1.570796251     asin(-1) = -π/2     ✓
0x859098    k=1    x≈-0.9995 -1.53954494     asin(-0.9995)      ✓（-1.5395）
0x859094+0x400  k=256 x=-0.875  -1.06543577  asin(-0.875)=-1.0654 ✓
0x859094+0x800  k=512 x=-0.75   -0.84806204  asin(-0.75)=-0.8481 ✓
0x85B094    k=2048 x=0     0                asin(0) = 0          ✓
```
**结论（实锤）**：`0x859094` 起的表 = **`asin(x)` 表，x ∈ [−1, 0]**（单调
−π/2 → 0）；函数 `0x4CADB0` = **`π/2 − asin(x) = acos(x)`**。这**修正 batch 350
的命名「表驱动反正切（atan）」为「表驱动反余弦（acos）」**——`atan(−1) = −π/4`
与 `k=0` 项 `−π/2` 矛盾，而 `asin`/`acos` 与全部抽样点吻合。
**处理方式（非破坏性）**：既有行（第 1110 行）的**描述不覆盖**，在其**证据字段
再追加**本批次裁定指针（batch 386 指针已在上一批追加）。**建议后续把该行描述的
「反正切」一词改为「反余弦」**（留待一次统一修订，不单列 commit 以免噪音）。
★跨批次：本裁定**闭合 batch 386 登记的待裁定项**，同时把 batch 384/385 的角度族
（`0x48A8D0` 角度→16 位整数、`0x48A9D0` 角度反解、`0x4CADB0` acos）**全部定型**。
