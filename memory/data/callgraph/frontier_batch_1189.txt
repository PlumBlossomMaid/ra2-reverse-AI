一、链语义（disasm 全 51B + 依赖交叉 + 调用现场 + 同族对

--------------------------------------------------------------
签名（推断）：cdecl 3 参（arg1=字符串指针、arg2=写出长度
、arg3=状态/计数指针），返回 void；写出失败（*arg3==-1）
提前退出。

主体（0x7DDC78-0x7DDCAA）：
007ddc78  push ebx
007ddc79  mov ebx,dword[esp+0xc]              ; ebx = arg2（长度）
007ddc7d  mov eax,ebx
007ddc7f  dec ebx                             ; ebx = 长度-1
007ddc80  push esi/push edi
007ddc82  test eax,eax
007ddc84  jle 0x7ddca7                        ; 长度<=0 → 直接退出
007ddc86  mov edi,dword[esp+0x18]             ; edi = arg3（状态指针）
007ddc8a  mov esi,dword[esp+0x10]             ; esi = arg1（串指针）
; → 写出循环（0x7DDC8E）：
007ddc8e  movsx eax,byte[esi]                 ; ★eax = (signed char)*esi
007ddc91  push edi                            ; 状态指针
007ddc92  push eax                            ; 字符值
007ddc93  inc esi                             ; esi++（串前进）
007ddc94  call 0x7ddc32                       ; ★★TSV:1890 0x7DDC32
                                              ;   控制台写出计数薄包装
                                              ;   （转调 0x7DE17D 核心；
                                              ;   核心返 -1 → *arg3=-1
                                              ;   否则 (*arg3)++）
007ddc99  cmp dword[edi],-1                   ; ★*arg3 == -1（出错）?
007ddc9c  pop ecx/pop ecx
007ddc9e  je 0x7ddca7                         ; 出错 → 提前退出
007ddca0  mov eax,ebx
007ddca2  dec ebx
007ddca3  test eax,eax
007ddca5  jg 0x7ddc8e                         ; 剩余>0 → 继续
007ddca7  pop edi/pop esi/pop ebx/ret

★语义：**MSVC6 CRT 控制台串段写出循环（推断名——格式化
引擎字符串段写出）**——cdecl 3 参：
  ① 从 arg1 串逐字符（signed char 符号扩展）经 0x7DDC32
     写出（每字符一次，计数递增）；
  ② arg2 指定写出字符数（先判 <=0 退出）；
  ③ 每轮检查 *arg3：==-1（核心出错）→ 提前退出循环。
  = 格式化引擎的「字符串段写出」原语（配合同族 0x7DDC4C
  的「填充字符重复写出」——宿主 0x7DDB40 现场 `push 0x20
  /push 0x30` 空格/零填充垫宽 + 本批串段写出的双兄弟）。

★调用点（探针 E8 实测 3 处，全在 0x7DDB 宿主区）：
  ① 0x7DDB72：lea eax,[ebp-0x14]（状态指针）/lea eax,
     [ebp-0x16]（串指针）/push [ebp-0x1c]（长度）/push
     eax/call——字符串段写出；
  ② 0x7DDBBC2/0x7DDBDD：同宿主后续（重复串段写出现场）。
  宿主 = 0x7DDB 区大格式化函数（0x7DDB40 起：test bl,0xc
  标志分支 + push 0x20/0x30 填充 + 调 0x7DDC4C 3 处 +
  调 0x7DDC78 3 处）——MSVC6 CRT 格式化输出引擎本体（宽/
  窄字符输出共用写出族）。

★E8 被调者：**0x7DDC32（★★TSV:1890 已登记 crt_runtime_

★全局：无（纯栈 + 参数透传）。

★原版怪癖（照抄）：
  ① 每轮从栈重载 esi（mov esi,[esp+0x10]）只做一次，循环
     内 inc esi 前进——长度与指针分离（不检查串尾 NUL，
     纯按 arg2 计数）；
  ② movsx **符号扩展**读字符（非 movzx）——高位字节为负
     值字符照传；
  ③ 错误检测用 *arg3==-1（状态指针间接读）而非返回值
     ——0x7DDC32 返 void，错误经 arg3 回传；
  ④ 退出前弹 edi/esi/ebx 三寄存器（先 push ebx 后 push
     esi/edi——弹栈逆序）；
  ⑤ 长度<=0 快路径（test/jle 在重载 edi/esi 之前）——空
     段不触指针；
  ⑥ ebx 递减从 长度-1 起（mov eax,ebx/dec ebx 双步）——
     循环计数与退出判定错位一拍（先判再减的 MSVC 模式）。
