0x631C80  链表节点析构（孪生或同族第二份）（21 callers，0x31B 全读完）
================================================================================
机器码（全 0x31B）——与 batch 106 登记的 0x6C9850 **同构**：
    mov esi, ecx / xor edi, edi
    mov eax, [esi+4]                 ; ★ 前向指针
    mov [esi], 0x7E6218              ; ★ 装虚表 0x7E6218（vs 0x6C9850 的 0x7E61F0）

    mov ecx, [esi+8] / mov [eax+8], ecx   ; 前向->+8 = 后向
  skip1:
    mov ecx, [esi+8] / cmp edi / je skip2
    mov eax, [esi+4] / mov edx, [ecx]     ; 后向->虚表
    push eax / call [edx + 0xC]           ; ★ 虚表槽 +0xC（vs 0x6C9850 的 +4）
  skip2:
    mov [esi+8], edi / mov [esi+4], edi   ; 双指针置 NULL
    ret

语义：**双向链表节点析构**——装虚表 0x7E6218、前向->后向贯通、后向节点虚表槽
+0xC 挂接通知、双指针置 NULL。与 batch 106 的 0x6C9850（装 0x7E61F0、槽 +4）
**仅虚表地址与通知槽位不同**——两个不同类/不同虚表布局的同类析构（未做归一化
比对不写「孪生副本」，按「同族第二份」登记）。
