一、链语义（disasm 全段复核 + golden 8 用例实证）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7C978A = MSVCRT 布尔规范化
包装——cdecl 1 栈参 p、ret 由调用者清栈。依赖 0x7C970C（0x40+ 长，
内部堆检查/realloc 链，batch 946 以桩注入返回值）。
  机器码（0x7C978A-0x7C979B，18B）：
    push [esp+4]        ; p 复制转发（push 原始参数槽内容）
    call 0x7C970C       ; eax = inner(p)
    neg eax             ; eax = -eax（NEG 置 CF=1 除非原 eax==0）
    sbb eax, eax        ; eax = eax - eax - CF = -CF = (原≠0) ? -1 : 0
    pop ecx             ; 清转发参数（cdecl 调用者清理）
    neg eax             ; (原≠0) ? 1 : 0
    dec eax             ; (原≠0) ? 0 : -1
    ret

★原版怪癖（golden 实证，照抄）：
  ① 最终语义：inner(p) 非零 → 返回 0；inner(p) 为零 → 返回 -1
     （neg/sbb/neg/dec 四步布尔规范化，非简单三元判断）；
  ② p 被复制转发（push [esp+4]）而非原地使用——inner 可安全修改
     自己的栈参槽而不影响调用者栈；
  ③ 全路径必然调用一次 inner（p==0 或任意 p 都转发，无 NULL 短路）。
