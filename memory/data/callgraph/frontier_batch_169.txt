(节名, 条目名, 输出缓冲)；名字==节名走主路径，否则走注册路径；两者都先把
名字喂给 batch 082 的 CRC 引擎（0x4A1DE0）算完整性校验值，经注册器族
（0x52B4F0/0x52B170/0x52B600/0x52B620/0x52B390，batch 125/130/137 已登记）
在 this->+0x28 起的条目表中查找/插入，命中后经 0x7C91D0 + batch 168 的
0x727CF0（trim）清洗，最后经 0x7B48D0 写入输出缓冲，返回 CRC/长度。

★跨批次闭合：batch 082（0x4A1DE0 CRC 引擎——本批确认 INI 查找也走
CRC）+ batch 125/130/137（注册器族 5 成员全被本函数调用）+ batch 168
（0x727CF0 trim）+ batch 072（0x7B5440 GetString）——INI 系统查找注册
链路全景。

0x52B170 未登记（11 callers）、返回值的精确含义（CRC/长度）。

    call 0x40A940                          ; ★ 首次 → trampoline 初始化

  0x407040（Release 形态，0x16 读完）：

    dec dword[0x87E730] / jne 返回

  0x40A940（trampoline，0x0F 读完）：

    mov ecx,[eax] / push eax / call [ecx+0x48]   ; ★ 全局函数指针 虚表槽 0x48

0x407010 getter），[0x87E730] 存引用计数：0x407020 首次计数为 0 时经
0x40A940（[0x87E8A0] 全局函数指针 trampoline，虚表槽 0x48）初始化后
计数++；0x407040 计数归零时经 0x40A950（同指针 虚表槽 0x24）释放。

同型——0x87Exxx 区全局函数指针 trampoline 族第二/三例。

⚠️ partial：[0x87E728] 单例对象身份、[0x87E8A0] 指针初始化点、虚表槽

0x7CA530  CRT 格式化族（20 callers，0x7CA530-0x7CA563 读完）

    mov eax,[ebp+8]                ; ★ arg1（目标缓冲）

  紧邻 0x7CA564 是同构变体（常量 0x42='B'、上限 0x7FFFFFFF、调 0x7D21BE）
  0x7CA530/0x7CA564 均为 0x7C-0x7D 区（MSVC6 静态 CRT，非 Westwood 手写）。

语义：**CRT 字符串格式化包装（vsnprintf 形态）**——0x7CA530 用 'I' 常量、
0x7CA564 用 'B' 常量 + 0x7FFFFFFF 上限（vsnprintf 标准形态），两者都委托
0x7D 系内部核心（0x7D15A0/0x7D170D/0x7D21BE）。★0x7C-0x7D 是 MSVC6
静态 CRT 区（项目记忆 ra2_code_region_layout_crt_provenance）——本批按

⚠️ partial：0x49/0x42 常量精确含义（格式标志/长度）、0x7D 系核心身份、
