0x005B43F0 —— 恒真谓词（5B，ret 4）（5 callers，全 5 字节读完；deps=937）
================================================================================
机器码（**全 5 字节，无分支无访存**）：
```
005b43f0  mov al, 1
005b43f2  ret 4
```
语义：**恒真谓词（推断名）**——`return true;`。`ret 4` = 1 个栈参，即
`__stdcall`/`__thiscall` 单参形态；函数体不读 this、不读参数、无副作用。
**这是教科书式的「虚函数默认实现」**（如 `IsXxx() { return TRUE; }`），
基类给出恒真默认值、派生类按需改写。
★邻函数对照（同 call 内顺带读出）：`0x005B4400` = `push ebx/esi / mov esi,ecx /
xor ebx,ebx / mov eax,[esi+0x24] / cmp eax,ebx / je … / cmp byte [esi+0x12],bl /
je … / push eax / call 0x7C8B3D（**batch 001 operator delete**）/ add esp,4 /
mov [esi+0x24],ebx`——**带双门控的缓冲释放器**（`+0x24` 指针非空 **且**
`+0x12` 标志字节非 0 才释放，随后指针清零）。两条一起说明 `0x5B43F0` 所属的
类有「真谓词 + 缓冲」成员对。
⚠️ partial：宿主类、谓词查询的具体属性名、`+0x24`/`+0x12` 字段语义。

0x00407010 —— 全局 getter（6B）（5 callers，全 6 字节读完；deps=202）
================================================================================
机器码（**全 6 字节**）：
```
00407010  mov eax, [0x87E728]   ; ★全局 [0x87E728]
00407015  ret                    ; 无栈参
```
语义：**全局 getter（推断名）**——`return g_something;`（`[0x87E728]`）。无参数、
无副作用、无 this。**属「全局状态读取口」**：这类函数的存在说明该全局被大量
读取且作者包了一层（便于后续改成惰性求值/加锁而不改调用点）。
★邻函数对照（同 call 内顺带读出，**同族第二个存取器**）：
```
0x00407020  mov eax, [0x87E730]   ; ★相邻全局（+8）
0x00407025  test eax, eax
0x00407027  jne 0x40702e
0x00407029  call 0x40A940          ; ★为 0 时惰性初始化
0x0040702e  inc dword [0x87E730]   ; ★随后自增（计数器）
0x00407034  ret
```
即 `0x407010` 是**纯读**、`0x407020` 是**惰性初始化 + 自增（计数器/惰性单例
引用计数）**——同一全局区 `[0x87E728..0x87E730]` 上的一对存取器，后者带
「为 0 才初始化」的门控与 `inc`。**两函数形状差异恰好说明前者读的是已就绪的
值、后者负责建立它**。
⚠️ partial：`[0x87E728]`/`[0x87E730]` 的语义（对象指针 + 计数器推断）、
`0x40A940`（惰性初始化函数）身份。

0x004F4CA0 —— 「字段为空」布尔谓词（10B）（5 callers，全 10 字节读完；deps=144）
================================================================================
机器码（**全 10 字节，无分支**）：
```
004f4ca0  mov dl, byte [ecx]   ; ★读 this+0 字节
004f4ca2  xor eax, eax
004f4ca4  test dl, dl
004f4ca6  sete al               ; ★相等（==0）则 al=1
004f4ca9  ret                    ; 无栈参
```
语义：**「字段为空」布尔谓词（推断名）**——`return (this->field0 == 0);`，
即 `Empty()/IsFree()/IsNull()` 一类。**注意方向**：字段为 0 返回 **1（真）**，
非 0 返回 0——是「空判定」而非「有值判定」。
★原版怪癖（照抄）：**用 `sete al` 而非常见的 `setne`**（判「空」而非判「有」，
调用方若把它当 `HasXxx()` 用会逻辑反转——这也解释了为什么它有 5 个调用点却
体积极小：调用点都在问「这个槽位空了吗」）。
★邻函数对照（同 call 内顺带读出）：`0x004F4CB0` = `push esi/edi / mov edx,ecx /
mov edi,[esp+0xc] / or ecx,-1 / xor eax,eax / repne scasb al,es:[edi] /
not ecx / sub edi,ecx / mov eax,ecx / mov esi,edi / mov edi,edx / shr ecx,2 /
rep movsd / mov ecx,eax …`——**内联 strlen + rep movsd 的字符串拷贝**
（`or ecx,-1` + `repne scasb` 求长，`not`/`sub` 修正，再 `shr ecx,2` + `rep movsd`
拷 dword、尾字节单独处理）——典型的 MSVC 内联 `strcpy` 形态。
⚠️ partial：宿主类、`this+0` 字段语义（是否为空位/句柄 0 推断）、调用点语义。
