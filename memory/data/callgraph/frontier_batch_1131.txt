★语义：**Westwood 缓冲分配器（推断名）**——thiscall 2 参
（this=ecx、param1=申请量 edx）：
  ① [this+0x84] 门控 bit0 置位 → 主缓冲路径：申请量超
     [this+0x7B4] 容量且 [this+0x790] 已用量为 0 → 虚表槽
     0x40 回调（事件码 5）扩展主缓冲 → 成功记账
     [this+0x790]+=申请量 + [this+0x794] 位图按单元数写 1；
  ② 容量不够或已用量>0 → 备缓冲路径：虚表槽 0x40 回调
     （事件码 5）→ [this+0x7B0]=申请量；
  ③ 门控 0 或主缓冲空 → 兜底路径：虚表槽 0x40 回调（事件
     码 7）→ 返回值折叠（neg/sbb/and 0xFB/dec）；
  ④ 成功返回 0xFFFFFFFF（-1），回调失败返回 0xFFFFFFFC
     （-4）。
  = 缓冲/槽位管理系统（主缓冲 + 备缓冲 + 位图记账 + 门控
  兜底）。

★调用点（探针 E8 实测 1 处 0x7BFB87）：宿主 0x7BFB60 区：
  call 0x7BD2D0（状态检查）→ cmp eax,-0xB（0xFFFFFFF5）→
  je 0x7C037E → mov edx,[ebp+0x150]/and edx,0xFFFFFFFE（清
  bit0）→ mov edx,[0xB78198]（★全局缓冲管理器引用）→ call
  0x7C2180 → cmp eax,-1 → jne 0x7C0399（失败）→ jmp
  0x7BFA37（成功续）——宿主为 Westwood 缓冲管理农场（全局
  [0xB78198] 管理对象 + [ebp+0x150] 状态位联动）。

★E8 被调者：零（虚表槽 [this+0x40] 回调 + 纯整数记账）。

★原版怪癖（照抄）：
  ① 申请量偶数化 `lea eax,[edi+1]/and al,0xFE`（odd +1 处理
     ——对齐怪癖）
  ② 成功返回值 0xFFFFFFFF（-1）而非 0——「-1=成功/-4=失败」
     逆向哨兵（调用方 cmp eax,-1 判成功）；

     三路径（主/备/兜底）——状态机式分配；
