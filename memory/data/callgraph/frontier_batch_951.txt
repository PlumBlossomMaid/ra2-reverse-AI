一、链语义（disasm 全段复核 + golden 10 用例实证）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7CA650 = MSVCRT _alloca_probe
（编译器生成 _alloca 大分配时 call 的栈探测例程）——eax 传分配的栈
字节数（无栈参数、非普通 cdecl），返回后 esp 向下移动 size 字节，
逐 4KB 页探测防栈底越界。纯内存操作，无子调用无全局引用。
  机器码（0x7CA650-0x7CA67E，47B）：
    push ecx                    ; 保存调用者 ecx
    cmp eax, 0x1000
    lea ecx, [esp+8]            ; ecx = 基点 = 进入前 esp + 4（调用者 esp）
    jb 0x7CA670                 ; size < 4KB → 直接收尾
  循环 0x7CA65C：
    sub ecx, 0x1000 / sub eax, 0x1000 / test dword [ecx], eax（逐页探测）
    cmp eax, 0x1000 / jae 0x7CA65C（剩余 ≥ 页 → 继续）
  收尾 0x7CA670：
    sub ecx, eax                ; ecx = 基点 - size（最后探测点）
    mov eax, esp                ; eax = push 后 esp（= 进入前 esp-4）
    test dword [ecx], eax       ; 最后探测
    mov esp, ecx                ; 栈顶下移 size 字节
    mov ecx, [eax]              ; 恢复调用者 ecx（[进入前esp-4]）
    mov eax, [eax+4]            ; 返回地址（[进入前esp]）
    push eax / ret              ; 压回返回地址再跳走

★原版怪癖（golden 实证，照抄）：
  ① 探测序列 = [基点-0x1000*i, i=1..k] + [基点-size]
     （k = size/0x1000 向下取整；size 恰为页倍数时循环末次探测与收尾
     探测同址、重复探测——PageBoundaryTail 用例实证）；
  ② eax 语义 = 分配的栈字节数，无栈参数；返回后 esp = 调用者 esp -
     size（mov esp,ecx → push 返回地址 → ret，净 -size）；
  ③ 探测是 test 读（页提交副作用），C++ 模型省略真实读、仅记录
     地址序列（golden 实证序列推导一致）。
