一、语义（全 0x222=546B 反汇编逐条核对 + 诊断槽值实证 + golden 闭环）
------------------------------------------------
真义（disasm.py 0x5A80B0 0x222，thiscall ecx=this ret 0）：
  · this->[0x60] = 有符号 int this60（fild dword 读）
  · A. 数组初始化两循环（与根 A 完全相同）：
       0xABE378 起 12B 步长写首 dword = [0xABC1D4]+i（101 项）
       0xABE834 起 12B 步长写首 dword = [0xABBEC0]+i（8 项）
  · B. [esp+0x30] = _ftol((double)this60 + [0x7EDB10]=0.49) * 2
       （fild dword → fadd 0.49 → fadd st0,st0（=×2）→ _ftol 0x7C5F00
       ——★与根 A 的 (this60+0.32)*3.0 不同！）
  · C. 外层循环（[esp+0x2C]<10 且 [esp+0x18]<上限）：
       内层选点（0x5A8133 起）：
         v = _ftol((double)(uint32)Random() * (double)side² * kInvUintMax)
         ——★PickBelowMul(side²) 形态：先 fild qword [esp+0x44]（无符号
         高 32 显式 0）→ fmul [esp+0x24]（side² double）→ fmul
         [0x7ED898]（kInvUintMax）→ _ftol；拒绝条件 ja 无符号
         v > side²-1。★与根 A 的 PickRange(0, side²-1) 不同！
       work[v].xy==(0,0) 判空重抽（0x42D470 构造 (0,0) + 0x50E470 判等）
       → 成功点计数 [esp+0x14]++（上限 20）→ ebp>200 强制 (0,0) →
       GetCellAt(0x5657A0)→0x486380 谓词失败 → 重选（ebp 保留）→
       [esp+0x14]<20 时：
         work[y*side+x].+0x45 != 0 → jne 0x5A8139 重选（ebp 清零）
         == 0 → 菱形校验 0x5A7250(x-4, y-4, w=8, h=8, flagA=dl=0,
         flagB=栈参 0) → 失败重选（ebp 清零）
         → 通过 → 0x578460 IsWithinUsableArea(&coord, push 1)
         （thiscall ecx=0x87F7E8 + 2 栈参 ret 8）→ 失败重选
  · D. 成功点==20 → 跳过三连调；否则**无条件三连调**（★无概率判定！
       ——根 A 有 Random 概率门 1.0-this60 vs r·kInv 分叉三连调/magic，
       根 B 没有，选点成功直接三连调）：
       al = 0x5A89D0(&coord)（al!=0 继续）→ 0x5A82E0 → 0x5A8720 →
       inc [esp+0x18]（内层完成数）→ 0x5A82B8 inc [esp+0x2C]（外层计数）

★与根 A 的差异清单（本批核心取证）：
  ① 数组初始化相同（101 项 + 8 项 12B 步长）；
  ② 内层上限换算不同：(this60+0.49)*2（根 A：(this60+0.32)*3.0）；
  ③ 取数惯用法不同：PickBelowMul(side²)（根 A：PickRange(0, side²-1)）；
  ④ ★无概率判定：选点成功直接三连调（根 A 有 Random 概率门 +
     magic 五连调/虚函数调用/push-1 槽错位）；
  ⑤ 邻域检查不同：+0x45 != 0 → 直接重选（根 A 走 ±7 邻域扫描
     0x4863D0）；== 0 → 菱形校验 0x5A7250 + 0x578460 可用区
     （根 A 无菱形/可用区）；
  ⑥ 三连调后 inc [esp+0x18] 是**直接指令**（0x5A82B4），无 push-1
     槽错位（根 A 的怪癖来自虚函数调用段）。

★随机消耗非定值：PickBelowMul 每次 1 Random + 空格/谓词失败重抽
  （golden next 对拍消耗次数与路径；NormalDeviate 不参与——根 B 无 ND）。

三、★本批实锤（两条，均为调试关键）
----------------------------------

   Oracle（3 种子 × 4 用例连续跑）时旧翻译块假执行，调用序列被多记

四、原版怪癖（照抄）
--------------------

② 内层上限 = _ftol((this60+0.49)*2)——fadd 0.49 先于 fadd st0,st0（×2）

   8,8,0,0) + 0x578460 IsWithinUsableArea(&coord,1)（thiscall + 2
   栈参 ret 8）；
⑧ ★push ebx 位移拼 rect 结构（与根 A push-1 槽错位同族）；
⑨ ★无概率判定：选点成功直接三连调（根 A 有 Random 概率门）——
   0x5A89D0 返回 al==0 时跳过后续两调但仍 inc 外层计数；
⑩ 外层循环退出双条件：内层完成数 >= 上限 或 外层计数 >= 10。
