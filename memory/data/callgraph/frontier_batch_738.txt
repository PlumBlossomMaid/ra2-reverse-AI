=== 语义 ===

**宽字符串类 operator+=（裸指针版，推断名）**——thiscall 1 栈参
ret 4（栈参 1=源 wchar_t* 裸指针，ecx=this）：① 源 NULL → 直接
返回 this（无兜底——调用方保证非空或静默忽略）；② 总长 =
wcslen(源) + 1 + wcslen(旧串)（旧串非空才加）；③ new 总长×4 →
this->[0] = 新缓冲；④ wcscpy 旧串（空则写宽 NUL）→ wcscat 追加
源串；⑤ delete 旧缓冲 → 返回 this。
★语义统一：与 batch 735 的 0x7B6B60（对象指针版 [eax] 解引用）
同操作两入口——0x7B6AE0 传裸 wchar_t*（调用方已有指针直接传）、
0x7B6B60 传 WStringClass*（从 [eax] 取内部指针）。与 batch
097/125 宽串 operator= 家族「0x7B66C0 拷裸指针 vs 0x7B6720 拷自
身型」的两版成对形态一致——宽串族的每个操作都有裸指针/对象指针
双入口惯例。
