0x633BC0  网络抽象解包→坐标（16 callers，0x95 全读完）
================================================================================
机器码还原（全 0x95）：
    mov al, [edx]                   ; ★ 参数首字节（类型码）
    cmp al, 4 / jne 失败路径        ; 类型 == 4 才继续
    mov al, [edx+0x12] / test / je 0x633BE7
    lea ecx, [edx+0xE]              ; ★ 子结构指针
    call 0x6E6E20                   ; ★ NetworkEvents::Abstract UNPACK
                                    ;   （YRpp NetworkEvents.h:98 实锤）
    test eax / je 失败
    mov edx, [eax] / lea ecx, [esp+4]
    push ecx / mov ecx, eax
    call [edx+0x58]                 ; ★ 虚表槽 0x58（取坐标）
    ; 输出 3 dword 到 [esi]（+0/+4/+8 = 坐标对）：
    mov ecx, [eax] / mov edx, esi / mov [edx], ecx
    mov ecx, [eax+4] / mov [edx+4], ecx / mov eax, [eax+8]
    mov [edx+8], eax / ret
  失败路径:
    mov [esi], -1 / [esi+4], -1 / [esi+8], -1 / ret

YRpp UNPACK 宏实锤）解出对象，再经其虚表槽 0x58 取坐标写入输出；失败填
(-1,-1,-1)。紧邻 0x633C60 是包装层：调 0x633BC0 → 0x6D2140（CoordsToClient，
batch 084 实锤）→ +[0x886FA0]/[0x886FA4] 偏移合成客户端坐标。

★跨批次连接：NetworkEvents::Abstract（网络事件解包）+ 虚表槽 0x58 +
CoordsToClient（batch 084）+ 0x886FA0 全局——网络层 → 世界坐标 → 客户端
坐标的全链，batch 105/126 的全局状态区（0x886xxx）再添消费者。
