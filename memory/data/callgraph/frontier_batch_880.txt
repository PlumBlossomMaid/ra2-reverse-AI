一、函数体全读（103B，disasm 0x55BB90 0x80 全量）
------------------------------------------------
参数契约（thiscall 3 栈参 ret 0xC）：ecx=src（源数据）、edx=长度、
[esp+4]=A1（源数据/目标缓冲）、[esp+8]=A2（&输出长度）、[esp+0xC]=
A3（新缓冲/容量/额外参）。
机器码（103B 全读，逐段要点）：
  0055bb90  xor eax,eax → push ebp → mov ebp,[esp+8]（★A1）→ push
    esi → test edx,edx → ja 0x55bba4（★★长度==0 → 直走尾段）
  0055bb9c  mov esi,[esp+0x10]（★A2=&输出长度）→ mov [esi],eax（★
    写 0）→ jmp 0x55bbdf
  0055bba4  cmp edx,0xd → ja 0x55bbcb（★★长度>13 → 委托长路径）
  0055bba9  push ebx → mov bl,dl → add bl,0x11（★★★控制字节 = 长度
    +0x11——与 batch 879 解码器首字节 `cmp dl,0x11 / jbe → and edx,
    0xff / sub edx,0x11` 逐字节共轭：编码写 0x11+len、解码读 >0x11
    为字面量长度！）→ push edi → mov byte[ebp],bl（★写控制字节到输
    出）→ lea edi,[ebp+1]
  0055bbb6  mov bl,[ecx] → mov byte[edi],bl → inc edi → inc ecx →
    dec edx → jne 0x55bbb6（★★字面量循环拷贝 len 字节——ecx=源）
  0055bbbf  mov esi,[esp+0x18]（★A2=&输出长度）→ sub edi,ebp（★写
    入量）→ mov [esi],edi（★输出长度写回）→ pop edi/ebx → jmp
    0x55bbdf
  0055bbcb  mov eax,[esp+0x14]（★A3）→ mov esi,[esp+0x10]（★A2）→
    push eax → push esi → push ebp → call 0x55bc00（★★长路径委托
    ——未登记）→ test eax,eax → jne 0x55bbf2（★成功 → 跳过尾段）
  0055bbdf  mov ecx,[esi]（★输出缓冲指针）→ mov byte[ecx+ebp],0x11

    byte[ecx],0 → mov byte[ecx+1],0（★★00 00 补零）→ add
    dword[esi],3（★★输出推进 3）
  0055bbf2  pop esi → pop ebp → ret 0xC
语义：**压缩字面量游程编码器（推断名）**——thiscall 3 栈参 ret 0xC：
  把 ecx 所指源数据（edx=长度）编码为压缩块：① 长度==0 → 输出长度
  写 0、尾部补终止符；② 长度<=13 → 写 `0x11+len` 控制字节 + 逐字节
  拷贝字面量；③ 长度>13 → 委托 0x55BC00 长路径（三参：A1/A2/A3）；
  ④ 收尾统一补 `0x11 00 00` 终止符并推进输出 3。★★与 batch 879
  0x55C0E0（缓冲打包/转换内核——解码端）构成 encode/decode 双向配
  对：0x11 阈值共轭（编码 0x11+len / 解码 >0x11）、终止符一致
  （0x11 00 00 ↔ 解码器 0x11 分档入口）。
