一、链语义（disasm 全 0x7DF3C2-0x7DF4FB，batch 1119/1120 对照）
--------------------------------------------------------------
签名（推断）：cdecl 7 参（同族布局：源字节指针/目标字指针/
行步进族/0x100 常数族[宿主 push]），MMX 像素混合写回目标
word，无返回值。

主体（0x7DF3C2-0x7DF4FB）：
007df3c2  push ebp/mov ebp,esp/add esp,-0x24/push ebx,ecx,edx,esi,edi
007df3cd  xor eax,eax/mov [ebp-0x14],eax        ; ★局部清零
007df3d2  mov eax,[ebp+0x1C]/mov [ebp-8],eax    ; ★外层行计数
007df3d8-3ed mov [ebp-0x1C]/[ebp-0x18]/[ebp-0x24]/[ebp-0x20],0
007df3f4  mov esi,[ebp+8]/mov [ebp-0xC],esi     ; ★字节源指针
007df3fa  mov edi,[ebp+0xC]/mov [ebp-0x10],edi  ; ★字目标指针
007df400  mov edx,[ebp+0x20]                     ; ★查表基址
007df403  mov eax,[ebp+0x18]/mov [ebp-4],eax    ; ★内层列计数
007df409  xor eax,eax/xor ebx,ebx/jmp 0x7DF480
; ★★布局：列推进段中置（0x7DF440，280 尾部/640 头部变体）
007df440  inc esi/lea edi,[edi+2]/dec [ebp-4]/jne 0x7DF480
007df449  行推进：mov esi,[ebp-0xC]/add esi,[ebp+0x10]/mov [ebp-0xC],esi
007df452  mov edi,[ebp-0x10]/add edi,[ebp+0x14]/mov [ebp-0x10],edi

007df480  mov al,[esi]/test al,al/je 0x7DF440    ; ★源字节 0 → 跳过
007df486  mov byte[ebp-0x1C],al                  ; ★α = 源字节
007df489  mov bx,word[edi]/mov byte[ebp-0x1A],al/mov byte[ebp-0x18],al
007df492  punpcklbw mm0,dword[edx+ebx*4]         ; ★★查表

007df4bf  mov cl,[ebp-0x20]/shl ecx,0xA

007df4f7  emms                                    ; ★★族差异#3：有 emms

007df4f9  pop edi/esi/edx/ecx/ebx/leave/ret      ; （函数边界 0x7DF4FB）

★语义：**Westwood MMX 像素合成函数（四兄弟族第三件，推断
名）**——与 batch 1119/1120 逐语义同构：
  ① 双指针双循环（内层逐列字节源 +1/字目标 +2，外层行步
     进 +[ebp+0x10]/+[ebp+0x14]）；
  ② 每像素：源字节（0 → 跳过）作 α → 目标 word 作表索引
     → [edx+ebx*4] 32 位调色板查表 → MMX punpcklbw/psrlw 8/
     pmullw ×α/psrlw 8/paddusb 饱和 → ★本件 psrlw 3（前两
     件 psrlw 2——衰减更重）；
  ③ RGB565 打包写回目标 word（本件掩码 0x7C00——比 280 的
     0xF800 少 g 高 1 位，打包通道宽度族间不同）；
  ④ 本件有 emms 收尾（0x7DF4F7）。

★调用点（探针 E8 实测 1 处 0x5FFA15）：宿主 0x5FFA 区调度
  （batch 1119 已证）：0x5FFA15 正是宿主第一调用点
  （cmp [0xAC1838],edx → 0x7FFA5E 附近分派链上第一项，
  7 参变体）。

★E8 被调者：零（纯 MMX + 查表内联）。

★族间差异登记（三件对照，本批新增）：
  ┌──────────┬──────────┬──────────┬──────────┐
  │ 差异点   │ 0x7DF280 │ 0x7DF640 │ 0x7DF3C2 │
  │          │(1119)    │(1120)    │(本批)    │
  ├──────────┼──────────┼──────────┼──────────┤

  → 核心 MMX 链（punpcklbw/pmullw/paddusb/查表）三件一致；
  差异集中在衰减移位/打包掩码/emms/代码布局——复制粘贴
  手改痕迹实锤，重写时逐件照抄。

★原版怪癖（照抄）：
  ① 族件间衰减不一致（psrlw 2 vs 3）——混合强度逐件不同；
  ② 族件间打包掩码三套（0xF800/0x423a0a60/0x7C00）——RGB
     通道位宽逐件不同；
  ③ 族件间 emms 有无不一（280 无）——MMX 状态清理靠调用
     方惯例，族内不统一；
  ④ 列推进段位置三件三样（尾部/头部/中置）——编译器布局
     随机性；
  ⑤ 族通用：目标 word 无符号 16 位作 64KB 表窗口索引；源
     字节 0 跳过透明像素；α 合成公式查表色×α+原色饱和→衰
     减。

三、三态判定（为何 semantics_verified 而非 crt_runtime_verified）
---------------------------------------------------------------
1. 归属：0x7DF3C2 = **Westwood 自有代码**——①MMX 像素合成
   （punpcklbw/pmullw/paddusb）非 MSVC6 CRT 形态；②32 位调
   色板查表 + RGB565 位拼为渲染管线特征；③宿主 0x5FFA 区渲
   染调度（cmp [0xAC1838] 分派 7/6 参形态）；④与 batch 1119/
   1120 四兄弟族同模板（差异=衰减/掩码/emms/布局——族间对
   照表实锤）。
2. 依赖：无子调用，纯 MMX + 表——重写时按像素合成语义等
   价实现（逐件照抄差异）。
3. 复刻纪律：Westwood 自有代码——不按商业库归档；像素合
   成非 RMG 管线依赖，保留 semantics_verified。
→ 状态：semantics_verified（MMX 链 + 族间差异对照 + 宿主调
度交叉；函数名「MMX 像素合成函数（四兄弟族第三件）」为推
断交叉标注——混合链/查表/打包由代码实测）。
