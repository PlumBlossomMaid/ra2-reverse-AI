0x49FA70 —— 数组递减弹出器（100B 全程读完）
================================================================================
签名：thiscall（ecx=this）+ 1 栈参（[esp+8]=索引）ret 4（递减后值）。
机器码骨架（0x49FA70-0x49FAD3）：

    mov edi, [esi+8]               ; ★当前长度

    mov eax, [esi]; lea ecx, [ebx+0xA]
    push 0; push ecx; mov ecx, esi
    call dword ptr [eax+8]         ; ★虚表槽 8（Grow 扩展至 idx+0xA）
    test al, al; je 0x49facc        ; ★扩展失败 → 返 0
    ...新扩展区清零循环（[esi+4][i]=0 for i in 旧长度..新长度）
    0x49faad:
    mov eax, [esi+4]
    mov ecx, [eax+ebx*4]; dec ecx; mov [eax+ebx*4], ecx  ; ★array[idx] -= 1
    mov eax, [esi+0x10]; dec eax; mov [esi+0x10], eax    ; ★计数 +0x10 -= 1
    ...返回 array[idx]（递减后）
    0x49facc: xor eax, eax; ret 4   ; 失败返 0

语义：**数组递减弹出器**——给定索引：越界则经虚表槽 8（Grow）扩展至
idx+0xA 并清零新扩展区；随后 array[idx] 递减 1、计数（+0x10）递减 1、
返回递减后值。★引用计数递减/占用标记清除形态。后邻 0x49FAE0 为同构
第二副本（同族候选未登记）。2 unique caller（8 callsite）。

★怪癖：①★越界自动 Grow（虚表槽 8 扩展到 idx+0xA——按需扩容）；
②★新扩展区清零循环；③★array[idx]-1 与计数-1 成对；④★失败返 0
（Grow 失败静默）；⑤★返回递减后值（读回 array[idx]）。

⚠️ partial：数组族语义（引用计数/占用标记）、虚表槽 8 的 Grow 宿主、
