一、链语义（disasm 全 148B + 宿主反汇编 + 全局引用分布，
0x7C61CF-0x7C6262）
--------------------------------------------------------------
签名（推断）：单参 cdecl（[ebp+8]=大结构体指针，进入即
`mov ebp,[ebp+8]` 重定向帧基），结构体字段族：
  [ebp+0x00]/[ebp+0x04] = 内/外层循环次数（byte）
  [ebp+0x10] = 偏移量（计数表增量基）
  [ebp+0x14]/[ebp+0x18]/[ebp+0x1C]/[ebp+0x20] = 行步进量
  [ebp+0x40] = 长度表（word，逐列 +2）
  [ebp+0x44] = 索引表（word，逐列 +2）
  [ebp+0x48] = 数据表（word，逐列 +2）
  [ebp+0x4C] = 源字节流指针（逐字节扫描）
  [ebp+0x50] = 计数表（byte，逐列 +1）
  [ebp+0x58]/[ebp+0x90] = 两级映射表（word 数组）

主体（0x7C61CF-0x7C6262）：
007c61cf  push ebp/mov ebp,esp/push ebp
007c61d3  mov ebp,[ebp+8]                    ; ★★帧基重定向到大结构体
007c61d6  xor ch,ch                          ; 外层计数 ch=0
007c61d8  mov esi,[ebp+0x4C]                 ; esi = 源字节流指针
007c61db  xor cl,cl                          ; 内层计数 cl=0
; → 内层循环顶（0x7C61DD）：
007c61dd  movzx eax,byte[esi]                ; al = 当前源字节
007c61e0  inc esi
007c61e1  test al,al/je 0x7c621e             ; ★0 字节跳过（不处理）
007c61e5  xor ebx,ebx
007c61e7  mov edi,[ebp+0x50]/mov edx,[ebp+0x40]
007c61ed  mov bl,byte[edi]                   ; bl = 计数表当前值
007c61ef  add ebx,[ebp+0x10]                 ; bx += 偏移量
007c61f2  and eax,0xff
007c61f7  cmp bx,word[edx]/jae 0x7c621e      ; ★★与长度表比较，超限跳过
007c61fc  mov word[edx],bx                   ; 写入长度表
007c61ff  mov ebx,[ebp+0x44]/mov edi,[ebp+0x48]
007c6205  movzx edx,word[ebx]                ; 索引表当前值
007c6208  mov ebx,[ebp+0x90]
007c620e  mov dx,word[ebx+edx*2]             ; ★经映射表1（[ebp+0x90]）
007c6212  mov dl,al                          ; ★低字节替换为源字节
007c6214  mov eax,[ebp+0x58]
007c6217  mov ax,word[eax+edx*2]             ; ★经映射表2（[ebp+0x58]）
007c621b  mov word[edi],ax                   ; 写入数据表
; → 内层尾（0x7C621E）：
007c621e  inc cl
007c6220  inc [ebp+0x50]/add [ebp+0x48],2/add [ebp+0x40],2/add [ebp+0x44],2
007c622f  cmp cl,byte[ebp]/jl 0x7c61dd       ; 内层列循环
; → 行尾步进（0x7C6234）：
007c6234  mov eax,[ebp+0x1C]/add [ebp+0x48],eax
007c623a  mov eax,[ebp+0x14]/add [ebp+0x40],eax/add [ebp+0x40],eax  ; ×2！
007c6243  mov eax,[ebp+0x18]/add [ebp+0x44],eax/add [ebp+0x44],eax  ; ×2！
007c624c  mov eax,[ebp+0x20]/add esi,[ebp+0x20]/add [ebp+0x50],eax
007c6255  inc ch/cmp ch,byte[ebp+4]/jl 0x7c61db  ; 外层行循环
007c6260  pop ebp/leave/ret

★语义：**Westwood 表面字符映射表构建器（推断名）**——双
层循环（行×列）遍历源字节流：
  ① 0 字节跳过；非零字节按计数表值+偏移量与长度表比较，
     超限跳过（边界保护）；
  ② 未超限 → 写长度表，索引表值经映射表1（[ebp+0x90]）查
     表、低字节替换为源字节、再经映射表2（[ebp+0x58]）查
     表 → 写入数据表；
  ③ 行尾按 [ebp+0x1C]/[ebp+0x14]×2/[ebp+0x18]×2/[ebp+0x20]
     步进各表指针。
  = 图形/表面子系统的字符→字形映射表构建（如字体位图、
  调色板索引映射）。

★调用点（探针 E8 实测 1 处 0x549506）：宿主 0x549xxx 主
  代码区（非 0x7C-0x7D CRT 区）——0x549480-0x549505 反
  汇编：操作 [0xAA10B8]/[0xAA10C4]/[0xAA10C8]/[0xAA10CC]/
  [0xAA10F8] 大全局结构 + `cmp byte[0xABC55C],0 / je` 门控
  + `push 0xAA10B8; call 0x7C61CF` 传入结构体指针——典型
  Westwood 渲染宿主域。

★全局引用分布（探针 PE 实锤）：
  [0xABC55C]：2 处（0x5488F5/0x5494FA）——门控标志
  [0xAA10B8]：42 处（0x5481E0-0x548F7D 区）——大结构体
  [0xAA10F8]：30 处（0x547FCA-0x54922C 区）——大结构体
  → 全部落在主代码区 0x547F-0x5492（西屋渲染宿主域），
  无一落在 0x7C-0x7D CRT 区——**非 CRT 全局，Westwood 自
  有数据结构**。

★E8 被调者：无（零子调用——纯结构体字段操作 + 无 CRT
  调用）。

★原版怪癖（照抄）：
  ① 行尾步进 [ebp+0x14]/[ebp+0x18] 各加两次（×2）而
     [ebp+0x1C]/[ebp+0x20] 只加一次——步进量语义不对称，
     结构体字段设计如此；
  ② 0 字节跳过不处理（源字节流以 0 作占位/终止语义）；
  ③ 映射表1查完用 `mov dl,al` 覆盖低字节再查映射表2——
     两级映射中间夹源字节的低字节替换（混合查表惯用）；
  ④ 计数表/长度表比较用 `cmp bx,word[edx]` + `jae` 无符
     号比较（16 位截断——长度表 word 上限 65535）；
  ⑤ 帧基重定向（`mov ebp,[ebp+8]` 后直接按字段族访问）
     ——无栈上局部变量，全结构体驱动。

三、三态判定（为何 semantics_verified 而非 crt_runtime_verified）
----------------------------------------------------------------
1. 归属：0x7C61CF = **Westwood 自有代码混入 0x7C 区样本
   （0x7C 区混入样本链 #15）**，非 MSVC6 静态 CRT——
   反汇编证据：
   a) 唯一调用者 0x549506 在主代码区（0x54xxxx 西屋渲染
      宿主域，操作 [0xAA10B8] 等大全局）——CRT 函数从不
      被 Westwood 渲染子系统这样调用；
   b) 零子调用 + 纯结构体字段驱动（[ebp+0x00]-[ebp+0x90]
      字段族）——MSVC6 CRT 无此类形态；
   c) 全局引用 [0xABC55C]/[0xAA10B8]/[0xAA10F8] 全部落在
      主代码区 0x547F-0x5492，无一在 0x7C-0x7D——非 CRT
      全局，西屋自有数据结构。
2. 方法论文档依据：batch 1116 修正后 0x7E1xxx 槽静态值不
   作语义证据；本批判定不依赖槽表，靠反汇编主体 + 调用
   者归属 + 全局分布三重实锤。
3. gamemd_replication_discipline：Westwood 自有代码混入
   CRT 区——重写 gamemd 时按宿主域语义（渲染字符映射表
   构建）复刻，但 0x7C 区整体按 CRT 层归档，本函数属混
   入样本需标注归属。
→ 状态：semantics_verified（全 148B 反汇编 + 宿主调用点
+ 全局分布实锤；函数名「表面字符映射表构建器」由结构体
字段族 + 双层循环 + 两级映射表语义交叉标注）。
