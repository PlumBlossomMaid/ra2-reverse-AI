一、链语义（完整汇编逐段核对 + 黄金 12 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码逐段确认）：
  · 0x7DC720（14B，ret 4——单栈参，wrapper）：
      push 0                ; ctor arg2（b）= 0
      push [esp+8]          ; = 调用方 [esp+4]（arg）
      call 0x7DCD9C         ; Throw(arg, 0)
      ret 4
    ≡ invalid_parameter_forward(arg) = crt_throw_exception(arg, 0)。
  · 0x7DCD9C（36B，noreturn——无 ret，尾部即 __CxxThrowException）：
      push ebp/mov ebp,esp/sub esp,0x10
      push 0                ; ctor arg2 = 0
      lea ecx,[ebp-0x10]    ; ctor this = 栈上临时异常对象
      push [ebp+0xc]        ; ctor arg1 = b
      push [ebp+8]          ; ctor arg0 = a
      call 0x7DCDC0         ; 构造异常对象
      lea eax,[ebp-0x10]
      push 0x80F0D0         ; ThrowInfo（RTTI）
      push eax
      call 0x7D2F64         ; __CxxThrowException（noreturn）
  · 0x7DCDC0（48B，ret 0xc——__thiscall + 2 栈参，异常对象构造器）：
      [this+0xC] = 0        ; 先清零（golden 恒 0）
      [this+4] = a
      [this]   = 0x7FA498   ; vtable（最后写）
      [this+8] = b
      b == 0 → 跳过引用计数
      cmp byte [esp+0x10],0 ; c 低字节
      c == 0 → 跳过
      ecx = [b]（b 的 vtable）；push b；call [ecx+4]（vtable[1] 引用计数）
      eax = this；ret 0xc
  输出对象布局：{vtable=0x7FA498, +4=a, +8=b, +0xC=0}。

★原版怪癖（golden 实证，C++ 侧逐条复刻）：
  ① 先写 +0xC=0 再写其余字段——+0xC 恒 0；
  ② 0x7DCD9C 无 ret（noreturn）——构造完直接进 __CxxThrowException；
  ③ wrapper 单栈参 ret 4，第二字段写死 0（b=0 → 引用计数永不触发）；
  ④ ctor 的引用计数分支由 b 非 0 **且** c 低字节非 0 共同门控（先 test b
     再 cmp byte c），命中时调 b->vtbl[1](b)（golden CTOR 14 fake 1 →
     rel=1 实证该虚调用路径真被走到）。

三、C++ 模型（code/rewrite/runtime/crt_error.{h,cpp}）
------------------------------------------------
namespace ra2::runtime。CrtExceptionObject{vtable,field4,field8,field_c}
四字段；CrtThrowWorld 抽象对外两件事：CxxThrow(obj, throw_info)（对应
0x7D2F64）与 ReleaseRef(b)（对应 b->vtbl[1] 虚调用）——C++ 侧不模拟
真正抛异常，回调计数即对拍点。三函数：
  crt_exception_ctor(world, a, b, c)    —— 0x7DCDC0：按原版字段顺序构造
    {+0xC=0, +4=a, +8=b, +0=vtable}，b!=0 && (c&0xFF)!=0 → world.ReleaseRef(b)
  crt_throw_exception(world, a, b)      —— 0x7DCD9C：ctor(a,b,0) +
    world.CxxThrow(obj, kCrtExceptionThrowInfo)；noreturn 语义由调用方
    保证（C++ 侧函数自然返回，对拍点为 CxxThrow 回调）
  invalid_parameter_forward(world, arg) —— 0x7DC720：throw_exception(arg, 0)
常量 kCrtExceptionVtable=0x7FA498、kCrtExceptionThrowInfo=0x80F0D0。
无失败路径（返回 void）。
