0x6D8B30 —— 坐标换算初始化器（289B 全程读完）
================================================================================
签名：thiscall（ecx=this）无栈参 ret 空。
机器码骨架（0x6D8B30-0x6D8C50）：
    ecx = [esi+0xD64]; edi = [esi+0xD68]     ; ★读两源字段
    [esi+0xB0] = ecx; [esi+0xB4] = edi        ; 先原样写目标
    eax = [0xB0CE30]; cdq; sub eax,edx; sar eax,1   ; ★[0xB0CE30]/2
    [esi+0xB0] = ecx - eax                    ; +0xB0 = 源1 - 全局1/2
    eax = [0xB0CE34]; cdq; sub eax,edx; sar eax,1   ; ★[0xB0CE34]/2
    [esi+0xB4] = edi - eax                    ; +0xB4 = 源2 - 全局2/2
    lea edx, [esi+0xDE4]; add eax, -0x1E      ; +0xB4-0x1E
    fild/fstp 浮点化（[esp+0xC]/[esp+0x14] 两个 int → float）
    call 0x5AFB80                             ; ★浮点变换（未登记）
    两次 fild → call 0x7C5F00（_ftol）        ; float → int 截断
    cdq; and edx,0xFF; add eax,edx; sar eax,8 ; ★有符号 >>8 量化
    [esi+0xD80] = eax; [esi+0xD84] = ecx      ; 写量化结果
    eax = 0x88888889; imul [0xB0CE30]         ; ★magic 除法
    sar edx,5; shr ecx,0x1F; lea edx,[edx+ecx+2]
    [esi+0xD88] = edx                         ; ★[0xB0CE30]÷10+2
    imul [0xB0CE34]; sar edx,3; shr eax,0x1F
    lea ecx,[edx+eax+4]; [esi+0xD8C] = ecx    ; ★[0xB0CE34]÷5+4（推断）

语义：**坐标换算初始化器**——从 +0xD64/+0xD68 读源坐标对，换算写
+0xB0/+0xB4（各减对应全局的一半）、+0xD80/+0xD84（经 0x5AFB80 浮点
变换 + _ftol 截断 + >>8 量化）、+0xD88/+0xD8C（★magic 0x88888889
imul 序列——[0xB0CE30] 商右移 5 = ÷10、[0xB0CE34] 商右移 3 = ÷5 的
除法替代，含符号修正 + 常量补偿 +2/+4）。3 unique caller（32 callsite）。

★怪癖：①★magic 0x88888889 imul 除法（÷10/÷5——sar+shr 符号修正
+ 补偿常量 +2/+4）；②★同一字段对先原样写再减半覆盖（+0xB0 两次写）；
③★有符号 >>8 量化（cdq/and 0xFF + sar——负值向下取整）；④★0x5AFB80
浮点变换夹在 fild/fstp 之间（int→float→transform→int 链）；⑤★源
字段（+0xD64/+0xD68）与目标（+0xB0/+0xB4、+0xD80/+0xD84、+0xD88/
+0xD8C）六字段族布局。

⚠️ partial：宿主类（0x6D8B3x 区——0x6Dxxxx 相机/坐标域，batch 记忆
0x6D2120 同区换算 getter）、0x5AFB80（未登记变换）、[0xB0CE30]/
[0xB0CE34] 全局（地图尺寸/半宽推断）、+0xDxx 六字段精确语义、
3 unique caller 身份。

0x4F4D80 —— 自跳转死循环陷阱（2B 全程读完）
================================================================================
签名：无参 ret 永不（★调用即挂起）。
机器码（全文 2 字节）：
    0x4F4D80: jmp 0x4F4D80        ; ★eb fe 自跳转——无限循环

语义：**自跳转死循环陷阱**——`jmp` 跳回自身，永不返回。★调用该地址
即无限挂起（原版保留的"永不返回"占位/禁用标记——MSVC6 对无返回路径
的 UB 形态产物）。后邻 0x4F4D90 为配套包装器（call 0x4F4D80 → neg al
→ sbb eax,eax → inc eax → ret——★同样是死循环，包装逻辑不可达）。
3 unique caller（30 callsite——★引用点多为数据/虚表项，实际执行即挂）。

★怪癖：①★2B 自跳转（eb fe 相对跳 -2——编译器生成的死循环陷阱）；
②★后邻包装器同样不可达（neg/sbb/inc 序列被死循环屏蔽）；③★callsite
30 与"游戏正常跑"矛盾——★必是未被实际调用的引用（占位/禁用路径）；
④★复刻时照抄 2B（不"修复"为 ret——原版怪癖）。

⚠️ partial：陷阱用途（未实现函数占位/禁用开关）、30 引用点身份、
后邻 0x4F4D90 包装器（同陷阱族）、宿主（0x4F4Dxx 区——0x4Fxxxx
HouseClass 域邻近）。

0x4B9BD0 —— 三字节清零器（13B 全程读完）
================================================================================
签名：thiscall（ecx=目标指针）无栈参 ret 空。
机器码（全文 13 字节）：
    mov eax, ecx; xor cl, cl
    mov byte [eax], cl        ; ★目标[0] = 0
    mov byte [eax+1], cl      ; 目标[1] = 0
    mov byte [eax+2], cl      ; 目标[2] = 0
    ret

语义：**三字节清零器**——把目标指针起始 3 字节清零（★3 字节结构头部
重置）。3 unique caller（30 callsite）。后邻 0x4B9BE0 为持有释放器
（+4 非空 && +0xD owns → 0x7C8B3D delete + 清 +0x10——VectorClass
家族第三副本变体，同族候选未登记）。

★怪癖：①★固定 3 字节（非 4 非变长——3B 紧凑结构头部）；②★xor cl
复用清零寄存器（无 movzx/立即数）；③★后邻 0x4B9BE0 持有释放器
（与 batch 1285/1287 同模板第四变体——+0x10 替代 +8 收尾）。

⚠️ partial：3 字节结构语义（ID/标志族）、宿主类（0x4B9Bxx 区）、
后邻 0x4B9BE0（同族候选）、3 unique caller 身份。
