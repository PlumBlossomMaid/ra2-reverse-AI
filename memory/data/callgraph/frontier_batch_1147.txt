一、链语义（disasm 全 139B + 双调用现场 + 字段族跨批交叉，
0x7C06B0-0x7C073A）
--------------------------------------------------------------
签名（推断）：thiscall + edx 隐式查找键 + 2 栈参 ret 8——
ecx=this、edx=key、[esp+0x18]=参1（输出 word）、[esp+0x1C]=
参2（输出 word）。字段族：this+0x758 = 16 位项数、
this+0x760 = word 表指针、this+0x10 = 末档默认值。

主体（0x7C06B0-0x7C073A）：
007c06b0  push ecx/push ebx                    ; ecx 占位存 ebx 原值
007c06b2  mov ebx,[ecx+0x760]                  ; ★★word 表指针
007c06b8  push ebp/push esi/xor esi,esi/push edi
007c06bd  mov si,word[ecx+0x758]               ; ★★16 位项数
007c06c4  mov edi,1/xor eax,eax
007c06cb  cmp esi,edi/mov [esp+0x10],ebx/jle 0x7c06f6
                                          ; ★项数<=1 → 直出 esi-1
; → 区间扫描顶（0x7C06D6）：
007c06d6  xor ebp,ebp/mov bp,word[ebx-2]        ; 前一项
007c06dc  cmp edx,ebp/jl 0x7c06e9               ; ★key < 前项 →
                                          ;   本区间不匹配，前进
007c06e0  xor ebp,ebp/mov bp,word[ebx]          ; 后一项
007c06e5  cmp edx,ebp/jl 0x7c06fb               ; ★★key < 后项 →
                                          ;   命中区间，eax=索引
007c06e9  inc eax/inc edi/add ebx,2
007c06ee  cmp edi,esi/jl 0x7c06d6               ; 循环
007c06f2  mov ebx,[esp+0x10]                    ; 恢复 ebx
007c06f6  lea eax,[esi-1]                       ; ★未命中 → 末索引
; → 输出段（0x7C06FF）：
007c06ff  mov edx,[esp+0x18]/test edx,edx/je 0x7c070f
007c0707  xor edi,edi/mov di,word[ebx+eax*2]/mov [edx],edi
                                          ; ★参1 ← 表[eax]（命中区间
                                          ;   上界 / 末项）
007c070f  mov edx,[esp+0x1c]/test edx,edx/je 0x7c0733
007c0717  dec esi/cmp eax,esi/jge 0x7c072e      ; eax < 项数-1 ?
007c071c  xor ecx,ecx/pop edi
007c071f  mov cx,word[ebx+eax*2+2]/pop esi/dec ecx
007c0727  mov [edx],ecx/pop ebp/pop ebx/pop ecx/ret 8
                                          ; ★参2 ← 表[eax+1]-1
                                          ;   （下一档起点-1）
007c072e  mov ecx,[ecx+0x10]/mov [edx],ecx      ; ★★参2 ← [this+0x10]
                                          ;   （末档默认值）
007c0733  pop edi/esi/ebp/ebx/ecx/ret 8

★语义：**Westwood 表面调色板 word 表区间查找器（推断名）**
——在 this+0x760 的 16 位有序 word 表中按 key（edx）定位
所在区间索引 eax，使 `表[eax-1] <= key < 表[eax]`；输出：
  ① 参1 ← 表[eax]（命中区间上界，未命中为末项）；
  ② 参2 ← 表[eax+1]-1（下一档起点-1）——eax 已到末项时改
     用 [this+0x10] 默认值；
  ③ 两项输出均先 test 指针，为 NULL 则跳过（可空输出）。
  = 连续值 → 分档索引的区间映射（调色板梯度/索引带）。

★调用点（探针 E8 实测 2 处，均在 0x7C0530 体内）：0x7C0578
  （两段中第一段，key 沿用宿主 edx）与 0x7C0595（第二段，
  `mov edx,[esi+0x184]` 换 key）——两次输出到 [esp+0x10] /
  [esp+0x14] 后由宿主 `cmp edi,...` 比较两索引（相等 →
  返回 -1）。

★E8 被调者：**零子调用**（全 139B 纯 word 表扫描 + 输出，
无 call 无全局引用）。

★字段族跨批交叉（★★本批最强证据）：this+0x758（16 位项
  数）+ this+0x760（word 表指针）与 **batch 1096 调色板块
  装载器（PIN 组 0x7C1BE0）装载现场逐字段重合**：
  `lea edi,[esi+0x758]` 读 16 位项数、`mov [esi+0x760],eax`
  写入分配表指针、`shl eax,1`（×2 字节/项 = word 表）——
  本函数正是对 PIN 组装载出的 word 表做区间查找的邻近方
  法（同对象）。

★原版怪癖（照抄）：
  ① ecx 入栈占位仅用于保存 ebx 原值（`push ecx` 非
     `push ebp/mov ebp,esp`）——无栈帧指针的裸 push 布局；
  ② 双向比较用 `jl`（有符号 <）——key 与表项均按有符号
     16 位比较（word 读入 movzx 后与 edx 有符号比）；
  ③ 循环初值 edi=1、eax=0：第一次比较即 `表[-1]`（表基
     -2 字节）——依赖表前 2 字节哨兵（照抄越界读惯用）；
  ④ 项数<=1 直接返 eax=esi-1（0 或 -1）——不做任何表访
     问；
  ⑤ 末档参2 走 [this+0x10] 默认值而非表末项——表与默认
     值双来源；
  ⑥ 两个输出指针独立 test/NULL 跳过——可只取其一。
