名）**——cdecl 4 参（输出缓冲/剩余容量/格式串/参数指针）：

三、三态判定（为何 crt_runtime_verified 而非 cpp_reimplementation）
----------------------------------------------------------------
1. 归属：0x7CCA34 = MSVC6 静态 CRT _output/sprintf 格式化引
   擎——0x7C-0x7D = MSVC6 静态 CRT（ra2_code_region_layout_
   crt_provenance）；'%' 指令/'#' 交替标志/DBCS lead-byte/
   转换字符分派/region lock 0x13 门控 = CRT 格式化标准形态。
2. 依赖：0x7CD9F5/0x7CDA56（region lock 已登记）+ 0x7CCB2E
   （子函数）+ [0x87C590] ctype 表——重写 gamemd 时用等价
   std::sprintf/snprintf 运行时代替。
3. gamemd_replication_discipline：MSVC6 CRT 格式化设施，重
   写时用等价运行时代替，逐字节复刻无意义——按商业库纪
   律归档，不写 C++ 模型不做 golden。
→ 状态：crt_runtime_verified（全 250B + 子函数 + lock 交叉；
函数名「_output/sprintf 格式化引擎」由 % 指令/'#' 标志/转换
字符分派/返回字符数实测交叉标注）。
