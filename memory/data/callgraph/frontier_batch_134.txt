================================================================================
0x4A1D50  CRC 4 字节包装（15 callers，0x16 全读完）
================================================================================
机器码（全 0x16，22B）：
    mov eax, [esp+4]                 ; ★ 4 字节值（arg）
    lea edx, [esp+4]                 ; &值
    push 4 / push edx                ; len=4, buf=&值
    mov [esp+0xC], eax
    call 0x4A1DE0                    ; ★ CRC 字节处理器（batch 082 实锤）
    ret 4

语义：**CRC32 的「4 字节值快捷包装」**——把单个 4 字节值当 4 字节缓冲喂
0x4A1DE0（batch 082 登记的 CRC 字节处理器）求校验和。紧邻 0x4A1D70 是同构
副本（batch 085 孪生现象）——同一源码两份编译副本，未做归一化比对不写
「已证为副本」但形态一致。

★跨批次连接：batch 082（0x4A1DE0 CRC 处理器）+ batch 090（INI CRC 查表）——
CRC 体系的「整值快捷入口」；15 个调用方 = 各处对整值求哈希（键查找预处理）。

⚠️ partial：无（全读完）；0x4A1D50 vs 0x4A1D70 未归一化比对。

================================================================================
0x7B7600  宽串 operator=（释放+重分配）（15 callers，>0x40 未读完）
================================================================================
机器码（前段）：
    mov esi, ecx                     ; this
    mov eax, [esi]                   ; ★ this->[0]（旧串指针）
    test eax / je 跳过
    push eax / call 0x7C8B3D         ; ★ CRT::_delete（batch 001/096 族）释放旧
    add esp, 4
  跳过:
    mov edi, [esp+0xC]               ; ★ 源参数字符串
    mov [esi], 0                     ; 先置 NULL
    test edi / je 空源
    push edi / call 0x7CA405         ; ★ CRT::wcslen（batch 097 实锤）
    add esp, 4 / inc eax             ; +1 给 '\0'
    jmp 定长
  空源:
    mov eax, 1
  定长:
    add eax, eax                     ; ★ ×2（wchar_t 宽）
    push eax / call 0x7C8E17         ; ★ CRT::_new（batch 001）
    add esp, 4 / mov [esi], eax      ; this->[0] = 新缓冲
    ...（wcscpy 拷贝——batch 097 实锤 0x7CA489）

语义：**宽字符串类 operator=（释放旧值 + 重新分配）**——先 _delete 释放
this->[0]，再按源 wcslen 定长 _new 分配并拷贝。与 batch 097（0x7B66C0 拷裸
指针）、batch 125（0x7B6720 拷自身型）成族——本条是「释放旧值版」第三变体。

★跨批次连接：_delete/_new/wcslen 三件套 + 宽串族（batch 097/110/112/115/
125/128）——宽串 operator= 家族成员增至 3+。

⚠️ partial：拷贝段（0x7B7640 起 wcscpy）未读完、宿主类名（WStringClass 推断）。

================================================================================
0x588C60  坐标差运算（15 callers，0x29 全读完）
================================================================================
机器码（全 0x29）：
    mov dx, [ecx]                    ; ★ this->X（word）
    mov eax, [esp+8]                 ; arg 坐标指针
    mov cx, [ecx+2]                  ; ★ this->Y（word）
    sub dx, [eax]                    ; X - argX
    sub cx, [eax+2]                  ; Y - argY
    mov eax, [esp+4]                 ; 输出指针
    mov [esp+8], dx / mov [esp+0xA], cx
    mov edx, [esp+8]
    mov [eax], edx                   ; ★ 输出差值（word 对）
    ret 8

语义：**CellStruct 坐标差（this - arg）**——两格坐标相减输出差值（word 对）。
ret 8 = 2 栈参（输出指针 + 参照坐标）。紧邻 0x588C90 是同宿主类构造/字段成员
（+0x10 计数清零等）——坐标/格子族。

★跨批次连接：坐标对运算与 batch 129（0x42B1C0 菱形线性换算）、batch 131
（0x53EDA0 字段拆分）同几何族——「格子→差值/换算」的又一工具。

⚠️ partial：宿主类（0x588xxx 区，坐标/格子族）与差值用途。
