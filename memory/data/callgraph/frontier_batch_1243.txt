0x625AE0 —— 单向链表头插（16B）
================================================================================
机器码（全文 16 字节）：
    mov eax, [esp+4]      ; eax = 新节点（栈参 1）
    mov edx, [ecx+4]      ; edx = this->+4（旧头）
    mov [eax+0xC], edx    ; 新节点->+0xC = 旧头（接链）
    mov [ecx+4], eax      ; this->+4 = 新节点（换头）
    ret 4                 ; 1 栈参，thiscall

语义：**单向链表头部插入**——this 对象 +4 持链表头指针；节点 +0xC 持
next 指针（新节点接旧头后成为新头）。57 调用点全在 FUN_006C6F50。

★怪癖：①next 指针在节点 +0xC（非 +0/+4 常见位）；②无空头检查/无计数维护
（纯指针操作，链表长度由调用者维护）；③头指针在持有者 +4（非虚表后首槽）。

⚠️ partial：FUN_006C6F50 语义、节点类型、+0xC 字段名。

0x538780 —— VectorClass 式尾部插入 + 容量预扩（80B）
================================================================================
机器码（0x538780-0x5387CD 全文）：
    push esi; mov esi, ecx              ; esi = this（容器）
    ecx = [esi+8]   ; 容量 cap
    eax = [esi+0x10]; 计数 count
    cmp eax, ecx; jl 0x5387B5           ; count < cap → 直接插入
    al = [esi+0xD]   ; 标志位
    test al, al; jne 0x538798           ; 标志非 0 → 跳过空容量检查
    test ecx, ecx; jne 0x5387AF         ; cap != 0 → 失败返 0
0x538798:
    eax = [esi+0x14]   ; 增长量 grow
    test eax, eax; jle 0x5387AF         ; grow <= 0 → 失败返 0
    edx = [esi]        ; 虚表
    eax += ecx         ; 新容量 = cap + grow
    push 0; push eax; mov ecx, esi
    call [edx+8]       ; ★虚表槽 8 = Reserve/扩容
    test al, al; jne 0x5387B5           ; 成功 → 插入
0x5387AF:
    xor al, al; pop esi; ret 4          ; 返回 0（插入失败）
0x5387B5:
    eax = [esi+0x10]   ; count
    edx = [esi+4]      ; 数据数组基址
    ecx = count + 1
    [esi+0x10] = ecx   ; count++
    ecx = [esp+8]      ; 栈参 1（值指针）
    pop esi
    ecx = [ecx]        ; ★解引用取值
    [edx + eax*4] = ecx; 数据[count] = *值指针
    mov al, 1; ret 4    ; 返回 1（成功）

语义：**VectorClass 风格尾部插入**（Insert/TryAdd）——容器布局
{+4 数组指针, +8 容量, +0xD 标志, +0x10 计数, +0x14 增长量, 虚表槽 8 扩容}。
count < cap 直接写尾部；否则按标志位/容量/增长量判定并经虚表槽 8 预扩
（新容量 = caps+grow），成功才插入。参数 = 指向值的指针（插入时解引用）。

★怪癖：①扩容只发生在 count==cap 时（无 =0 快路径，而是查标志）；②标志
+0xD 非 0 时跳过"容量非空即失败"检查（可空容器 + 有 grow 才能扩）；③grow
<= 0 直接失败（无默认增长量）；④参数解引用插入（传指针非值）；⑤返回
bool（al = 1/0）区分成功失败。

⚠️ partial：虚表槽 8 的 Reserve 实现、+0xD 标志语义、宿主类（VectorClass
家族推断，batch 597/7AE5D0 有先例）。
