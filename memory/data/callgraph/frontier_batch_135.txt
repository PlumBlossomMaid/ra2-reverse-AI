0x7B5B30  窄串转小写（15 callers，0x3F 全读完）
================================================================================
机器码（全 0x3F）：
    mov ebx, ecx                    ; this
    xor esi, esi                    ; 索引 i = 0
  loop:
    mov edx, [ebx]                  ; ★ this->[0]（串指针）
    test edx / je 收尾
    ; ★ strlen（repne scasb 求长）
    or ecx, -1 / xor eax / repne scasb / not ecx / dec ecx
    cmp esi, ecx / jae 收尾          ; i >= len → 收尾
    mov dl, [edx+esi]               ; ★ 取第 i 字节
    cmp dl, 0x41 / jl 跳过           ; ★ 非 'A'..'Z'（0x41-0x5A）跳过
    cmp dl, 0x5A / jg 跳过
    movsx eax, dl / push eax
    call 0x7CAFF4                   ; ★ CRT tolower（batch 001 CRT 族，
                                    ;   [0xB782A0] locale 检查 + A-Z→+0x20）
    add esp, 4
    mov ecx, [ebx] / mov [ecx+esi], al   ; ★ 写回小写
  跳过:
    inc esi / jmp loop

语义：**窄字符串类转小写（逐字符 tolower）**——遍历 this->[0]，只对 A-Z
（0x41-0x5A）字符调 CRT::tolower（0x7CAFF4）转小写写回，其余跳过。★原版
怪癖：先求 strlen 再按索引遍历（每次循环重读 [ebx]，len 只算一次）；非
A-Z 字符不写回（保持原样）。紧邻 batch 118 的 0x7B47F0（窄串比较）——
窄串族处理成员。

★跨批次连接：CRT::tolower 0x7CAFF4（[0xB782A0] locale 门 + A-Z→+0x20）与
batch 093（strcmpi 的 0x7C8D20 同 CRT 层）；窄串族（batch 085/088/090/118/
122/134）处理方向。

⚠️ partial：宿主类名（StringClass 推断）+ 0x7CAFF4 与 0x7C8D20 的精确关系
（tolower vs 比较内联——未归一化比对）。
