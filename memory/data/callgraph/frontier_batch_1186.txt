一、链语义（disasm 全 55B + 调用点宿主 + batch 881 交叉，
0x7D6A1D-0x7D6A53）
--------------------------------------------------------------
签名（推断）：cdecl 1 参（[esp+4]=字符串指针），就地变换，
返回 void。

主体（0x7D6A1D-0x7D6A53）：
007d6a1d  mov ecx,dword[esp+4]                 ; ecx = 串指针（参1）
007d6a21  mov al,byte[ecx]
007d6a23  test al,al
007d6a25  je 0x7d6a3c                          ; ★空串 → 直接 ret
007d6a27  push esi
; → 主循环（0x7D6A28，逐字符）：
007d6a28  cmp al,0x30
007d6a2a  jl 0x7d6a3d                          ; < '0' → 非数字分支
007d6a2c  cmp al,0x39
007d6a2e  jg 0x7d6a3d                          ; > '9' → 非数字分支
007d6a30  sub al,0x30                          ; ★数字字符 → 数值
007d6a32  mov byte[ecx],al                     ; ★★写回原位（就地转换）
007d6a34  inc ecx
007d6a35  mov al,byte[ecx]
007d6a37  test al,al
007d6a39  jne 0x7d6a28                        ; 非 0 → 继续
007d6a3b  pop esi
007d6a3c  ret
; → 非数字分支（0x7D6A3D，分号删除）：
007d6a3d  cmp al,0x3b                          ; al == ';' ?
007d6a3f  jne 0x7d6a34                        ; ★非 ';' → 跳过（inc 继续）
007d6a41  mov eax,ecx                          ; eax = 当前位置
007d6a43  mov dl,byte[eax+1]                   ; ★前移覆盖（删分号）
007d6a46  lea esi,[eax+1]
007d6a49  mov byte[eax],dl
007d6a4b  mov eax,esi
007d6a4d  cmp byte[eax],0
007d6a50  jne 0x7d6a43                        ; ★循环前移到串尾
007d6a52  jmp 0x7d6a35                        ; ★重读原位（ecx 未动）

★语义：**MSVC6 CRT 数字列表字符串→数值字节数组变换器（推
断名——分号分隔数字串预处理）**——cdecl 1 参就地变换：
  ① 主循环逐字符：'0'-'9'（0x30-0x39）→ 减 0x30 得数值
     （0-9）写回原位；
  ② 非数字字符：== ';'（0x3B）→ 整体前移删除该分号（两
     段式覆盖到串尾）；≠ ';' → 跳过保留；
  ③ 删除后 ecx 不动、jmp 回 0x7D6A35 重读原位——连续分
     号逐个删；
  ④ 空串快速返回（test al,al/je）。
  = 「12;3」→ {1,2,3}：分号分隔的数字字符列表转成数值字
  节数组（每数字字符独立成字节，不合并多位数）。

★调用点（探针 E8 实测 1 处 0x7D696B）：宿主 FUN_007d68fb
  （0x7D68FB-0x7D6A1C——batch 881 点名的两新宿主之一，
  15 处 0x7DAF28 调用、movzx edi,word[0xb78534] + 长度常
  量 0x14/0x15/0x16/0x17/0x18/0x50/0x51 模式 1 分发链）。
  现场 0x7D6966：push dword[esi+0x1c]（★★传 esi 结构
  +0x1C 处字符串指针）→ call 0x7D6A1D——宿主在 0x7DAF28
  逐字段装载后对本串做数字/分号预处理。

★E8 被调者：**零子调用**（全 55B 纯串内变换）。

★全局：**零**（无 [0x...] 引用，纯寄存器+栈）。

★原版怪癖（照抄）：
  ① 数字字符**独立**转数值（不减 0x30 前不合并多位数）——
     "12" → {1,2} 而非 12；
  ② 转换**就地写回原串**（mov [ecx],al）——调用者原缓冲
     被改；
  ③ ';' 删除用两段式前移（dl=[eax+1] 起循环覆盖到串尾
     0）——非 memmove 库调用手写内联；
  ④ 删除后 **ecx 不动** jmp 重读原位——连续分号逐次删
     （每次前移整段）；
  ⑤ 非数字非分号字符跳过保留（jne 0x7d6a34 直接 inc）；
  ⑥ 空串快速返回在 push esi **之前**（test al,al/je
     0x7d6a3c——栈平衡靠不压入）——首字符检查特判；
  ⑦ ret 时 eax 为最后 al 扩展残留（无显式返回值，调用者
     忽略）。
