0x750030 —— 浮点双阈值分级器（44B 全程读完）
================================================================================
签名：thiscall（ecx=this）+ 0 栈参 ret eax。

    fcomp dword [0x7e37b4]        ; 与 2.0 比较（pop）
    fnstsw ax; test ah,1          ; 测 C0（ST0 < 2.0 → C0=1）
    jne 0x750042                  ; C0=0（ST0 >= 2.0）→ 第二段
    xor eax,eax; ret              ; ST0 < 2.0 → 返 0

    fnstsw ax; test ah,1

语义：**浮点双阈值分级器**——this+0 的 float 经两级 fcomp 分级：
val < 2.0 → 0；val >= 2.0 再与 1.0 比较：val >= 1.0 → 1、val < 1.0 → 2。

传统写法）；②★第二阈值 1.0 在门控后恒真——返 2 是不可达死代码（原版
未优化，照抄）；③★[ecx] 重新 fld 两次（每次比较前重载）；④常量为
