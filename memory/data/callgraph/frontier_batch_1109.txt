★语义：**MSVC6 CRT setlocale 条目更新器（推断名——locale
域条目更新/注册）**——cdecl 2 参（param1=类别索引 0/1/2、
param2=类别名称串）：
  ① 调 0x7CDF2E（batch 1038 locale/code-page 名称解析器，
     5 参变体）解析 → 失败返回 0；
  ② _strlen 取长 → inc → malloc 分配新副本（失败返回 0）；
  ③ 表项步长 idx*12：[0x87C484]+idx*12 表（+0 名称指针 /
     +4 函数指针回调）与 [0xB78298]+idx*4 全局槽——先保存
     旧值（回滚用）→ memmove 拷贝缓冲 → strcpy 写新副本 →
     表项 +0 更新 → [0xB78298] 写类别值 → memmove 二次 →
     idx==2 → [0xB782B0] / idx==1 → [0xB782B4] 全局名称槽；
  ④ call [0x87C488]（表项 +4 函数指针）回调——失败走回滚
     路径（恢复表项/槽/全局 + free 新副本），成功路径对旧
     值非共享对象（≠0x87C370）free；
  ⑤ 返回 0=失败 / 表项值=成功。
  调用方 = setlocale 主流程（0x7CDB40 片区，wait 循环 +
  5 项表遍历 + strcmp 0x7CDA90 名称比对）。
