frontier batch 128 — 哨兵 getter 族补员 + 宽串 length + 全局状态快照器（2026-10-13）

================================================================================
0x696F50  哨兵值对 getter 族第四成员（16 callers）
================================================================================
机器码（全 0x15）：
    mov edx, [ecx+0x5F]             ; ★ 哨兵字段（+0x5F）
    mov eax, 0xFFFFFFFE
    cmp edx, eax / jne 返值
    cmp dword [ecx+0x5B], -1 / je 返 -2
  返值:
    mov eax, [ecx+0x5B] / ret       ; ★ 值字段（+0x5B）

语义：**batch 122 哨兵值对 getter 族的第四成员**（0x696F10=+0x4B/+0x4F、
0x696F20=+0x53/+0x57、0x696F30=三态、本条=+0x5B/+0x5F）——同一宿主对象的
第 4 对「可选值+有效性标志」。紧邻 0x696F70（+0x63/+0x67）是第五成员——
宿主对象持有 4+ 组哨兵值对，字段按 0x0C 间隔排列（0x4B/0x4F → 0x53/0x57 →
0x5B/0x5F → 0x63/0x67）。

★跨批次连接：batch 122（0x696F10 族首成员）+ 哨兵 -2/-1 语义同族。

⚠️ partial：宿主类（+0x4B..+0x67 多组哨兵值对的对象未对齐）、-2/-1 语义
（与 batch 122 相同推断）。

================================================================================
0x7B71B0  宽串 length（16 callers，0x10 全读完）
================================================================================
机器码（全 0x10）：
    mov eax, [ecx]                 ; ★ this->[0]（串指针）
    test eax / jne 非空
    ret                             ; NULL → 返 0
  非空:
    push eax / call 0x7CA405        ; ★ CRT::wcslen（batch 097 实锤）
    add esp, 4 / ret

语义：**宽字符串类的 length()**——this->[0] 非空则 wcslen 返回字符数，NULL
直接返 0。紧邻 0x7B71D0 是 operator= 变体（wcslen 后分配拷贝）。★与 batch 088
（窄串 length）、batch 097/110/112/115/125（宽串族）成镜像——宽串 length
成员。

⚠️ partial：宿主类名（WStringClass 推断，batch 097 预设命名）。

================================================================================
0x72AD20  全局状态快照器（16 callers，0x61 全读完）
================================================================================
机器码（全 0x61）：
    sub esp, 0x10
    mov edx, [0x886FB4]            ; ★ 全局 A（[0x886FB4]）
    mov ecx, [0x886FB0]            ; ★ 全局 B（[0x886FB0]）
    mov bl, [0xA8EB7C]             ; ★ 门禁标志 1（[0xA8EB7C]）
    mov esi, [0x886FBC]            ; ★ 全局 C（[0x886FBC]）
    mov edx, [0x886FB8]            ; ★ 全局 D（[0x886FB8]）
    test bl / jne 跳过             ; [0xA8EB7C] 置位 → 直接快照
    mov bl, [0xA8ED6B]             ; ★ 门禁标志 2（[0xA8ED6B]，batch 124 同款）
    test bl / jne 跳过
    mov ecx, 0xA8                  ; ★ 未置位 → 快照值改 0xA8（疑默认参数）
  跳过:
    mov [eax], ecx / [eax+4], edi / [eax+8], edx / [eax+0xC], esi
    ret                            ; ★ 输出 4 dword 到调用者缓冲

语义：**「把四个全局状态打包成 16B 快照」的 getter**——读 [0x886FB0]/
[0x886FB4]/[0x886FB8]/[0x886FBC] 四个全局，按两个门禁标志（[0xA8EB7C]/
[0xA8ED6B]，batch 124 的 [0xA8ED6B] 同款触发器全局）决定快照内容（未置位时
首字段用 0xA8 默认），输出 4 dword。紧邻 0x72AD90 是同构第二成员（读
[0xA8EB84]/[0xA8EB88] 等 A8 区全局）。

★跨批次连接：[0xA8ED6B] 与 batch 124（TagClass::RaiseEvent 总开关）同全局
互证；0x886xxx 区全局（batch 124 的 [0x887368]/[0x88730C] 邻域）——渲染/
状态区快照。

⚠️ partial：四个全局（[0x886FB0]-[0x886FBC]）语义、0xA8 默认值含义、
门禁标志逻辑极性。
