0x4E49A0  对话框控件查表组合（13 callers）
================================================================================
机器码还原（前 0x50）：
    mov esi, edx                    ; ★ 参数（控件/类型值）
    mov ebp, ecx                    ; this
    push esi / push ebp
    call [0x7E14A8]                 ; ★ GetDlgItem（batch 099 实锤导入槽）
    push 0 / push eax
    call [0x7E1498]                 ; ★ ShowWindow（batch 094 实锤导入槽）
    test eax / sete byte [esp+0xB]  ; ★ 记录显示结果
    cmp esi, 0x6A2 / je 返 0        ; ★ 参数 == 0x6A2
    cmp esi, 0x522 / je 返 1        ; ★ 参数 == 0x522
    cmp esi, 0x523 / je 返 ...      ; ★ 参数 == 0x523
    ; ★（0x6A2/0x522/0x523 = batch 108 查表族的「值」域——0x4E37D0 的
    ;   0→0x6A1、1→0x510；0x4E41D0 的 0→0x6A2、1→0x522——同 ID 空间）

语义：**「GetDlgItem 取控件 → ShowWindow 显隐 → 按类型值查表分支」的组合**——
先按控件 ID 取句柄并控制显隐，再按参数（0x6A2/0x522/0x523 等）查表返回
对应结果。★跨批次价值：batch 094/099 的 UI 导入槽（GetDlgItem/ShowWindow）
与 batch 108 的查表值（0x6A2/0x522/0x523）在一条函数里咬合——UI 显隐 + 类型
映射的双重组合。

★跨批次连接：batch 099（GetDlgItem 0x7E14A8）+ batch 094（ShowWindow
0x7E1498）+ batch 108（0x4E41D0 查表 0→0x6A2/1→0x522）。

⚠️ partial：查表完整分支（0x4E49D5 起多个 cmp）、参数语义（类型值 vs
控件 ID）、函数后半返回路径。

0x517440  除 255 比例运算（13 callers）
================================================================================
机器码还原（前 0x50）：
    mov al, [ecx+2] / mov esi, eax  ; ★ 字节 3
    mov al, [ecx] / mov bl, [ecx+1] ; ★ 字节 1/2
    mov edi, 0xFF
    lea ecx, [eax+eax*2] / shl ecx, 1   ; ★ 字节1×6
    idiv edi                         ; ×6 后除 255
    mov eax, 0x80808081              ; ★ 除 255 魔术数（乘法替代除法）
    imul edx, ebx / mul edx / shr edx, 7   ; ★ 字节2 处理
    sub edi, edx
    mov eax, 0x80808081
    imul edi, esi / mul edi ...
    ; ★（0x80808081 = 1/255 的定点近似，标准「RGB → 比例/压缩」惯用法）

语义：**RGB 字节的比例/压缩运算**——三个字节（+0/+1/+2）经 0x80808081 魔术
数（÷255 的乘法近似）与 ×6/×7 组合换算，疑「颜色亮度/加权」计算。0x51xxxx
区（batch 127 的 Index_IsMP 同区）——颜色/UI 计算族。

★跨批次连接：0x80808081 魔术数与 batch 112（ReadDouble 的 0.01 常量）、
batch 122（DistanceFrom3D 的 ×64）同「引擎常数族」；÷255 惯用法是
RGB 处理的 MSVC 标准产物。

⚠️ partial：×6/×7 组合的精确公式、输入三字节语义（RGB?）、输出用途。
