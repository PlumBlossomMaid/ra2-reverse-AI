0x7B7F90  窄→宽串转换 operator=（12 callers，0x53 未读完）
================================================================================
机器码还原（前 0x53）：
    mov ebx, edx                    ; ★ 源（窄串对象/指针）
    mov esi, ecx                    ; this
    mov eax, [ebx]                  ; ★ 源内部指针
    test eax / jne 非空
    xor edi / jmp 定长
  非空:
    push eax / call 0x7CA405        ; ★ CRT::wcslen（batch 097 实锤）
    mov edi, eax
  定长:
    lea eax, [edi+1] / push eax
    call 0x7C8E17                   ; ★ CRT::_new（(len+1)×2? 未 ×2，见下）
    mov ebp, eax                    ; 新缓冲
    mov eax, [ebx] / test / jne 非空2
    mov eax, 0x887734               ; ★ 空源 → 全局兜底 0x887734（batch 112 实锤）
  非空2:
    push edi / mov edx, eax / mov ecx, ebp
    call 0x735090                   ; ★ 宽→窄转换（batch 137 已登记的
                                    ;   0x735090 反向宽→窄版? 或 0x735060 窄→宽）
    test ebp / je 收尾
    mov edi, ebp / or ecx, -1 / xor eax
    ...（收尾置 NULL/释放旧值）

语义：**窄→宽字符串转换 + operator= 组合**——按源内部指针求长（wcslen，
空则 0）→ _new 分配（len+1）→ 0x735090 转换拷贝（batch 137 登记的转换工具，
疑此处是反向宽→窄方向或同向）→ 空源用全局兜底 0x887734。★与 batch 137
（0x735060/0x735090 转换对）、batch 112（0x887734 兜底全局）串链——宽窄串
转换族的 operator= 形态。

★跨批次连接：batch 137（0x735090 转换）+ batch 097（wcslen）+ batch 112
（0x887734 兜底）+ _new/_delete 三件套。

⚠️ partial：转换方向（0x735090 vs 0x735060 的精确引用）、(len+1) 未 ×2 的
语义（疑此处是窄串分配）、收尾释放旧值段。

0x5E6520  数组按索引取串（12 callers，0x150 栈帧未读完）
================================================================================
机器码还原（前 0x50）：
    sub esp, 0x150
    cmp ecx, 0 / jl 收尾            ; ★ 索引 < 0 → 收尾
    cmp ecx, [0xA8B8D8] / jge 收尾  ; ★ 索引 >= 计数 → 收尾

    lea edx, [esp+0xD8]             ; 栈输出缓冲

    add edi, 0x58                   ; ★ item->+0x58（字符串字段）
    repne scasb 求 strlen
    rep movsd / rep movsb           ; ★ 字符串拷到栈缓冲
    ...

语义：**按索引取全局数组项的字符串字段（item->+0x58）拷到输出**——[0xA8B8CC]
全局数组（计数 [0xA8B8D8]，4B/项指针），索引越界（<0 或 >=计数）收尾；
命中取 item->+0x58 字符串 strlen + rep movsd/movsb 拷出。★0xA8Bxxx 区全局
（batch 126 的 [0xA8B244]/[0xA8B238] 相邻）——游戏全局状态区。

★跨批次连接：0xA8Bxxx 全局区（batch 126/105）+ 数组按索引取（batch 147
0x634290 同族）——全局对象表的字符串读取端。

⚠️ partial：数组宿主（[0xA8B8CC] 的对象类型）、item->+0x58 字段语义、
