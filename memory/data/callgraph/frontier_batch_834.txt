一、参数契约（8 栈参 ret 0x20，调用点现场 + 函数体读法双证）
------------------------------------------------------------
call 后 esp=E0：[E0]=ret、[E0+4]=p1..[E0+0x20]=p8；
函数序言 sub esp,0x1c 后 [esp+0x20]=p1；push ebx/ebp/esi/edi 后偏移 +0x2c：
  p1（[esp+0x20],sub 后）      = 目标值（= 宿主+0x308 字段，→ 0x5A0700）
  p2（[esp+0x34],push 后 =E0+8）= 迭代轮数（调用点实测 1 / 6；jle 0x5A03C4 直接收尾）
  p3（[esp+0x38]=E0+0xC）       = 扩散矩形 x 左界
  p4（[esp+0x3c]=E0+0x10）      = 扩散矩形 y 左界
  p5（[esp+0x40]=E0+0x14）      = 矩形宽（x < p3+p5 判定）
  p6（[esp+0x44]=E0+0x18）      = 矩形高（y < p4+p6 判定）
  p7（[esp+0x48]=E0+0x1C）      = 写 cell 高度字节标志（test al,al 双分支）
  p8（[esp+0x4c]=E0+0x20）      = cell+0x11B 高度字节值
调用点栈布局实测（0x59E299）：push 1（p2）→ sub esp,0x10 结构 = {0,0,0x200,0x200}
  = p3..p6（全图矩形 0x200=512 哨兵）→ push [ebx+0x308]（p1 最后压）→ call；
  0x59E3F2 同款（p2=6）；0x59D323 同款（p2=1，p3/p4 来自调用方现场 eax/ecx）；
  0x59ECCE 同款（p2=2，矩形 {ecx,edx,上两参,+0xC}）。ecx=宿主（River 的 ebx）
  ——但函数体不读 ecx（纯栈参函数，ecx 是宿主对象指针供 +0x308 读值用）。

三、语义（推断名 + 调用现场双证）
--------------------------------
**RMG 8-邻域迭代散布器（河湖扩散）**——① 开头唯一一次调 0x5A0700（batch 530
「收集 work[].+0x38==目标值 的格子」）取初始格集（迭代起点）；② 外层按 p2 迭代
轮数循环：每轮从当前收集器逐格取 8 方向邻格（[0x89F688] 方向表 {dx,dy} word 对），
过菱形四边界（[0xABED04]=W/[0xABED08]=W+2H——batch 086）与扩散矩形 p3..p6 后，
按邻格 work[].+0x38 三态判定：==0（无主谓词 0x486380）或（p1-1 标记且落多区间
0x4865D0）→ 邻格坐标追加进结果容器（虚表槽 8 SetCapacity 扩容——batch 467/469
同款）并写 work[邻].+0x38 = p1（扩散归属）；==p1 → 跳过（已处理）；其他 → 整体
失败 al=0；③ p7 非零时条件写 cell+0x11B 高度字节 = p8（GetCellAt 二次查格）；④
每轮结束把本轮结果容器当下一轮收集器（迭代传播），最后一轮结果在收尾析构前
保留——即「从初始格集出发，迭代 p2 轮 8 邻域生长」。

六、原版怪癖（照抄）
-------------------
① 结果容器容量预置 = Count×3（8 方向最多 8 邻却预置 3 倍——启发式预分配，
   与 batch 530 的「+0x14=side 面积」同属预置形态）；
② p2 轮数循环每轮**重分配**结果容器（0x5A0187 new），上轮结果容器在
   0x5A03A7 移交为下轮收集器后不复用分配（每次 new+构造）；
③ work[邻].+0x38 == p1-1 的「标记」只由 p7 标志使能（[esp+0x48] 测试）
   ——bl=1 时才允许 0x4865D0 多区间归属路径；
④ 追加判定三态（0 走无主 / p1-1+标记走区间 / p1 跳过 / 其他整体失败 al=0）
   ——失败路径 0x5A03DE 双容器析构；
⑤ 方向表 [0x89F688] word dx/dy 对 + lea [edx*4+0x89F688]（8 项 ×4B）；
⑥ p7 高度写入前二次 GetCellAt（0x5A035C）还需 0x486380 无主通过——写高度
   有双门控；
⑦ 收集器只在开头调 0x5A0700 一次，第 2+ 轮直接复用上轮结果（work.+0x38
   已写 p1 → 0x5A0700 的「==目标值」谓词语义在本函数内被迭代替代）。
