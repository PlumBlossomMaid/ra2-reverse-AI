★0x7C6064（14B，__cdecl 1 参 = rdtsc 时间戳壳）：
007c6064  push ebp / mov ebp, esp / push esi
007c6068  rdtsc                  ; edx:eax = TSC
007c606a  mov esi, [ebp + 8]     ; 输出指针

★语义：**rdtsc 高 32 位读出壳（推断名——写参1 指向的 dword）**。

★0x7CEAAF（18B，__cdecl 2 参 = FPU 精度控制壳）：
007ceaaf  push 0x30000           ; mask = MCW_PC（精度控制位）
007ceab4  push 0x10000           ; new  = _PC_53（53 位双精度）
007ceab9  call 0x7CBF49          ; ★_control87 内核（TSV

★语义：**`_control87(_PC_53, MCW_PC)`（推断名——53 位精度
  固定闰入）**。与 WinMain 的 _control87(_RC_CHOP, _MCW_RC)
  （QWEN 记录 0x6BBFB7 push 0x300/push 0x300）同为 0x7CBF49
  内核的不同调用封装。

★0x7CBB76（23B，__cdecl 4 参转发壳）：
007cbb76  push 1                 ; 常量 1 → 参1
007cbb78  push [esp + 0x10] ×3   ; 原参2/3/4 → 参2/3/4
007cbb84  call 0x7CB9CF          ; ★转发（TSV crt_runtime_verified）
007cbb89  add esp, 0x10 / ret
★语义：**插常量 1 作首参的 4 参转发壳（推断名）**——参数原样
  透传 0x7CB9CF，仅头部插固定 1。

★0x7D8EE3（18B，__cdecl 1 参 = x87 取整）：
007d8ee3  push ebp/mov ebp,esp/sub esp,8
007d8ee8  fld qword [ebp+8]      ; st0 = x
007d8eeb  frndint                ; ★st0 = 按当前舍入模式取整
007d8eed  fstp qword [ebp-8]     ; 存回
007d8ef0  fld qword [ebp-8]      ; 重载（双精度规整）
007d8ef3  leave / ret

  名在 functions.tsv 已标 __frnd。★★原版怪癖（照抄）：frndint
  行为取决于全局 FPCW（RA2 运行时为 RC_CHOP 向零截断，见
  FPCW=0x0E7F 取证）——重写取整须同模式。

★x87 状态字读取二连（14/15B，__cdecl 无参）：
0x7DBC5A  wait                   ; 等待待决异常完成
          fnstsw word [ebp-2]    ; 状态字 → 栈上
          movsx eax, word [ebp-2] ; 有符号扩展返回
          leave / ret
0x7DBC68  fnstsw word [ebp-2]    ; 状态字 → 栈上
          fnclex                 ; ★清异常（不等待）
          movsx eax, word [ebp-2] ; 返回
          leave / ret
★语义：**CRT `_statusfp`/`_clearfp` 内核（推断名——fnstsw
  状态字读取；0x7DBC68 额外 fnclex 清异常）**。0x7DBC5A 带
  wait（与 batch 中 wait+fnstsw 形态一致），0x7DBC68 不带。

★0x7C3950（7B，thiscall 0 栈参 = 累加器）：

三、三态判定（为何 crt_runtime_verified 而非 cpp_reimplementation）
----------------------------------------------------------------
1. 归属：十四函数均在 0x7C-0x7D = MSVC6 静态 CRT
   （ra2_code_region_layout_crt_provenance）；IAT 跳板 =
   ff25 标准导入形态；FPU 壳/状态字 = _control87/__frnd/
   _statusfp 标准 CRT 内核；转发壳 = 常量插入透传。
2. 依赖：挂靠目标全部已登记（0x7CBF49 _control87 内核、0x7CB9CF、
   0x7D478B、0x7CEAFF 均 crt_runtime_verified；0x7D2E9B
   semantics_verified）——重写用等价运行时（stdlib 控制/
   取整/状态查询 + 导入声明）代替。
3. gamemd_replication_discipline：MSVC6 CRT 标准设施，
   按商业库纪律归档，不写 C++ 模型不做 golden。
→ 状态：crt_runtime_verified ×14（全机器码读完 + IAT 槽
内容解引用 + 目标交叉；函数名推断标注）。
