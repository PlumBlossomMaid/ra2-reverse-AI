0x00486380  CellClass 类型查询族 —— 「无主」谓词 + 两个区间检查
================================================================================
33 callers（0x486380）。死代码 `0x58C4A0`/`0x58C5A0` 反复调用的
`FUN_00486380(cell)` 就是这组。三个紧邻的同族小函数：

`0x486380` —— 「格子无主/空」谓词（0x14 字节）：
    mov eax, [ecx+0x38]          ; this->[0x38]（类型/归属字段）
    cmp eax, 0xffff / je ret 1   ; == -1（0xFFFF）→ 返 1
    test eax, eax / je ret 1     ; == 0 → 返 1
    xor al, al / ret             ; 否则返 0

即「`cell->[0x38]` 为 0 或 0xFFFF 则视为主权未定/空」——死代码的
「随机抽格子」族（0x58BE20/0x58C320/0x58C4A0/0x58C5A0）用它来筛可用格。

`0x4863A0` —— 区间检查 A∪B（0x2B 字节）：
    mov eax, [ecx+0x38]
    ; 判 eax ∈ [[0xABC1D8], [0xABC1D8]+20) 或 ∈ [[0xAA1058], [0xAA1058]+12)
    ; 命中任一 → 返 1，否则返 0

`0x4863D0` —— 区间检查 C（0x1E 字节）：
    mov edx, [0xAA1020] / cmp edx,-1 / je → 返 1
    ; 判 eax ∈ [[0xAA1020], [0xAA1020]+40) → 返 1，否则返 0

★ **这就是死代码方案反复调用的格子类型查询族**——`this->[0x38]` 是
cell 的类型/归属字段（与 batch 065 的 `0xA8ED2C` 表索引同源）。
`0xABC1D8`/`0xAA1058`/`0xAA1020` 三个全局是类型区间的边界（运行时常量，
⚠️ 具体值未读——它们在 .data，可读但本轮未取）。

0x004A1DE0  CRCEngine 字节处理器（4 字节字累加 + 满则 flush）
================================================================================
37 callers（符号名 USER_DEFINED，YRpp 覆盖，名字可信）。反汇编起始
0x70 字节：

    mov ebp, [esp+0xc]           ; arg1（字节串）
    test ebp, ebx / je exit      ; NULL → 退出
    mov edi, [esp+0x18]          ; arg2（长度）
    cmp edi, ebx / jle exit      ; <= 0 → 退出
    mov eax, [esi+4]             ; ★ this->[4] = 字内计数（0..3）
    cmp eax, ebx / je ...
    cmp eax, 4 / jae ...         ; 满 4 字节 → flush
    mov cl, [ebp]                ; 取一字节
    mov [eax+esi+8], cl          ; ★ 写进 this->[8+计数]（4 字节字缓冲）
    mov ecx, [esi+4] / inc ecx
    mov [esi+4], ecx             ; 计数 +1
    ; 计数到 4 → call 0x4A1FB0（flush：把累加的 4 字节字并进 CRC）

判据：`this->[4]` 是 0..3 的字内计数，`this->[8]` 起是 4 字节字缓冲，
**字节逐个进、凑满 4 字节就经 `0x4A1FB0` 并入 CRC**——CRC 按 4 字节
字处理的标准形态。名字「CRCEngine::operator」可信（YRpp 覆盖，但
行为与 CRC 字节喂入一致）。

★ **跨批次连接**：batch 074 的 INI 函数（0x526960/0x526CC0/0x528660）
都调 `0x4A1DE0`——即 INI 序列化时对每个键值喂 CRC（用于校验/签名）。
INI 读写的完整性校验走 CRC 引擎，本条是它的字节入口。
