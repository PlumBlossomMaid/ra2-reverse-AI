一、链语义（disasm 全 58B + 全局分布 + 调用点宿主，
0x7D5A2E-0x7D5A67）
--------------------------------------------------------------
签名（推断）：cdecl 2 参（[esp+8]=结构表指针、esi=查询值
经寄存器传入），返回首字段命中项指针 / 0。

主体（0x7D5A2E-0x7D5A67）：
007d5a2e  mov edx,dword[esp+8]                  ; edx = 表指针（参1）
007d5a32  mov ecx,dword[0x87cba4]              ; ★★[0x87CBA4] 项数全局
                                              ;   （locale 域共享）
007d5a38  push esi
007d5a39  mov esi,dword[esp+8]                  ; esi = 查询值
007d5a3d  cmp dword[edx],esi                    ; ★首表项 vs 查询值
007d5a3f  push edi
007d5a40  mov eax,edx
007d5a42  je 0x7d5a55                           ; ★首项即命中
; → 循环（0x7D5A44，12B/项扫描）：
007d5a44  lea edi,[ecx+ecx*2]                  ; edi = 项数×3
007d5a47  lea edi,[edx+edi*4]                  ; ★表尾 = 表头+项数×12
007d5a4a  add eax,0xc                          ; ★★12 字节步进
007d5a4d  cmp eax,edi/jae 0x7d5a55            ; ★到表尾 → 出口
007d5a51  cmp dword[eax],esi/jne 0x7d5a4a      ; ★★首字段 == 查询值 ?
                                              ;   不等 → 继续
; → 出口（0x7D5A55，命中确认）：
007d5a55  lea ecx,[ecx+ecx*2]
007d5a58  lea ecx,[edx+ecx*4]                  ; ★表尾重算
007d5a5b  cmp eax,ecx/jae 0x7d5a63            ; ★超尾 → 返 0
007d5a5f  cmp dword[eax],esi/je 0x7d5a65      ; ★★命中确认（在尾部
                                              ;   检查后）
007d5a63  xor eax,eax                          ; ★未命中 → 0
007d5a65  pop edi/pop esi/ret                  ; ★命中 → eax=项指针

★语义：**MSVC6 CRT 结构表按首字段线性查找器（推断名——
locale/环境结构表查找）**——cdecl 2 参：
  ① [0x87CBA4] 项数全局 × 12B/项 = 表总长（lea ×3 + ×4
     复合缩放）；
  ② 从表头 12B 步进扫描：首字段双字 == esi（查询值）即
     命中；
  ③ 首项特判（cmp [edx],esi/je）+ 循环扫描 + 表尾双重
     检查（0x7D5A55 重算表尾再确认）；
  ④ 命中返项指针（eax）、未中返 0。
  = CRT 结构表线性查找（12B/项固定步进），[0x87CBA4] 项
  数由 locale 域维护（读侧消费）。

★调用点（探针 E8 实测 1 处 0x7D5903）：宿主 0x7D59xx 区
  （0x7D59 域——locale/time 解析链，batch 1112/1135
  localtime/mktime 域附近，结构表查询消费）。

★E8 被调者：**零子调用**（全 58B 纯地址运算 + 字段比较）。

★全局：[0x87CBA4]（3 处引用——0x7D48E0/0x7D4B98/0x7D5A34
  全在 0x7D4x/0x7D5A locale 域；写侧 0x7D48E0/0x7D4B98 与
  读侧 0x7D5A34 本批）。

★原版怪癖（照抄）：
  ① 表总长 lea ×3 + ×4 复合缩放（lea edi,[ecx+ecx*2] →
     lea edi,[edx+edi*4] = 项数×12B）——编译器强度削减；
  ② 首项特判（cmp [edx],esi/je）与循环分离——循环从
     eax=edx（表头）起 add 0xc（跳过首项）——首项双检；
  ③ 出口 0x7D5A55 **重算表尾**再做命中确认（先查尾后
     查字段——与循环内顺序相反）——两段式确认；
  ④ 表尾检查 `jae`（无符号）——项数非负假定；
  ⑤ esi 经寄存器传查询值（参2 由 [esp+8] 读回——本函
     数压栈后 esp 偏移）——寄存器/栈双来源；
  ⑥ 命中/未中双出口（xor eax,eax vs 保留 eax）共用
     pop 序列。
