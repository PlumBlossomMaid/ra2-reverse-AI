0x65D660  虚表安装器（20 callers，6B）
================================================================================
机器码（全 6B）：
    mov dword ptr [ecx], 0x7F0954
    ret

语义：**单指令虚表安装**——把 0x7F0954 写入对象虚表槽（+0）。紧邻 0x65D670
（19B）是引用计数递减成员：
    mov eax, [ecx+4] / dec eax / mov [ecx+4], eax / jne 收尾
    test ecx / je 收尾 / mov eax, [ecx] / push 1 / call [eax]
    ; ★ 引用计数减到 0 → 调虚表槽 0（析构，arg=1）
语义族：**「装虚表 + 引用计数对象」的构造/释放对**——0x65D660 装 0x7F0954
虚表，0x65D670 是标准引用计数递减（到 0 析构）——对象生命周期基建。

⚠️ partial：虚表 0x7F0954 类归属、+4 计数字段语义、紧邻 0x65D690（xor al/ret 4

0x5AE860  Matrix3D::MakeIdentity（19 callers，0x30B 全读完）
================================================================================
身份：ranking.tsv 符号名 Matrix3D::MakeIdentity（confirmed_identity 列非空）。
机器码（全 0x30，48B）：
    mov edx, 0x3F800000               ; ★ 1.0f 位模式
    xor eax, eax
    mov [ecx], edx                    ; 对角 0,0
    mov [ecx+4], eax / [ecx+8] / [ecx+0xC] / [ecx+0x10]
    mov [ecx+0x14], edx               ; ★ 对角 1,1
    mov [ecx+0x18] / [ecx+0x1C] / [ecx+0x20] / [ecx+0x24]
    mov [ecx+0x28], edx               ; ★ 对角 2,2
    mov [ecx+0x2C], eax
    ret

语义：**3×4 矩阵单位化**——三个对角元素（+0/+0x14/+0x28）写 1.0f，其余 9 个

（4×3 矩阵变换）同族、batch 106 的 0x5AFC00（48B rep movsd 矩阵拷贝）一致）。
ranking 名 MakeIdentity 与机器码完全吻合。

拷贝）同对象族——Matrix3D 类的 ctor/单位化成员之一。

⚠️ partial：紧邻 0x5AE890（fld [esp+8]/fmul [ecx+4]... 矩阵·向量点积）是同一
类的变换成员，本批只登记 MakeIdentity。
