0x6C9820 —— 浮点四元查找器（33B 全程读完）
================================================================================
签名：thiscall（ecx=this 指向 float 数组）+ 0 栈参 ret eax（索引/-1）。
机器码（全文 33 字节）：
    xor edx, edx               ; edx = 0（索引）
    0x6C9822 循环:
    fld dword ptr [ecx]        ; ST0 = this[edx]（float）

    cmp edx, 4; jl 0x6C9822    ; 扫 4 个

语义：**浮点四元查找器**——扫描 this 起始的 4 个 float，返回第一个
< [0x7E1748]（常量）的索引（0..3）；全不满足返 -1。3 unique caller

================================================================================

语义：**环形索引判定器**——取 this+0x318 索引 +1（带符号 byte 回绕，

（★判定"下一个索引是否撞上限"）。3 unique caller（30 callsite）。

★怪癖：①★与 batch 1266 0x54F1C0（循环缓冲写入器）同 +0x318/+0x314
