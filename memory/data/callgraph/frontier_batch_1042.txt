一、链语义（disasm 全 811B，0x7CF7E8-0x7CFB12）
------------------------------------------------
调用现场（batch 945 实锤）：`push esi(p) / push eax(seg) / call
0x7CF7E8` → cdecl 2 参：param_1 = seg（段记录指针，栈顶）、
param_2 = p（释放指针）。入口 `shr esi,0xf` 把 seg>>15 作段序号。

控制流全景（逐段）：
  A. 入口段（0x7CF7E8 起，240B）：
     prologue（push ebp/mov ebp,esp/push ebx,esi,edi；尾部

     lea [ecx+eax+0x144] 元数据表定位（[0xB78B90]=堆结构基）。
     空闲位图清位：mov edi,0x80000000 / shr edi,cl / not /
     and [eax+esi*4+0x44] 与 and [+0xc4] 双端链。
     链表维护：mov [ecx+4],edi / mov [ecx+8],edi（+4/+8 前向/
     后向指针）。
  B. 中段（560B，0x7CF8D8-0x7CFA0E）：前后邻空闲双向合并 →
     尺寸类（bin）跨越槽位重挂（+0x44/+0xC4 双端链）→ 段内全
     空判定准备。
  C. ★尾段（本批新读，0x7CFA0E-0x7CFB13）：

★语义：**CRT 堆段释放内核**——free 未命中段内小块时的段级回收：
  ① param1=seg 记录、param2=释放指针；seg>>15 段序号查 0x204
     表；
  ② 空闲位图清位（+0x44/+0xC4 双端链 + shr edi,cl 位掩码）+
     +4/+8 前向后向链表维护（中段空闲合并/槽位重挂）；
  ③ 段内页全释放（+0x43 页计数递减至 0）→ 清在用标志 →
     段全空（[+8]==-1）才整段回收：
       VirtualFree(段基址,0x8000,MEM_DECOMMIT) 散页 →
       位图恢复 or [eax+8],edx / and [eax+ecx*4+0xC4],0 →
       VirtualFree(段基址,0,MEM_RELEASE) 整段归还 →
       HeapFree(heap,[0xB78B9C],0,页表基) 释放页表 →
       memmove 0x7CA090 段数组紧凑搬迁 → 段计数-- ；
  ④ 非全空路径（[+8]!=-1）→ 恢复 [0xB78B90]=seg/
     [0xB78B88]=段序号后直接返回。

★原版怪癖（照抄）：
  ① 逐页 DECOMMIT（0x8000 固定页块）后再整段 RELEASE——
     两道 VirtualFree 而非一次 RELEASE 大块；
  ② MEM_RELEASE 时 dwSize=0（Windows 契约）→ 两次调用参数
     形态不同（DECOMMIT 带 size / RELEASE 带 0）；
  ③ 段数组删项用 memmove 0x7CA090 覆盖搬迁（数组非链表），
     段记录固定 0x14（20B）；
  ④ [0xB78B94] 计数递减发生在搬迁之后；
  ⑤ 空堆（[0xB78B90]==0）直接早退不碰 IAT。

★依赖链实锤（本批 disasm）：
  ① [0x7E1290] = IAT 槽（VirtualFree 形态：DECOMMIT/RELEASE 双
     调用参数均吻合 win32 契约）；
  ② [0x7E127C] = IAT HeapFree（batch 945 已确认）；
  ③ 堆全局五件套 [0xB78B88](段索引)/[0xB78B90](堆结构基)/
     [0xB78B8C](尾部索引)/[0xB78B94](段计数)/[0xB78B98]/
     [0xB78B9C](heap handle)；
  ④ 0x7CA090 = memmove 三参变体（prologue 读 [ebp+8]/[+0xC]/
     [+0x10] + test edi,3 对齐 + 重叠判向 —— 与 batch 036
     0x7D0A20 同族但独立地址，批内标注交叉）。
