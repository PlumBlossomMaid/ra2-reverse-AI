一、语义（完整汇编逐段核对 + 黄金 10 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码逐段确认）：
  · 调用约定：thiscall 变体（ret 0，无栈参），仅寄存器传参：
    - ecx = 矩形结构指针 this（[this+0] 低16=x、[this+4] 低16=y、
      [this+8]=w int32、[this+0xC]=h int32）
    - dl = flagA（0x5A744E mov [esp+0x13],dl，唯一标志，
      0x5A7607 mov al,[esp+0x13] 读回）
    ★与 7250 不同：7250 是 ret 4（flagA=dl + flagB=栈参 1）；
    7440 无栈参，6D0/6F0 共用 dl 单标志。
  · 四角菱形判定（0x5A7449-0x5A755F，与 0x5A7250 完全相同）：
    角0=(x,y)、角1=(x+w-1,y)、角2=(x,y+h-1)、角3=(x+w-1,y+h-1)。
    每角四判据（判据顺序固定，有符号 jle/jge/jg）：
      X+Y <= W → fail（[0xABED04]）；X-Y >= W → fail；
      Y-X >= W → fail；X+Y > W+2H → fail（[0xABED08]）。
    ★角坐标 16 位截断：角1/3 的 X（0x5A7497 lea [w+raw_x-1] →
    0x5A749F movsx edx,cx）、角2/3 的 Y（0x5A74DF lea [h+raw_y-1] →
    0x5A74EA movsx ecx,cx），与 7250/76E0 同构。
  · 起点格期望高度（★7440 独有，0x5A7565-0x5A758D）：
    GetCellAt((x,y))（0x5A7579，无条件在扫描前调用）→
    movsx ecx,[eax+0x11B]（cell+0x11B 有符号字节）→ 存 [esp+0x1C]。
  · 全矩形扫描（★与 7250 同为整 w×h 矩形，非 76E0 的 3×3+边带）：
    外层 cy 从 raw_y 起、条件 cy < h+raw_y（0x5A758B add/0x5A7593
    jge 0x5A762C：h<=0 → 直接成功返 1，但★起点格已查——golden
    h-zero gc=1 实证）；
    内层 cx 从 raw_x 起、条件 cx < w+raw_x（0x5A759E add/0x5A75A2
    jge 0x5A761B：w<=0 → 内层空——golden w-zero gc=1 实证，四角 +
    起点格仍判）。
    每格 (cx,cy)：
      a. ★高度一致性比对（0x5A75B8 GetCellAt → 0x5A75C3 movsx
         edx,[cell+0x11B]; 0x5A75CA cmp edx,[esp+0x1C]; 0x5A75CC
         jne 0x5A7636 → 与起点格高度不等 → 整体 fail，★不查谓词）
      b. tile=[cell+0x38] → 5 谓词链按序（0x5A75D0-0x5A7603）：
         p. 0x4866D0（tile ∈ [paved, +0xf)，[0xABBEC8]）：过 →
            flagA!=0 → 继续（0x5A7607 检查，0x5A760D je fail）
         q. 0x4866F0（tile ∈ [paved4, +4)，[0xABBEC4]）：过 →
            ★共用 flagA（0x5A7607）
         r. 0x486380（tile==0xFFFF || tile==0）：过 → 直接继续
            （0x5A760F，不查 flag）
         s. 0x486650（tile ∈ [misc, +0xE)，[0xAA10A4]）：过 → 直接继续
         t. 0x486670（tile ∈ [pavet, +0x10)，[0xABC2B0]）：过 → 直接
            继续；全失败 → 整体 fail（0x5A7603 je 0x5A7636）
  · 返回 al：全过 1（0x5A762F mov al,1）/任一失败 0（0x5A7639
    xor al,al）。判定函数（调用方用 al 分支）。
  RNG 不参与（golden 零采样，全段无随机取数）。

★谓词窗口宽度（与 batch 934 同源，dump 实锤）：
  0x4866D0：[paved, paved+0xf)，[0xABBEC8]，★宽度 0xf
  0x4866F0：[paved4, paved4+4)，[0xABBEC4]
  0x486380：==0xFFFF || ==0
  0x486650：[misc, misc+0xE)，[0xAA10A4]
  0x486670：[pavet, pavet+0x10)，[0xABC2B0]

★原版怪癖（golden 实证，C++ 侧逐条复刻）：
  ① 高度先于谓词：扫描格高度 != 起点格高度 → 立即 fail（不查谓词）。
     golden height-mismatch 实证：gc=7（起点1+扫描6）但 p6d0=5——
     末格 (10,7) 高度 9≠7 在谓词链前被拦下。
  ② 双前置谓词门控共用 dl 单标志：6D0/6F0 通过后检查 flagA，为 0 时
     **整体失败**——golden flagA-zero gc=2 实证首格即 fail（起点1+
     首扫描格1，其余格未访问），与 7250 的 flagB 机制同构但无第二
     标志。
  ③ 起点格无条件先查：h-zero/w-zero gc=1（矩形空，但起点格 GetCellAt
     照查、期望高度照存）。
  ④ 谓词链序：6D0 → 6F0 → 380 → 650 → 670，前两个带 flag 门控、
     后三个直接继续（与 7250 相同；与 76E0 边带 670→380→650 不同）。
  ⑤ 角 1/3、2/3 的加宽坐标先 32 位求值再 movsx 截断回 16 位。
  ⑥ 谓词/GetCellAt 全是有符号比较（jl/jge），tile 按有符号 int32 读；
     cell+0x11B 高度按有符号字节（movsx）读。
