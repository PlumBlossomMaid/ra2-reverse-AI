★语义：**Westwood 虚表槽 0x40 分派双路径操作器（推断名—
—[ecx+0x764] 存在性分派的对象方法）**——thiscall：
  ① [ecx+0x764] 非 0 → 5 参虚表槽调用（edx+1&~1 对齐值、
     [ecx+0x764] 指针、5、this）；
  ② [ecx+0x764] == 0 → 4 参虚表槽调用（edx+1&~1、1、7、
     this）；
  ③ 槽返回 0 → 成功 eax=-1；非 0 → 失败（-4 标志非 0 路
     径 / -6 标志 0 路径）。
  = 对象方法经虚表槽 [ecx+0x40] 分发到变长参数子例程的
  包装（参数面随 [ecx+0x764] 存在性变化）。

★调用点（探针 E8 实测 1 处 0x7C295C）：宿主 0x7C295C 区
  （0x7C29xx——batch 1096 调色板域 0x7C1BE0 同簇后邻，
  表对象方法链）。

★E8 被调者：**零 E8 调用**（虚表槽 call dword[ecx+0x40]
  间接分派，无直接子调用）。

★虚表槽契约（★归属判定关键）：[ecx+0x40] 虚表槽分派与
  batch 1057 已登记 0x7C0530（虚表对象方法家族第 3 成员）
  同契约（[esi+0x40] 虚表槽派发）——Westwood 对象方法
  标准形态。

★原版怪癖（照抄）：
  ① [ecx+0x764] 存在性分派——两路径参数面不一致（5 参
     vs 4 参）；
  ② edx+1&~1 对齐（inc edx/and edx,0xfffffffe）两路径
     共用——偶数化处理（单元尺寸推断）；
  ③ 常量 5 vs 1/7 两路径参数差异——标志非 0 传对象指针
     +5、标志 0 传 1+7（语义不对称照抄）；

  ⑤ 失败码 -4/-6 硬编码（0xfffffffc/0xfffffffa）——
     两路径独立失败值；
  ⑥ 成功统一 or eax,-1（非 xor eax,eax）——-1 成功语义
     （0 保留给失败判定）。
