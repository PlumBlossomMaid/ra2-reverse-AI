一、语义（完整汇编逐段核对 + 黄金 10 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码逐段确认）：
  · 调用约定：thiscall，ecx = this（16 字节结构），无栈参，普通 ret
    （0x5A78B9）。this 布局：+0 低16 = x（movsx esi, cx 有符号）、
    +4 低16 = y（movsx edx, di）、+8 = w（int32）、+0xC = h（int32）。
  · 四角菱形判定（0x5A76E9-0x5A77FA），任一失败 → 0x5A78BA 返回 0：
    - 角 0 = (x, y)、角 1 = (x+w-1, y)、角 2 = (x, y+h-1)、
      角 3 = (x+w-1, y+h-1)（角 1/3、2/3 的加宽坐标先 32 位 lea 求值
      再 movsx dx 截断回 16 位——★原版怪癖，照抄）
    - 每角四判据（对角 (X,Y)，判据顺序固定）：
        X+Y <= W      → fail（0x5A7702 jle，W = [0xABED04]）
        X-Y >= W      → fail（0x5A770E jge）
        Y-X >= W      → fail（0x5A7718 jge）
        X+Y >  W+2H   → fail（0x5A772A jg，W+2H = [0xABED08]）
    - == 菱形区域：W < X+Y <= W+2H 且 |X-Y| < W。golden 三 corner-fail
      用例（x+y<=12 / 角1 33>28 / 角2 43>28）各打一条失败路径。
  · 内块扫描（0x5A7800-0x5A7859，3×3）：外层 y ∈ {y..y+2}、内层 x ∈
    {x..x+2}（x 优先，golden inner-fail gc=5 实锤遍历序）：
    - CellStruct{x16, y16} → GetCellAt(0x5657A0)（thiscall ecx=0x87F7E8
      MapClass::Instance）→ tile = [cell+0x38]（dword，有符号比较）
    - tile ∈ [PavedRoads, PavedRoads+1]（[0xABBEC8]，★闭区间——内联
      0x5A782C-0x5A7839 cmp/jl/inc/jle，与谓词的半开区间不同，golden
      inner-paved+1 tile=16∈[15,16] 直接过且 p730=0 实锤）→ 直接通过
    - 否则 0x486730（tile ∈ [Medians, Medians+14)，[0xAA0E20]）→
      通过 or fail
  · 边带扫描（0x5A785B-0x5A78AE，3 格 (x..x+2, y+3)）：
    - GetCellAt → tile，按序三谓词（任一通过继续下一格，全失败 → fail）：
        0x486670（tile ∈ [PaveTile, +16)，[0xABC2B0]）→ 通过
        0x486380（tile==0xFFFF || tile==0）→ 通过
        0x486650（tile ∈ [MiscPaveTile, +14)，[0xAA10A4]）→ 通过
    - golden edge-ffff（0xFFFF 走 p380）、edge-misc（205 走 p650）、
      edge-fail（300 三谓词全拒 → 第 1 格即 fail，gc=10=9+1 实锤短路）
  · 全过 → 0x5A78B3 mov al,1 返回 1。RNG 不参与（0x65C780 零调用，
    golden 各用例 rng 恒 0）。
  · 四谓词反汇编（2026-10-19 dump，四个 .qwen/tmp/_486*_dump.txt）：
    - 0x486670/0x486730/0x486650 三窗口谓词同构：mov eax,[ecx+0x38];
      mov ecx,[窗口]; cmp eax,ecx; jl 返 0; add ecx,跨度; cmp eax,ecx;
      jge 返 0; mov al,1 返 1——★有符号 jl/jge，半开区间 [base,base+跨度)
      （跨度：670=0x10，730/650=0x0E）
    - 0x486380：cmp eax,0xFFFF; je 返 1; test eax,eax; je 返 1; 返 0

三、C++ 模型（code/rewrite/rmg/dead_code_76e0.{h,cpp}）
------------------------------------------------
签名：int DeadCode76E0(const DeadCode76E0Context& ctx)；ctx 携带
DeadCode76E0World* / raw_x,raw_y,w,h / w_bound,w2h_bound / 四窗口基址。
world 抽象真身语义：CellTile（0x5657A0，返回 tile）、IsPaveTile
（0x486670 半开 [pavet,pavet+16)）、IsVoidTile（0x486380 ==0xFFFF||0）、
IsMiscPaveTile（0x486650 半开 [misc,misc+14)）、IsMedianTile（0x486730
半开 [medians,medians+14)）。实现要点：
  · 角坐标 16 位截断：角 0/2 的 X、角 0/1 的 Y = (int16)raw；角 1/3 的
    X = (int16)(w+raw_x-1)、角 2/3 的 Y = (int16)(h+raw_y-1)（32 位
    求值再截断，0x5A773B/0x5A7786 movsx dx 照抄）
  · 单角四判据顺序固定：X+Y<=W / X-Y>=W / Y-X>=W / X+Y>W+2H，全有符号
  · 内块：外层 y、内层 x（x 优先）；tile ∈ [paved, paved+1] 闭区间直通
    （★与谓词半开区间不同），否则 IsMedianTile 失败即返 0
  · 边带：3 格 (x..x+2, y+3)，PaveTile→VoidTile→MiscPaveTile 顺序，
    全失败返 0
  · 返回 1/0（mov al,1 / xor al,al）
