一、语义（全 0x33B=827B 四段反汇编逐条核对 + 诊断槽值实证 + golden 闭环）
------------------------------------------------
真义（disasm.py 0x5A5020 0x33B，thiscall ecx=this ret 0）：
  · this->[0x60] = 有符号 int this60（fild dword 读）
  · A. 数组初始化两循环（0x5A505B-0x5A508D）：
       0xABE378 起 12B 步长写首 dword = [0xABC1D4]+i（101 项到 0xABE834）
       0xABE834 起 12B 步长写首 dword = [0xABBEC0]+i（8 项到 0xABE894）
  · B. [esp+0x40] = _ftol((double)this60+0.32)*3.0 ——内层完成数上限
       （fild dword → fadd 0.32 → fmul 3.0 → _ftol 0x7C5F00）
  · C. 外层循环（[esp+0x24] 轮次 <10 且 [esp+0x18] 内层完成数<上限）：
       内层选点（0x5A50B1）：v=PickRange(0x598030, ecx=0, edx=side²-1)
       → work[v].xy==(0,0) 判空重抽（0x42D470 构造 (0,0) 临时 +
       0x50E470 判等：x==0 && y==0 返回 1 → jne 0x5A50BC 重抽）
       → 成功点计数 [esp+0x20]++（上限 20）→ ebp>200 强制坐标 (0,0)
       → GetCellAt(0x5657A0)→0x486380 谓词失败 → 重选（ebp 保留）
       → [esp+0x20]<20 时 work[y*side+x].+0x45!=0 走 ±7 邻域扫描
       （GetCellAt→0x4863D0 命中 → ebp=0 重抽）→ 概率判定（0x5A51C6）
  · D. 概率判定（0x5A51C6）：r=Random()（0x65C780）→ fild qword 无符号
       （高 32 位显式 0）→ *kInvUintMax（[0x7ED898]）→ fild dword this60
       → fsubr 1.0（[0x7E1718]）→ fcompp（比较 1.0-this60 vs r·kInv）
       → fnstsw ax; test ah,0x41（=C0|C3 实测：C0=AH bit0、C3=AH bit6）
       → jne 0x5A5238（magic 路径）；ST0>ST1（C0=C3=0）→ 三连调路径
       ★★整数 this60≥1 时 1-this60≤0 恒 ≤ r·kInv∈[0,1) → **三连调
       分支不可达**（C++ 两分支照抄，golden 只覆盖 magic 路径——实锤）
  · E. magic 路径（0x5A5238）：[esp+0x20]==20 → 跳过五连调；
       magic 除法定标（0x5A5243-0x5A5273）：(int32)0x88888889 ×
       (H*W*2) imul 高位 + 修正 → W=H=100 → magic=1916
       → 双段选 scale/offset（0x5A5279-0x5A52CB）：
         段 1 预置：scale=300.0（[esp+0x48..4C]={0,0x4072C000}）、
         offset=magic（fild/fst 存回 double）
         magic-300 > 2000 → 段 2（scale=0x408DB000 位模式=950.0、
         offset=0x40906800 位模式=1050.0）
         否则 magic+300 > 100 → 段 1（用预置）；否则段 2
       → NormalDeviate(0x5980C0) 拒绝循环（0x5A52CF-0x5A52F9）：
         do st0 = ND*scale+offset while (st0<100 || st0>2000)（接受 [100,2000]）
       → _ftol → h → 0x5A5360(&coord, h)（2 栈参 ret 8；返回对象）
       → 对象非 0 → 五连调 0x5A5B50/0x5A6510/0x5A6920/0x5A78D0 →
       虚函数调用（0x5A5337 mov edx,[esi]; 0x5A5342 call [edx]，push 1）
       ★★0x5A5333 mov ecx,[esp+0x18]; mov edx,[esi]; inc ecx; push 1;
       mov [esp+0x1c],ecx——push 之后 [esp+0x1c]==push 前 [esp+0x18]！
       "写错槽"实为内层完成数+1（golden 3/6/9 轮退出机制）
  · F. 三连调路径（0x5A51F8，不可达但照抄）：al=0x5A89D0(&coord)；
       al 非 0 → 0x5A82E0 → 0x5A8720 → inc [esp+0x18]（不动 [esp+0x24]）

★随机消耗非定值：PickRange 空格重抽 + 概率判定 Random 每轮无条件 1 次
  （NormalDeviate 打桩零消耗）；golden next 字段对拍消耗次数与路径。

★诊断槽值实证（.qwen/tmp/_diag_5a5020c.py，this60=1/side=8）：
  · [esp+0x18]（内层完成数）每轮五连调后 +1：0→1→2→3
  · [esp+0x40]=3（上限）；+18=3 >= +40=3 → jge 退出（3 轮）
  · RNG 消耗每轮 2 次（PickRange 1 + 概率判定 1），total=6 next=0xF4AE1A0E
    ——与 golden 完全一致

三、本批实锤（三条，均为调试关键）
----------------------------------
① **x87 状态字位布局**（.qwen/tmp/_verify_fcom_sw.py 实测）：
   fcompp + fnstsw ax 后 **C0 = AH bit0（0x01）、C3 = AH bit6（0x40）**
   ——test ah,0x41 = C0|C3。概率判定「1.0-this60 vs r·kInvUintMax」
   的 fcompp 方向据此确定：jne 走 magic 当 ST0<=ST1（C0 或 C3 置位）。
   （此前凭记忆推断 C0 在 AH bit3——实测推翻，全项目浮点判定统一口径）
② **NormalDeviate 打桩值必须落拒绝循环接受窗口**：0x5A52E9
   test ah,1 / jne 重取 拒 st0<100；0x5A52F9 test ah,0x41 / je 重取
   拒 st0>2000 → 接受 [100,2000]。桩值 2500.0 → st0≈75 万恒>2000 →
   死循环（探针 300s 超时仅打印 [seed 0]）；改 0.2 → 1976 落窗一次通过。
   ★拒绝循环是"重取 ND"不是"重取 Random"——ND 打桩零 RNG 消耗，
   golden next 不受拒绝循环影响；真身 ND 缓存串留给后续批次。
③ **push-1 槽错位**：0x5A533A push 1（esp-4）之后 0x5A533C
   mov [esp+0x1c],ecx 实际写入 **push 前的 [esp+0x18]**（内层完成数槽）
   ——"写错槽"实为内层完成数+1。诊断日志 [0x5344 outer-inc] +18 从 0→1
   逐轮递增实证；golden 3/6/9 轮退出机制的唯一解释。

四、原版怪癖（照抄）
--------------------
① 数组初始化两循环 12B 步长（0xABE378 101 项 + 0xABE834 8 项）；
② 内层上限 = _ftol((this60+0.32)*3.0)——fadd 0.32 在 fmul 3.0 **之前**
   （加法先于乘法，浮点顺序敏感）；
③ work[v].xy==(0,0) 判空重抽（0x50E470 两 u16 相等判定）；
④ ebp>200 强制坐标 (0,0)（选点重试上限，200 次兜底）；
⑤ [esp+0x20] 成功点计数上限 20（≥20 跳过邻域扫描、magic 路径跳过五连调）；
⑥ magic 除法定标 (int32)0x88888889 有符号 imul（负乘数！）+ add mw +
   sar 4 + 符号修正（W=H=100 → 1916）；段 2 常量是 double 高 32 位
   位模式 {0,0x408DB000}=950.0 / {0,0x40906800}=1050.0；
⑦ NormalDeviate 拒绝循环接受 [100,2000]（<100 或 >2000 重取 ND）；
⑧ ★push-1 槽错位 = 内层完成数+1（"写错槽"实现计数）；
⑨ 三连调路径不动 [esp+0x24]（outer）——golden 未覆盖（不可达），照抄；
⑩ 虚函数调用二次解引用（mov edx,[esi]; call [edx]——vtable 槽存函数
   地址，对象首字段是 vtable 指针）。
