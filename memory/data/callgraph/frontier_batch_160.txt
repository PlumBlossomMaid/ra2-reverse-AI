0x477E10  容器构造器（batch 092/136 同族，11 callers）
================================================================================
机器码还原（前 0x50）：
    mov ebp, [esp+0xC]             ; ★ 参数（初始容量?）
    mov esi, ecx                    ; this
    test ebp / je 收尾
    mov ebx, [esp+0x18]             ; ★ 参数（外部缓冲指针?）
    mov byte [esi+0xC], 0           ; ★ +0xC 持有标志清零
    test ebx / jne 采用外部
    lea eax, [ebp*4] / call 0x7C8E17  ; ★ CRT::_new(容量×4)（batch 001）
    mov edi, eax
  采用外部:
    mov edi, ebx
    test edi / mov byte [esi+0xC], 1   ; ★ 持有标志置 1
    je 分配失败
    mov eax, [esi+4] / test / je 跳过
    mov ecx, [esi+8] / cmp ebp, ecx ...
    ; ★（按 min 拷贝旧数组 → 释放旧 → 存新指针）

语义：**0x477xxx 容器家族的构造/扩展成员**——按容量分配（外部缓冲优先否则
_new(容量×4)），拷贝旧数组后挂新指针、置 +0xC 持有标志。★与 batch 092
（0x42FCB0 外部缓冲 ctor）、batch 136（0x477BE0 同区 ctor）、batch 145
（0x477D20 同区析构/索引）**同家族**——0x477xxx 区容器的构造端补全。

★跨批次连接：batch 092/136/145（容器家族）+ _new/_delete 三件套 +
0x477xxx 区对象基建。

⚠️ partial：参数语义（容量/外部缓冲精确排布）、拷贝与释放细节（0x477E88 起）、

0x735090  宽→窄转换（batch 137 反向闭合，11 callers，0x2B 全读完）
================================================================================
机器码（全 0x2B）：
    cmp word [edx], 0 / je 写终止符  ; ★ 宽串首字符 == 0
    mov esi, [esp+8]               ; ★ 长度上限（-1=无限）
    test esi / je 写终止符
  loop:
    mov al, [edx]                   ; ★ 取宽串字节（低 8 位）
    add edx, 2 / mov [ecx], al      ; ★ 写窄串（1 字节）
    inc ecx
    cmp esi, -1 / je 跳过计数       ; ★ 无上限 → 不递减
    dec esi
  跳过计数:
    cmp word [edx], 0 / jne loop    ; ★ 遇宽串 '\0' 停
  写终止符:
    mov byte [ecx], 0 / ret 4       ; ★ 窄串终止符

语义：**宽串→窄串转换器（wchar_t* → char*）**——逐宽字符把低字节写入窄串，
遇宽串 '\0' 或长度上限（arg2，-1=无限）停，末尾写窄串终止符。★batch 137
闭合：当时登记 0x735060（窄→宽）标注「紧邻 0x735090 是反向宽→窄版」——
本批正式立案，0x735060/0x735090 转换对双向闭合。

★跨批次连接：batch 137（0x735060 窄→宽对）+ batch 151（0x7B7F90 用 0x735090
的 operator= 组合）——宽窄串转换家族。

⚠️ partial：无（0x2B 全读完）；长度上限语义（-1=无限 与 batch 137 同款
cmp esi,-1）。
