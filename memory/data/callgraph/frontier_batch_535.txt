**语义（推断名）**：**GDI 网格文本绘制器**——把网格对象的字符/颜色缓冲绘到窗口：
① **双门控**：`[0xABF23A]` 字节标志非 0 **且** `this == [0xABF23C]`（头槽）才绘制；
② **DC 前置**：`GetDC([0xABF240])` → `SetBkMode(hDC,2=TRANSPARENT)` →
   `SetBkColor(hDC,[0xABF128])` → `SetTextColor(hDC,[0xABF110])`；
③ **选字体**：`SelectObject(hDC,[0xABF244])` 并保存旧对象；
④ **双层遍历**：外层 = param2..param2+param4（列），内层 = param1..param1+param3（行），
   逐格 `call 0x5BD3D0(this, hDC, 列, 行)`；
⑤ **收尾**：恢复旧字体 + `ReleaseDC`。
签名推断 = `(int rowStart, int colStart, int rowCount, int colCount)`。
★原版怪癖（照抄）：① **双门控只放行头槽**（[0xABF23C] 只在 0x5BC180 里被赋为
首槽对象 → 8 槽中**只有 idx 0 能绘制**）；② **hDC 为空提前返回但已调三次 GDI
设置且不 ReleaseDC/不恢复字体**（资源处理不对称）；③ `SelectObject` 返回值
保存于栈槽 `[esp+0xC]` 供恢复（旧字体）；④ 循环边界 = 起点 + 计数（非终点直给）。
★跨批次闭合：**batch 307（0x5BC180 八槽位布局表构造）**——该批实锤 0x5BC180
用 `(0,0,0x50,0x19)` 四参调 0x5BD490 做"初始化"，**本批证伪该命名**：0x5BD490
不是初始化器而是**绘制器**，构造时调用它 = 把刚建好的空网格（全 0x20 空格）
**首绘一次**；0x2738B 对象布局由此闭合（见下）。

⚠️ partial：宿主窗口身份（[0xABF240] hWnd 归属窗口类——UI 网格/菜单推断）、
`[0xABF1C8]/[0xABF1D8]/[0xABF1E0]` 定位常量语义（像素步进推断）、
`[0xABF23A]/[0xABF23C]` 精确含义（已初始化标志 + 头槽指针推断）。

**语义（推断名）**：**网格单格绘制回调**（thiscall，ecx = 网格对象；3 栈参
= hDC, 行, 列）：
① **读颜色**：`this[(行*25+列+500)*4]`（dword 网格，偏移 500 个 dword = 2000
   字节处起）；与缓存 `this+0x2714` 相同则跳过两个 Set*Color（**GDI 调用去重**）；
② **选色（两常量交叉）**：
   - 值 == 1 → `SetBkColor(hDC,[0xABF110])` + `SetTextColor(hDC,[0xABF128])`
   - 值 != 1 → `SetBkColor(hDC,[0xABF128])` + `SetTextColor(hDC,[0xABF110])`
   然后 `this+0x2714 = 颜色值`（更新缓存）；
③ **画字符**：`TextOutA(hDC, x=步进*列+10, y=[0xABF1E0]*行+10, &this[行*25+列], 1)`
   （字节网格字符，单字符输出）。
★对象布局（**由索引算式反推，与 batch 307 的 0x2738B 精确吻合**）：
```
this+0x0000 .. 0x07CF : byte 字符网格 [80 行 × 25 列]（行主序，index = 行*25+列）
this+0x07D0 .. 0x2713 : dword 颜色网格 [80 × 25]（index = 行*25+列）
this+0x2714           : dword 颜色缓存（上次绘出的颜色值）
```
（2000 字节 byte 网格 + 8000 字节 dword 网格 = 0x2710，+4 缓存 = 0x2714；
对象总大小 0x2738 = batch 307 op_new 实锤值 —— **闭环**。）

★原版怪癖（照抄）：① **两颜色常量交叉使用**（值 1 与非 1 各把两常量对调分配给
BkColor/TextColor）；② **颜色缓存去重**（`this+0x2714` 与当前值相同则完全跳过
Set*Color —— 相邻同色格只设一次）；③ **单字符 TextOutA**（cchString 恒 1，
逐格一次 GDI 调用 —— 无批量优化，原版口味）；④ **行/列索引非对称**（字符与
颜色网格用同一 index 算式但对颜色网格 +500 dword 基址）；⑤ 坐标各 +10 像素
硬偏移（写死 0xa，无配置）。
