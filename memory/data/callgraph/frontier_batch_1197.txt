  ④ 返回读入项数（eax 透传核心结果）。
  = fread 公开入口的锁包装层（核心 + 加解锁 = CRT FILE 读
  侧公开形态）。

★原版怪癖（照抄）：
  ① 锁 Enter/Leave 各用 push [ebp+0x14] 单独压 FILE*
     （cdecl 1 参）——锁对象显式重传；
