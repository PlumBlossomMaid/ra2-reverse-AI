一、函数体全读（92B，disasm 0x7D7DC0 0x60 全量）
------------------------------------------------

push ecx×2 留 8B 槽 + fld/fstp 压入）、[ebp+0x10] = 栈参3（输出结构
指针 esi——宿主 &[ebp-0x10]）、[ebp+0x14] = 栈参4（缓冲指针 edi——
宿主 &[ebp-0x28]）。
机器码（92B 全读，逐段要点）：

    [ebp+8]（★&double）→ push edi → push eax（★压 &[ebp+8]）→ lea
    eax,[ebp-0xc] → push eax（★压 &[ebp-0xc]）→ call 0x7d7e1c（★紧邻
    double 拆解器：cdecl 2 参，先压 &[ebp+8] 为参数2、后压 &[ebp-0xc]
    为参数1——输出写 [ebp-0xc]）→ pop ecx ×2（清参）
  组装格式化: lea eax,[ebp-0x28]（★缓冲）→ push eax（★参数4=&缓冲）
    → push 0（★参数3）→ push 0x11（★参数2=17）→ sub esp,0xc（★留
    12B 结构槽）→ mov edi,esp → movsd ×2 + movsw（★★拷 [ebp-0xc] 的
    10B 拆解结构作参数1）→ call 0x7db207（★★格式化主函数：cdecl 4
    参——10B 结构/0x11/0/&缓冲）
  输出结构组装: mov esi,[ebp+0x10]（★栈参3=输出结构）→ mov edi,
    [ebp+0x14]（★栈参4=缓冲）→ mov [esi+8],eax（★★结构+8=0x7DB207
    返回）→ movsx eax,byte[ebp-0x26]（★缓冲+2 字节，带符号）→ mov
    [esi],eax（★★结构+0）→ movsx eax,word[ebp-0x28]（★缓冲首 word，
    带符号）→ mov [esi+4],eax（★★结构+4）→ lea eax,[ebp-0x24]（★缓
    冲+4）→ push eax → push edi（★缓冲）→ call 0x7d4bf0（★★batch
    008 string_copy_legacy——复制缓冲）→ add esp,0x20
  收尾: mov [esi+0xc],edi（★★结构+0xC=缓冲指针）→ mov eax,esi（★返
    回结构指针）→ pop edi → pop esi → leave → ret

  0x7D7E1C（IEEE 754 double 手动拆解器）把 8B double 拆成 10B 结构写
  [ebp-0xc]；② 拷贝 10B 结构 + 参数 0x11/0 + 缓冲指针调用 0x7DB207
  （十进制格式化主函数，写缓冲）；③ 组装输出结构 {+0: 缓冲+2 字节

  指针}；④ 经 0x7D4BF0 复制缓冲；⑤ 返回结构指针。★★与 batch 905
  的 0x7D7D49 成对：0x7D7D49 消费本函数结构 {+0xC 源串指针 / +4 指数
  字段} 做四舍五入/指数调整——**CRT 浮点格式化链前置段**。
