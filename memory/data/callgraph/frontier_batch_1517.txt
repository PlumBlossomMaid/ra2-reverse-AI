0x5B4590 —— 链表摘除器（45B 全程读完）
================================================================================
签名：thiscall 无栈参 ret（ecx=this=摘除节点；0x5B4590-0x5B45BC）。
机器码结构（0x5B4590-0x5B45BC，全程读完，关键锚点）：
    段1 校验：test ecx → je 0x5B45BC（★null 直接返回）→ mov edx,
    [ecx+4]（★前向）→ test → je 0x5B45BC → mov eax,[ecx+8]（★后向）→
    test → je 0x5B45BC（★三空检查）
    段2 摘除：mov [eax+4],edx（★★后向节点的前向 = 本节点前向——贯通）
    → mov eax,[ecx+4] → mov edx,[ecx+8] → mov [eax+8],edx（★★前向节点
    的后向 = 本节点后向——贯通）→ mov [ecx+8],0 → mov [ecx+4],0（★★
    本节点前向后向清零）→ ret
语义：**链表摘除器（推断名——45B「双向链表摘除 + 节点清零」）**——把
[ecx] 节点从双向链表摘除：后向节点的前向（[eax+4]）接本节点前向、前
向节点的后向（[eax+8]）接本节点后向，然后本节点 [+4]/[+8] 指针清零
——纯摘除（无重挂）。
★怪癖：①★★三空检查（this/前向/后向任一空直接返回——悬挂节点保
护）；②★★摘除后节点指针清零（[ecx+8]=0/[ecx+4]=0——与 batch 117
0x40E340 的摘除半段逐指令同款）；③★★纯摘除无重挂（与 0x40E340 的
「摘除+重挂到新链」区分——本版只摘除）；④★与 batch 104（0x407450
摘除+自环）同族。
