三、三态判定（为何 crt_runtime_verified 而非 cpp_reimplementation）
----------------------------------------------------------------
1. 归属：四十四函数均在 0x7C-0x7D = MSVC6 静态 CRT
   （ra2_code_region_layout_crt_provenance）；转换/MultiByte
   ToWideChar/Sleep/DeleteCriticalSection/IsBadWritePtr 全为
   Windows API 调用方壳；long double 族 = x87 数学内核；
   异常魔数 = MSVC EH 基础设施；uc=0 死代码。
2. 依赖：挂靠目标全部已登记（0x7D4715/0x7D473F/0x7D475A/
   0x7D4811/0x7CC0A5/0x7D544A/0x7DC1C2 等；IAT 槽 0x7E11C4=
   MultiByteToWideChar/0x7E11F0=Sleep/0x7E11E4=DeleteCritical
   Section/0x7E129C=IsBadWritePtr 逐一解引用实锤）——重写
   用等价运行时（stdlib + WinAPI 声明）代替。
3. gamemd_replication_discipline：MSVC6 CRT 标准设施 + 死
   代码，按商业库纪律归档，不写 C++ 模型不做 golden。
→ 状态：crt_runtime_verified ×44（头段定性 + 家族归类 +
