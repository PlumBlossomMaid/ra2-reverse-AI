★语义：**CRT `calloc`（推断名——num×size 分配 + 清零）**——
cdecl 2 参（num, size）：
  ① num×size（imul——calloc 决定特征）；
  ② 0 → 补 1；16 字节对齐（+0xF & ~0xF）；
  ③ 对齐后 <= [0x87C584] 小分配阈值 → 锁 9 临界区走 0x7CFB13
     小分配器 → 命中后 memset(0) 清零（小块无 ZERO_MEMORY）；
  ④ 大块 → HeapAlloc(heap, HEAP_ZERO_MEMORY=8, size)（大块自
     带清零）；
  ⑤ 失败 → [0xB782C4] 门控 0x7D06E8 失败处理 → 有效则重试循环
     （jmp 0x7D3394）；无效 → 返回 0。

★原版怪癖（照抄）：
  ① imul 无溢出检查（num×size 回绕——乘法前无校验）；
  ② 0 字节补 1（malloc 语义对齐）；
  ③ 对齐用 add 0xF + and ~0xF（非 roundup 除法）；
  ④ 小块走 CRT 小分配器 + 显式 memset（0x7D75E0）清零、大块
