================================================================================

```
004d0444  push esi / mov esi,ecx         ; this
004d0447  xor edx,edx
004d0449  cmp eax,edx                    ; size==0?

004d0466  je 0x4d0471                    ; array==0 → 自分配
004d0468  mov [esi+4],ecx                ; this->+4 = 外部缓冲（★直用）

004d047d  mov [esi+4],eax                ; this->+4 = 新缓冲
004d0480  mov byte [esi+0xd],1           ; ★+0xD = 1（自分配标志）
004d0484  mov eax,esi / pop esi / ret 8
```
**语义（推断名）**：**VectorClass 构造器**——`Vector(size, array)`（**YRpp
`VectorClass(int size=0, T* array=0)` 签名吻合**）：`+0xC=1`、`+8=size`、`+4=0`、
虚表 0x7E192C；size≠0 时 array≠0 → **外部缓冲直用**（`+4=array`，不自分配）；
array==0 → **`operator new(size×4)`** 自分配（`+4=新缓冲`、`+0xD=1` 标记）。
★原版怪癖（照抄）：① **`+0xD` 自分配标志仅在 array==0 路径置 1**（外部缓冲
路径保持 0——"谁分配谁负责释放"的运行时标记）；② `size==0` 时**完全跳过
分配段**（`+4` 保持 0、`+0xD` 保持 0——惰性构造）；③ `+0xC` 恒 1（与 size 无关）；
④ 参 2 优先级高于自分配（**外部缓冲直用不复制**——非 `new+copy`，是裸接管）；
⑤ `shl eax,2` = `size×4`（元素 4 字节，未乘元素类型尺寸——调用方已按 T 换算）；
⑥ 虚表 0x7E192C 直接写（非通过 ctor 链）。
★跨批次（同族连接）：**batch 384 `0x7C8E17`（CRT operator new）第 2 消费点**；
虚表 **0x7E192C**（0x7E19xx .rdata 虚表区）；ret 8 = 2 栈参（size/array）。
★新登记：**VectorClass 字段 [+0]（虚表）/ [+4]（数据指针）/ [+8]（容量）/ [+0xC]/
[+0xD]（自分配标志）**；虚表 **0x7E192C**；「外部缓冲 vs 自分配」双路径构造惯用。
