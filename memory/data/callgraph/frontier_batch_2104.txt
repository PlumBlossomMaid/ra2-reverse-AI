## 原版怪癖（照抄）

1. a 路 `inc ecx`（元素指针 +1 跳过首字节）再字符串比较——元素是**前缀字节 + 字符串**结构；未命中 `xor ax,ax` 只清低 16 位（eax 高位残留计数高 16 位——计数 < 0x10000 时恰为 0）；
2. a 路与 batch 2103 b 0x664400 是 **+0x25 读写对**但匹配惯用法不同（0x664400 = movsx 首字节 ==，本路 = 0x7c8d20 字符串比较）；
3. b 路 **环形缓冲 [0xa802d4] 128 槽**，索引递增 `and 0x7f` 环形回绕，满 0x80（jge）时**跳过记录拷贝但函数指针调用与结果写照做**；
4. b 路记录 111B = rep movsd 27 dwords + movsw + movsb 拼装（无 0x6F 显式常量，寻址用 lea 链 ecx*9→*37→*111）；
5. b 路字节值 0xb04e9c ==5 走不同 sprintf 格式串（0x839bbc vs 0x839be8）；
6. c 路清空是 **O(n²) 逐元素 delete + 整体左移**（非标准的计数清零/批量 delete）；
7. c 路 [edi+0x28] 写 **1<<i** 位掩码（按外层循环索引置位而非按对象 ID）；
8. c 路扩容走 Vector 虚表槽 8（call [edx+8]），owns([esi+0xd]) 非零或容量为 0 时强制扩容路径。
