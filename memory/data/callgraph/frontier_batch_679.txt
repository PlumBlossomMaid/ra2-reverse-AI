=== 语义 ===

**COM 接口查询持有器（推断名）**：__thiscall 1 栈参 ret 4。this = 调用
方栈上的输出槽（持有 COM 指针，+0）；栈参1 = 对象字段地址（&obj->+0x674）：
① 字段对象非空时对其做 QueryInterface(虚表槽 0, 0x819088 的 GUID, &out)
（__stdcall 三参：push out/push IID/push this）；② 成功：this->+0 旧指针
Release（虚表槽 8）→ 存入 out（QI 结果）→ 返 HRESULT；③ 失败：this->+0
旧指针 Release → 清 0 → 返 HRESULT；④ 字段空：this->+0 旧指针 Release →
清 0 → 返 E_NOTIMPL(0x80004002)。

★调用形态：调用方 `push &obj->+0x674; lea ecx,[esp+N]（输出槽）;
call 0x45AF20`——this 不是对象而是栈槽，QI 结果写入调用方局部变量。

★IID = {92FEA800-A184-11D1-B70A-00A024DDAFD1}（"Weapons factory" 接口
