一、链语义（disasm 全段复核）
------------------------------------------------
0x7CA845(19B) = MSVC6 CRT 句柄表操作包装（0x7C-0x7D 静态 CRT 区）——
cdecl 2 栈参（参数1/参数2），固定压常量 0x40 转调 0x7CA814：
  push 0x40                    ; ★常量 0x40 第三参数
  push [esp+0xC] ×2            ; ★参数1 转发两次（压栈后 [esp+0xC]
                               ; 先后指向参数2、参数1）
  call 0x7CA814                ; ★句柄表操作主体
  add esp,0xC / ret            ; cdecl 弹 12B（3 参）
  等价：return 0x7CA814(p1, p2, 0x40)

被调 0x7CA814(47B) 全段复核（batch 226 已录，本批交叉确认）：
  push esi / call 0x7D2DA6    ; ★★取表项（句柄表查找，Handles 层）
  mov esi,eax / test esi,esi
  jne 0x7CA822 / pop esi / ret ; ★未命中返 NULL
  0x7CA822: push edi / push esi / push [esp+0x18] ×3
  call 0x7D2C36                ; ★★三参操作（首参=句柄）
  push esi / mov edi,eax
  call 0x7CB44B                ; ★★流锁 Leave（batch 961 归档）
  add esp,0x14 / mov eax,edi / pop 族 / ret

★语义：**句柄表操作包装**——0x7CA845 固定压 0x40（长度/模式/权限位
推断）+ 参数转发 0x7CA814；后者 0x7D2DA6 取句柄（未命中返 NULL），
命中则 0x7D2C36 三参操作并以 0x7CB44B 流锁 Leave 收尾，返回
0x7D2C36 结果。

③0x7D2DA6 未命中返 NULL 即短路返回——不消费后续参数。
