================================================================================

    edi = [esp+0x10]        ; 源对象（栈参 1）

    jle 0x47781E            ; 容量<=0 → 跳过

    ecx = [ecx+eax*4]       ; 源[i]

alloc-hook 推断）；④+0xC 恒 1、+0xD 随分配置 1/0；⑤复制循环用 [esi+8]
