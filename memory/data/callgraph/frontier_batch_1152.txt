一、链语义（disasm 全 125B + 双调用现场 + 字段族跨批交叉，
0x7C19F0-0x7C1A6A）
--------------------------------------------------------------
签名（推断）：thiscall + edx 隐式查找键 + 2 栈参 ret 8——
ecx=this、edx=key、[esp+0x14]=参1（输出 word）、[esp+0x18]=
参2（输出 word，值-1）。字段族：this+0x74C = 16 位项数、
this+0x754 = word 表指针（步进 6 字节/项，比较首 word）。

主体（0x7C19F0-0x7C1A6A）：
007c19f0  push ebx/mov ebx,[ecx+0x754]       ; ★★word 表指针
007c19f7  push ebp/push esi/xor esi,esi/xor eax,eax
007c19fd  mov si,word[ecx+0x74c]             ; ★★16 位项数
007c1a04  mov ecx,1
007c1a09  cmp esi,ecx/push edi/jle 0x7c1a2d  ; ★项数<=1 → 直出 esi-1
; → 区间扫描顶（0x7C1A11，步进 6B/项）：
007c1a0e  lea edi,[ebx+6]
007c1a11  xor ebp,ebp/mov bp,word[edi-6]     ; 前一项首 word
007c1a17  cmp edx,ebp/jl 0x7c1a24            ; ★key < 前项 → 前进
007c1a1b  xor ebp,ebp/mov bp,word[edi]       ; 当前项首 word
007c1a20  cmp edx,ebp/jl 0x7c1a30            ; ★★key < 当前项 → 命中
007c1a24  inc eax/inc ecx/add edi,6          ; ★★步进 6 字节/项
007c1a29  cmp ecx,esi/jl 0x7c1a11            ; 循环
007c1a2d  lea eax,[esi-1]                    ; ★未命中 → 末索引
; → 输出段（0x7C1A30）：
007c1a30  test eax,eax/jne 0x7c1a3a
007c1a34  xor ecx,ecx/xor edx,edx            ; ★eax==0 → ecx=0/edx=0
007c1a38  jmp 0x7c1a3f
007c1a3a  lea ecx,[eax-1]/mov edx,eax        ; ecx=eax-1/edx=eax
007c1a3f  mov esi,[esp+0x14]/test esi,esi/je 0x7c1a52
007c1a47  lea ecx,[ecx+ecx*2]                ; ★参1 索引 ×3
007c1a4a  xor edi,edi/mov di,word[ebx+ecx*2] ; 表[ecx*6B] 首 word
007c1a50  mov [esi],edi                      ; 参1 ← 表值
007c1a52  mov ecx,[esp+0x18]/test ecx,ecx/je 0x7c1a66
007c1a5a  lea edx,[edx+edx*2]                ; ★参2 索引 ×3
007c1a5d  xor esi,esi/mov si,word[ebx+edx*2] ; 表[edx*6B] 首 word
007c1a63  dec esi                            ; ★★值-1
007c1a64  mov [ecx],esi                      ; 参2 ← 表值-1
007c1a66  pop edi/esi/ebp/ebx/ret 8

★语义：**Westwood 表面调色板 CIN 组 word 表区间查找器（推
断名）**——在 this+0x754 的 6 字节/项表中按 key（edx）定位
所在区间索引 eax（表[eax-1] 首 word <= key < 表[eax] 首
word）；输出：
  ① 参1 ← 表[ecx]（ecx = eax==0 ? 0 : eax-1，即前一档）
     首 word；
  ② 参2 ← 表[eax] 首 word - 1（命中档上界-1）。
  = batch 1147（0x7C06B0 PIN 组）的同族模板——本批 CIN 组
  消费侧（步进 6B/项 + 项内偏移 0 首 word 比较）。

★调用点（探针 E8 实测 2 处，均在 0x7C07D5 体内）：
  0x7C07E3（第一段：`mov edx,ebx` 键 + push 双输出指针）
  与 0x7C07F8（第二段：`mov edx,[esi+0x184]` 换键 + push 0×2
  输出 NULL）——与 batch 1147 宿主 0x7C0530 内 0x7C0578/
  0x7C0595 双调用模式同构（两次查找 + 比较）。

★E8 被调者：**零子调用**（全 125B 纯 word 表扫描 + 输出）。

★字段族跨批交叉（★★本批最强证据）：this+0x74C（16 位项
  数）+ this+0x754（表指针）与 **batch 1105 调色板块装载器
  CINH/CIND 组装载现场逐字段重合**——batch 1147 的 0x7C06B0
  消费 PIN 组（this+0x758/0x760）、batch 1150 提及 LINH/LIND
  组（this+0x714/+0x71C）——本批是 CIN 组消费侧，三组装载
  器字段族全景消费侧第二件（PIN→CIN）。

★原版怪癖（照抄）：
  ① 步进 **6 字节/项**（`add edi,6`）而 batch 1147 是 2 字
     节/项——CIN 组表项 6B 布局（首 word 参与比较，余 4B
     未用）；
  ② 输出索引换算用 `lea ecx,[ecx+ecx*2]`（×3）后 `[ebx+
     ecx*2]`（=×6B 偏移）——×3×2 复合缩放；
  ③ eax==0 特判 `xor ecx,ecx/xor edx,edx`（参1 索引 0/参2
     索引 0）而 eax>0 时 ecx=eax-1/edx=eax——参1 索引比
     命中索引少 1（前一档）而参2 用命中索引（上界）；
  ④ 参2 恒 `dec esi`（值-1）——上界-1 语义；
  ⑤ 两输出指针独立 test/NULL 跳过（0x7C07F8 段传 NULL×2
     只取参1 返回值 eax）；
  ⑥ 项数<=1 直接返 eax=esi-1 不查表。

   （混入样本链 #17）**，非 MSVC6 静态 CRT——证据：

      法调用约定，MSVC6 CRT 无此形态；

      载器逐字段重合（同对象邻近方法），且与 batch 1147

      0x7C0530 同 0x7C07xx 对象方法域）体内，双调用模式
      同构；
