★语义：**Westwood 像素格式转换器（推断名——RGB888 →
RGB565/RGB555/16 位）**——cdecl 7 参（源指针/目标指
针/宽度/R 乘数/G 乘数/B 乘数/行指针）：
  ① 三路分派：门控 [0x84E862]（MMX）→ MMX 宽路径；
     [0x84E860]（SSE/增强）→ 标量 565；全 0 → 标量 555；
  ② 每通道独立乘数（imul [ebp+0x10]/[ebp+0x14]/
     [ebp+0x18]）+ 饱和钳制（test/cmovne [ebp-4]）；
  ③ RGB 位域打包（R 5 位 + G 6 位/5 位 + B 5 位 →
     16 位 word 输出）；
  ④ 被主代码区 blit 循环逐行调用（行步进 0x200）。

★门控写入者实锤（E8 全 exe 扫描）：
  [0x84E862] = 0x7C5FE7/0x7C5FF5（0x7C5FC0 区 CPUID 检
  测——cpuid/test edx,0x800000 → MMX 标志）；
  [0x84E860] = 0x7C6024/0x7C603A/0x7C6050（0x7C6000 区
  CPUID 检测——cpuid/test edx,0x8000 → SSE 标志）；
  四孪生读点：0x7DE20D/0x7DE547/0x7DE887/0x7DEBC7（本
  批 + 0x7DE53A/0x7DE87A/0x7DEBBA 三个同族变体）。

★原版怪癖（照抄）：
  ① 三路分派由两个全局门控字节决定（CPU 特性检测写入

三、三态判定（为何 semantics_verified 而非 crt_runtime_verified）

1. 归属：0x7DE200 = **Westwood 自有代码**——①caller =
   0x556344 主代码区 blit 循环（7 参 + 行步进 0x200 逐
   行转换）；②RGB 位域打包 + 每通道乘数 = Westwood 调
   色板/像素转换惯用；③三路 CPU 门控分派（MMX/SSE 特
   化）——非 CRT 标准函数形态。

   CPUID 检测 0x7C5FC0 区）——重写时按语义等价实现
   （std::transform 或直写）。
