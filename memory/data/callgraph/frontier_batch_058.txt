0x007CBED3  CRT _initterm
================================================================================
26B，6 条指令：

    007cbed3  push esi
    007cbed4  mov esi, [esp+8]            ; 表首
    007cbed8  cmp esi, [esp+0xc]          ; 表尾
    007cbedc  jae  0x7cbeeb
    007cbede  mov eax, [esi]
    007cbee0  test eax, eax
    007cbee2  je   0x7cbee6               ; 跳过 NULL 项
    007cbee4  call eax                    ; 调用函数指针
    007cbee6  add esi, 4
    007cbee9  jmp  0x7cbed8
    007cbeeb  pop esi / ret

判据：按 [begin,end) 字节区间逐 dword 取值、非 NULL 则 call —— MSVC6
静态 CRT 的 _initterm 标准实现（C++ 全局构造/析构函数指针表遍历）。

0x007CBDAF  CRT C++ 静态构造分发（_cinit）
================================================================================
45B：

    007cbdaf  mov eax, [0x87BEB8]
    007cbdb4  test eax, eax
    007cbdb6  je   0x7cbdba               ; 为 0 则跳过
    007cbdb8  call eax                    ; 早期 CRT 钩子
    007cbdba  push 0x815DBC               ; 表尾
    007cbdbf  push 0x815DA8               ; 表首
    007cbdc4  call 0x7cbed3               ; _initterm
    007cbdc9  push 0x815DA4               ; 表尾
    007cb dce push 0x812000               ; 表首
    007cbdd3  call 0x7cbed3               ; _initterm
    007cbdd8  add esp, 0x10 / ret

两轮 _initterm，表区间分别为 [0x812000,0x815DA4) 与 [0x815DA8,0x815DBC)。
注意两表之间恰好跳过 0x815DA4..0x815DA8 四字节 —— 典型的 .CRT$XCU 分段
布局（各 TU 的静态构造段按字母序分段，中间是段头指针）。
