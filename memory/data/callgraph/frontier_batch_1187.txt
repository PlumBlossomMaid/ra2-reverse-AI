★语义：**MSVC6 CRT 宽字符格式化字符串包装器（推断名——
swprintf 族变体）**——cdecl 变参：
  ① 栈上手工装配 FILE 结构（sub esp,0x20）：_ptr=_base=目
     标缓冲、_cnt=wcslen(buf)*2（宽字符双字节计数）、
     _flag=0x49；
  ② 3 参委派 _woutput(FILE*, 格式串, vararg 起点地址)；
  ③ 返回 _woutput 结果（eax 透传）。
  = 宽 sprintf 包装（swprintf 变体），把格式串输出写进目
  标缓冲。

★调用点（探针 E8 实测 1 处 0x695D52）：Westwood 主代码
  区（0x69xxxx）。现场 0x695D45-0x695D52：lea ecx,[ebp+
  0x90]（vararg 缓冲）/push 0x81b3d0（★★格式串常量 = .data
  区 L"%d" 宽字符——0x81B3D0 字节 25 00 64 00 00 00 =
  UTF-16LE "%d\0"；紧邻其后是独立 ASCII 串 "%s: %s\n
  Scheme: %d\n Lost = %d\n Kills = %d" 属另一常量）/push
  edx（[eax*4+0x83EB58] 表取值=目标缓冲）/call——主区把整
  数格式化进宽字符缓冲（L"%d"）。

★原版怪癖（照抄）：
  ① FILE 结构**栈上手工装配**（mov 逐字段写 [ebp-0x14]/
     [ebp-0x18]/[ebp-0x1C]/[ebp-0x20]）而非 CRT 标准宏初始
     化；
  ② _cnt = wcslen(buf)*2（宽字符双字节计数）而非标准

     局怪癖；

     va_list 实参传递）；
  ⑤ eax 重复使用（mov eax,[ebp+8] → push eax → 两次 mov
     存 _base/_ptr）——编译器寄存器调度；
  ⑥ 空缓冲也走 wcslen——无空指针保护；
  ⑦ eax 透传 _woutput 结果（无额外处理直接 leave/ret）。
