一、语义（137B 全读 + emu 黄金闭环）
------------------------------------------------
真义（黄金实证，★★推翻 docs/dead-code-functions.md:149「Random()*10.0/2³²
  + 0.5*arg − 0.02*euclid」——逐字节追栈证明 [esp+0xC]（pop esi 后）= sqrt
  结果 float32 槽、[esp+0x14]（pop esi 后）= 第三栈参 arg3；机器码是唯一
  权威）：
  ① dx/dy = p1-p2 坐标差（movsx word 带符号读 int16）
  ② d2 = dx*dx + dy*dy（int32 imul 回绕——大坐标回绕成负值）
  ③ s32 = ChopFloat(FastSqrt((double)(int32)d2))（★fstp dword 窄化 float32
    ——与 0x5A2ED0 存 qword 不同！）
  ④ u = (double)(uint64)Random()（fild qword 无符号扩展）
  ⑤ 返回 u * kInvUintMax * 10.0f + 0.5f * (double)s32
       - 0.02f * (double)(int32)arg3（全程 RC=chop）
  权重常量（.rdata 实证）：0x7ED764=0.5f / 0x7ED768=10.0f / 0x7ED76C=0.02f。

★arg3 敏感性验证：arg3=100 → 结果减 2.0（0.02×100）、arg3=-32768 → 结果

  fsubp` 完全吻合，黄金锁死「第三栈参参与权重减法」。

三、C++ 模型（code/rewrite/rmg/dead_code_jitter.{h,cpp}）
------------------------------------------------
签名：double DeadCodeDistanceJitterF(Randomizer& rng, int16 ax/ay/bx/by,
  int32 arg3)。
实现链：dx/dy int32 → d2 int32 回绕 → FastSqrt → ChopFloat（fstp dword
  窄化）→ (double)(uint64)Random() → ChopJitterChainF：
  u*kInvUintMax（RC=chop 1 次）→ ×10.0f（精确）→ + 0.5f*s32（RC=chop 1
  次）→ − 0.02f*arg3（RC=chop 1 次）。
★浮点环境坑：原版 x87 全局 RC=chop，C++ SSE 默认 round-to-nearest——
  与 batch 924 同修法（MXCSR _MM_ROUND_TOWARD_ZERO + volatile 防重排）；
  非 x86_64 降级同数学语义（主对拍平台为 x64）。
