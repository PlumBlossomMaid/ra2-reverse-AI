================================================================================
0x006D2140  TacticalClass::CoordsToClient —— 等距世界坐标→客户端屏幕坐标
================================================================================
53 callers（符号名 USER_DEFINED，YRpp 覆盖，按推断名标注）。
`sub esp,8` + push 四寄存器，入参是指向 {x,y,z} 三个 int32 的结构。骨架：

    mov esi, [ebx]              ; x
    mov eax, [ebx+4]            ; y
    mov ebx, [ebx+8]            ; z
    lea eax, [esi+esi*2]        ; x*3
    lea eax, [eax+eax*4]        ; x*15
    shl eax, 2                  ; x*60
    cdq / sub eax,edx / mov ecx,eax / sar ecx,1   ; x*60/2 = x*30（带符号）
    lea eax, [esi+esi*2] / lea eax,[eax+eax*4] / shl eax,1 / sar → x*15
    mov eax, edi (arg2) / shl eax,4 / sub eax,edi / neg eax / shl eax,2 / sar → -arg2*30
    add ecx, eax                ; x*30 + (-arg2*30)

判据：**RA2 等距格子的屏幕像素尺寸是 60×30**（宽 60、高 30 像素/格），
`CoordsToClient` 的核心就是把格坐标乘上这些尺寸——`x*60/2 = x*30`、
`arg2*16-arg2 = arg2*15 → *2 = arg2*30` 是「格坐标 × 屏幕格子半宽/半高」
的定点运算（`cdq/sub/sar` 是带符号除 2 的经典序列）。

**等距投影的实锤**：横向 `+30`、纵向 `-30` 的组合（`x*30` 加 `arg2*(-30)`）
正是等距投影「X 右下、Y 左下」的斜向布局——X 轴和 Y 轴在屏幕上各占
30 像素的水平/垂直分量。这与 RA2 等距菱形地图的投影几何完全吻合。

⚠️ partial：z（高度）如何叠加、以及 30/60 这组常数是否还有别的来源
（如视野缩放）未实锤。

0x0042D510  二维点加法（坐标运算）
================================================================================
50 callers。全部 0x27 字节：

    0042d510  mov eax, [esp+8]            ; arg：另一坐标对
    0042d514  mov dx, word [eax]          ; arg.x
    0042d517  mov ax, word [eax+2]        ; arg.y
    0042d51b  add ax, word [ecx+2]        ; arg.y + this->y
    0042d51f  add dx, word [ecx]          ; arg.x + this->x
    0042d522  mov [esp+0xa], ax
    0042d527  mov eax, [esp+4]            ; arg：输出指针
    0042d52b  mov [esp+8], dx
    0042d530  mov ecx, [esp+8]
    0042d534  mov [eax], ecx              ; *out = (x,y) 打包
    0042d536  ret 8

即 `(this->x + arg.x, this->y + arg.y) → *out` 的**二维点加法**
（thiscall，ecx=this；两坐标都是 int16，add word 级相加，溢出按 int16
回绕）。是 Point2D/Vector 类的 `operator+` 或 `Add`。

紧邻的 `0x42D540` 是另一函数（清 +0x10、条件 delete +0x4、清标志字节
+0x0D/+0x08），与本函数不同族。
