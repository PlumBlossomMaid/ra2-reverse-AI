★语义：**MSVC6 CRT RTTI 类型查询辅助（推断名——_RTDynamicCast
族）**：
  ① SEH 帧（_except_handler3 + scope 0x7F9630）；

  ⑤ 槽调用非 0 → 构造 0x80F038 异常并 throw；
  ⑥ AV 过滤器捕获 0xC0000005 → handler 转 0x80F038 异常。
  = RTTI 类型查询/动态转换标准支持代码（MSVC6 C++ EH + RTTI
