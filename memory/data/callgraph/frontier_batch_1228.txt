一、语义（全段反汇编逐条核对 + golden 40 行闭环）
------------------------------------------------
真义（机器码全 259B 确认，disasm.py 0x58C5A0 0x103）：
  · 调用约定（★与 0x58C4A0 不同）：
    - ecx = 输出指针（[esp+0x14] 槽，出入口都读它）
    - edx = arg2（入口 `mov [esp+0x1c],edx`，0x56D230 返回值比较基准）
    - 栈参1 = arg3（[esp+0x3c]；==-1 跳过 [0x38] 比对，否则须相等）
    - ret 4（清 1 个栈参 = arg3）
  · side  = [0x89C2DC]；total = side*side（imul）
  · scale = (double)(uint64)total（fild qword [esp+0x20]：高 32 显式 0）
  · loop（0x58C5E3 起循环头）：
      r = Random()（mov ecx,0xABE890 / call 0x65C780）
      v = _ftol((double)(uint64)r * scale * kInvUintMax)
        （mov {eax=r,edi=0} → fild qword 无符号 → fmul [esp+0x30]=scale
          → fmul [0x7ED898]=kInvUintMax → call 0x7C5F00 _ftol）
      cmp eax,esi（esi=total-1）/ ja 0x58C5E3 —— 拒绝采样（无符号，
        ★回循环头只重取随机数，不消耗尝试计数）
      p = [0xABED10] + v*0x50（lea esi,[eax+eax*4]; shl esi,4 = v*0x50）
      ★rep movsd 0x14 dword（80B）把 work[v] 复制到 work[0]
        （edi=ebx=[0xABED10] work 基址）——「当前格」= 复制后 work[0]
      ★inc [esp+0x10]（0x58C623）→ cmp 0x64 / jge 0x58C685
        —— **100 次尝试上限**（inc-before-cmp 同 0x58C4A0，见二、(1)）
      ★cell = GetCellAt(0x5657A0, &work[0])（thiscall ecx=0x87F7E8，
        1 栈参=坐标指针 ret 4）→ esi = cell
        （★GetCellAt 先于空格判定——0x58C637 call 在 0x58C63C cmp 之前）
      if (work[0].x == 0 && work[0].y == 0) goto loop     （空格子重抽）
      ★if (0x56D230(0x87F7E8, cell+0x24, 0, 0) != [esp+0x1c](=arg2))
        goto loop （thiscall +3 栈参 ret 0xC；0x58C654 call / 0x58C659
        cmp / 0x58C65D jne；golden 打桩注入固定返回值）
      if (0x486380(cell) == 0) goto loop                  （谓词判定：
        cell+0x38 == 0xFFFF || == 0 → al=1 通过）
      if (arg3 != -1 && work[0].[0x38] != arg3) goto loop（arg3==-1 跳过，
        0x58C672-0x58C67E；成功出口 0x58C6A3 直达）
      *out = work[0] 首 dword（x | (y<<16)）；ret 4
  · fail（0x58C685）：xor 0 写 *out = (0,0)；ret 4
    （★不额外采样——已消耗的 Random 不退）

公式（golden 40 行实证）：
  loop: v = _ftol((double)(uint64)Random() * (double)(side*side)
            * kInvUintMax)
        若 (unsigned)v > side*side-1 → 重取随机数（不计数）
        rep movsd 复制 work[v] 80B → work[0]；attempts++
        若 attempts >= 100 → 失败返回 (0,0)
        cell = GetCellAt(&work[0])
        若 work[0] 为 (0,0) → 重抽
        若 0x56D230(cell+0x24) != arg2 → 重抽
        若 !CellPass(work[0]) → 重抽
        若 arg3 != -1 且 work[0].[0x38] != arg3 → 重抽
        返回 work[0] 首 dword（x | (y<<16)）

★与 0x58C4A0 的差异（末级三条）：
  ① **0x56D230 谓词替代 field44 检查**——本函数无 field44 判定，
     返回值须 == arg2（第三重前置判定换成查表谓词）；
  ② **edx=arg2 + 栈参 arg3 双参数契约**（arg3==-1 跳过 [0x38] 比对，
     0x58C4A0 无此豁免）；
  ③ 判定顺序：GetCellAt → 空格 → 0x56D230 → 0x486380 → arg3
     （0x58C4A0：类型 → 空格 → field44 → GetCellAt 谓词）。

(1) ★★本批实锤一：Unicorn TB 缓存坑（自修改代码失效）
  修好 EDX 传递（探针初版误写 EAX，0x58C5BD 实际读 EDX——所有用例
  全拦截）后，主探针同进程多用例仍异常：case3（d56=0x22）行为与
  case1（d56=0x11）完全一样（out=0x50004、next=0x6A2B5556，只耗 1 次
  随机数）——本该走 100 次失败路径。独立进程单用例诊断
  （.qwen/tmp/_diag_58c5a0.py/_diag_58c5a0b.py）则完全正确：
  stub 字节 b822000000c20c00、ret_to=0x58C659、cmp eax=0x22 vs
  slot=0x11 → 每轮 jne 重抽 → 100 次失败（out=0x0、
  next=0xB7E560BA）。
  根因：**Unicorn 2.1.4 指令翻译块（TB）缓存**——mem_write 改
  0x56D230 打桩字节后，同进程第二次 emu_start 复用 case1 首次翻译
  的 TB，新桩不生效。
  修复：每次写桩后 `o.uc.ctl_remove_cache(D56, D56 + 8)`。
  教训：同进程多次改码（打桩 imm 逐例变化）必须显式失效 TB；
  否则「单跑对、连跑错」的假数据会污染 golden。

(2) ★★本批实锤二：100 次上限计数器语义（同 0x58C4A0）

(3) ★golden 与探针同源：40 行全部由修复后探针重采（含 TB 失效），
