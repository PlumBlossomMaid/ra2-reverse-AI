★语义：**CRT `_putenv` 环境设置器（推断名——getenv 链第三段）**：
  ① param1="key=value" 串（param2=冗余拷贝标志，0 跳过写系统环境）：
     找 '='（0x7DC378 strchr 类）拆 key/value；'=' 在串首或缺失 → -1；
  ② ebx = ('=' 后是 NUL)?1:0 ——「删除式」（无值）与「赋值式」区分；
  ③ 环境表 [0xB781E4]（表头）/[0xB781EC]（表尾）/[0xB781E8]（已建
     标志）——表头未建且 param2!=0 且表尾空 → 先互调 0x7D461E
     （getenv 构建器）物化 ANSI 表；表头为 0 时 malloc(4) 初始化；
  ④ 0x7DAB54 查 key 索引：命中 → 删除式（free 旧值 + 数组左移 +
     realloc 收缩）/ 赋值式（覆盖槽）；未命中 → realloc 扩容追加
     （新槽 = 串 + 尾 NULL）；
  ⑤ param2!=0（写系统环境）→ malloc 拷贝 "key=value" → '=' 处写
     NUL 拆两份 → SetEnvironmentVariableA(key, value) → free；
  ⑥ 返回 0 成功 / -1 失败（NULL/无 '='/建表失败/realloc 失败）。

★原版怪癖（照抄）：
  ① 删除式（key=）与赋值式（key=value）双路径——'=' 后是否 NUL
     用 sete 精确判定；
  ② 表头未建时先 getenv 构建器物化（0x7D461E）再操作——两函数
     构成 getenv/putenv 共享表；
  ③ 删除式数组左移用 esi 计数 + edi 步进 4 手写循环（非 memmove）；
  ④ 写系统环境时先拷贝拆分（'=' 处 and [eax],0 破坏拷贝而非原串）；
  ⑤ SetEnvironmentVariableA 只走窄字符（ASCII 环境）；
  ⑥ realloc 失败全部短路 -1（表头/表尾/扩容三处独立判）。
