一、链语义（全段 disasm 复核 + golden 13 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7CA090 = MSVC6 静态 CRT 重叠感知
字节拷贝 `memmove`——cdecl 3 栈参、ret 无栈清理、返回 dst：
  · 入口：esi=[ebp+0xC]（src）、ecx=[ebp+0x10]（count）、
    edi=[ebp+8]（dst）、eax=src+count
  · 重叠判定：
      cmp edi,esi / jbe 正向        ; dst <= src → 正向
      cmp edi,eax / jb 反向(0x7CA228) ; src < dst < src+count → 反向
      （否则 dst >= src+count → 正向）
  · 正向路径（0x7CA0B0）：
      test edi,3 / jne 0x7CA0CC     ; dst 未 4 对齐 → 先逐字节对齐
      shr ecx,2 / and edx,3 / cmp ecx,8 / jb 跳转表
      rep movsd / jmp [edx*4+0x7CA1D8] ; 对齐 dword 复制 + 尾部补齐
      （非对齐：mov al,[esi]/mov [edi],al 逐字节补齐至对齐后同走）
  · 反向路径（0x7CA228）：
      lea esi,[src+count-4] / lea edi,[dst+count-4] ; 尾部指针
      test edi,3 / jne 0x7CA25C     ; dst 未 4 对齐 → 先对齐
      shr ecx,2 / and edx,3 / cmp ecx,8 / jb 跳转表
      std / rep movsd / cld / jmp [edx*4+0x7CA370] ; 反向 dword + 补齐
      （非对齐：反向逐字节对齐后同走）
  · 收尾（各路径汇聚）：mov eax,[ebp+8]（返回 dst）/ pop esi/pop edi/
    leave / ret

★原版怪癖（golden 实证，C++ 侧逐条复刻）：
  ① 返回 eax = dst（入口即存、永不修改）；
  ② 重叠判定：dst<=src 或 dst>=src+count 走正向；src<dst<src+count
     走反向（memmove 保序语义）——与 0x7D0A20（lowlevel.cpp 的
     std::memmove 包装）同语义但独立实现；
  ③ 正向/反向均按 dst 4 字节对齐优化（rep movsd + 尾部跳转表
     0x7CA1D8/0x7CA370），对齐优化不改变最终字节内容（行为等价）；
  ④ 无溢出防护，纯逐字节/dword 复制。

三、C++ 模型（code/rewrite/runtime/crt_memmove.{h,cpp}）
------------------------------------------------
namespace ra2::runtime。单函数（纯内存复制，无世界抽象）：
  memmove_090_legacy(dst, src, count) —— 0x7CA090：
    dst<=src 或 dst>=src+count → 正向逐字节拷贝；
    src<dst<src+count → 反向逐字节拷贝（保序）。
  返回 dst。
无失败路径、无额外校验。

★命名决策（LNK4006 事件）：低层 lowlevel.cpp 已有 `memmove_legacy`
（0x7D0A20，std::memmove 包装，lowlevel.h:83-84 声明），本批首版
误用同名 → 链接器 `memmove_legacy 已在 lowlevel.cpp.obj 中定义；已
忽略第二个定义`（0x7CA090 复刻被忽略）。经 grep 确认冲突后决定
**改名 memmove_090_legacy**（补丁 .qwen/tmp/_patch_943_rename.py，
三文件 7 处替换）——0x7CA090 与 0x7D0A20 是两个独立函数（对齐优化
+ 反向 rep movsd + 跳转表 vs std::memmove 薄包装），独立命名避免
符号冲突与语义混淆。
