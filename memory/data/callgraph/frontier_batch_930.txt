一、语义（完整汇编逐段核对 + 黄金 5 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码逐段确认）：
  · 共用约定：thiscall 无 this，ret 0x10 四栈参——栈参1 = 输出坐标指针
    （写最终坐标 dword：低 16 = X、高 16 = Y；出界写 0）、栈参2 =
    参考坐标 CellStruct*（兼初始坐标源，[esp+0x10] 打包初值）、栈参3 =
    区域 {x,y,w,h}（[esp+0x44]）、栈参4 = 方向参数（[esp+0x48]）。
  · 0x5A6D80（定向步进 + 命中分支 + 距离采样 + 反向补步）：
    ① 档位（0x5A6DB0-0x5A6DFF）：direction==2 → (edi,ebx)=(1,3)、
       [esp+0x1c]=-3、[esp+0x18]=6、ebp=0、off14=0；
       direction!=2 → (edi,ebx)=(3,1)、ebp=-3、off14=6。
    ② 主循环（0x5A6E01）：movsx 判界 X>=w+x 或 Y>=h+y → 0x5A6E79
       出界写 0；GetCellAt（0x5657A0，ecx=MapClass@0x87F7E8，栈参
       &[esp+0x10]）→ cell+0x38 == [0xABC2B0] → je 0x5A6E99 命中分支；
       否则 方向&7 查 [0x89F688] 方向表 → X+=dx、Y+=dy → 主循环。
    ③ 命中分支（0x5A6E99）：重新判界出界写 0；矩形
       {X+ebp, Y+off1c, edi+off14}（[esp+0x28]/[esp+0x2c]/[esp+0x30]）
       → push [esp+0x20]（栈垃圾，golden 观察 0）→ lea ecx,[esp+0x2c]
       → call 0x5A7250（打桩，azn/one_shot 序列）→ al 非零 → 成功路径。
    ④ 成功路径（0x5A6F55）：esi = max(Y-refY, X-refX)（有符号比较
       取大）；esi<=0 → 写当前坐标（hit-ok：起点=参考点距离 0 直写，
       rng=0 实锤）；否则拒绝采样 n = ftol(rand * (esi+1) * 2^-32)，
       n>esi 重抽（ja 无符号）；n<=0 → 写当前坐标；n>0 → 反向补步
       （0x5A6FCE）：(direction-4)&7 方向逐格，每步矩形
       {X+ebp, Y+i, edi+off14, ebx+off18} 调 0x5A7250，al==0 中止写
       当前坐标，n 走完写最终坐标。
    ⑤ ★命中失败路径（0x5A6EF6）：方向表步进后 jmp 0x5A6E9D **复用
       命中分支判界**（不再 GetCellAt）——golden 6d80-hit-fail 实证
       （首拒后第二格矩形 a=1 即步进到 (1,0) 继续命中分支）。
  · 0x5A7070（正向步进 + 反向随机补步）：
    ① 档位（0x5A70A4）：direction==2 → (esi,edi)=(1,3)、off14=-3、
       off1c=6；!=2 → (3,1)、off10=-3、off18=6。
    ② 主循环（0x5A70EE）：判界带 +1（X>=w+x+1 出界，区别于 6D80）；
       矩形 {X+offxx, Y+offyy, esi+offxx, edi+offyy} 每步调 0x5A7250
       （al==0 → 0x5A7192 补步；al!=0 → 方向表 (direction&7) 步进）。
    ③ 补步分支（0x5A7192）：idx=(direction-4)&7，目标 = 当前+方向；
       距离 = max(目标X-refX, 目标Y-refY)；<=6 → 直写目标（不吃 RNG，
       golden 7070-walk-back/fail-close 均走此支）；>6 → 拒绝采样
       n = ftol(rand * 4/2^32)（[0x7EDA38]），n>3 重抽；n<=0 直写；
       n>0 → 沿 idx 逐格补 n 步写最终坐标。
  · 常量（.rdata 取证）：[0x7ED898] = 2^-32×(1+2^-40)（采样缩放）、
    [0x7EDA38] = 4/2^32×(1+2^-40)（0..3 拒绝采样比例）。
  · 共表 [0x89F688] 方向表：.data 未初始化区（PE raw 范围外）= 真机全 0
    ——★怪癖：两函数主循环靠它步进，真机被调用会死循环；golden 灌
    DIR8 标准表（batch 928 只单次合成坐标不受影响，本批必须灌才能收敛）。
