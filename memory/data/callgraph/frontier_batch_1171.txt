一、链语义（disasm 全 73B + 调用点宿主核对，0x7CCFB3-0x7CCFFB）
--------------------------------------------------------------
签名（推断）：cdecl 3 参（[ebp+8]=数值、[ebp+0xC]=目标指
针槽、[ebp+0x10]=位数预算指针），就地写十进制 + 反转。

主体（0x7CCFB3-0x7CCFFB）：
007ccfb3  push ebp/mov ebp,esp/push ebx/push esi
007ccfb8  mov esi,[ebp+0x10]                    ; esi = 预算指针
007ccfbb  push edi
007ccfbc  mov edi,[ebp+0xc]                     ; edi = 目标指针槽
007ccfbf  mov ecx,[edi]                         ; ★★ecx = 目标缓冲首
007ccfc1  cmp [esi],1/jbe 0x7ccfe4             ; ★★预算 <=1 → 跳过直写
                                              ;   （边界门控）
; → 除 10 写字符循环（0x7CCFC6，右→左）：
007ccfc6  mov eax,[ebp+8]/push 0xa/pop ebx/cdq
007ccfcd  idiv ebx                              ; ★★除 10 取商余
007ccfcf  mov eax,[ebp+8]
007ccfd2  add dl,0x30
007ccfd5  mov [ecx],dl/inc ecx                 ; ★★余数+0x30 写字符
007ccfd8  cdq/idiv ebx                          ; 商继续
007ccfdb  dec dword[esi]                        ; ★★预算递减
007ccfdd  test eax,eax/jg 0x7ccfc6             ; ★商 >0 续写
007ccfe4  mov eax,[edi]
007ccfe6  mov [edi],ecx
007ccfe8  dec ecx
; → 就地字节反转（0x7CCFE9，字符串回正）：
007ccfe9  mov bl,[eax]/mov dl,[ecx]             ; ★★双指针交换字节
007ccfed  mov [ecx],bl/dec ecx
007ccff0  mov [eax],dl/inc eax
007ccff3  cmp eax,ecx/jb 0x7ccfe9              ; ★到相交停止
007ccff7  pop edi/esi/ebx/pop ebp/ret

★语义：**MSVC6 CRT 十进制 itoa 内联实现（推断名——batch
1153 0x7CCF44 的 [0xB78BB0]!=0 备用路径）**——cdecl 3 参：
  ① 预算 [ebp+0x10] >1 才进入写循环（jbe 直出）；
  ② 循环除 10（idiv 0xa）+ 余数+0x30 右→左写字符 + 预
     算递减 + 商 >0 续写（与 batch 1153 内联路径同款但改
     读 [edi] 指针槽——非双重缓冲）；
  ③ 收尾就地字节反转（eax 串首 / ecx 串尾双指针交换到
     相交）——写出的逆序串回正。
  = itoa 手写实现（除法取余 + 反转），备用路径（当
  [0xB78BB0]!=0 时替代 batch 1153 的 inline 路径）。

★原版怪癖（照抄）：
  ① 预算 `cmp [esi],1/jbe`——预算 0/1 都直出（不写）；
  ② 写循环从右→左（[ecx] 递增）后统一反转——与 batch
     1153 内联路径的左→右写（[ebp+0xC] 位置递减）相反
     （两条路径实现不同——复制粘贴不参数化）；
  ③ 反转双指针 eax/ecx 逐字节交换到 `cmp eax,ecx/jb`

     1153/1157 同款）；

     的 [ebp+0x10] 双重缓冲语义在此退化为指针槽）；
  ⑥ idiv 有符号除（cdq 扩展）——负数值符号位照抄。
