0x54F1C0 —— 循环缓冲写入器（62B 全程读完）
================================================================================
签名：thiscall + 1 栈参（16 位，仅低 16 位被读）ret 4。
机器码（0x54F1C0-0x54F1FE）：
    mov edx, [ecx+0x318]      ; edx = this->+0x318（当前写索引）
    push esi
    lea eax, [edx+1]          ; eax = idx+1
    and eax, 0x800000ff       ; 保符号位+低字节（模 256 回绕准备）
    jns 0x54f1d8              ; 非负 → 跳
    dec eax; or eax, 0xffffff00; inc eax   ; ★符号扩展 byte 回绕
    0x54f1d8:
    cmp eax, [ecx+0x314]      ; 新索引 vs this->+0x314
    je 0x54f1f9               ; == → 返回 0（满/失败）
    mov si, [esp+8]           ; si = 栈参（16 位）
    mov [ecx+edx*2+0x114], si ; this->+0x114 + idx*2 = 栈参（写 16 位项）
    mov [ecx+0x318], eax      ; 更新索引 = (idx+1) 回绕
    mov al, 1; pop esi; ret 4 ; 返回 1
    0x54f1f9: xor al, al; pop esi; ret 4

语义：**循环缓冲写入器**——this+0x318 是写索引（byte 回绕，步进 1），
this+0x114 起是 16 位/项的数组（edx*2 步进），this+0x314 是容量上限/哨兵。
新索引 == +0x314 时返回 0（不写）；否则写当前槽 [0x114+idx*2] = 栈参（低
16 位），索引前进，返回 1。9 unique caller（63 callsite）。

★怪癖：①★索引回绕是**带符号 byte**（and 0x800000ff + dec/or/inc 符号扩展
分支——不是朴素 &0xFF，高位置位走负路径）；②★容量判定用**相等**比较

字符/短值缓冲）；④栈参仅低 16 位被读（ret 4 清 4 字节）。

⚠️ partial：this+0x318 索引维护者、+0x314 上限语义（容量/水位）、+0x114
数组容量与宿主类（0x54Fxxx 网络/会话缓冲域）、栈参语义（写入值）、
调用约定（thiscall+1 参）。

0x412A40 —— 20列网格索引换算（115B 全程读完）
================================================================================
签名：3 栈参 ret 0xC（参1=a、参2=b；★参3 存在但从未读取）。
机器码（0x412A40-0x412AB3）：
    mov ecx, [esp+4]          ; a
    push esi
    mov eax, ecx; mov esi, 0x14（20）; cdq; idiv esi

    sar edx, 3                ; ★高 32 位 >>3（组合成 ÷20 商）
    mov eax, edx; shr eax, 0x1f; add edx, eax   ; 有符号商修正
    lea eax, [ecx+esi]        ; eax = b + (a%20)
    test eax, eax; pop esi; jl 0x412a7a
    cmp eax, 0x13（19）; jle 0x412a7a
    mov ecx, 0x13; jmp 0x412a84
    0x412a7a: xor ecx,ecx; test eax,eax; setl cl; dec ecx; and ecx,eax
                              ; ★eax<0 → 0，否则原值（钳制下界）
    0x412a84:
    mov eax, [esp+0xc]        ; b
    add eax, edx              ; eax = b + (a/20)
    test eax,eax; jl 0x412aa1; cmp eax,0x13; jle 0x412aa1
    mov eax, 0x13             ; 钳制上界 19
    lea eax, [eax+eax*4]      ; eax = 5*19 = 95
    lea eax, [ecx+eax*4]      ; ecx + 95*4 = ecx + 380 = ecx + 19*20
    ret 0xc
    0x412aa1: xor edx,edx; test eax,eax; setl dl; dec edx; and eax,edx

    ret 0xc

语义：**20×20 网格线性索引换算**——a 拆成商 q=a/20 与余 r=a%20（★同除 20
两种实现：余用 idiv 真除法、商用魔数乘法 0x66666667>>35），x = clamp(b+r,
0,19)，y = clamp(b+q, 0,19)，返回 x + y*20（20 列网格线性索引）。9 unique
caller（116 callsite）。

★怪癖：①★同除 20 双实现——idiv（取余）与魔数乘法 0x66666667 高 32 位
sar 3（取商），魔数验证：0x66666667/2^35 ≈ 0.0500000000004（÷20）；②★
钳制用 setl+dec+and 怪写法（eax<0→0，其余原值；>19→19 单独分支），非
cmov；③★第三栈参从未读取（ret 0xC 清 3 参但只用 2——cdecl 遗留）；④lea

⚠️ partial：调用者（116 callsite 分属谁）、参1/参2 语义（网格坐标偏移）、
