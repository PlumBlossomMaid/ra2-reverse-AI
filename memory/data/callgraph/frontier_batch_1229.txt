一、语义（全段反汇编逐条核对 + golden 24 行闭环）
------------------------------------------------
真义（机器码全 110B 确认，disasm.py 0x5A6BA0 0x6E）：
  · 调用约定：**thiscall 无栈参 ret 0**——ecx = 锚点 CellStruct
    {int16 x, int16 y}（`movsx word [ecx]` / `movsx word [ecx+2]`
    符号读；入口 `sub esp,8` + 栈上 CellStruct 局部）。
  · 循环（0x5A6BAE 起）：
      X = movsx word [ecx]；Y = movsx word [ecx+2]
      loop: x ∈ [X-7, X+7) 外层（lea edi,[ecx-7] 起，cmp edi,edx
            / jge 0x5A6BFA 退出返 1 —— ★X 边界先判）
            y ∈ [Y-7, Y+7) 内层（lea ebp,[eax-7] 起，cmp ebp,ebx
            / jge 0x5A6BF5 跳外层 —— ★Y 边界先判）
            每格：{x,y} 写入栈上 CellStruct 结构（mov word
            [esp+0x14],di / mov word [esp+0x16],si）→
            ★GetCellAt(0x5657A0，thiscall ecx=0x87F7E8，1 栈参=
            坐标指针 ret 4) → eax = cell 指针 → mov ecx,eax →
            ★0x4863D0(cell) 谓词 → test al,al / jne 0x5A6C04
            —— 谓词真 → 返 0（邻域内有可用格，提前退出）
  · 全邻域无命中 → 返 1（mov al,1——邻域全不可用）
  · ★★全程零取数点：不调 Randomizer（不消耗随机数——golden next
    字段实证：同种子所有用例 next 相同 = 调用前后 RNG 状态不变）

公式（golden 24 行实证）：
  X=[ecx]（int16）；Y=[ecx+2]（int16）
  for x in [X-7, X+7):
    for y in [Y-7, Y+7):
      if CellPass(GetCellAt(x,y)) return 0;   // 邻域内有可用格
  return 1;                                    // 邻域全不可用

★与其他死代码族的差异：
  ① 零取数点（58BE20 系每轮消耗 1 个随机数，本函数全程不碰 RNG）；
  ② 双层循环 ±7 邻域（不是拒绝采样）；
  ③ al 返回值语义反转（0=邻域内有可用格 / 1=全不可用）。

三、原版怪癖（照抄）
--------------------
① 零取数点（全程不调 Randomizer——与同族最大差异，golden next 实证）；
② ±7 邻域开区间 [X-7,X+7)×[Y-7,Y+7) 双层循环（外层 X 内层 Y）；
③ GetCellAt → 0x4863D0 谓词链（邻域内有可用格 → 提前返 0）；

   恒不触发，原版存在该分支，语义照抄）；
