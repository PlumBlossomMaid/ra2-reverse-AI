0x63D960 —— 分段循环调度器（86B 全程读完）
================================================================================
签名：非 thiscall（ecx=长度+2 计数、edx=第二参寄存器透传）+ 4 栈参 ret
0x10（0x63D960-0x63D9B3）。
机器码结构（0x63D960-0x63D9B3，全程读完，关键锚点）：
    push ecx → add ecx,-2（★n=ecx-2）→ push esi → test ecx,ecx → push
    edi → mov [esp+8],edx（★★edx 第二参存栈——借用 this 保存槽，this
    已用完）→ jg 0x63D974（★n>0 正常路径）→ 空路径：xor esi/xor edi →
    jmp 0x63D982（★esi=edi=0——见怪癖①）
    正常路径 0x63D974：mov eax,ecx → cdq → sub eax,edx（★ceil 修正）→
    mov edi,eax → sar edi,1（★★edi=ceil(n/2)——后半段起点）→ mov
    esi,edi → sub esi,ecx → inc esi（★esi=edi-n+1——前半段起点，可负）
    循环 0x63D982：cmp esi,edi → jg 0x63D9B0（★esi>edi 退出）→ 循环体
    0x63D986：push ebx → mov ebx,[esp+0x20]（★调用者参4）→ push ebp →
    mov ebp,[esp+0x20]（★调用者参3）→ mov eax,[esp+0x1C]（★调用者参2）
    → mov edx,[esp+0x10]（★★读回 edx 第二参保存槽）→ push 1（★常量
    1=最末参）→ push ebx → push ebp → push eax → mov eax,[esp+0x28]
    （★调用者参1）→ mov ecx,esi（★★this=esi 索引）→ push eax → call
    0x63D810（★★已登记 batch 285 坐标换算分发——5 栈参+ecx 签名吻合

    ebp/pop ebx → 0x63D9B0: pop edi/pop esi/pop ecx → ret 0x10
语义：**分段循环调度器（推断名——86B「n=ecx-2 分段 + 逐索引调 0x63D810」
）**——以 ecx-2 为段长 n，计算索引段 [esi..edi]（edi=ceil(n/2)、
esi=edi-n+1，段长恰为 n；n≤2 时 esi 可为负），从 esi 到 edi 逐索引为
this 调用 0x63D810（已登记坐标换算分发），每轮透传：edx 第二参（寄存器）
+ 调用者 4 栈参 + 常量 1（5 栈参——与 0x63D810 ret 0x14 签名完全吻合）。
★怪癖：①★★空路径（n≤0）不跳过——esi=edi=0 时 cmp jg 不跳，仍执行
一次循环体（this=0 调 0x63D810）——MSVC do-while 形态边缘行为，照抄；
②★段起点可负（n=1 时 esi=1、n=2 时 esi=0、n=4 时 esi=-1）——索引
从负数起调 0x63D810，调用者约定；③★edx 第二参借 this 保存槽透传
（[esp+8] 覆盖 push ecx 槽——寄存器参数透传惯用）；④常量 1 恒为最末栈参。
⚠️ partial：宿主语义（索引含义/0x63D810 在此上下文的业务角色）、调用者
4 参语义、2 unique caller。
