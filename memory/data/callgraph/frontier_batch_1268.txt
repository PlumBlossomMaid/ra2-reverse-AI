================================================================================
签名：thiscall + 2 栈参（[esp+4]=坐标结构指针、[esp+8]=第三字段值）ret 8。

    movsx edx, word [edx]     ; edx = (int16)*(int16*)(ptr+0)（★x）
    shl ecx, 8                ; y << 8
    add ecx, 0x80             ; +128（★四舍五入偏置）

    mov ecx, [esp+8]          ; 第二栈参
    add edx, 0x80             ; (x<<8)+128

caller（46 callsite）。函数区间 0x642740-0x64276F，ret 8 后 nop 对齐，
0x642770 起是下一函数（xor eax,eax; mov [0xac4f18]/[0xac4f1c] 全局清零）。
