一、语义（全段反汇编逐条核对 + golden 40 行闭环）
------------------------------------------------
真义（机器码全 107B 确认，disasm.py 0x5A5AE0 0x80）：
  · 调用约定：cdecl 2 栈参 ret 8，x87 返回 double：
    - [esp+0xC] = p1 坐标对指针（{int16 x; int16 y}）
    - [esp+0x10] = p2 坐标对指针（同上）
  · 坐标差（movsx word 有符号读 int16）：
      dx = p1.x - p2.x ; dy = p1.y - p2.y
      （0x5A5AEC-0x5A5AFC：movsx esi,[eax] / movsx edx,[ecx] /
       movsx eax,[eax+2] / movsx ecx,[ecx+2] / sub eax,ecx(dy) /
       sub esi,edx(dx)）
  · 无分支绝对值（cdq/xor/sub 惯用法，0x5A5AFE-0x5A5B0B）：
      adx = |dx| ; ady = |dy|（三份 cdq/xor/sub 对,中间 pop esi 恢复）
  · 切比雪夫距离（0x5A5B0D-0x5A5B17）：
      cmp eax,ecx（|dx| vs |dy|）→ jg 跳过 → [esp+0xC] = max 值
      （eax 先存 |dx|，若 |dx|<=|dy| 则覆盖为 |dy|——max 语义）
  · 随机抖动（0x5A5B19-0x5A5B43）：
      mov ecx,0xABE890（全局 Randomizer @0xABE890，batch 002 实锤）
      call 0x65C780（Randomizer::Random，__thiscall ret 0）
      mov [esp],eax / mov [esp+4],0 → fild qword（uint32 无符号扩展）
      fmul [0x7ED818]（=3.0，.rdata 字节实读 4008000000000000）
      fmul [0x7ED898]（=kInvUintMax 2.3283064370807974e-10，
        3df0000000100000——与 scaled_random.h:41 常量逐位一致）
      fild dword [esp+0xC]（max 有符号 int32 读入）
      faddp st(1)（j + base，x87 返回 ST0）
  · 全程 x87 FPCW=0x0E7F（RC=chop + PC53——WinMain 0x6BBFB7 实锤），
    复刻用 MXCSR toward-zero 临时切换（同 ChopJitterChain 修法）。

公式（golden 40 行实证，BitEq 逐位一致）：
  base = max(|p1.x-p2.x|, |p1.y-p2.y|)          // 切比雪夫
  u    = (double)(uint64)Random()
  j    = u * 3.0 * kInvUintMax                  // 两次 fmul + faddp，RC=chop 链
  返回 j + base

三、原版怪癖（照抄）
--------------------
① fild qword 无符号扩展（高 32 位显式写 0，non movzx——r 无符号读）；
② fild dword 有符号读 base（max 非负，符号无关但照抄形态）；
③ 双常量连乘抖动（u*3.0*kInvUintMax 两次 fmul——非预折叠单乘）；
④ RC=chop 全链（乘法+加法各一次向零截断，C++ 需 MXCSR toward-zero）；
⑤ 切比雪夫距离（max(|dx|,|dy|)，非欧氏 sqrt——与 0x5A2ED0 族区别要点）；
⑥ 无分支绝对值（cdq/xor/sub，中间 pop esi 穿插——坐标差不溢出 int32，
三目等价）。
