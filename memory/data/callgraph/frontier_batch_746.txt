① **首字节符号扩展 ID 匹配**（movsx byte[item]——ID 是带符号
   字节字段，负 ID 参与比较）；
② **命中返回 +0x28 状态字节、0 归一成 -1**（非 0 直返/0 折
   -1——查询失败与状态 0 同义）；

   分配）；
⑦ 0x663D20 前邻同构未归一（返回 bl 原始字节）——两版本并存；
⑧ 七调用点全 0xB052D0（单一对象多消费者——通用查询服务）。
