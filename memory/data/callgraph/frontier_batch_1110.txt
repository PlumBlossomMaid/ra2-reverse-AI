★语义：**MSVC6 CRT 80 位扩展精度浮点除法辅助器（推断名
——denormal 安全 x87 除法 _fdiv 类）**：
  ① 无栈帧序言，cdecl 栈传参：a @[esp+4]（10B xword）、
     b @[esp+0x10]（10B xword），结果 st(0)；
  ② 常规路径（指数分类表 [0x87D3F0] 表项 0）直接
     fdivp 返回；特殊路径走 denormal 处理；
  ③ b 指数 0 或全 1、a==0 → 直接除（交给 x87 异常语义）；
  ④ denormal 处理：fnstcw 保存 → or 0x33F / and 0xF3FF
     （设 64 位精度 + 清所有异常掩码）→ fldcw 切换 →
     两操作数同乘 15/16（[0x87D400]）或 17/16（[0x87D404]，
     a 指数==1 分支）→ 恢复控制字 → 除后返回；
  ⑤ b denormal 且 a 非零：×2^63（[0x87D408]）写回操作数
     a → 跳回 0x7D7EE8 主循环重试（防下溢/上溢）；
  ⑥ 结果正确性依赖 x87 80 位内部精度 + 全局 RC=chop。

★E8 被调者：零（纯 x87 内联 + 查表，无子调用）。

★调用点（探针 E8 实测 46 处）：0x7D803F-0x7D86DC 全部在
  CRT 数学库区间（0x7D7FF7 起下一函数区）——编译器把可能
  denormal 的除法生成 call 本辅助器而非直接 fdiv 指令。

★原版怪癖（照抄）：
  ① 无 push ebp 序言（CRT 汇编级浮点辅助标准形态，直接
     esp 相对寻址）；
  ② 两操作数同乘缩放因子（15/16 或 17/16）保持比值——
     除法的 denormal 归一化惯例；
  ③ denormal 大数路径只缩 a 不缩 b，跳回重试（循环而非
     尾递归）；
  ④ fnstcw/fldcw 精度切换三处展开（0x7F24/0x7F92/两处恢
     复），不抽公共 helper；
  ⑤ a 指数==1 与 b 指数 0 的双分支结构不对称（15/16 vs
     17/16 系数互换）；
  ⑥ 0x7D7FC2/0x7D7FCC 的 add eax,eax + jae/jb 组合是符号
     位提取（CF 判断）惯用，非算术。

   MSVC CRT 浮点异常/denormal 处理标准形态；46 调用点全在
   CRT 数学库区间。

   写时用等价运行时代替，逐字节复刻无意义——按商业库纪
