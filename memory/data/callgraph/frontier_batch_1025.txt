★语义：**CRT bsearch（二分搜索）**——cdecl 5 参（key / base /
count / step 元素大小 / 比较器函数指针 [ebp+0x18]）：
  ① 终点 = base + (count-1)*step；lo > 终点 → 返 0；
  ② 中点 = lo + (count/2 调整)*step；call 比较器(key, 中点)：
     ==0 命中返中点地址；<0 左半（mid-step）；>0 右半（lo =
     mid+step）；
  ③ count/2==0（count<2）→ 单元素路径：call 比较器(key, base)，
     neg/sbb/not/and 惯用 → 命中返 base、未命中返 0。
