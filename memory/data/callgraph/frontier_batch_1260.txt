0x5654A0 —— 坐标合成器（60B 全程读完）
================================================================================
签名：thiscall + 2 栈参（[esp+0x10]=输入点、[esp+8]=输出点）ret 8。
机器码（0x5654A0-0x5654D9）：
    eax=[ecx+0xFC]（this 字段 1）
    esi=[ecx+0x100]（this 字段 2）
    edi=[esp+0x10]（输入点）
    ecx=[ecx+0xF4]（this 字段 0）
    edx=[edi]（输入 x）; edx+=eax
    eax=[edi+4]（输入 y）; eax+=esi
    lea esi,[eax+1]; sar eax,1; sar esi,1（★(y+1)/2 与 y/2——两档半取整）
    ecx+=eax（★字段 0 + y/2）
    eax=[esp+8]（输出点）
    esi+=edx（★(y+1)/2 + 输入 x + 字段 1? 不对——esi=原输入x+字段1 + (y+1)/2）
    ecx-=edx（★字段 0 + y/2 - 输入 x - 字段 1）
    [eax]=esi（输出 x）; [eax+4]=ecx（输出 y）
    ret 8

语义：**坐标合成/投影器**——输入点 {x,y} + this{+0xF4/+0xFC/+0x100 三字段}
合成输出 {x,y}：x' = 输入x + 字段1 + (输入y+1)/2（★向正取整），
y' = 字段0 + 输入y/2 - 输入x - 字段1（★截断）。紧邻 0x5654E0 是反向/另一
形态（test bl,1 分支 + sub/inc——坐标差异运算），非本函数。

★怪癖：①★(y+1)/2 与 y/2 双档（sar 截断 vs +1 后截断——棋盘格半距惯用）；②
x' 含 y 分量/2、y' 含 -x 分量——等距投影半距合成推断；③三字段组合输出（+
0xF4/+0xFC/+0x100——地图偏移三件套推断）；④ret 8 双栈参。

⚠️ partial：三字段语义（地图原点/尺寸偏移推断）、输入/输出点类型（Point2D
推断）、紧邻 0x5654E0 关系、宿主（0x565xxx 坐标变换域——batch 460 等距
