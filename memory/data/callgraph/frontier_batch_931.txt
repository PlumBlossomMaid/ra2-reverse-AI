一、语义（完整汇编逐段核对 + 黄金 5 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码逐段确认）：
  · 调用约定：thiscall 无 this + 1 栈参（宿主对象指针 edi = [esp+0xA8]）
    ret 4。宿主对象 edi：+4 = 模板项数组（4B/项 dword，X=低16 有符号、
    Y=高16 有符号）、+0x10 = 循环上限 limit。
  · 外层循环双计数（0x5A7985-0x5A7B26）：
    - [esp+0x10] 成功放置轮数，上限 ebp = limit/50
      （0x51EB851F magic 配 sar edx,4——★标准 /100 是 sar 5，这里是
      原版怪癖 /50，golden all-fail limit=100 → ebp=2 实锤）
    - [esp+0x30] 总轮数，上限 esi = ebp*10（0x5A798B lea ebp*5 / shl 1）
    - 两计数任一达上限退出
  · 每轮（0x5A79B8-0x5A79FE）：拒绝采样 [0, limit-1]（fild qword 无符号
    读 Random + fmul [0x7ED898]=2^-32×(1+2^-40) + ja 无符号重抽）→
    [edi+4][采样] → 拆 X/Y 模板坐标。
  · 模板循环（0x5A7A36-0x5A7A67）：edi=0..4 最多 5 项，栈上模板数组
    [esp+0x60] 起 0x10 间隔（项 = {a=[ptr-4], b=[ptr]}，a 序列
    {6,4,4,4,2}、b 序列 {4,6,4,2,4}——★push edi 前 [esp+0x58]=6 物理
    落在 push 后 [esp+0x5C]（= 项 0 的 a），[esp+0x5C]=4 落在 [esp+0x60]
    （= 项 0 的 b），即项 0 是 {6,4} 不是 {4,0}，golden ZN d2 首值 6
    实锤）→ 组装 {X, Y, a, b} 调 0x5A7B40（菱形校验打桩，azn_seq 序列）
    → 成功 bl=1 提前退出。
  · bl=0 全失败 → 只 [esp+0x30]++ 跳过本轮（golden all-fail 用例：5 个
    azn=0 耗尽后第 6 次起返 1 → 第 2 轮成功放置）。
  · 成功（0x5A7A71-0x5A7B08）：0..5 拒绝采样（fmul [0x7EDA40]=
    6/2^32×(1+ε)，ja 重抽）→ 宿主 = [0xAA10A4] + 采样 + 8 → 双重循环
    （外层 Y 上限 = tmpl_b>>1 有符号 sar、内层 X 上限 = tmpl_a>>1）：
    坐标 = {X+2*esi, Y+2*edi} → 0x5A6C10（放置打桩，记录 ecx=宿主、
    edx=&坐标结构、栈参 -1/-1）。
  · 返回 EAX 无意义（0x5A7B2C pop 后 EAX 未定义），C++ 返回 0 对拍。
  · 常量（.rdata 取证）：[0x7ED898] = 2^-32×(1+2^-40)（拒绝采样缩放）、
    [0x7EDA40] = 6/2^32×(1+2^-37+2^-41)（0..5 采样比例）、[0xAA10A4] =
    宿主基址全局（.data 未初始化区，golden 按用例灌值）。
