0x7B5B80  字符串复制+大写转换（10 callers，0x7B5B80-0x7B5BE0 读完）
================================================================================
机器码（0x7B5B80，关键路径）：
    push ebx/ebp/esi/edi / mov esi,ecx
    xor ebx / mov edi,[esi]              ; ★ this->[0] 源串
    test edi / je 收尾
    or ecx,-1 / xor eax / repne scasb / not ecx   ; ★ strlen(源串)
    push ecx / call 0x7C8E17             ; ★ _new(strlen)（batch 001 CRT）
    mov edi,[esi] / mov ebx,eax          ; ★ 新缓冲
    repne scasb（再 strlen）/ sub edi,ecx
    rep movsd + rep movsb                ; ★ 复制串到新缓冲
    xor esi / test ebx / je 收尾
    mov edi,ebx / repne scasb / not ecx / dec ecx  ; ★ strlen(新串)
    cmp esi,ecx / jae 收尾
    大写循环:
    mov al,byte[esi+ebx] / cmp al,0x41 / jl 下一个   ; ★ <'A' 跳过
    cmp al,0x5A / jg 下一个               ; ★ >'Z' 跳过
    and al,0xDF / mov byte[esi+ebx],al    ; ★★ 转大写（and 0xDF = -0x20）
    下一个: inc esi / jmp 大写循环
    收尾: mov eax,ebx / ret               ; ★ 返回大写串副本

语义：**字符串复制+原地大写转换（strtoupper 形态）**——strlen 源串后
_new 分配同长缓冲、逐字节复制，然后第二遍遍历把 ['A','Z'] 区间字符
`and al,0xDF` 转大写（等价 -0x20），返回新串。★0x7B 系字符串工具
（batch 072 的 0x7B5440 GetString 同区）——文本规范化族。

⚠️ partial：宿主（StringClass/工具函数）、调用方上下文、收尾分支
（ebx==0 时返回什么未读尽 0x7B5BF4 起）。

   返 0: xor eax / ret

  0x5F1EE0（getter 3）：
    mov eax,[ecx+0x38] / test / je 返 0

batch 177 的 ObjectTypeClass 0x5F7090 同区）——对象链式访问端。
★0x48BA80 未登记（getter 3 委托目标）。

⚠️ partial：+0x38 子对象类型、+4/+0x28/+0x38 字段语义、0x48BA80 身份。

成员（+4 存参数）。★虚表安装家族（batch 117 单虚表 / batch 123 四虚表 /

⚠️ partial：宿主类（虚表 0x7EF738/0x7EF720）、0x624140 后续成员。
