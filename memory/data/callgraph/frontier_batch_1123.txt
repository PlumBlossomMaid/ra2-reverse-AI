一、链语义（disasm 全 232B + helper 交叉，0x7C94EB-0x7C95D1）
--------------------------------------------------------------
签名（实测）：cdecl 4 参（param1=buffer @[ebp+8]、param2=
element_size @[ebp+0xC]、param3=count @[ebp+0x10]、param4=
FILE* stream @[ebp+0x14]），返回读入项数（成功=count，部分
读=(total−remaining)/size，EOF/错误=0 或部分值）。

主体（0x7C94EB-0x7C95D1）：
007c94eb  push ebp/mov ebp,esp/push ecx/push ebx,esi,edi
007c94f2  mov edi,[ebp+0xC]/imul edi,[ebp+0x10]   ; ★total = size×count
007c94f9  mov ebx,[ebp+8]/mov ecx,edi             ; ★buffer / total
007c94fe  test edi,edi/mov [ebp-4],edi            ; ★保存 total
007c9506  jne 0x7C950F/xor eax,eax/jmp 0x7C95B8   ; ★total==0 → 返回 0
007c950f  mov esi,[ebp+0x14]                      ; ★stream
007c9512  test word[esi+0xC],0x10C/je 0x7C9522    ; ★标志 0x10C 分流
007c951a  mov eax,[esi+0x18]/mov [ebp+0x14],eax   ; ★[esi+0x18] 块大小
007c9522  mov dword[ebp+0x14],0x1000              ; ★否则默认 0x1000
; → 主循环（0x7C952B-0x7C95AB）：
007c952b  mov ecx,[ebp+8]                         ; ★剩余计数
007c952e  test word[esi+0xC],0x10C/je 0x7C9560    ; ★0x10C 再判
007c9536  mov eax,[esi+4]/test eax,eax/je 0x7C9560 ; ★[esi+4] 流剩余
007c953d  cmp ecx,eax/jb 0x7C9545/mov edi,ecx
007c9545  mov edi,eax                             ; ★edi = min(rem,剩余)

007c954e  sub [ebp+8],edi/sub [esi+4],edi/add [esi],edi ; ★游标推进

; → 循环/退出（0x7C95AB）：
007c95ab  cmp [ebp+8],0/jne 0x7C952B             ; ★主循环
007c95b5  mov eax,[ebp+0x10]                      ; ★返 count
007c95b8  pop 族/leave/ret
; → EOF/错误尾（0x7C95BD/0x7C95C3）：
007c95bd  or dword[esi+0xC],0x10                  ; ★置 _IOEOF(0x10)

007c95c7  mov eax,edi/xor edx,edx/sub eax,[ebp+8] ; ★(total−rem)/size
007c95ce  div [ebp+0xC]/jmp 0x7C95B8              ; 部分读项数

★语义：**MSVC6 CRT fread**——cdecl 4 参：
  ① total = size×count；total==0 直接返回 0；
  ② stream 标志 0x10C（_IOSTRG 字符串流域）命中块大小取
     [esi+0x18]，否则默认 0x1000；
  ③ 主循环：标志 0x10C 且 [esi+4]（流剩余）>0 → memmove
     （0x7D0A20）直读路径 → 游标推进；
  ④ rem ≥ 块大小 → 大块路径：按块对齐 → 读分发（0x7D07DF，
     句柄 [esi+0x10]）——返回值 0=EOF 置 _IOEOF(0x10)、-1=错
     误置 _IOERROR(0x20)、正=读入量推进；
  ⑤ rem < 块大小 → 小块路径：逐字节 fgetc（0x7D0703）；
  ⑥ 成功返回 count（[ebp+0x10]），EOF/错误返回
     (total−remaining)/size 部分读项数。
  与 MSVC6 fread 语义完全吻合（4 参返回项数 + 部分读除法回
  值 + EOF/ERROR 标志位）。

★E8 被调者：0x7D07DF（batch 039 流槽校验+读分发——本批
  0x7C957B 大块路径交叉，6 callers）+ 0x7D0703（batch 035
  CRT fgetc——本批 0x7C9594 小块逐字节交叉，5 callers）+
  0x7D0A20（batch 032 memmove——直读路径）——全部已登记。

★原版怪癖（照抄）：
  ① 标志 0x10C 判断出现两次（0x7C9512 设块大小 + 0x7C952E
     主循环入口）——fread 首轮与循环内重复判定；
  ② EOF（0x10）与错误（0x20）标志位分离（0x7C95BD vs
     0x7C95C3）——读分发返回值 0/-1 双出口；
  ③ 部分读回值 (total−remaining)/size（0x7C95CB 减法后除）
     ——读成功项数，EOF/错误都走此除法路径；
  ④ 大块/小块分界 = [ebp+0x14]（字符串流取 [esi+0x18] 否
     则 0x1000）；
  ⑤ 循环内小块路径更新 [ebp+0x14] = [esi+0x18]（0x7C95A8
     ——读流大块大小动态跟进）；
  ⑥ 直读 min(rem, 流剩余) 无符号 jb/ja 分支选择读入量（与
     fwrite 对称同模板）。
