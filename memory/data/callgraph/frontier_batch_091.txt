81 字节。与 batch 073 登记的 0x4F9A50（HouseClass* 变体，45 callers）同一
语义的两个重载——**本条多一步「虚表取宿主」**。

    push esi / esi = this（HouseClass*）
    ecx = [esp+8]（arg：AbstractClass*）
    test ecx,ecx / je 返 0                ; arg NULL → 非联盟
    eax = [ecx] / call [eax+0x3C]         ; ★ 虚表偏移 0x3C：取宿主/owning house
    test eax,eax / je 返 0                ; 取不到 → 非联盟
    cmp eax, esi / je 返 1                ; 宿主 == this → 是
    eax = [eax+0x30] / ecx = [esi+0x30]   ; 两者联盟下标
    cmp eax,ecx / je 返 1                 ; ★ 下标相等 → 是（同阵营）
    cmp eax,-1 / je 返 0                  ; 对方下标 -1（无阵营）→ 退避
    edx = 1 / cl = eax / shl edx,cl       ; 1 << 对方下标
    eax = [esi+0x5788]                    ; ★ 联盟位掩码
    test edx,eax / setne al / ret         ; 位掩码命中

`call [arg->vtable+0x3C]` 把 AbstractClass 解析成宿主 HouseClass**。
[0xA8B238]（SessionClass::Instance/GameMode）在 batch 062/064 已登记，
