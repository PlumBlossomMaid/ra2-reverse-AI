一、链语义（disasm 全段复核 + golden 12 用例实证）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7CA8C6 = MSVCRT wcschr（宽字符
查找）——cdecl 2 栈参 (s, c)，返回 s 中首次出现宽字符 c 的指针、未
找到返回 0；★c==0 时返回指向终止 NUL 的指针（标准 wcschr 语义）。
纯内存操作，无子调用无全局引用——全程可真身模拟。
  机器码（0x7CA8C6-0x7CA8EE，41B）：
    mov eax,[esp+4]=s（串指针）
  扫描循环（0x7CA8CA）：
    cx=word[eax]（*s）→ test cx,cx → je 0x7CA8DD（★串到 NUL → 收尾）
    cmp cx,word[esp+8]（★与目标宽字符 c 比较）→ je 0x7CA8DD（命中）
    inc eax ×2（宽字符步进 +2）→ jmp 循环
  收尾（0x7CA8DD）：
    cx=word[eax] → sub cx,word[esp+8]（★cx = *位置 - c，16 位）
    neg cx（★CF = (cx != 0)）→ sbb ecx,ecx（ecx = -CF）
    → not ecx（★命中 CF=0 → ecx=-1；未命中 CF=1 → ecx=0）
    → and eax,ecx（★命中保留指针 / 未命中清 0）
  ret

★原版怪癖（golden 实证，照抄）：
  ① 逐 2 字节扫描（宽字符），步进 inc ×2；
  ② 串到 NUL 即停，NUL 不参与与 c 的匹配（c==0 时例外）；
  ③ ★c==0 时返回指向串尾 NUL 的指针（golden：s="abc" → &s[3]、
     空串 → &s[0]——标准 wcschr 语义）；
  ④ 未命中返回 0（sbb/not/and 归一化：CF 标志驱动掩码）；
  ⑤ 收尾掩码是 32 位 `and eax,ecx`（x86 指针宽度——模型须用
     ~uintptr_t{0} 保 64 位宿主完整指针，见四节调试记录）。
