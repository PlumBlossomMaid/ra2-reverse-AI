★语义：**CRT 字符分类表查询器（推断名——isctype/locale 表查
询族）**——cdecl 1 参（param1=结构：+8 code word、+0xC 标志字
节）：①bh bit8 分支：code 10B 步进查表 0x87DA30（13 项）命中后
按标志位（bl&3 → 0x38 / bl&0xC → 0x36 / bl&0x10 → 0x34 / 默认
0x32）选列偏移（ecx*10+表基+列偏移）；②非 bh bit8 分支：code*8
直索引（表 0x87DAA8/0xAA/0xAC/0xAE 按标志位选）读表项首字节 →
无效判定（0 或 0xE0 且次字节 0）；③命中返回偏移、无效返回 0。

★原版怪癖（照抄）：
  ① bh bit8 双层表查（10B 步进 13 项 + 列偏移）vs 非 bit8 单
     层 code*8 直索引——两套表并存（0x87DA30 区 vs 0x87DAA8
     区）由高位字节位 8 分流；
  ② 标志字节 bl&3/0xC/0x10 三组决定表列——标志位两两组均非
     排他（先 3 后 0xC 后 0x10 串行判定，3 命中优先）；
  ③ 表项首字节 0xE0 特判 + 次字节 0 判有效（字符区间编码）；
  ④ 无效返回 0 / 命中返回偏移（非表项内容本身——由调用方解
     释偏移语义）；
  ⑤ 分支1 未命中（13 项无匹配）返回 ecx=13（计数）而非 0——
     ★与分支2 语义不一致（busy 计数值怪癖）。
