一、链语义（disasm 全 90B + 两依赖交叉 + locale 阈值重叠，

--------------------------------------------------------------
签名（推断）：cdecl 1 参（[esp+8]=16 位字符值），返回分类
后值 / 索引换算值（esi-0x27 / esi-7）。

主体（0x7D453C-0x7D4595）：
007d453c  push esi/mov esi,[esp+8]            ; esi = 字符值
007d4541  test si,0xff00/jne 0x7d4580         ; ★★高字节非 0（MB 范围）

007d4548  cmp [0x87c79c],1/jle 0x7d4564       ; ★★locale 阈值 [0x87C79C]

                                              ;   & mask=4）
007d4560  pop ecx/pop ecx/jmp 0x7d4577
; → locale<=1 路径（0x7D4564，ctype 表直查）：
007d4564  mov ecx,[0x87c590]                  ; ★★ctype 表指针 [0x87C590]

★语义：**MSVC6 CRT MBCS 字符分类映射器（推断名——_ismbc 族
（_ismbclegal/_ismbcsymbol 类））**——cdecl 1 参：
  ① `test si,0xff00`：高字节非 0（多字节范围）→ 直接宽分
     类（0x7D3920）；
  ② locale 阈值 [0x87C79C]>1 → 0x7D1311 _isctype（&mask=4）
     查表分类；≤1 → [0x87C590] ctype 表直读（2B/项）按位
     4 测试；
  ③ 分类命中 → 返原值；未命中/越界 → 0x7D3920 _iswctype
     宽分类后按结果返 esi-0x27（命中）或 esi-7（未命中）
     ——索引换算映射。
  = MBCS 字符分类的多路径选路标准形态（locale 阈值 + ctype
  表 + 宽分类三级）。

★调用点（探针 E8 实测 2 处）：0x7D42AF/0x7D4465——均 CRT
  区（0x7D42xx/0x7D44xx 字符分类域），宿主调用点前后缀字
  符/宽字符比较上下文。

★E8 被调者：0x7D1311（★★TSV:134/186 _isctype 字符分类查
  询 ✓已登记——49 callers，lead-byte 超界经 0x7D9729）+ 
  0x7D3920（★★TSV:141/187 _iswctype 宽字符分类掩码 ✓已
  登记——19 callers，0xFFFF→0/c<0x100 查 [0x87C594] 256
  项表/c≥0x100 走 0x7DA0F1 GetStringTypeW）——**两个依赖
  全部已登记**。常量：[0x87C79C]（locale 阈值，batch
  1082/1084/1091 同款）+ [0x87C590]（ctype 表指针，batch
  044/056 同款）。

★原版怪癖（照抄）：
  ① `test si,0xff00` 是 16 位测试但入参 si（mov esi,[esp+8]
     截断 32 位）——高位测试用 test si 而非 test esi；
  ② locale 阈值 [0x87C79C]<=1 走表直查（【≤1】含 0/1 两
     态——batch 1082 系同款双路径）；>1 才走 _isctype 函
     数查询；
  ③ ctype 表 [0x87C590] 按 eax*2 索引（2B/项）但只取 al
     低字节（mov al,byte[ecx+eax*2]）——表项高字节丢弃；
  ④ 未命中/越界统一走 0x7D3920 宽分类——单字节入口也能
     掉进宽分类路径（多级回退语义）；
  ⑤ 返回换算：命中 esi-0x27（39）、未命中 esi-7——两个
     魔术常量索引换算（符号/类别编号映射，照抄）；
  ⑥ 分类位测试按 **bit4**（and eax,4）——MSVC6 ctype 表
     位布局（_UPPER=1/_LOWER=2/_DIGIT=4…）具体到某一位
     面，非全字面。
