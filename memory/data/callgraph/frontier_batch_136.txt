0x477BE0  数组容器构造器（batch 092 同族，15 callers）
================================================================================
机器码（全 0x48，72B）：
    mov eax, [esp+4]                 ; ★ arg1（容量）
    mov esi, ecx                     ; this
    mov [esi+4], edx                 ; +4 = NULL（数组指针先清）
    mov [esi+8], eax                 ; ★ +8 = 容量（arg1）
    mov byte [esi+0xC], 1            ; ★ +0xC 持有标志 = 1
    mov byte [esi+0xD], dl           ; ★ +0xD 第二标志 = 0
    mov [esi], 0x7E4DB8              ; ★ 装虚表 0x7E4DB8
    test eax / je 收尾               ; 容量 0 → 跳过分配
    mov ecx, [esp+0xC]               ; ★ arg2（外部缓冲指针）
    test ecx / je 分配
    mov [esi+4], ecx                 ; ★ 采用外部存储
    ret 8
  分配:
    shl eax, 2 / push eax / call 0x7C8E17   ; ★ CRT::_new（容量×4）
    mov [esi+4], eax / mov byte [esi+0xD], 1 ; ★ 自分配标志置 1
    ret 8

语义：**「可带外部缓冲的数组/向量」构造器（batch 092 同族）**——+4 数组指针 /
+8 容量 / +0xC 持有标志 / +0xD 自分配标志，装虚表 0x7E4DB8；arg2 给指针则
直接采用外部存储（不分配），否则 CRT::_new 分配容量×4 字节。
★与 batch 092 登记的 0x42FCB0（装虚表 0x7E38D0、+0x4/+0x8/+0xC/+0xD 布局
完全一致、同样外部缓冲 + _new 分配）**字段排布逐字节互证**——同一容器类的
第二构造器（不同虚表 0x7E4DB8 vs 0x7E38D0），该类成员增至 ctor×2 + resize
（batch 102 的 0x42F860）。

★跨批次连接：batch 092（0x42FCB0 ctor）+ batch 102（0x42F860 resize）——
「DynamicVectorClass 系」容器成员第二份 ctor，字段互证闭合。

⚠️ partial：虚表 0x7E4DB8 与 0x7E38D0 的类归属（同族推断）、与 0x42FCB0 的
精确类关系（未归一化比对不写孪生）。

0x7BC2B0  坐标浮点换算（15 callers，0x64B 未读完）
================================================================================
机器码（前 0x64B 实读）：
    push ebp / mov ebp, esp / and esp, 0xFFFFFFF8 / sub esp, 0x64
    mov edi, edx                    ; ★ arg2（输出坐标?）
    mov edx, ecx                    ; ★ arg1（输入坐标）
    mov ecx, [ebp+8]                ; ★ arg3（参照/相机类?）
    mov eax, [ecx] / mov esi, [ecx+4] / mov ebx, [ecx+8]   ; ★ 参照对象三字段
    fild dword [esp+0x14]           ; ★ int → float（x87 转换）
    fst qword [esp+0x30] / fild dword [esp+0x14]
    fild dword [edx] / fstp qword [esp+0x38]   ; arg1->[0]
    fild dword [edx+4] / fstp qword [esp+0x28] ; arg1->[4]
    fild dword [edi] / fst qword [esp+0x68]    ; arg2->[0]
    fild dword [edi+4] / fstp qword [esp+0x40]
    fld qword [esp+0x38] / fld st(1) / fsub st(1)   ; ★ 差值计算
    ...（fsub/fmul/faddp 链，疑坐标变换 + 缩放）

语义：**坐标浮点换算/变换**——把 arg1 与 arg2 的 int 坐标转 float 做差值/变换
（fild → fsub/fmul 链），参照 arg3 的三字段参与。与 batch 096（AdjustForZ 的
fild/fmul/_ftol）、batch 103（0x5AFB80 矩阵变换）、batch 122（DistanceFrom3D
的 fild 平方和）同 x87 浮点几何族。⚠️ 函数主体（fsub/fmul 后段）未读完，精确
公式 partial。

⚠️ partial：x87 链后段公式、三个参数角色（arg1/arg2/arg3）、宿主类。

掩码索引 [eax+edi*4]）——「装虚表 + 哈希容器」对象对（batch 091 的
0x5B40B0 哈希表家族同思路）。
