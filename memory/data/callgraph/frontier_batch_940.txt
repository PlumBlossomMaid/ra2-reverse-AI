一、链语义（全段 disasm 复核 + golden 6 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7C8EF4 = vsprintf 薄封装——
与 batch 938 的 0x7CA564（vsprintfW 宽版）**同构配对**，但核心引擎是
0x7CE2A5（ANSI 窄字符格式化核心）且收尾只写**一个**单字节 NUL：
  · 入口（cdecl 3 栈参，ret）：
      mov [ebp-0x20], eax       ; 槽 = dst
      mov dword [ebp-0x14],0x42 ; 死值 'B'（从未被读取，同 0x7CA564）
      push &args / push fmt / push &槽
      call 0x7CE2A5             ; ANSI 格式化核心（桩边界）
      add esp,0xC
  · 收尾（核心返回后）：
      dec [ebp-0x1C]            ; 上限 0x7FFFFFFF--
      mov esi, eax              ; 保存返回值
      js 0x7C8F34               ; 上限为负 → 0x7CE18D（不可达）
      mov eax,[ebp-0x20]
      and byte [eax],0          ; ★写 NUL #1（单字节）
      jmp 0x7C8F41              ; ★无 inc——槽不推进！
      mov eax, esi / ret        ; 返回核心返回值

★原版怪癖（golden 实证，C++ 侧逐条复刻）：
  ① [ebp-0x14]=0x42（'B'）写入后从未被读取——MSVC6 编译器遗留死值
     （与 0x7CA564 同款）；
  ② 上限 0x7FFFFFFF 减一次 js 永不成立——0x7CE18D 分支实际不可达
     （代码照抄，golden 语义断言 0 次调用）；
  ③ ★只写**一个**单字节 NUL（ANSI 窄字符串终止符），且写后槽不推进
     ——与 0x7CA564 的**双** NUL（宽 L'\0'，且第一次写后槽 +1）成
     窄/宽配对；
  ④ 返回值原样透传核心结果（含负值）——golden WRITE 0 - r -1 用
     uint32 打印 4294967295 实证透传语义。

三、C++ 模型（code/rewrite/runtime/crt_format.{h,cpp}）
------------------------------------------------
namespace ra2::runtime。复用 batch 938 的 CrtFormatWorld（WideFormat
= 格式化核心、WriteTerminator = js 分支终止符）。新增单函数：
  vsprintf_legacy(world, dst, fmt, args) —— 0x7C8EF4：槽=dst →
    WideFormat(&槽, fmt, args) → 上限 0x7FFFFFFF 减一次 → 非负则写
    **单字节 NUL（槽不推进）** → 返回引擎返回值。
与 vsprintfw_legacy（0x7CA564，双 NUL + 槽推进）在头注释内并列成对，
两函数共用 CrtFormatWorld 抽象。kVsprintfwLimit 常量共用（两个变体
的上限均为 0x7FFFFFFF）。
无失败路径、无额外校验。

四、单测（test_crt_vsprintf.cpp，全量 58 项之一）
------------------------------------------------
CrtVsprintfTest：读 golden 原档（RA2_GOLDEN_DIR 宏）6 WRITE 用例 + 3 项
结构断言：
  GoldenVsprintfShellMatches（逐用例：透传返回值/fmt/args、槽起点=
  dst、term==0、缓存 payload+单 NUL 逐字节 == golden dst[0..n]）、
  SingleNulWrittenAndSlotNotAdvanced（NUL 在 payload 后一位、再往后
  0xCC 不动——槽不推进实证）、

  0x7CA564 双 NUL，同一桩世界跑两函数对比）。

INT_MAX 截断风险）。预期 6 用例全量对拍，ctest 58/58 全绿（#7
crt_vsprintf 通过，无回归）。
