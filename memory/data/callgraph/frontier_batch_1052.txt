一、链语义（disasm 全段复核 + IAT 三槽实锤）
------------------------------------------------
**0x7DDC32（26B，0x7DDC32-0x7DDC4B）计数/错误薄包装**：
  007ddc32 ff742404       push [esp+4]            ; ★param1 转调参数
  007ddc36 e842050000     call 0x7de17d          ; ★★转调核心
  007ddc3b 83f8ff         cmp eax,-1
  007ddc3e 8b44240c       mov eax,[esp+0xc]       ; ★eax = param2（计数指针）
  007ddc42 59             pop ecx
  007ddc43 7504           jne 0x7ddc49
  007ddc45 8308ff         or dword[eax],-1        ; ★核心返 -1 → *param2 = -1
  007ddc48 c3             ret
  007ddc49 ff00           inc dword[eax]          ; ★否则 (*param2)++
  007ddc4b c3             ret
  ★怪癖：①转调失败（-1）置 *param2=-1、成功则 ++（计数/错误
  双义薄包装）；②param2 在转调后才读（[esp+0xC]——不提前解
  引用）；③返回 void（eax 残留 param2 指针，调用方不用）。

**0x7DE17D（75B，0x7DE17D-0x7DE1C0）单字节控制台写出核心**：
  ① push ebp/mov ebp,esp/sub esp,0x10/push ebx,esi,edi；
  ② [0x87DD84] 门控 == -2（未初始化）→ call 0x7DE110 懒初始
     化（CreateFileA 开 CONOUT$）→ 门控 = 句柄或 -1；
  ③ 门控 == -1（开失败）→ or eax,-1 返回 -1；
  ④ 成功路径：[ebp-4]=0 计数器、[ebp+0xB]=param1 单字节 →
     五参 WriteConsoleA（[0x7E1344]：handle, &[ebp+0xB],
     1, &[ebp-4], 0）→ 失败 → -1；
  ⑤ 返回 [ebp+0xB]（写出字节）。
  ★怪癖：①[0x87DD84] 句柄/门控双义（-2 未初始化/-1 失败/其余
  句柄）；②WriteConsoleA 五参带 written 计数槽 [ebp-4]；
  ③写出对象取 param1 低字节（mov [ebp+0xB],al——单字节语义）。

**0x7DE110（31B，0x7DE110-0x7DE12E）懒初始化**：
  007de110 xor eax,eax / push eax×2 / push 3 / push eax /
           push 3 / push 0x40000000 / push 0x7fa4a4
  007de123 call [0x7e11bc]          ; ★★CreateFileA(0x7FA4A4=
                                        "CONOUT$", GENERIC_WRITE
                                        (0x40000000), 3, NULL, 3
                                        (OPEN_EXISTING), 0, NULL)
  007de129 mov [0x87dd84],eax        ; ★门控 = 句柄（或 -1）
  007de12e ret
  ★怪癖：①CreateFileA 七参全常量（CONOUT$ + GENERIC_WRITE +
  FILE_SHARE_RW + OPEN_EXISTING）——一次开句柄永不关闭；
  ②失败时 eax=-1 直接进门控（调用方判 -1）。

★依赖链实锤（本批 disasm + IAT 解析）：
  ① [0x7E1344] = KERNEL32!WriteConsoleA（pefile 实证）——
     五参句柄写出；
  ② [0x7E11BC] = KERNEL32!CreateFileA（pefile 实证）——七参
     开 CONOUT$；
  ③ [0x87DD84] 句柄/门控全局——三函数共享；
  ④ 0x7FA4A4 = "CONOUT$" 常量串（数据区）。
