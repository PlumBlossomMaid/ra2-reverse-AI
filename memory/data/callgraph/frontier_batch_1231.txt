一、语义（全段反汇编逐条核对 + golden 12 行闭环）
------------------------------------------------
真义（机器码全 125B 确认，disasm.py 0x5A3A60 0x7D）：
  · 调用约定：**cdecl 无参 ret 0**（无 ecx/this 使用——纯工具函数，
    与 0x5A6BA0/0x58C4A0 族的 thiscall 不同）。
  · side  = [0x89C2DC]（MapGen 边长）
  · CellIterator_Reset(0x578350，thiscall ecx=0x87F7E8)
  · loop（0x5A3A78 起）：
      cell = CellIterator_Next(0x578290，thiscall ecx=0x87F7E8)
      test eax,eax / je 0x5A3AD9 —— NULL 终止
      非 NULL：
        ecx = [cell+0x24]（坐标打包 dword：低16=X、高16=Y）
        Y = movsx word [esp+6]（高16 符号扩展）
        idx = Y * side + X（imul [0x89C2DC] + movsx cx 低16）
        p = [0xABED10] + idx*0x50（lea eax,[eax+eax*4]; shl eax,4）
        p+0x20 = [0x7ED7F8]；p+0x24 = [0x7ED7FC]
        p+0x28 = [0x7ED7F0]；p+0x2C = [0x7ED7F4]
  · ★★全程零取数点：不调 Randomizer（golden next 字段实证：同种子
    所有用例 next 相同 = 调用前后 RNG 状态不变）

公式（golden 12 行实证）：
  CellIterator_Reset()
  while (NextCell(x, y)) {            // CellIterator_Next 打桩，NULL 终止
    idx = y*side + x;                 // imul 边长 + movsx 低16
    p = work + idx*0x50;              // [0xABED10] + idx*80
    p+0x20 = c_f8; p+0x24 = c_fc;     // [0x7ED7F8]/[0x7ED7FC]
    p+0x28 = c_f0; p+0x2C = c_f4;     // [0x7ED7F0]/[0x7ED7F4]
  }

★与同族差异：
  ① 零取数点（同 0x5A6BA0——不消耗 RNG）；
  ② **CellIterator_Reset/Next 双轮遍历**（0x578350/0x578290——活代码
     batch 006 家族；本批打桩：指针表顺序取 cell，NULL 终止）；
  ③ **idx = Y*side + X 线性索引**（imul 边长——RMG 工作数组寻址约定，
     与活代码 [0xABED10] 索引同套）；
  ④ 每格写 p+0x20..0x2C 四个 dword（.rdata 常量 [0x7ED7F0..FC]）。

二、golden 采集（emu_oracle 指令级模拟）
--------------------------------------
探针 .qwen/tmp/_emu_deadcode_5a3a60.py：调 0x5A3A60（cdecl 无参），灌
side [0x89C2DC]、work [0xABED10]（HEAP 0x30004000，256×0x50B）、
.rdata 四常量 [0x7ED7F0..FC]、cell 对象数组（0x3000A000，+0x24 坐标
dword）、CellIterator 打桩：
  · Reset = mov dword [0x1F010000],0x1F01000C; ret（指针表重置回头）
  · Next = mov eax,[0x1F010000]; mov eax,[eax]; add dword [..],4; ret
    ——★★二次解引用：先取表当前项地址、再取 cell 指针，NULL 终止
    （初版漏二次解引用，函数把「表地址」当 cell 用 → [eax+0x24] 读
    垃圾 → 坐标越界 → UC_ERR_READ_UNMAPPED；探针纪律同 batch 1228
    TB 缓存坑——修后全用例合理）。
seed_global 播种。存档 memory/data/rmg/deadcode_5a3a60_golden.txt：
3 种子 × 4 用例 = 12 行。用例矩阵：side ∈ {8,16} × cells ∈
{[(1,2),(5,3)], [(0,0)], [], [(3,4),(15,15),(7,0)]} × consts ∈
{0x11111111.., 0xAAAA0000.., 0xDEADBEEF.., (1,2,3,4)}。
★golden 含 consts 字段（四常量直读——测试不再按用例特征猜常量）。
★next 字段 = 调用后下一次 Random() 值（= 同种子首采值——零取数点
实证）。

(1) golden 写入规律（逐项核对）：
  · (1,2)/(5,3) side=8 → idx=2*8+1=17、3*8+5=29 ✓
  · (0,0) side=8 → idx=0 ✓
  · [] → none（无写入）✓
  · (3,4)/(15,15)/(7,0) side=16 → idx=4*16+3=67、15*16+15=255、
    0*16+7=7 ✓
  · 常量映射：p+0x20=c_f8、p+0x24=c_fc、p+0x28=c_f0、p+0x2C=c_f4
    （golden 行 consts=(11111111,22222222,33333333,44444444) →
    idx17=(33333333,44444444,11111111,22222222) ✓）

(2) ★★本批实锤：CellIterator 打桩二次解引用
  探针初版 Next 打桩 = mov eax,[0x1F010000]; add dword [..],4; ret
  ——直接把「表内容地址」当 cell 指针返回，函数读 [eax+0x24] 得到
  指针表垃圾 → 坐标 Y*side+X 越界 → UC_ERR_READ_UNMAPPED（emu
  中断，后续写入缺失）。修复：mov eax,[0x1F010000]; mov eax,[eax]
  （二次解引用取 cell 指针）；add dword [..],4; ret。教训：打桩的
  返回值必须与函数调用约定一致（该函数要的是 cell 指针，不是地址）。
