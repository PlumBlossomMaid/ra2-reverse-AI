0x634290  对象数组按值找索引（13 callers，0x2F 全读完）
================================================================================
机器码（全 0x2F）：
    mov esi, [ecx+0x10]             ; ★ this->+0x10（计数）
    or eax, -1 / xor edx, edx        ; 结果初值 -1 / 索引 0
    test esi / jle 返 -1
    mov ecx, [ecx+4]                ; ★ this->+4（对象数组，4B/项）
    mov edi, [esp+0x10]             ; ★ 目标值
  loop:
    mov ebx, [ecx] / cmp [ebx], edi / je 命中   ; ★ item->[0] == 目标
    inc edx / add ecx, 4 / cmp edx, esi / jl loop
    返 -1                            ; 未命中
  命中:
    mov eax, edx / ret 4            ; ★ 返回索引

语义：**对象数组按「首字段值」线性查找返回索引**——遍历 this->+4 数组（计数
+0x10，4B/项指针），比较每项 item->[0] 与目标值，命中返回索引、未命中 -1。
紧邻 0x6342D0 是按索引取值（`mov eax,[ecx+4]; mov edx,[eax+ecx*4]; mov eax,
[edx]`）——「按值找索引 + 按索引取值」的配套对。

★跨批次连接：+4 数组/+0x10 计数与 batch 109（0x65AD30 数组族）、batch 127
（0x65AE30 RadioClass::HasAnyLink）同「对象持数组+计数」登记册风格；按首
字段查值同 batch 120（0x68CA50 名+索引查表）——数组查找族。

⚠️ partial：宿主类（0x634xxx 区对象）、item->[0] 字段语义（ID/句柄?）。
