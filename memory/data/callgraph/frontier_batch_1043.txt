一、链语义（disasm 全段复核 + golden 32 用例实证）
------------------------------------------------
**0x7D46B9（92B）核心**，cdecl 4 栈参 (value, buffer, radix,
sign)：
  ① sign!=0 → `mov byte [ecx],0x2d`（'-'）/ `inc ecx` /
     `neg esi`（★无条件无符号取负）；sign==0 → value 位型原样；
  ② 0x7D46D6 `mov edi,ecx` = 数字区起点（负号之后）；循环：
     `mov eax,esi / xor edx,edx / div radix`（div1 商 eax/余
     edx）→ `mov eax,esi`（★eax 重置，div1 商丢弃）→
     `mov ebx,edx`（★余数经 ebx 保留）→ `xor edx,edx / div
     radix`（★div2 重算商，edx 同样重算但不用）→
     `cmp ebx,9 / mov esi,eax`（★esi = div2 商）→
     `jbe 0x7D46F4`：余>9 → `add bl,0x57`（★0x57+'9'+1 = 'a'，
     小写 hex）/ 余<=9 → `add bl,0x30` →
     `mov [ecx],bl / inc ecx` / `test esi,esi / ja`（商!=0 循环）；
  ③ `and byte [ecx],0`（NUL）→ `dec ecx`（★ecx = 最后一个数字）；
  ④ 反转循环（do-while 先执行一次）：`mov dl,[edi] /
     mov al,[ecx]`（★al = 残留读取 — 与 edi 交换）→
     `mov [ecx],dl / mov [edi],al / dec ecx / inc edi` /
     `cmp edi,ecx / jb`（无符号 edi < ecx）；
  ⑤ 返回 eax = 反转循环最后一次 `mov al,[ecx]` 的低字节
     （高 24 位 = div 循环退出时商残值 0）——调用方自恢复
     buffer 指针，核心返回约定不依赖。

**0x7D473F（27B）`_ultoa(value, buffer, radix)`**：恒 sign=0 第
4 参补 0 → 调核心 → 返回 buffer（`mov eax,[esp+0x18]` 重读参2）。
**0x7D4715（42B）`_ltoa(value, buffer, radix)`**：
`sign = (radix==10 && value<0) ? 1 : 0`（`cmp [ebp+0x10],0xa /
jne` + `cmp [ebp+8],0 / jge` 判定）→ 调核心 → 返回 buffer。

★原版怪癖（golden 32 用例实证，照抄）：
  ① div 两遍冗余——div1 商被 `mov eax,esi` 丢弃、余数经 ebx 保
     留，div2 重算商进 esi（edx 重算但不用）——数学等价、寄存器
     节奏不同；
  ② sign!=0 无条件 neg（**正数也翻转**——golden:
     2147483647, radix=10, sign=1 → "-2147483649"）；
  ③ sign==0（_ultoa 恒真）按无符号位型除——golden:
     -12345, radix=10 → "4294954951"；
  ④ 余数 >9 → +0x57 小写 hex——golden: 0xABCDEF → "abcdef"；
  ⑤ 反转 do-while 先执行一次（与 0x7D468C batch 023 同构）；
  ⑥ 核心 eax = 反转残留（调用方不用，返回 buffer 由包装重读）。

三、C++ 模型（code/rewrite/runtime/crt_itoa.{h,cpp}）
------------------------------------------------
namespace ra2::runtime。三函数：
  itoa_core_legacy(int32 value, char* buffer, int32 radix,
    int32 sign) -> uint32（eax 残留）——div 两遍（ebx 余 + esi
    商分开步进）、neg 无条件、+0x57 小写 hex、do-while 反转全
    照抄；
  ultoa_legacy(uint32 value, ...) -> char*——恒 sign=0；
  ltoa_legacy(int32 value, ...) -> char*——sign 判定 + buffer
    返回。
无失败路径、无额外校验。结构 = 原版 161B 控制流逐条照抄。
★MSVC 坑实记：char*→uintptr_t 需 reinterpret_cast（MSVC 禁
static_cast 指针→整型）。
