★语义：**代码页转换包装器（推断名——查大小→分配→填充三
阶段）**——cdecl 5 参（param1/param2=转换源、param3=输出缓
冲、param4=缓冲大小、param5=locale 名）：
  ① 全局门 [0xB7859C] 三态惰性初始化：0 → 槽 [0x7E1338]
     初始化，失败试 [0x7E130C]，成功置门=1/2；
  ② 门==2 → 4 参转发 [0x7E130C];
  ③ 门==1 → param5 为 0 时取 [0xB782B0]（batch 1109
     setlocale 全局名称槽）兜底 → 调 [0x7E1338] 查所需大小
     → 对齐（add eax,eax+3/and al,0xFC）→ _alloca_probe 栈
     分配 → 调 [0x7E1338] 填充 → 调 [0x7E124C] 8 参收尾
     （含 0x220/edi/-1 参数）；
  ④ 失败统一返回 0。
  调用点宿主（0x7DAF40 区）三连调用 = 经典「buf=0 查大小 →
  malloc(0x7C9430) → 带 buf 填充」CRT 转换模式。

★槽目标交叉（探针 PE 字节 + 反汇编）：
  [0x7E1338]→0x410FCE（0x410FD2 起 = mov edx,[ecx]/lea
    eax,[esp+0x18]/call [edx+0x14]——★★thiscall 虚表槽分派）
  [0x7E130C]→0x410F0E（lea eax,[eax+ecx*2]/add edi,ecx/esi+
    0x10/+0x18 字段——★★宽字符步长推进循环）
  [0x7E124C]→0x40FA00（mov byte[eax],al; ret——★★3B 字节写
    stub）
  [0x7E1200]→0x40F868（xor al,al/pop 族/ret 8——★★false 返
    回 stub + 0x40F870 mov edx,[ecx+0x10] 容器线性查找：逐项
    cmp [ecx],esi）
  → 0x410xxx 密集小函数区（0x410CD2-0x411064）为分派目标
    族，多含 thiscall 虚表分派形态。

★调用点（探针 E8 实测 3 处，同宿主 0x7DAF40 内）：0x7DAF56/
  0x7DAF78/0x7DAFA3。宿主语义：
  · 0x7DAF44 push 0x80/push eax(buf)/push [ebp+0x10]/push
    [ebp+0xC]/call 0x7DC5DC —— 5 参（128B 栈缓冲）
  · 失败后 call [0x7E1200]/cmp eax,0x7A（★'z' 字符判定）→
    重试查大小（三参 0）
  · 成功 → call 0x7C9430（★★malloc batch 063）分配 esi 字
    节 → 第三次带 malloc 缓冲调用
  · 0x7DAFBD mov [ecx],eax —— 结果写 [ebp+0x14] 输出指针

★原版怪癖（照抄）：
  ① 全局门 [0xB7859C] 三态（0 未初始化/1 主槽可用/2 备槽可
     用）——主槽 [0x7E1338] 失败自动降级备槽 [0x7E130C]；
  ② param5（locale 名）为 0 时从 [0xB782B0]（setlocale 全
     局名称槽，batch 1109 实锤写入端）兜底——转换默认跟随
     当前 locale；
  ③ 查大小与填充复用同一槽 [0x7E1338]（首调 buf=0 返回大
     小，次调带栈缓冲填充）——两步走无独立大小 API 包装；
  ④ 大小对齐 add eax,eax+3/and al,0xFC（×2 后 4 对齐——宽
     字符 2 字节 ×2 语义）；
  ⑤ 栈分配走 0x7CA650（_alloca_probe）而非 malloc（门==1
