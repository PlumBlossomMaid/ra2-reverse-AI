★语义：**RTTI 偏移表查找 + 指针叠加（MSVC6 C++ RTTI/异常运行时内部
处理器）**——输入 obj 结构 {+0: 基址, +4: 索引, +8: 附加偏移} 与
表基指针；索引 ≥ 0 时：查表 表[索引] 得 dword 项（作指针）→ 解引用
(表项 + 附加偏移) 得累加值；索引 < 0 时累加值 = 0；返回 基址 + 累
加值（调整后指针）。
★原版怪癖（照抄，batch 952 已录）：
  ① ★索引 < 0 走 jl 跳过整段查表（符号判定后 ecx 保持 0——不被
     查表路径污染，仅基址返回）；
  ② 表[索引] 读 dword 后**再解引用一次**（表项本身是指针，指向的
     dword 才是要加的偏移）——两级间接；
  ③ 附加偏移 [eax+8] 与索引并存于 obj 结构同一低位字段簇——RTTI
     调整描述符布局（推断，未 golden 实证）；
  ④ 返回前不恢复 esi 以外的寄存器（eax/ecx/edx 作为调用者保存——
     cdecl 调用约定）。

★宿主上下文（batch 952 已实锤）：0x7CAAE4 SEH 帧安装 → CHD 三路
遍历（0x7CAC66 单继承 / 0x7CACC0 多继承 / 0x7CADB9 虚继承）→ 三
路处理器均以「目标 type_info 匹配 + 0x7CAEF1 指针调整 + 目标偏移
校验」为收尾——0x7CAEF1 是 RTTI 类型表命中后的指针偏移计算器。
