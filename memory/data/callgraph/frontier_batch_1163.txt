★语义：**MSVC6 CRT _findenv 环境键查找器（推断名——batch
1045 _putenv 内的查 key 索引段）**——cdecl 2 参：
  ① [0xB781E4] 环境表 HEAD 迭代（char* 表，项 NULL 终止）；
  ② 每项 __mbsnbicoll 比较（key_len 前缀，0x7D45DF batch
     1046 多字节不敏感）；
  ③ 相等后验 `[]= '='/NUL`（key=value 分隔）——两项判命中；
  ④ 返回（项地址-表头）>>2 正索引 / 未命中负索引（neg）。
  = _findenv 标准实现（偏移索引返回——vs getenv 指针返
  回），_putenv 用索引定位槽位。

★调用点（探针 E8 实测 1 处 0x7DAACF）：宿主 0x7DA9CD
  _putenv 环境设置器（batch 1045 已登记 391B）——0x7DAA6F
  起：sub esi,[ebp+8]_push esi,push [ebp+8]_call 0x7DAB54
  → jl 0x7DAACF 未命中追加 → 正索引走命中（覆盖/删除式）
  ——与本批文档点名段逐字吻合。

★E8 被调者：0x7D45DF（★★batch 1046 __mbsnbicoll 多字节
  比较 ✓TSV:1881，2 callers——0x7DAB6C 本批 + 0x7CBC8E
  getenv）——**唯一函数依赖，已登记**。常量：[0xB781E4]
  （环境表 HEAD，batch 1045/1142 同全局）。

★原版怪癖（照抄）：
  ① 命中判定两步：__mbsnbicoll 前缀比较 + 后续 '='/NUL
     验证——与 batch 1034 getenv 的「节点长 ≤ key 长先拒
     + 前缀比较」同一键值对验证模式；
  ② 返回偏移索引（（地址-表头）>>2）而非值指针——与
     getenv 的「lea 值指针」不同（本批服务于 _putenv 槽
     位定位）；
  ③ 未命中负索引（neg eax）——调用方 jl 判负走追加路径
     （正/负双语义索引）；
  ④ key 长在 [esp+0x14] 预存（调用前外层压入）——栈槽复
     用传参；
  ⑤ 表项 NULL 判在循环头（mov eax,[esi]/test）而前进在
     尾（mov eax,[esi+4]/add）——头判尾进不对称；
  ⑥ 命中判 '=' 用 0x3d 硬编码且同时测 NUL（cmp al,0x3d
     + test al,al 两跳）——双条件连测。
