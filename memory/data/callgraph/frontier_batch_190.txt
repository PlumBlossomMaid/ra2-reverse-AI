0x7C8EC0  CRT __allmul（64 位有符号乘；9 callers，全 0x2B 读完）
================================================================================
身份：rank 观察名 __allmul（MSVC CRT 64 位乘法辅助函数——编译器对
__int64 乘法的内建调用目标，属 0x7C-0x7D MSVC6 静态 CRT 区，项目记忆
ra2_code_region_layout_crt_provenance 同区）。

机器码（全 0x2B）：
    mov eax,[esp+8]              ; ★ 乘数 A 高 32 位
    mov ecx,[esp+0x10]           ; ★ 乘数 B 高 32 位
    or ecx,eax / mov ecx,[esp+0xC]  ; ★ A 低 32 位
    jne 复杂路径                 ; ★ 两高 32 位都为 0 → 快路径
  快路径:
    mov eax,[esp+4] / mul ecx / ret 0x10   ; ★ 低×低 32 位乘
  复杂路径:
    push ebx / mul ecx           ; ★ A低 × B低（edx:eax）
    mov ebx,eax
    mov eax,[esp+8] / mul dword[esp+0x14]  ; ★ A高 × B低
    add ebx,eax / mov eax,[esp+8] / mul ecx ; ★ A高 × B低 + A低 × B高
    add edx,ebx ...              ; ★ 交叉项累加组合 64 位积

语义：**CRT __allmul（64 位有符号乘法辅助）**——两 64 位乘数（栈上各
8B）做 32 位分段乘法：低 32 位直接 mul，交叉项（A高×B低 + A低×B高）累加
进位，组合成 64 位乘积。★编译器在遇到 `__int64` 乘法时调用（9 callers 即
9 处 64 位乘点）。
★与 batch 001（0x7C8E17 _new）同 MSVC6 CRT 区——CRT 算术辅助族
（_allmul 是编译器运行库四大辅助之一）。

⚠️ partial：无（全 0x2B 读完）；9 个调用点的具体位置未逐一查。

0x53EF30  全局门控比较族（9 callers，0x53EF30-0x53EF90 读完）
================================================================================
机器码（0x53EF30，前 0x60）：
    mov eax,ecx / mov edx,[esp+4]
    mov ecx,[0x828140]           ; ★ 全局门控（batch 183 的 0x53F200 同款）
    push esi/edi
    sub ecx,2 / neg ecx / sbb ecx,ecx / and ecx,2 / add ecx,4
    ; ★ [0x828140]==2 → ecx=6；!=2 → ecx=4（比较长度 6/4 字节）
    lea esi,[eax+4] / lea edi,[edx+4]
    xor eax / repe cmpsb          ; ★ 逐字节比较 +4 起 ecx 字节
    pop edi/esi / sete al / ret 4 ; ★ 全等 → 1

语义：**全局门控比较族（[0x828140] 门控）**——按全局 [0x828140]==2 选
比较长度（6 字节 vs 4 字节），对 this->+4 与参数->+4 起做 cmpsb 逐字节比较
返相等标志。★与 batch 183 的 0x53F200（[0x828140]==2 才写 word setter）
同全局门控——0x53F2xx/0x53EFxx 区共享 [0x828140] 状态的字段族。
★**长度 6/4 的切换**：==2 时比较 6 字节（多比 2 字节），!=2 时 4 字节——
状态 2 下对象多一个 word 字段参与比较（版本字段推断）。

⚠️ partial：[0x828140] 状态 2 语义（batch 183 同 partial）、+4 起 6/4 字节
布局、紧邻 0x53EF60 变体（==2 时比较 [0] word + +4 dword）。
