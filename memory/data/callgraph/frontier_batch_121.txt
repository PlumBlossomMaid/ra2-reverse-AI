0x4E1390  GadgetClass 析构/清全局（18 callers）
================================================================================
机器码（前 0x40 实读）——ranking 名 GadgetClass::~GadgetClass：
    mov [ecx], 0x7E92BC            ; ★ 装虚表 0x7E92BC
    mov eax, [0x8B3E90]            ; ★ 全局（当前 Gadget 指针）
    cmp ecx, eax / jne 跳过1
    mov eax, [ecx+0x20] / and ah, 0xFE / mov [ecx+0x20], eax   ; ★ 清 +0x20 bit
    xor eax / mov [0x8B3E90], eax   ; ★ 全局清空
  跳过1:
    mov esi, [0x8B3E88] / cmp ecx, esi / jne 跳过2
    mov [0x8B3E88], edx             ; ★ 第二全局清空
  跳过2:
    mov esi, [0x8B3E8C] / cmp ecx, esi / jne 跳过3
    ...                             ; ★ 第三全局清空（0x8B3E8C）

语义：**「析构时若自己是全局注册对象则清对应全局」的模式**——装虚表 0x7E92BC，

还顺带清 +0x20 的低位 bit）。与 batch 102（AnnounceExpiredPointer 清

全局槽疑为 GadgetClass 的「当前/焦点/悬停 gadget」注册。

⚠️ partial：三个全局槽（0x8B3E88/0x8B3E8C/0x8B3E90）语义、+0x20 bit 含义、
函数后半（0x4E13D3 起）未读完、宿主类名（GadgetClass 为 ranking 名）。

================================================================================
