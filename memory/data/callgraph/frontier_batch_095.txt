机器码还原（105B，签名 byte __thiscall()）：
    push esi / mov esi, ecx                    ; this
    mov eax, [esi + 0x318]                     ; ★ this->[0x318]（计数器）
    inc eax
    and eax, 0x800000ff                        ; ★ 低 8 位回绕+符号扩展（-128..127 环）
    jns over / dec eax / or eax, 0xffffff00 / inc eax
  over:
    cmp eax, [esi + 0x314]                     ; ★ 与 this->[0x314]（上一值）比较
    je skip
    call 0x5d4d50                              ; 不等 → 调 helper（见下）
  skip:
    mov eax, [esi + 0x318]
    mov [esi + 0x314], eax                     ; this->[0x314] = this->[0x318]
    lea ecx, [eax + 1]
    and ecx, 0x800000ff / jns over2 / dec / or 0xffffff00 / inc
  over2:
    cmp ecx, eax
    je done
    call 0x5d4d50                              ; ★ 第二次 helper 调用（回绕触发）
  done:
    mov eax, [esi + 0x318]
    mov [esi + 0x314], eax                     ; this->[0x314] = this->[0x318]
    pop esi / ret

语义：**把 this->[0x318] 的 8 位回绕「下一值」与 this->[0x314] 比对，变化时调
0x5D4D50 做一次轮询/同步**，然后把 [0x318] 拷贝进 [0x314] 作为上次值缓存。
两次比较点的差异：
  ① `(byte)([0x318]+1) != [0x314]` —— 首次进入或上次值不匹配；
  ② `(byte)([0x318]+1) != [0x318]` —— 仅当 [0x318] 是 0x7F/0x80 邻域回绕时触发
     （即值跨越 ±128 边界，低 8 位环到另一侧）。
推断：这是「帧间轮询游标推进」——[0x318] 是当前游标/键位组索引，[0x314] 是上
一次处理过的值；调用方每帧（或每次 FocusOnWindow）调它，游标环内推进，跨边界
时触发 0x5D4D50 刷新。⚠️ 0x318/0x314 字段的 YRpp 名称（Keycodes 后的计数器）
未对齐布局文档，语义为推断。
