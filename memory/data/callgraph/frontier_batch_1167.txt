★语义：**MSVC6 CRT 双字段宽串输出写入器（推断名——batch
1041 邻族消费点）**——cdecl 2 参：
  ① 0x7D4BF0（batch 008 strcpy 词级）把对象本体拷入
     目标宽串缓冲（对象首串 = 基础内容）；
  ② 字段 [esi+0x40] 字节标志非 0 → 经 0x7CE049（batch
     1041）count=2 双源拼接（源 A=&字段 0x40、源 B=常量
     串 0x818D7C）追加到目标；
  ③ 字段 [esi+0x80] 字节标志非 0 → 同款双源拼接（源 A=
     &字段 0x80、源 B=常量串 0x826598）追加。
  = 对象化宽串/格式串输出（两可选字段按标志位拼常量后
  缀）——CRT 字符串拼接链（batch 008 词级 strcpy + batch
  1041 count 循环器）的组合消费。
