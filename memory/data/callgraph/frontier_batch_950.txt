栈）。纯内存操作，无子调用无全局引用——全程可真身模拟。
  机器码（0x7CA5D3-0x7CA607，53B）：

    （第2参，注意 0x7CA5D8 在 push esi 之后取址）；push edi；

  循环 0x7CA5E0：

    movzx edi, cx          ; edi = *s2（零扩展）

    jne 0x7CA5F8           ; 差值非 0 → 跳出比较
    test cx, cx            ; *s2 == 0（仅在相等时检查，只看 s2 的 NUL）
    je 0x7CA5F8

    mov cx, [esi] / jmp 循环
收尾 0x7CA5F8：pop edi / pop esi；
    test eax, eax

    eax<0 → or eax, 0xFFFFFFFF → ret -1
