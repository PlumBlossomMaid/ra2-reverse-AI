一、链语义（全段 disasm 复核 + golden 15 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7C8D20 = MSVC6 静态 CRT
`_stricmp`（strcmpi）——大小写不敏感字节串比较，返回折叠 s1<折叠 s2
→ -1 / 相等 → 0 / > → +1。分两路径，由 locale 全局 [0xB782A0] 门控：
  · 快路径（[0xB782A0]==0，游戏默认 C locale 恒走此路）：
      mov al,0xFF（哨兵：首轮 or al,al 非零保证进入循环）
      循环顶 or al,al / je 返回：al 为上一轮读到的 s2 字符——s2 先到
      NUL 且与 s1 全等 → 返回 0
      mov al,[esi](s2++)；mov ah,[edi](s1++)；cmp ah,al / je 循环顶
      （原始相等 → 继续）
      折叠 s2 字符：sub al,0x41 / cmp al,0x1A / sbb cl,cl / and cl,0x20
        / add al,cl / add al,0x41 —— 仅 'A'..'Z'（无符号 <26）加 0x20
      xchg al,ah；折叠 s1 字符（同款）
      cmp al,ah（折叠后比较）/ je 循环顶
      sbb al,al / sbb al,0xFF → 折叠 s1<折叠 s2（无符号）→ -1 否则 +1
      movsx eax,al / ret
  · 慢路径（[0xB782A0]!=0，locale 激活）：
      lock inc [0xB78BA4]（锁计数++）/ cmp [0xB78BA0],0 / jg 重入分支
      重入分支：lock dec 回退 + push 0x13 / call 0x7CD9F5（报错，
        golden 灌锁未持有不触发）/ mov [esp],1（锁状态 1）
      正常：push 0（锁状态 0）
      循环同快路径，但字符不等时：
        push eax（存 s2 字符）/ push ebx（第一参 = s1 字符）
        call 0x7CB063（tolower(s1)）→ eax → mov ebx,eax
        call 0x7CB063（第二参复用栈上 s2 字符 → tolower(s2)）
        cmp bl,al（tolower(s1) vs tolower(s2)）/ je 循环顶
        sbb eax,eax / sbb eax,-1 → s1<s2 → -1 否则 +1
      pop eax（锁状态）/ or / jne 0x7CDA56（异常解锁，不触发）
      lock dec [0xB78BA4]（正常解锁）/ mov eax,ebx / ret

★原版怪癖（golden 实证，C++ 侧逐条复刻）：
  ① 循环顶 `or al,al` 判定的是**上一轮读到的 s2 字符**——首轮用哨兵
     al=0xFF 保证进入；s2 先到 NUL 且与 s1 全等 → 返回 0；
  ② 大小写折叠仅 'A'..'Z'（c-0x41 无符号 < 0x1A）加 0x20，sbb cl,cl/
     and cl,0x20 惯用法；'@'(0x40) 减 0x41 回绕成 0xFF 后仍原样
     （非字母不动，'Z'+0x20='z'、'a' 减 0x41=0x20 不小于 0x1A 原样）；
  ③ 比较结果 = 折叠 s1 < 折叠 s2（无符号）→ -1，否则 +1（cmp 后
     sbb al,al / sbb al,0xFF 惯用法，0 已被前面 je 短路）；
  ④ 慢路径 tolower 调用序：**先 s1 后 s2**（push eax 存 s2 字符、
     push ebx 作第一参 → call 0x7CB063 先 tolower(s1)，第二次调用复用
     栈上 s2 字符 tolower(s2)）——与快路径的折叠顺序相反但比较方向
     一致；golden tl 序列逐字符实证；
  ⑤ 慢路径锁 [0xB78BA4] +1 后 -1 平衡（golden lockf=0 locka=0）；
  ⑥ 重入分支（[0xB78BA0]>0）与 0x7CD9F5/0x7CDA56 在 golden 中 0 次
     调用（灌 lock_held=0）——C++ 侧保留 AcquireLock/ReleaseLock 接口
     对齐结构，重入路径留待锁家族独立批次。

三、C++ 模型（code/rewrite/runtime/crt_stricmp.{h,cpp}）
------------------------------------------------
namespace ra2::runtime。CrtStricmpWorld 抽象四事：LocaleActive
（[0xB782A0]!=0 快/慢路径门控）、LocaleToLower（0x7CB063，慢路径
逐字符转换）、AcquireLock/ReleaseLock（慢路径锁 inc/dec）。单函数：
  stricmp_legacy(world, s1, s2) —— 0x7C8D20：快路径纯 ASCII 折叠
    逐字节比较（哨兵 al=0xFF、fold 只用 'A'..'Z'）；慢路径 AcquireLock
    → 逐字节 tolower 比较（先 s1 后 s2）→ ReleaseLock → 返回 -1/0/+1。
  stricmp_ascii_fold(c) —— 快路径折叠单元（sbb/and 惯用法等价、
    无符号回绕语义保留）。
  kStricmpLocaleGlobal=0xB782A0 常量暴露原版 locale 门控全局。
无失败路径、无额外校验。
