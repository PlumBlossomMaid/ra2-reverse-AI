================================================================================
FacingStruct —— 16 位朝向控制器（0x18 字节）
================================================================================
布局（逐偏移由汇编确认，与 YRpp GeneralStructures.h:255 一致）：
    +0x00  uint16 Value    目标朝向（想转去哪）
    +0x04  uint16 Initial  本次旋转起点朝向
    +0x08  uint32 StartTime  Timer.StartTime（0xFFFFFFFF=未启动/-1 哨兵）
    +0x0C  uint32 unused   匿名位域，本家族从不读
    +0x10  uint32 TimeLeft  Timer.TimeLeft（旋转总帧数）
    +0x14  uint16 ROT      转速 = INI 值 ×256（ctor clamp 到 127）
DirType 16 位：0x10000 = 一整圈。

家族成员（8 个）：
  0x4C91E0  ctor(rot)：Value/Initial/TimeLeft=0、StartTime=CurrentFrame、
           ROT=clamp(rot,0..127)<<8（0x4C91FF cmp 0x7F / jl / mov 0x7F 实锤）
  0x4C9220  SetDesired(DirType)：Value==target 返 false；否则
           Initial=current()（旋转中途改向 = 从此刻实际朝向继续）、Value=target、
           ROT>0 时 StartTime=CurrentFrame、TimeLeft=|Value-Initial|/ROT
           （0x4C92B1 mov [ecx+4],eax 实锤 Initial 记的是 current()）
  0x4C93D0  GetFacing(DWORD*)：current() 插值主函数（★ 本批主登记项）
  0x4C9470  裸 getter：*out = *(uint32*)this（3 callers）
  0x4C9480  IsRotating（YRpp 符号）：ROT>0 && GetTimeLeft()>0
  0x4C94B0  IsRotatingCW（YRpp 符号）：旋转中 && (Value-Initial)>0（setg）
  0x4C94F0  IsRotatingCCW（YRpp 符号）：旋转中 && (Value-Initial)<0（sets）
  0x4C9530  Difference()：Value - current()（1 caller）
  0x4C95D0  Difference(DirType)：给定朝向 - current()（ret 8 双参）
  0x4C9300  同 0x4C93D0 但经 TimerStruct::GetTimeLeft(0x426630) 调用（未注册）
辅助：0x426630 = TimerStruct::GetTimeLeft——StartTime==-1 原样返回 TimeLeft；
      elapsed=frame-StartTime；elapsed>=TimeLeft 钳 0（无符号 jge）。

★ 插值公式（机器码顺序，关键差异点）：
    steps = |Value-Initial| / ROT；per_step = (Value-Initial) / steps
    current = Value - per_step * GetTimeLeft()
  机器码是「先除后乘」：0x4C943B idiv（diff/steps）→ 0x4C943D imul（×remaining）。
  OpenTS facing.cpp Current() 同序：`dir.Facing -= RotationTimer * (diff / rot)`。
  **YRpp 头文件写反了**：`steps_left * diff / num_steps`（先乘后除），整数截断
  点不同（如 diff=2047,steps=7,left=10：机器码=292*10，先乘后除=(10*2047)/7=2924）
  ——模型按机器码/OpenTS 写，单测 DivideBeforeMultiplyMatchesMachineCode 钉死。

三层参照：
  RA1 FACING.H（CnCRemastered GPL）：老版 FacingClass 更简单（Current/Desired
  两字段 + Difference，无定时器插值）——RA2 版是 TS 时代演化，加了 StartFacing/
  RotationTimer/ROT 三字段做匀速旋转。
  OpenTS code/facing.{h,cpp}（TS 重建）：SetDesired/Current/Is_Rotating_CW/CCW/
  Difference/Set_ROT 与 RA2 asm 逐函数对应，是本批的语义蓝本。
  YRpp GeneralStructures.h:255：FacingStruct 布局与成员方法名（current/turn/
  in_motion/difference/num_steps）全部吻合。
