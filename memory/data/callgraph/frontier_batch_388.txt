机器码（要点）：

计数数组里**前移删除**，目标格经 `[vtable+8]` 扩容后在**尾部 append**；
**起点与终点同格则直接返回**。入口先经参1 对象的虚表槽 `0x2F8` 做一次调用。
★原版怪癖（照抄）：① **16 位坐标、负数钳 0**（`test ax,ax / jge`+`movsx`，
负 → `xor`——**-1 坐标不会被地图边缘吸收而是直接当 0**）；
② **魔数 0x66666667 有符号 ÷10** 加 `sar 3` 与符号修正（非 div）；
③ **clamp `0x13`（19）硬编码**，且另两个 16 位参同样钳；④ **起点先做一次
`call [vtable+0x2F8]`**（结果未在本函数内使用——**纯副作用调用，或参数校验**）；
⑤ **同一数组删除走"计数递减 + 向前搬移"、append 走"[vtable+8] 扩容 + 尾部写"**

② 0x005F6CD0 —— 双判据碾压判定（推断名，195B，ret 4；ranking 带名 ObjectClass::IsCrushable）
================================================================================
机器码（要点）：
```
005f6cd0  push esi/edi / edi = [esp+0xC]（★参1 = 施压/来源对象）/ esi = ecx（★this = 被压对象）
005f6cd8  **test edi,edi / je 0x5f6d3f**（★参1 为空 → 走判据 B）
 ; —— 判据 A（有来源对象）：
          **call [edi_vtable + 0x84]** → cl = [eax + 0xD29] / test / je 0x5f6d3f（★来源类型门控）
          test esi,esi / je 0x5f6d3f
          **test byte [esi + 0x14], 1 / je 0x5f6d3f**（★★this+0x14 **bit0** 门控）
          **call [esi_vtable + 0x84]** → cl = [eax + 0xD2A] / test / **jne 0x5f6d3f**（★互斥字节）
          **call [esi_vtable + 0x2C]** → **cmp eax, 6 / je 0x5f6d3f**（★★槽 0x2C == 6 拒绝——
            batch 384 装配器 `cmp 6`、batch 387 `cmp 4` **同族魔数判据**！）
          ecx = [edi + 0x21C]（★来源类型指针）→ push esi → **call 0x4F9A90**（★关系/许可查询）
            → test al / jne 0x5f6d3f
          **call [esi_vtable + 0x160]** → test al / **jne 0x5f6d3f**
          → **mov al,1 / ret 4**（★碾压可行）
005f6d3f  ; —— 判据 B（参1 为空 / 判据 A 失败）：
          **call [esi_vtable + 0x88]** → cl = [eax + 0x22D] / test / je 0x5f6d8c
          test esi,esi / **test byte [esi+0x14],1** / je 0x5f6d8c（★同一 bit0 门控）
          **mov al,[esi + 0x2A4]**（★**直接字节字段**判据）/ test / jne 0x5f6d8c
          ecx = [edi + 0x21C] / push esi / **call 0x4F9A90** / test al / jne 0x5f6d8c
          **call [esi_vtable + 0x160]** / test al / jne 0x5f6d8c

```
**语义（按机器码登记；ranking 带名 ObjectClass::IsCrushable）**：**双判据碾压
判定**——判据 A（参1 非空）：来源对象类型 `[vtable+0x84]→[+0xD29]` 与自身
`[vtable+0x84]→[+0xD2A]` 两字节、`this+0x14 bit0`、**槽 0x2C != 6**、`0x4F9A90`
查询、槽 `0x160` 全过 → 返回 1；判据 B（参1 空或 A 失败）：`[vtable+0x88]→[+0x22D]`、
`this+0x14 bit0`、**`this+0x2A4` 直接字节**、`0x4F9A90`、槽 `0x160` 全过 → 返回 1；
否则返回 0。
★原版怪癖（照抄）：① **两套判据并存**（参1 空/非空走不同的字节门控集——`+0xD29/
+0xD2A` 走 A、`+0x22D/+0x2A4` 走 B）；② **`test byte [esi+0x14],1` 位 0 门控**
（整字节非零不行，**只在 bit0**）；③ **槽 `0x2C == 6` 时拒绝**（不是"== 6 允许"，
相反——与 batch 384 装配器 `cmp 6` **同族但语义取反**）；

字段读**，判据 A 却用虚表槽 `0x84` 间接——**同一查询两种取值方式**。
★跨批次连接：**槽 `0x2C` 魔数判据族**（batch 382 的 `cmp 1`、384 的 `cmp 6`、
387 的 `cmp 4` → 本条 `cmp 6`）——**0x2C 槽返回值语义在 6 处不同函数里出现，

`HouseClass::TakeMoney 0x4F9790`，**同为 0x4F9 族，未读，不猜**）。
★新登记：函数 **`0x4F9A90`**（关系/许可查询，未读）；字段 **`+0x14`（bit0）**、
**`+0x2A4`**、类型字节 `[+0xD29]/[+0xD2A]/[+0x22D]`；虚表槽 `0x84/0x88/0x2C/0x160`。
