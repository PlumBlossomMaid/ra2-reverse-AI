★语义：**CRT pow() ±Inf 特殊值边界处理器（推断名——
IEEE-754 pow 特殊值分派表）**：
  ① y==+Inf：|x|>1 → +inf / |x|<1 → 0.0 / |x|==1 → NaN（返回 1）
  ② y==-Inf：|x|>1 → 0.0 / |x|<1 → +inf / |x|==1 → NaN（返回 1）
  ③ x==+Inf：y>0 → +inf / y==0 → 1.0 / y<0 → 0.0
  ④ x==-Inf：y>0 且奇整 → -inf（偶整 → +inf）/ y<0 且奇整 →
    -0.0（偶整 → +0.0）/ y==0 → 1.0
  ⑤ 普通 x、x=NaN → 不写 out 返回 0（交回主流程）
  与 IEEE-754 pow 特殊值语义完全吻合。

★子函数 0x7CF64C（紧邻 304B/13B? 实 0x7CF64C-0x7CF6B3，
68B）= **y 奇偶整数性判定器**：调 0x7D930F（★★batch 012
已登记 IEEE-754 double 分类器 _fpclass）+ test al,0x90
（NaN/Inf 位）→ 非数返回 0 → frndint(y)==y（★0x7D8EE3
frndint 包装）判断整性 → 再 frndint(y/2)==y/2（★[0x7E1708]
=2.0）判偶 → 返回 0=非整/1=奇整/2=偶整。

★E8 被调者：0x7CF64C（紧邻奇偶判定器，1 caller=0x7CF5EF）
  → 0x7D930F（batch 012 _fpclass）+ 0x7D8EE3（frndint 包装

★调用点（探针 E8 实测 2 处，与 pool callers=1 口径有出入）
  ：0x7C90E5 + 0x7CF13C——两宿主均为 fnsave→call→frstor
  FPU 环境环（CRT 数学函数标准形态，__CIpow 类入口）。

★原版怪癖（照抄）：
  ① 返回标志 1 仅在「y=±Inf 且 |x|==1」写 NaN 时置位；
     其余边界输出返回 0，由调用方 test eax/eax 判定是否已
     处理；
  ② x 为 NaN 直接返回 0 不写 out（NaN 传播交主流程）；
  ③ 奇偶判定走 frndint——原版全局 RC=chop（向零截断）下

   重写时用等价运行时（标准 C 库 pow）代替，逐字节复刻无
