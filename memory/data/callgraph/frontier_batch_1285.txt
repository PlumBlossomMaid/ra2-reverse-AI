计数复位）。4 unique caller（39 callsite）。

★怪癖：①★双重门控（+4 非空 && +0xD owns 才释放——与 batch 记忆

0x54A950 —— 位索引 bit 测试器（50B 全程读完）
================================================================================
签名：thiscall（ecx=位图基址）+ 1 栈参（edx=位索引）ret al。
机器码（全文 50 字节）：
    push ebx; push esi
    mov eax, edx; mov esi, ecx; mov ecx, eax     ; ecx = 位索引
    and ecx, 0x80000007; jns 0x54a965            ; ★byte 索引回绕准备
    dec ecx; or ecx, 0xfffffff8; inc ecx          ; ★带符号 mod 8
    0x54a965:
    cdq; and edx, 7; mov bl, 1                   ; bl = 1（位掩码基）
    add eax, edx; shl bl, cl                     ; ★bit 位 = 1<<(idx mod 8)
    sar eax, 3                                   ; 字节索引 = idx/8（有符号）
    mov dl, [eax+esi]                            ; ★读位图字节
    pop esi
    and bl, dl; neg bl; sbb ebx, ebx; neg ebx    ; ★!=0 → 1（布尔归一）
    mov eax, ebx; pop ebx; ret

语义：**位索引 bit 测试器**——位索引 edx：字节索引 = idx/8（sar 3 有符号
除）、位掩码 = 1 << (idx mod 8)（★and 0x80000007 + 符号扩展回绕），读
位图字节并测试该位，结果归一为 0/1（★neg/sbb/neg 布尔化——batch 1264
0x69DEB0 同款惯用法）。4 unique caller（50 callsite）。

★怪癖：①★带符号 mod 8（and 0x80000007 + dec/or/inc——负索引安全）；
②★sar 3 有符号字节索引（负索引向下除）；③★neg/sbb/neg 布尔归一
（非零→1——与 batch 1264 0x69DEB0 的 0x800 标志合成同款）；④★位图
基址 this 直接作字节数组（内存密集位图——flags 位图推断）。

⚠️ partial：位图语义（flags 集合）、宿主类（0x54Axxx 区——网络/会话
域 batch 1266 0x54F1C0 邻域）、4 unique caller 身份。
