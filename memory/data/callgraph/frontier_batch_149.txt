0x6612C0  字节 alpha 混合（13 callers）
================================================================================
机器码还原（前 0x50）——逐字节 lerp：
    mov bl, [ecx]                   ; ★ 源字节（第 1 通道）
    mov esi, [esp+0xC]              ; ★ 因子（α，0x00-0xFF）
    mov edi, [esp+0x14]             ; ★ 目标字节数组
    mov al, [edi] / and edx, 0xFF / and esi, 0xFF
    sub eax, edx                    ; 目标 - 源
    imul eax, esi                   ; × α
    cdq / and edx, 0xFF
    add eax, edx / sar eax, 8       ; ★ (diff×α)>>8
    add al, bl                      ; 源 + 偏移
    mov [ecx], al                   ; 写回
    mov bl, [ecx+1] ...             ; ★ 逐通道循环（第 2 通道同构）

语义：**逐字节 alpha 混合（lerp）**——对字节数组逐通道做
`dst = src + ((tgt - src) × α >> 8)`，α 取 0x00-0xFF，sar 8 得整数。★这是
调色板/表面混合的 RGB 处理惯用法（batch 144 的 0x80808081 ÷255 运算同理论
域但不同实现——一条是魔术数除法、本条是 sar 8 比例）。

★跨批次连接：batch 144（0x517440 除 255 比例）+ 颜色/绘制族——逐字节 lerp
的标准实现。

⚠️ partial：α 语义（0xFF=全换 0x00=保持?）、通道数与目标布局、后半循环。
