一、链语义（disasm 全 37B + 双调用宿主交叉 + 双依赖登记
交叉，0x7D45BA-0x7D45DE）
--------------------------------------------------------------
签名（确认）：cdecl 2 参（[esp+4]=int* count 计数器指针、
[esp+8]=stream 流上下文），返回最后一个非空白字符（ax/di
低 16 位）。

主体（0x7D45BA-0x7D45DE）：
007d45ba  push esi
007d45bb  mov esi, [esp+8]                 ; ★esi = 参1
                                           ;   &count（push 后
                                           ;   [esp+8]=原[esp+4]）
007d45bf  push edi
007d45c0  push [esp+0x10]                  ; ★push 参2 stream
                                           ;   （两次 push 后
                                           ;   [esp+0x10]=原
                                           ;   [esp+8]）
007d45c4  inc dword[esi]                   ; ★(*count)++
007d45c6  call 0x7d4596                    ; ★★TSV:1921 CRT 流
                                           ;   字符读取器薄包
                                           ;   装（0x7DA512 直
                                           ;   通——读一个字符）
007d45cb  mov edi, eax                     ; edi = ch
007d45cd  push edi
007d45ce  call 0x7cb8a8                    ; ★★TSV:1857 宽字
                                           ;   符空白分类（掩
                                           ;   码 8 _iswctype）
007d45d3  pop ecx
007d45d4  test eax, eax
007d45d6  pop ecx                          ; 清 stream 参
007d45d7  jne 0x7d45c0                     ; ★空白 → 循环
                                           ;   （再 inc/再读）
007d45d9  mov ax, di                       ; 返回最后非空白
                                           ;   字符
007d45dc  pop edi
007d45dd  pop esi
007d45de  ret

★语义：**MSVC6 CRT wcstod/strtod 族前导空白跳过计数器
（推断名——跳过流前导空白并累计消费字符数）**——cdecl
2 参：
  do {
      (*count)++;                  // 每读一字符计数 +1
      ch = 0x7D4596(stream);       // 流字符读取
  } while (0x7CB8A8(ch));          // 空白（掩码 8）继续
  return ch;                       // 返回第一个非空白字符
  = strtod/wcstod 解析的空白跳过前置（计数供解析后偏移量
  结算——消费长度 = count 值），最后非空白字符作为首解析
  字符交给下游。

★调用点（探针 E8 实测 2 处）：
  ① 0x7D3ABA（wcstod/strtod 族主解析宿主，未登记）：前
     缀链 push 8/push eax/call 0x7D3920（★★TSV:141
     _iswctype 掩码 8 空白检查）→ dec [ebp-4]（★count--）/
     lea eax,[ebp-4]/push [ebp+8]（stream）/push eax（&count）
     → call 0x7D45BA（★本批）→ pop ecx×2 → push eax →
     call 0x7D45A1（★★TSV:165 十进制两位数格式化守卫 -1
     直通）→ inc edi×2 → mov ax,[edi]……（继续数值解析
     ）——计数流共用（[ebp-4] 计数器先 dec 再交本批循环）
     ；
  ② 0x7D3C3E（同族另一分支）：movzx esi,[edi]/or esi,0x20
     /cmp esi,0x6e（'n'）/0x63（'c'）/0x7b（'{'）（★
     inf/nan/hex 前缀判定）→ push [ebp+8]/lea eax,[ebp-4]
     /push eax → call 0x7D45BA（★本批）→ pop ecx → jmp
     0x7D3C51——前缀分支也走空白跳过（计数同 [ebp-4]）。
  两调用点均传 &count=[ebp-4]（宿主局部计数器）+ stream=
  [ebp+8]（宿主参）。

★全局：零（纯栈 + 调用方指针传参）。

★原版怪癖（照抄）：
  ① do-while 先读后判（无条件先 inc/读一字符再判空白）—
     —与标准 while 前导跳过不同，流至少读一个字符；
  ② 计数器每轮 +1（含被跳过空白）——消费长度统计含空白
     （strtod 偏移量语义）；
  ③ 空白判定走宽字符 _iswctype（掩码 8）而非窄字符
     isspace——wcstod 侧读宽流（[esi+0xC] 位 0x40 宽窄分
     流见 batch 1059 0x7DA512）；
  ④ 返回最后一个非空白字符经 ax=di（edi 仅低 16 位有效）
     ——高 16 位不清理（调用方按字符用）；
  ⑤ stream 参数经两次 push 后 [esp+0x10] 读取（esi/edi 各
     push 后偏移 +8 的栈读法）——编译器栈偏移惯用；
  ⑥ 两调用点共享 [ebp-4] 计数器（先 dec 再交循环再传
     &count）——计数回退语义在调用方（本批只增不减）。
