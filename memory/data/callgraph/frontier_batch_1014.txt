★语义：**三字段批量查询器（推断名）**——thiscall（ecx=this，edx=
参1 指针，[esp+4]=参2 指针，[esp+8]=参3 指针）：把对象三个
byte 字段读出来零扩展写进调用者给的三处 dword：
  ① [this+0xF2] → *edx；
  ② [this+0xF3] → *[esp+4]；
  ③ [this+0x108] → *[esp+8]；
  ④ 全部写完后返回 -1。

★无子调用无全局引用（44B 全读实证）——纯内存对象批量 getter。

★★字段交叉实锤：+0xF3/+0x108 = batch 1008（0x7C30D0 上层推进器）
读过的同字段——0x7C30D0 的
  `mov dl, byte ptr [esi+0xf5]`（邻位 +0xF2/+0xF3 word 簇）
  + `mov al, byte ptr [esi+0x108] / test al,al / jne 跳过检查链`
（初始化跳过门控）。本函数是 0x7C30D0 字段访问链的配套查询侧
（把宿主对象状态一次性批量读出供上层判断）。

★原版怪癖（照抄）：
  ① 返回恒 -1（or eax,0xFFFFFFFF）——非 0 成功码（与 0x7C3230/
     0x7C3690 同款）；

     （先清 32 位再填 8 位）——MSVC6 byte→int 提升惯用；
