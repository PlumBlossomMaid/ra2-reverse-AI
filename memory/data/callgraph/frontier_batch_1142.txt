★语义：**MSVC6 CRT DBCS 感知字符串查找器（推断名——_mbschr
族，向前查找）**——cdecl 2 参：
  ① 门控 [0xB7885C]==0（locale 未初始化）→ 快路径直调
     strchr（batch 126），不加锁不感知 DBCS；
  ② 门控!=0 → 锁 0x19 临界区逐字节扫描：`[0xB78961]&4`
     判 lead-byte——非 lead → 单字节比较；lead → 次字节
     组合 (lead<<8)|trail 双字节比较；
  ③ 单字节命中返当前位置；双字节命中返前导字节位置
     （esi 已 inc → lea esi-1）；次字节 NUL 直接放弃返 0；
  ④ 单字节/终止共用出口用 sub/neg/sbb/not/and 无分支条件
     返回（target==current 返 esi，否则 0——终止时
     current=0：target==0 返终止符位置=strchr 语义、否则
     返 0）。

★调用点（探针 E8 实测 1 处 0x7DA9E1）：宿主 0x7DA9CD 起
  函数——`push 0x3d`（'=' 0x3D）+ call 0x7DC378 找 '='，
  未找到/'=' 在首位返，`cmp byte[esi+1],0` + 读 [0xB781E4]
  全局——CRT 环境/ini 键值分割域（batch 1044/1045
  getenv/_putenv 链同 0xB78xxx 全局区）。

★E8 被调者：0x7CAF30（batch 126 strchr——快路径）+ 
  0x7CD9F5（batch 966/TSV:238 锁 Enter）+ 0x7CDA56（batch
  961/TSV:239 锁 Leave）——**三个依赖全部已登记**。

★原版怪癖（照抄）：
  ① 门控 [0xB7885C]==0 → 快路径 strchr：不感知 DBCS、不加
     锁——与 batch 1047 0x7D571F 同款门控但彼用 strrchr
     快路径（查找方向不同同族对照）；
  ② 双字节命中返**前导字节**位置（esi 已 inc 过 → lea
     esi-1）；单字节命中返当前位置（esi 未 inc）——两条
     路径 esi 语义不一致靠补偿指令对齐；
  ③ 次字节 NUL → 直接放弃返 0（不完整双字节字符无命中，
     不继续扫描）；
  ④ 单字节/终止共用出口 `sub/neg/sbb/not/and` 无分支条件
     返回——target==0 终止时返终止符位置（strchr 语义正
     确）、target!=0 终止时返 0；
  ⑤ 锁编号 0x19（25）——字符分类锁族（batch 1036/1047
     同，区别于 batch 244 tolower 的 0x13）；
  ⑥ [0xB78961]&4 DBCS lead-byte 表（batch 1051 写侧置位/
     batch 040/1036/1047 消费侧同表同位）。

三、三态判定（为何 crt_runtime_verified 而非 cpp_reimplementation）
----------------------------------------------------------------
1. 归属：0x7DC378 = MSVC6 静态 CRT DBCS 感知字符串查找器
   （_mbschr 族）——0x7C-0x7D = MSVC6 静态 CRT
   （ra2_code_region_layout_crt_provenance）；门控
   [0xB7885C] + lead 表 [0xB78961]&4 + 锁 0x19 = CRT
   多字节字符处理标准形态（batch 1047 0x7D571F 同族已
   归档）。
2. 依赖：3 个已登记函数（0x7CAF30 strchr batch 126 /
   0x7CD9F5 锁 Enter / 0x7CDA56 锁 Leave）——重写 gamemd
   时用等价运行时（std::string find / 直接字节扫描）代替。
3. gamemd_replication_discipline：MSVC6 CRT 多字节库设施，
   重写时用等价运行时代替，逐字节复刻无意义——按商业库
   纪律归档，不写 C++ 模型不做 golden。
→ 状态：crt_runtime_verified（全 151B + 三依赖交叉 + 门控
写侧取证；函数名「DBCS 感知字符串查找器」由 strchr 快路径
