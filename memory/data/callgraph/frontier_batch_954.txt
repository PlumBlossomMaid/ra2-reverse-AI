纯内存操作，无子调用无全局引用——全程可真身模拟。

    al=ch（零扩展）；edx=s
  对齐探测（0x7CAF40）：test edx,3；未对齐逐字节：
    cl=[edx] / inc edx / cmp cl,bl（命中）→ je 0x7CAF20（返回
    edx-1，lea eax,[edx-1] 实锤）；test cl,cl（NUL）→ je 0x7CAFA4
    （返 0）直到对齐
  四字节 pattern（0x7CAF5B）：or ebx,eax / shl ebx,0x10 / or ebx,eax
    （ch 展开成 4 字节重复）
  主循环（0x7CAF66 四字节批量扫描）：
    ecx=*(u32*)edx；eax=ecx
    esi=ecx+0x7EFEFEFF（NUL 检测 A）
    edi=(ecx^pattern)+0x7EFEFEFF（命中检测）
    ecx^=pattern；ecx^=-1 → ecx^=edi → and ecx,0x81010100（命中位）
    eax^=-1 → eax^=esi → and eax,0x81010100（NUL 位）
    edx+=4
    ecx 非 0 → 0x7CAFA8 逐字节回验
    eax 非 0 → 0x7CAF93：and eax,0x1010100 → 非 0 真 NUL → 返 0；
      否则 and esi,0x80000000 → 非 0 假阳性 → 继续循环；==0 → 返 0
  回验（0x7CAFA8）：eax=*(u32*)(edx-4) 逐字节
    cmp al,bl → je 0x7CAFE5 返 edx-4 / test al,al → je 返 0
    cmp ah,bl → je 0x7CADF0... （edx-3 / -2 / -1 各命中返）
    全部不中 → jmp 0x7CAF66 继续

    小段，0x7CAF20-0x7CAF2F，本批实锤）。
