一、链语义（disasm 全 49B + 三依赖交叉 + 调用点宿主，
0x7CB80B-0x7CB83B）
--------------------------------------------------------------
签名（确认）：cdecl 1 参（[esp+4]=FILE* 流指针），返回读
取字符（int，0xFF 扩展）/ -1（EOF/错误）。

主体（0x7CB80B-0x7CB83B）：
007cb80b  push esi
007cb80c  mov esi,dword[esp+8]                 ; esi = FILE*（参1）
007cb810  push edi
007cb811  push esi
007cb812  call 0x7cb3f9                        ; ★★TSV:197 batch 046/
                                              ;   966 流锁 Enter
007cb817  dec dword[esi+4]                     ; ★★_cnt--（FILE+4）
007cb81a  pop ecx
007cb81b  js 0x7cb827                          ; 负 → 慢路径（补缓冲）
; → 快路径（0x7CB81D，缓冲有字符）：
007cb81d  mov eax,dword[esi]                   ; _ptr（FILE+0）
007cb81f  movzx edi,byte[eax]                  ; ★读一字符（零扩展）
007cb822  inc eax
007cb823  mov dword[esi],eax                   ; _ptr++
007cb825  jmp 0x7cb830
; → 慢路径（0x7CB827，_cnt<0 补缓冲）：
007cb827  push esi
007cb828  call 0x7d0703                        ; ★★TSV:160 batch 062/
                                              ;   035 fgetc 单字节读取
                                              ;   （流状态机底层读回调）
007cb82d  pop ecx
007cb82e  mov edi,eax                          ; ★字符/EOF = edi
; → 合流（0x7CB830，解锁返回）：
007cb830  push esi
007cb831  call 0x7cb44b                        ; ★★TSV:198 batch 046/
                                              ;   961 流锁 Leave
007cb836  pop ecx
007cb837  mov eax,edi
007cb839  pop edi/pop esi/ret                  ; ★返回字符

★语义：**MSVC6 CRT _fgetc 核心（推断名——流缓冲单字符读
取）**——cdecl 1 参：
  ① 流锁 Enter 后 `_cnt--`（FILE+4）；
  ② _cnt 非负 → 快路径：读 `_ptr`（FILE+0）处一字符
     （movzx 零扩展）、_ptr++；
  ③ _cnt 为负 → 慢路径：0x7D0703 fgetc 单字节读取（流
     状态机，底层读回调 0x7D07DF 补缓冲）拿字符；
  ④ 流锁 Leave 后返回字符（int，0xFF 扩展）。
  = FILE 流缓冲 getc 族核心（快/慢双路径 + 锁包围）。

★调用点（探针 E8 实测 3 处）：
  ① 0x7CB840：**紧邻 6B 转调壳**——call 0x7CB80B / pop
     ecx / ret（无参直转核心——fgetc 公开入口形态，本批
     函数即其实现体）；0x7CB847 起为新函数（[0x87C590]
     ctype 表查询 0x8000 位——_isalpha 类）。
  ② 0x5DC2B2：主区（5DC29B call 0x7CA845 打开文件后）
     push ebp/call——读字符消费；
  ③ 0x5DC2FC：同宿主后续读字符。

★E8 被调者（3 个，全已登记）：
  ① 0x7CB3F9（★★TSV:197 流锁 Enter——batch 046/966

  ② 0x7CB44B（★★TSV:198 流锁 Leave——batch 046/961

  ③ 0x7D0703（★★TSV:160 fgetc 单字节读取——batch 062/

  全部已登记，无未登记依赖。

★全局：无（纯 FILE 结构 + 锁分发）。

★原版怪癖（照抄）：
  ① `dec [esi+4]`（_cnt--）在快路径判断**之前**——先减后
     判，负则补缓冲（经典 getc 展开形态）；
  ② 快路径读字符用 movzx（零扩展）——返回 0-255 非符号
     扩展；
  ③ 慢路径把 0x7D0703 返回值（字符/EOF）放 edi 与快路径
     汇合——两条路径共用解锁出口；
  ④ 锁 Enter 用 push esi/call/pop ecx（cdecl 1 参清理）
     而 Leave 同形——锁调用无栈帧开销；
  ⑤ 无返回前对 EOF/错误专门处理（0x7D0703 内部管 -1）—
     _fgetc 上层透明；
  ⑥ 入口 push esi 后从 [esp+8] 读参（先压栈再取）——MSVC
     栈偏移惯用。
