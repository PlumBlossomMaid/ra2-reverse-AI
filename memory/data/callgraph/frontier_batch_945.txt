一、链语义（disasm 全段复核 + golden 5 用例实证）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7C93E8 = MSVCRT `free` 的调度
入口——cdecl 1 栈参 p、ret 由调用者清栈、返回 void。零子调用零全局
的纯调度结构不成立：锁家族 0x7CD9F5/0x7CDA56（CRT region lock）、
0x7CF7BD FindHeapSegment（已有 REIMPL find_heap_segment_legacy）、
0x7CF7E8 FreeSegment（811B 语义 partial）、[0xB78B9C] heap handle、
[0x7E127C] IAT HeapFree——全部作为 CrtFreeWorld 桩注入，结构指令真身。
  机器码（0x7C93E8-0x7C9430）：
    push esi / mov esi,[esp+8]（p）/ test esi,esi / je 直接返回
    push 9 / call 0x7CD9F5        ; EnterLock(9)
    push esi / call 0x7CF7BD      ; seg = FindHeapSegment(p)
    pop ecx / test eax,eax / pop ecx   ; 清 Find 参 + EnterLock 参
    je 0x7C9417（未命中）
    命中（0x7C9404）：
      push esi(p) / push eax(seg) / call 0x7CF7E8  ; FreeSegment(seg,p)
      push 9 / call 0x7CDA56      ; LeaveLock(9)
      add esp,0xC / pop esi / ret  ; 清 FreeSeg 2 参 + Leave 1 参
    未命中（0x7C9417）：
      push 9 / call 0x7CDA56      ; LeaveLock(9)
      pop ecx                     ; 清 Leave 参
      push esi(p) / push 0 / push [0xB78B9C](heap) / call [0x7E127C]
                                  ; HeapFree(heap, 0, p)（stdcall 3 参）
      pop esi / ret

★原版怪癖（golden 实证，照抄）：
  ① p == NULL → 不碰锁/堆，直接返回（不调任何桩）；
  ② 命中/未命中都在临界区内完成查找，未命中路径先 LeaveLock 再
     HeapFree（释放系统堆段不持 CRT 锁）；
  ③ EnterLock/LeaveLock 固定 key=9；
  ④ HeapFree 参数 = ([0xB78B9C], 0, p)——flags 恒 0，heap 恒全局。

三、C++ 模型（code/rewrite/runtime/crt_free.{h,cpp}）
------------------------------------------------
namespace ra2::runtime。单函数 + CrtFreeWorld 世界抽象（5 桩 + 1 全局
heap handle，参数与调用顺序按原版汇编固定）：
  free_legacy(world, p) —— 0x7C93E8：
    p == nullptr → 直接返回
    world->enter_lock(9)
    seg = world->find_segment(p)
    seg != nullptr → world->free_segment(seg, p) + world->leave_lock(9)
    seg == nullptr → world->leave_lock(9) + world->heap_free(heap, 0, p)
无失败路径、无额外校验。结构 = 原版 72B 控制流逐条照抄。

四、单测（test_crt_free.cpp，全量 63 项之一）
------------------------------------------------

  GoldenWorldCallSequenceMatches（逐用例：世界桩调用序列（标签+参数+

hex（0x41=65、0x7fffffff=2147483647），WorldCall 参数为十进制整数。
