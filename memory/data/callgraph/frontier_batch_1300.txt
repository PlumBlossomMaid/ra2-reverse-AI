0x7AE0C0 —— 位掩码截断器（29B 全程读完）
================================================================================
签名：thiscall（ecx=this）+ 1 栈参（[esp+8]）ret eax。
机器码（全文 29 字节）：
    push esi; mov esi, ecx
    mov ecx, [esp+8]               ; 栈参
    call dword ptr [esi+0x18]      ; ★虚表槽 0x18（取源值）
    mov ecx, [esi+0xC]             ; ★this->+0xC（位数 n）
    mov edx, eax
    mov eax, 1
    pop esi
    shl eax, cl                    ; ★1 << n
    dec eax                        ; (1<<n) - 1
    and eax, edx                   ; ★源值 & 掩码
    ret 4

语义：**位掩码截断器**——经虚表槽 0x18 取源值，按 this+0xC 的位数 n
做 (1<<n)-1 掩码截断（★低位保留、高位清零——n 位模运算形态）。
2 unique caller（8 callsite）。

★怪癖：①★虚表槽 0x18 取源值（动态源——宿主虚表决定）；②★1<<n 后
dec 得掩码（移位-1 惯用法）；③★this+0xC 作位数（字段存宽度/长度）；
④★结果 & 掩码截断（非模除——低位保留）。

⚠️ partial：宿主类（0x7AE0Cx 区——0x7AExxx 区）、虚表槽 0x18 语义、
this+0xC 位数用途、栈参含义、2 unique caller 身份。

0x777170 —— 双窗口字节求和器（★Ghidra 误标修正，74B 全程读完）
================================================================================
★边界修正：ranking/functions.tsv 标注 0x777170（1B）为函数起点——
反汇编证明 0x777170 是函数中段（jl 0x7771A9 条件分支点），真实函数

签名：thiscall（ecx=this 兼基址参）edx=数量 ret eax。
机器码（全文 0x777160-0x7771AA）：
    mov eax, ecx; push esi
    and eax, 0xFFF                ; ★基址低 12 位
    sub edx, eax                  ; 数量调整
    cmp edx, 1
    lea esi, [eax+ecx]            ; ★esi = 基址 + 低 12 位
    jl 0x7771A9                   ; 数量 < 1 → 直接返回
    mov eax, edx; and eax, 0xFFF; sub edx, eax
    cmp edx, 1; jl 0x7771A9       ; 再调一轮
    mov eax, 0x10000; xor ecx, ecx  ; ★累加器 ecx=0，窗口 0x10000
    cmp edx, eax; jle 0x7771A9    ; 数量 <= 0x10000 → 返回
    push ebx; push edi
    循环: movsx ebx, byte [eax+esi]            ; ★窗口 1：读字节（有符号）
    movsx edi, byte [eax+esi-0x10000]          ; ★窗口 2：读 0x10000 前字节
    add ebx, ecx
    add eax, 0x1000              ; ★步长 0x1000
    cmp eax, edx
    lea ecx, [ebx+edi]           ; ★累加两窗口字节
    jl 0x77718D                  ; 循环
    pop edi; pop ebx
    0x7771A9: pop esi; ret

语义：**双窗口字节求和器**——以 0x1000 步长遍历 [0x10000, 数量) 范围，
逐字节累加两个窗口（[基址+i] 与 [基址+i-0x10000]，movsx 有符号读），
结果在 ecx。★疑似地形/网格统计（跨页差分求和形态）。2 unique caller
（8 callsite）。

★怪癖：①★Ghidra 误标起点（0x777170 实为函数中段 jl 分支——按机器码
修正登记真实边界 0x777160）；②★双窗口差分累加（当前地址 + 0x10000
前地址——页/块差分统计）；③★movsx 有符号字节读（非零扩展）；
④★步长 0x1000（4096 对齐遍历）；⑤★范围门控（<1 或 <=0x10000 直接
