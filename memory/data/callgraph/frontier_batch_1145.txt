★语义：**MSVC6 CRT 浮点格式化链尾数/指数分派器（_ecvt/_fcvt
族宿主③）**——cdecl 4 参：
  ① 压 8B double 调 0x7D7DC0（前置组装器）得 10B 结构（写
     [ebp-0x10] 区）；
  ② 组装三参调 0x7D7D49（辅助器）做四舍五入/指数调整；
  ③ 分派：结构+4 指数域值<-4 或 >=目标 → 指数路径
     （0x7CEC87 五参）；否则尾数收尾扫描（NUL 扫描回退清
     尾）→ 尾数路径（0x7CED9E 四参参4=1）。
  = _ecvt/_fcvt 族格式化链的「组装 → 整形 → 尾数/指数分派」
  中间层。

★调用点（探针 E8 实测 1 处 0x7CEF0C）：宿主 0x7CEFxx 区
  分派器（0x7CEF00 现场：push [ebp+0x18]/[ebp+0x14]/[ebp+0xC]/
  [ebp+8] 四参 → call 0x7CEE45 / call 0x7CEC26（★未登记同族
  宿主）→ add esp,0x10/ret——公共入口分派 0x7CEE45 与
  0x7CEC26 两分支）。

★E8 被调者：0x7D7DC0（★★batch 906 前置组装器）+ 0x7D7D49
  （★★batch 905 辅助器）+ 0x7CED9E（★★batch 1064 尾数格式
  化器）+ 0x7CEC87（★★batch 1062 指数格式化器）——**四个
  依赖全部已登记**。

★原版怪癖（照抄）：
  ① 分派条件不对称：指数路径 = eax<-4 或 eax>=目标（双
     条件），尾数路径 = 否则（含 -4<=eax<目标 且
     esi<eax）——边界语义照抄；
  ② 尾数收尾扫描用 `and byte[edi-2],al`（al=0 → 回退两位
     清 NUL）——扫描后回退清尾惯用；
  ③ 尾数路径参4 固定 1、指数路径参4=[ebp+0x14] 参5 固定
     1——两路径参数面不一致（4 参 vs 5 参）；
  ④ 0x7D7D49 返回后 [ebp-0xc] 被重复读取（mov eax 两次）
     与 esi 预存值比较——辅助器结构字段复用；
  ⑤ 负号偏移：`cmp [ebp-0x10],0x2d/sete al + add eax,[ebp
     +0xc]`——'-' 判断加目标，与 batch 905/906 同款结构
     首字 '-' 约定；
  ⑥ 压参顺序 cdecl 右向左（先 [ebp+0x14] 后 [ebp+0xC]）—
     -指数路径五参末参=1 常数。
