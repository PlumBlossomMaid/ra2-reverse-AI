## 原版怪癖（照抄）

1. a 路与 2106 c 路同族但**无查找无分支**——同族对象两条读取路径（纯读 vs 查表更新）；
2. b 路外层索引**从计数-1 递减到 0**（倒序遍历，jns 判定）；
3. b 路槽 0x10 返回 -1 或 ≥ 计数时**照常 delete 元素**（删除判定与 delete 分离）；
4. c 路**双重删除**：槽 0x10 命中调 0x660f10 删除 + 外层循环对 edi 处再左移删除（若 edi < 更新后计数）——同一轮可能删两个位置；
5. c 路后半 `new 64B` 失败时 eax=0 仍照调 vtable[0xC](this,0,64,0)（不跳过）；
6. c 路 0x65fb80 构造器带 **(对象, -1, 0)** 三参；注册循环里临时 word[0]=0/word[2]=0 写栈再读回 push；
