一、链语义（disasm 全 48B + 调用点宿主，0x7DDE50-0x7DDE7F）
--------------------------------------------------------------
签名（确认）：cdecl 1 参（[ebp+8]=字符串指针），原地反转
后返回原串指针。

主体（0x7DDE50-0x7DDE7F）：
007dde50  push ebp/mov ebp,esp
007dde53  push edi/push esi
007dde55  mov edi,dword[ebp+8]                 ; edi = 串指针（参1）
007dde58  mov edx,edi                          ; ★edx 保存原串指针
007dde5a  mov esi,edi                          ; esi = 左指针
007dde5c  xor eax,eax
007dde5e  or ecx,0xffffffff
007dde61  repne scasb al,byte es:[edi]         ; ★★repne scasb 扫串尾
                                              ;   （strlen 惯用展开）
007dde63  cmp ecx,-2
007dde66  je 0x7dde7a                          ; ★空串（ecx==-2）→
                                              ;   直接返回
007dde68  dec edi                              ; 右指针 = 串尾前
007dde69  dec edi
; → 交换循环（0x7DDE6A）：
007dde6a  cmp esi,edi
007dde6c  jae 0x7dde7a                          ; ★★左 >= 右 → 完成
007dde6e  mov ah,byte[esi]                     ; ah = *左
007dde70  mov al,byte[edi]                     ; al = *右
007dde72  mov byte[esi],al                     ; *左 = *右
007dde74  mov byte[edi],ah                     ; *右 = *左
007dde76  inc esi
007dde77  dec edi
007dde78  jmp 0x7dde6a
; → 出口（0x7DDE7A）：
007dde7a  mov eax,edx                          ; ★返回原串指针
007dde7c  pop esi/pop edi/leave/ret

★语义：**MSVC6 CRT __strrev 字符串反转器（标准 strrev）**
——cdecl 1 参：
  ① repne scasb 找串尾（ecx 余值判空串：-2 → 直接返回）；
  ② 双指针（esi 左 / edi 右）从两端向中间交换字符，
     jae（左 >= 右）为终止边界；
  ③ 返回 edx 保存的原串指针（itoa/strrev 族惯例）。
  = 标准原地字符串反转（strlen 内联 + 交换循环）。

★调用点（探针 E8 实测 2 处，全在 Westwood 主区 0x5F9Fxx）：
  ① 0x5F9F83：call 0x4A1DE0 后 lea ecx,[esp+0x2c]/push
     ecx/call 0x7DDE50/add esp,4——对栈上 [esp+0x2c] 缓冲
     反转；
  ② 0x5F9FAF：同宿主后续同模式反转。
  宿主 0x5F9F70 区（lea edx,[esp+0x2c]/lea ecx,[esp+0x18]
  + 多寄存器保存 ebp/ebx——字符串处理工具函数，反转后
  继续消费）。

★E8 被调者：**零子调用**（全 48B 纯内联 strlen+交换）。

★全局：无。

★原版怪癖（照抄）：
  ① **repne scasb 内联 strlen**（or ecx,0xffffffff →
     repne scasb → 从 ecx 余值倒推长度）——非 call strlen
     库函数，编译器 -O1 展开；
  ② 空串特判 `cmp ecx,-2/je`（strlen==0 → ecx==-2）——
     反转循环跳过直接返回；
  ③ 终止边界用 **jae（无符号 >=）**——左指针越过右指针
     即停（奇偶长度统一）；
  ④ 交换用 **ah/al 双寄存器中转**（mov ah,[esi]/mov al,
     [edi]/写回）——非 XCHG 单条（编译器强度削减）；
  ⑤ 返回 edx 保存的原串指针（edx 在入段即拷贝）——标准
     strrev 返回约定；
  ⑥ 右指针起始 = 串尾前 2 个位置（dec edi ×2——scasb
     停在后一个 NUL 位置再退 1 到 NUL、再退 1 到末字符）。
