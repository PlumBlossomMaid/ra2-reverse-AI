0x7AF000 —— VectorClass 扩容器（143B 全程读完）
================================================================================
签名：thiscall（ecx=this）+ 1 栈参（[esp+8]）ret al。
机器码骨架（0x7AF000-0x7AF08E）：
    mov ebx, ecx
    mov eax, [ebx]               ; ★+0 旧容量
    mov ecx, [ebx+4]             ; +4 当前容量
    cmp eax, ecx; jge 0x7AF012
    xor al, al; ret              ; ★旧容量 < 当前 → 返 0 不扩容
    0x7AF012:
    lea esi, [eax+eax]           ; ★新容量 = 2×旧容量
    cmp esi, 0xA; jge 0x7AF02D
    mov [esp+0x10], 0xA          ; ★最小 10
    0x7AF02D:
    lea edi, [esi*4]; push edi
    call 0x7C8E17                ; ★new 容量×4 字节
    mov ebp, eax
    rep stosd + rep stosb        ; ★新内存清零
    mov eax, [ebx+8]             ; +8 旧数组指针
    test eax, eax; je 0x7AF075
    mov ecx, [ebx]; shl ecx, 2
    rep movsd + rep movsb        ; ★拷贝旧数据（旧容量×4）
    0x7AF075:
    mov ecx, [ebx+8]; push ecx
    call 0x7C8B3D                ; ★delete 旧数组
    mov [ebx+4], esi             ; 新容量
    mov [ebx+8], ebp             ; 新数组
    mov al, 1; ret

语义：**VectorClass 扩容器（Grow）**——旧容量 < 当前容量时返 0 不扩容；
否则新容量 = max(2×旧容量, 10)，new（0x7C8E17）容量×4 字节、清零、
拷贝旧数据（旧容量×4）、delete 旧数组（0x7C8B3D），更新 +4/+8，
返 1。★VectorClass 家族标准扩容（倍增 + 最小 10 下限）。2 unique
caller（8 callsite）。

★怪癖：①★新容量 2×旧 + 最小 10（lea eax+eax 倍增 + cmp 0xA 下限）；
②★rep stosd/movsd 双阶段（4 字节 + 余数字节拷贝）；③★先清零新内存
再拷旧数据（顺序敏感）；④★旧容量 < 当前容量快速返 0（不重复扩容
判定）；⑤★delete 旧数组在收尾（新数组就绪才释放）。

⚠️ partial：宿主类（0x7AF0xx 区——VectorClass 派生）、+0/+4/+8 布局
（容量/容量/数组）、栈参语义、2 unique caller 身份。

================================================================================

CF 标志直接布尔化）。2 unique caller（8 callsite）。后邻 0x765710
为标量删除析构器（vtable 0x7F6F6C + 0x65D460 析构 + flag&1 → delete——
同族候选未登记）。

★怪癖：①★sbb eax,eax 后 neg（CF 布尔归一——无分支比较结果）；
②★一级间接取上限（+4 对象 -> +0x10）；③★14B 极简（无栈帧）。

⚠️ partial：+4 对象类型、+0x10 上限语义、+8 比较值含义、宿主类
