=== 语义 ===

**DSurface 系矩形填充例程（推断名）**——thiscall 3 栈参 ret
0xC（ecx=表面对象、参 1=[ebp+8] 矩形对象、参 2=[ebp+0xC] 区域
对象{+0/+4 起点、+8 宽、+0xC 高}、参 3=[ebp+0x10] 填充值）：
① 区域宽/高<=0 → 直接返 0（空区域短路）；
② this 虚表槽 0x78 取边界 → 0x421B60（batch 078）与参 1 矩形
  合并 → 起点相加 → 0x45A130（batch 112）打包宽高 → 0x421B60
  第二合并 → 结果宽/高<=0 返 0；
③ 槽 0x74 取行步长 → 0x437F30（batch 129）拷贝矩形 8B → 槽
  0x5C 锁定取表面缓冲（空返 0）；
④ 槽 0x70 模式判定：==1 → 快速填充（双字×4 填充，宽/4 dword +
  余数，行循环按步长推进）；!=1 → 按缓冲低位 esi&3 分派
  （%4==0 双字、%4==2 word、其他通用）；
⑤ 各成功路径 call 槽 0x60 收尾 → 返 1；失败返 0。
★语义统一：DSurface 系 16 位表面区域填充（Fill_Rect 族）——
