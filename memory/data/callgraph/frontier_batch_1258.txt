0x67AFF0 —— 容器构造器（可带外部缓冲，虚表 0x7F0D7C→0x7F0DEC，93B 全程读完）
================================================================================
签名：thiscall + 2 栈参（[esp+4]=容量、[esp+0xC]=外部缓冲）ret 8。
机器码（0x67AFF0-0x67B04A）：
    eax=[esp+4]（容量）
    [esi+4]=0; [esi+8]=eax（容量）
    byte[esi+0xC]=1; byte[esi+0xD]=0
    [esi]=0x7F0D7C（★装虚表 A）
    test eax; je 0x67B033（容量 0 → 跳过分配）
    ecx=[esp+0xC]（外部缓冲）
    test ecx; je 0x67B020
    [esi+4]=ecx（★采用外部缓冲）
    jmp 0x67B033
0x67B020:
    shl eax,2; push; call 0x7C8E17（operator new 容量×4）
    [esi+4]=eax; byte[esi+0xD]=1（★自分配标志）
0x67B033:
    [esi]=0x7F0DEC（★换虚表 B）
    [esi+0x14]=0xA（★增长量 10）; [esi+0x10]=0
    eax=this; ret 8

语义：**「可带外部缓冲的数组/向量」构造器**——与 batch 136 的 0x477BE0
（虚表 0x7E4DB8）同族：{+4 数组指针、+8 容量、+0xC 持有=1、+0xD 自分配、
+0x14 增长量=10、双虚表 0x7F0D7C→0x7F0DEC}。外部缓冲（栈参 2）非空则直接
采用不分配；空则 operator new 容量×4 分配并置自分配标志。

★怪癖：①★双虚表 0x7F0D7C→0x7F0DEC（基类构造后换派生表——batch 201/210
同款）；②外部缓冲优先（栈参 2 非空不分配）；③+0x14=0xA 增长量硬编码
（与 batch 1243 0x538780 / batch 1251 0x67A470 同字段同值）；④容量 0 跳过
分配（+4 保持 0、自分配=0）。

⚠️ partial：宿主类（0x67Axxx 容器族）、双虚表类归属、+0x14 增长量消费端。

0x67B100 —— 容器尾部插入器（80B 全程读完）
================================================================================
签名：thiscall + 1 栈参（[esp+8]=值指针）ret 4。
机器码（0x67B100-0x67B14D）：
    ecx=[esi+8]（容量）; eax=[esi+0x10]（计数）
    cmp eax,ecx; jl 0x67B135（count<cap → 直接插入）
    al=[esi+0xD]（自分配标志）; test; jne 0x67B118
    test ecx; jne 0x67B12F（cap≠0 → 失败返 0）
0x67B118:
    eax=[esi+0x14]（增长量）; test; jle 0x67B12F（grow≤0 → 失败返 0）
    edx=[esi]（虚表）; eax+=ecx（新容量=cap+grow）
    push 0; push eax; mov ecx,esi
    call [edx+8]（★虚表槽 8 扩容——Reserve）
    test al; jne 0x67B135
0x67B12F:
    xor al,al; ret 4（失败返 0）
0x67B135:
    eax=[esi+0x10]（计数）; edx=[esi+4]（数组）
    lea ecx,[eax+1]; [esi+0x10]=ecx（计数++）
    ecx=[esp+8]（栈参 1）; ecx=[ecx]（★解引用取值）
    [edx+eax*4]=ecx（数组[count]=*值指针）
    mov al,1; ret 4（成功返 1）

语义：**VectorClass 式尾部插入**——与 batch 1243 的 0x538780 完全同构：
count<cap 直接写尾部；count==cap 时按自分配标志/容量/增长量判定并经虚表槽 8
预扩（cap+grow）成功才插入；参数解引用插入（传指针非值）；返回 bool。

★怪癖：①★扩容条件与 0x538780 完全同构（+0xD 标志/cap≠0 拒扩/grow≤0 拒扩/
虚表槽 8）；②参数解引用（[ecx] 取值后写数组）；③+0xD 自分配标志此时读作
「固定容量模式跳过检查」（与 batch 1243 记录一致）；④成功路径 al=1/失败 al=0。

⚠️ partial：虚表槽 8 的 Reserve 实现、宿主类（与 0x67AFF0 同容器族——+0x10
计数/+0x14 增长量字段互证）。

0x67C280 —— 容器拷贝构造（虚表 0x7F0D7C→0x7F0D1C，136B 全程读完）
================================================================================
签名：thiscall + 1 栈参（源容器）ret 4。
机器码（0x67C280-0x67C305）：
    edi=[esp+0x10]（源）; esi=this
    [esi+4]=0; [esi+8]=0; byte[+0xC]=1; byte[+0xD]=0
    [esi]=0x7F0D7C（★装虚表 A）
    cmp esi,edi; je 0x67C2EE（★自拷贝短路——跳过复制）
    call [0x7F0D88]（★数据区函数指针——同 batch 244 的 [0x7E4DC4] 形态）
    eax=[edi+8]（源容量）; [esi+8]=eax; je 0x67C2E8（容量 0 → +4=0/+D=0）
    shl eax,2; push; call 0x7C8E17（operator new 容量×4）
    [esi+4]=eax; je 0x67C2EE（分配失败跳过）
    ecx=[esi+8]; eax=0; byte[esi+0xD]=1（自分配）
    jle 0x67C2EE
    复制循环（0x67C2D2-0x67C2E4）: [esi+4][i]=[edi+4][i]
0x67C2E8:
    [esi+4]=0; byte[esi+0xD]=0
0x67C2EE:
    [esi+0x10]=[edi+0x10]; [esi+0x14]=[edi+0x14]（★双尾字段）
    [esi]=0x7F0D1C（★换虚表 B）
    eax=this; ret 4

语义：**容器拷贝构造**——与 batch 1244 的 0x67A090 / batch 1250 的 0x5AC430
同构（虚表槽入口函数指针 + 容量拷 + operator new + owns=1 + 逐元素浅拷贝 +
双尾字段 +0x10/+0x14 + 双虚表切换）。虚表 0x7F0D7C→0x7F0D1C 为该族新实例。

★怪癖：①★双虚表 0x7F0D7C→0x7F0D1C；②★入口 call [0x7F0D88]（数据区函数
指针，每次拷贝必调——同 batch 244 [0x7E4DC4] 形态：通知/计数推断）；③自
拷贝短路但虚表仍换 B；④分配失败路径返 this；⑤复制循环用 [esi+8] 容量做界。

⚠️ partial：[0x7F0D88] 函数指针身份、+0x10/+0x14 字段语义、宿主类（与
0x67AFF0/0x67B100 同容器族——虚表 0x7F0D7C 与构造器共用，拷贝版/普通版同
虚表同 batch 244 模式）。
