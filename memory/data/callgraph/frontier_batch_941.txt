一、链语义（全段 disasm 复核 + golden 6 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7CA489 = MSVC6 静态 CRT 宽字符
字符串拷贝 `wcscpy`——逐 16 位宽字符复制直到 NUL（含 NUL 本身），
返回 dst。cdecl 2 栈参、ret 无栈清理：
  · 入口：
      mov ecx, [esp+8]   ; ecx = src（第二参）
      mov eax, [esp+4]   ; eax = dst（第一参）——★返回 eax = dst
  · 流水线（"读-写-推进-测试"）：
      mov dx, [ecx]      ; dx = src[0]
      lea esi, [eax+2]   ; esi = dst+2（字节偏移，即 dst[1] 槽）
      mov [eax], dx      ; dst[0] = dx
      inc ecx / inc ecx  ; ecx → src[1]
      test dx, dx        ; ★dx 载入后在 ecx 推进之后才 test
      je 返回
      mov dx, [ecx]      ; dx = 当前源字符
      mov [esi], dx      ; 写目标
      inc esi / inc esi  ; esi += 2
      jmp 回 inc ecx×2 + test
  · 收尾：pop esi / ret（返回 eax = dst）

★原版怪癖（golden 实证，C++ 侧逐条复刻）：
  ① 返回 eax = dst——入口即存、永不修改；
  ② "读-写-推进-测试"流水线：dx 载入后在 ecx 推进之后才 test——
     等效 `c=src[0]; dst[0]=c; while(c){c=*src++; *dst++=c;}`，
     NUL 也会被写入 dst 后才返回（空串也写 NUL 到 dst[0]）；
  ③ 纯 cdecl 2 参、无溢出防护、宽字符 16 位逐字复制；
  ④ 无任何外部全局/子调用——纯内存复制，整函数可真身模拟（本批
     唯一零桩边界批次）。
