0x72A9E0 —— 四字段双轴偏移器（34B 全程读完）
================================================================================
签名：thiscall（ecx=this）+ edx（偏移量 d）ret 空。
机器码（全文 34 字节）：
    mov eax, [ecx]; add eax, edx; mov [ecx], eax        ; this->+0 += d
    mov eax, [ecx+4]; add eax, edx; mov [ecx+4], eax    ; this->+4 += d
    lea eax, [edx+edx]                                  ; eax = 2d
    mov edx, [ecx+8]; sub edx, eax; mov [ecx+8], edx    ; this->+8 -= 2d
    mov edx, [ecx+0xC]; sub edx, eax; mov [ecx+0xC], edx ; this->+0xC -= 2d
    ret

语义：**四字段双轴偏移器**——前两字段 (+0/+4) 加 d、后两字段 (+8/+0xC)
减 2d（★成对双轴变形——坐标对 + 范围对形态推断：+0/+4=起点坐标、
+8/+0xC=尺寸/对角，向起点加向量 d 的同时从尺寸/对角减 2d，矩形
"一角固定另一角回缩"类变换）。5 unique caller（34 callsite）。

★怪癖：①★单参同量双轴（一个 edx 同时作用于 +0/+4 两轴——dx=dy=d）；
②★lea [edx+edx] 实现 ×2（无乘法指令）；③★+0/+4 与 +8/+0xC 符号相反
（加 d vs 减 2d——不对称变形）；④★后邻 0x72AA10 是双参独立版
（[esp+4] 作用于 +4/+0xC、edx 作用于 +0/+8——两轴可独立偏移）——
同模板两形态。

⚠️ partial：结构语义（坐标对+范围/对角）、宿主类（0x72A9Ex 区——
batch 记忆 0x72xxxx 资源/文件域）、5 unique caller 身份、后邻 0x72AA10
