一、函数体全读（119B，disasm 0x7D7D49 0x80 全量）
------------------------------------------------
参数契约（cdecl 3 栈参）：[ebp+8] = 栈参1（输出字符串指针 esi）、
[ebp+0xC] = 栈参2（长度计数 ebx）、[ebp+0x10] = 栈参3（目标结构指针
edx——+0xC 源串指针 / +4 指数字段）。
机器码（119B 全读，逐段要点）：
  序言: push ebp → mov ebp,esp → mov edx,[ebp+0x10]（★栈参3=目标结构）
    → push ebx → mov ebx,[ebp+0xc]（★栈参2=长度）→ push esi → mov
    esi,[ebp+8]（★栈参1=输出串）→ mov ecx,[edx+0xc]（★★目标结构+0xC
    =源字符串指针）→ push edi → lea edi,[esi+1]（★edi=输出+1）→ mov
    byte[esi],0x30（★★输出首字符写 '0'！）
  复制循环: test ebx → jle 0x7D7D86（★长度<=0 跳过）→ mov [ebp+8],
    ebx → xor ebx → mov dl,[ecx]（★源字符）→ test → je 0x7D7D78（★源
    字符 0 → 补 '0'）→ movsx edx,dl → inc ecx → jmp → 0x7D7D78: push
    0x30 → pop edx（★用 '0'）→ mov [eax],dl（★写输出）→ inc eax → dec
    [ebp+8] → jne 循环（★★复制 min(长度,源串长) 个字符——源空时补
    '0' 填满）
  截断: 0x7D7D86: and byte[eax],0（★写 0 终止）→ test ebx → jl
    0x7D7D9F（★跳过舍入）
  四舍五入: cmp byte[ecx],0x35 → jl 0x7D7D9F（★★源串下一个字符 < '5'
    不进位）→ 进位循环: dec eax → cmp byte[eax],0x39 → jne 0x7D7D9D →
    mov byte[eax],0x30（★'9' → '0' 继续进位）→ jmp → 0x7D7D9D: inc
    byte[eax]（★★非 '9' → +1 完成进位——字符串四舍五入！）
  指数调整: 0x7D7D9F: cmp byte[esi],0x31 → jne 0x7D7DA9（★输出首字符
    检查）→ inc dword[edx+4]（★★目标结构+4 = 指数字段++——首字符
    '1' 时指数+1）→ jmp 0x7D7DBB → 0x7D7DA9: push edi → call 0x7d15a0
    （★★batch 017 _strlen——输出串长）→ inc eax → push eax → push
    edi → push esi → call 0x7ca090（★★batch 031 memmove——输出串左移
    腾位！）→ add esp,0x10
  收尾: pop 族 → ret（★cdecl 无清理）
语义：**浮点格式化辅助器（推断名）**——cdecl 3 栈参：① 输出串首字符
  写 '0'；② 按长度复制源串（源字符 0 时补 '0' 填满）；③ 截断写 0 终
  止；④ 源串下一个字符 >= '5' 时对输出串四舍五入进位（'9'→'0' 连
  进）；⑤ 输出首字符 '1' 时目标结构+4（指数字段）++，否则 strlen+1
  经 0x7CA090 memmove 左移腾位（补前导 '1' 空间）——★MSVC6
  _ecvt/_fcvt 族浮点转字符串格式化链的辅助段。★★紧邻 0x7D7DC0（更大
  函数，宿主2/3 现场先调它再调本函数）成对——CRT 浮点格式化双段。
