**0x7C1F30（384B，0x7C1F30-0x7C20AF，ret 平返）虚表对象方法**：
  入口 sub esp,0xC / push ebx,ebp,esi,edi / mov esi,ecx（★this）
  / mov al,[esi+0xF5]（★参2 字节槽）/ mov ebx,[esi+0x164] /
  lea edi,[edx+1]（★参2+1）/ mov eax,[esi+0x178] / and edi,-2 /
  [esp+0x18]=edx（参2）/ [esp+0x10]=ebx / [esp+0x14]=ebp；
  A. [esi+0x178]==0 且 [esi+0xF5]!=0 → ecx=ebp × edi + (ebp+1&-2)
     → [esi+0x17C]=ecx（★双倍索引公式）；
  B. [esi+0x178]==0 且 [esi+0xF5]==0 → 表扫描：[esi+0x754] 表 /
     [esi+0x74C] word 计数逐项 6B 步进比较 [esi+0x180] 阈值 →
     命中项 +2 偏移 dword → [esi+0x17C]=结果（未命中 0）；
  C. [esi+0x154]&1 == 0 → [ebx+0x10] = [esi+0x768] - [esi+0x17C]
     （★槽位差写入调用方缓冲 +0x10）；否则 [ebx+0x10]=0；
  D. 虚表调度：eax=[ebx+0x10]+[ebx] + [esi+0x178] → push edi /
     push eax / push 5（★★操作码 5）/ push esi → call [esi+0x40]
     → 失败（!=0）→ 返回 0xFFFFFFFC(-4)；
  E. 成功：edx=[esp+0x18]+[esi+0x178] → [esi+0x178]=edx；
     [esi+0x174]++（计数）→ 收敛分支：计数==[esi+0xF5] → 清
     0x174/0x178、[ebx+0xC]=0xA、[esi+0x168]=ebx、
     [esi+0x164]=[ebx+4]、[esi+0xE8] word<3 → [edx+eax+1]=0x80
     （★0x80 标记写入）→ 返回 0xFFFFFFFF(-1)；溢出 → -4。
  ★原版怪癖：①虚表 [esi+0x40] 操作码 5 提交（batch 378/1053

  -4/-1 哨兵族。

**0x7D3982（116B，0x7D3982-0x7D39F5）CRT `_towupper` 包装**：
  ① xor ebx,ebx / cmp [0xB782A0],ebx——★单线程门控全局==0 →
     快路径：c>='a' && c<='z' → c-0x20（ASCII 转大写）→ 返回；
  ② 门控!=0 → push esi,edi,esi / call [0x7E11C8]
     （★★InterlockedIncrement——IAT 实证）/ cmp [0xB78BA0],0 /
     mov edi,[0x7E11CC]（★★InterlockedDecrement）/ je 跳过 →

     （★★EnterLock 0x13——batch 244 tolower 同锁族）→ ebx=1；
  ③ push [esp+0x10] / call 0x7D39F6（★★towupper 核心）；
  ④ ebx!=0 → push esi / call edi（Decrement 收尾）；
     mov ax,[esp+0x10] / 返回。
  ★原版怪癖：①单线程门控 [0xB782A0]==0 走 ASCII 快路径（无
  锁无 IAT）；②多线程 InterlockedInc/Dec 引用计数 + 锁 0x13
  包核心调用；③快路径 -0x20 只处理 ASCII 'a'-'z'。
