=== 原版怪癖（照抄） ===

① 五槽全释放但**无循环里计数缓存**（每次循环重读 [0x7C8B3D] 后
   内层重取表基址/计数——batch 708 同款低效重读）；
② 链表释放是**头节点弹出式**（[0x87F6A8]-1 前先存 next 再 delete
   头——不断链：mov next → 头=next → delete 旧头）；
③ 数组释放两遍式（先逐项 delete 再 delete 表本体——batch 720
   段2 同款表项+本体两段）；
④ 两表共用计数 [0xB1CF70]（Value 表 1/2 同长——batch 562 分配
   同 count 证实）；
⑤ 空项跳过（je 0x734D88）但计数不减——空洞保留；
⑥ 标志 [0xB1CF80] 复位放最后（五槽清完才置 0——释放途中若失败
   标志仍为 1，重载被幂等门拦截）；
⑦ 释放顺序 = 链表1 → Value 表1/2 → Label 表 → 链表2 → 标志
   （固定次序，与 batch 562 分配次序（Label→Value）不对称）；
⑧ 双子宿主各持独立名字槽（[0xB1CF84]/[0xB1CF60]）但共用已登记

   双份名字状态冗余）。
