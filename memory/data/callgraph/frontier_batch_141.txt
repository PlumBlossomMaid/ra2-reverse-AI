0x7CA610  CRT::strncmp（13 callers）
================================================================================
ranking 名 _strncmp（confirmed_identity 列表），YRpp CRT.h 无 JMP 宏覆盖。
机器码还原（全 0x38，56B）：
    push ebp / mov ebp, esp
    mov ecx, [ebp+0x10]             ; ★ Count（第三参）
    jecxz 返 0
    mov edi, [ebp+8]                ; ★ Str1
    repne scasb 求 Str1 长           ; ★ 先求 Str1 长度
    mov esi, [ebp+0xC]              ; ★ Str2
    repne cmpsb                      ; ★ 逐字节比较 min(len, Count)
    mov al, [esi-1] / cmp al, [edi-1] ; ★ 尾部字节比较定符号
    ja / je / dec / not ecx
    mov eax, ecx / ret

语义：**标准 CRT 定长字符串比较（strncmp）**——比较前 min(Count, Str1 长度)
个字节，相等时按 m[b]，返回 <0/0/>0 归一到 -1/0/1。★0x7C-0x7D CRT 层字符串
家族再添 strncmp（strlen 内联 + cmpsb 硬件前缀）——与 batch 126 的 strchr
（SWAR 优化）同区同源。

★跨批次连接：batch 093（strcmpi）/batch 126（strchr）/batch 123（wcscmp）
——CRT 字符串比较族；`repe cmpsb` 硬件前缀是 MSVC6 CRT 标准实现指纹。

⚠️ partial：无（全 0x38 读完）。返回值归一细节与 MSVC6 标准 strncmp 一致。

0x5E2820  控件文本组装（batch 110 闭合，13 callers）
================================================================================
机器码还原（前 0x40）：
    sub esp, 0x28
    mov esi, edx                    ; 参数字符串
    push esi / call 0x7CA405        ; ★ CRT::wcslen（batch 097 实锤）
    mov ebx, [esp+0x40]             ; 目标控件
    lea edx, [esp+0x28] / mov ecx, ebx
    call 0x775690                   ; ★（格式化/缓冲准备）
    mov ebp, [0x7E14A4]             ; ★ SendMessageA（batch 099 实锤导入槽）
    push 0 / push 0 / push 0x4A0    ; ★ WM_SETTEXT(0x4A0) + lParam 参数
    push ebx
    ...（call ebp = SendMessageA(hwnd, 0x4A0, 0, text)）

语义：**batch 110 对话框控件刷新链（0x5E2700）尾段的组装函数**——当时 0x5E2700
以 `call 0x5E2820` 收尾并标注「wcslen 开头字符串写入」，本批立案：wcslen 定长 →
0x775690 准备 → SendMessageA(控件, WM_SETTEXT=0x4A0, 0, 文本) 写入控件文本。

★跨批次连接：batch 110（0x5E2700 尾段 partial 闭合）+ batch 097（wcslen）+
batch 099（SendMessageA 0x7E14A4 导入槽）——UI 家族「GetDlgItem 取控件 →
SendMessage 填文本」链的组装端。

⚠️ partial：0x775690 身份与缓冲准备细节、0x4A0=WM_SETTEXT 推断（0xA0 偏移
形态，符合 Windows WM_SETTEXT=0x0C 不对——0x4A0 疑自定义消息，未实锤）。

0x4072D0  链表自环 + 有序插入（14 callers）
================================================================================
机器码（fy 两函数）：
  0x4072D0（0x0B 全读完）：
    mov [ecx], ecx                  ; ★ 节点->next = 自己
    mov [ecx+4], ecx                ; ★ 节点->prev = 自己
    mov [ecx+8], 0                  ; +8 = 0（附属字段）
    ret                             ; ★ 自环初始化（空链表头）
  0x4072E0（有序插入）：
    mov edi, [edx+8]                ; ★ 参照节点的 +8（排序键）
    mov esi, [ecx]                  ; 链头
   loop:
    test esi / je 收尾
    mov ebx, [esi+8] / cmp esi, ebx / je 收尾   ; ★ 自环检测（到达尾）
    cmp edi, ebx / jle 插入          ; ★ edi <= 当前节点键 → 插到其前
    inc eax / mov esi, [esi]         ; 前进
    jmp loop
  插入:
    mov ecx, [esi+4] / mov [edx], esi / mov [edx+4], ecx
    mov [esi+4], edx ...            ; ★ 双向链表按 key 有序插入

语义：**0x4072D0 = 双向链表节点自环初始化**（+8 附属字段清 0——batch 104 的
0x407450 摘除+自环同族，本条是纯构造侧）；**0x4072E0 = 按 +8 排序键的有序
插入**（自环检测作尾哨兵，jle 插前，batch 106/116 链表析构同族）。

★跨批次连接：batch 104（0x407450 摘除）/batch 106（0x6C9850）/batch 116
（0x631C80）——链表基建家族（0x407xxx 区）的「构造自环 + 有序插入」成员。

⚠️ partial：+8 排序键语义（计数/优先级推断）、宿主类（0x407xxx 基建区推断）。
