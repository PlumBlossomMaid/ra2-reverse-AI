★语义：**MSVC6 CRT wcsrchr 宽字符串反向查找器（推断名——
标准 C 库 `wcsrchr`）**——cdecl 2 参：
  ① 前向扫描到宽终止符（2 字节/字符步进）；
  ② 从终止符位置反向（向前）扫描查询宽字符；
  ③ 命中出口（当前位置字符 == 查询）→ sub cx,si/neg/
     sbb/not/and 无分支条件保留 eax（命中保留当前指针，
     未命中 → eax 掩 0）；
  ④ 串首兜底出口（未命中）→ 同无分支判定（终止符场景）。
  = wcsrchr 标准实现（宽字符 2 字节步进 + 反向扫描 + 哨兵
  条件返回），与 batch 1142 0x7DC378 strchr 的收尾惯用逐
  字节同款（sub/neg/sbb/not/and 模板）。

★调用点（池登记 callers=3）：0x7CAxxx 宽字符处理域（batch
  1047 0x7D571F DBCS 查找、batch 1142 0x7DC378 _mbschr、
  batch 1150 0x7CD615 后缀递增器等同域）——宽串解析消费。

★E8 被调者：**零子调用**（全 64B 纯宽字符扫描 + 无分支条
  件返回）。

★原版怪癖（照抄）：
  ① 步进量 2 用 push 2/pop ecx 载入（省字节惯用）——与
     batch 1153/1157 的 push 0xa/pop ebx 同款；
  ② 前向扫描先读后加（mov si,[eax] → add eax,2 → 再
     mov si,[eax]）——预读 + 循环步进交错；
  ③ 宽终止符判 test si,si（16 位）——宽串 NUL 语义；
  ④ 反向扫描从终止符前一位（sub eax,ecx 先减）开始——
     跳过终止符本身；
  ⑤ 无分支条件返回 sub cx,si/neg/sbb/not/and——与 batch

     0），终止符场景也经此判定（cx=0 时对查询字符的减法
     = -查询值 → 掩 0 返回 NULL）；
