★语义：**CRT `wcstol`（宽字符 strtol）**——cdecl 3 参
（param1=宽字符串，param2=endptr，param3=base）：
  ① iswctype 掩码 8 跳空白 → 符号（负号位 2）→ base 校验
     （<0/==1/>36 → *endptr=str 返回 0）；
  ② base==0 自动检测（'0x' → 16 / '0' → 8 / 默认 10）；
     base==16 且 '0x' 前缀 → 跳过；
  ③ 主循环：iswctype 掩码 4 数字 → c-'0'；掩码 0x103 字母 →
     0x7D3982 转换 → c-0x37；digit >= base → 停止；溢出检测
     （预除商 (-1)/base vs 值/余）→ 位 4；
  ④ 无数字 → *endptr=str 值 0；溢出 → errno=0x22 + 钳制
     （负 0xFFFFFFFF / 正 INT_MAX）；
  ⑤ *endptr = 游标（停止处）；负号 → neg；返回 eax=值。
