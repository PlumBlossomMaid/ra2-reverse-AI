一、函数体全读（74B，disasm 0x510550 0x60）
---------------------------------------------
参数契约（thiscall 2 栈参 ret 8）：
  ecx = this（容器对象）
  [esp+4]  = 栈参 1 = 容量（eax）
  [esp+0xC] = 栈参 2 = 外部缓冲指针 pMem（可 0）
机器码（74B 全读）：

  00510554  push esi / mov esi,ecx（★this）
  00510557  xor edx,edx / cmp eax,edx
  0051055b  mov [esi+4],edx             ; ★+4 数组指针 = NULL
  0051055e  mov [esi+8],eax             ; ★+8 容量 = 栈参 1
  00510561  mov byte[esi+0xC],1         ; ★+0xC 持有标志 = 1
  00510565  mov byte[esi+0xD],dl        ; ★+0xD 第二标志 = 0
  00510568  mov [esi],0x7E9E44          ; ★装虚表 0x7E9E44
  0051056e  je 0x510594                 ; ★容量 0 → 收尾（不分配）
  00510570  mov ecx,[esp+0xC]（★栈参 2 pMem）
  00510574  cmp ecx,edx / je 0x510581   ; ★pMem 空 → 走分配
  00510578  mov [esi+4],ecx             ; ★采用外部存储（不分配）

  00510590  mov byte[esi+0xD],1         ; ★+0xD 自分配标志 = 1
  00510594  mov eax,esi / pop esi / ret 8
语义：**「可选外部缓冲数组容器构造器」（DynamicVectorClass 系）**——+4 数组
指针/+8 容量/+0xC 持有标志/+0xD 自分配标志，装虚表 0x7E9E44；栈参 2 给指针
则直接采用外部存储（不分配），否则 operator new（0x7C8E17）分配容量×4B；
容量 0 时跳过分配直接返回。与 batch 092 的 0x42FCB0（装 0x7E38D0）和 batch
136 的 0x477BE0（装 0x7E4DB8）**逐字段同构**——同一容器模板第三编译实例。

六、原版怪癖（照抄）
-------------------
① 容量==0 且 pMem==0 时直接跳过分配（je 0x510594）——构造空容器占位，
   后续 SetCapacity 扩容（HouseClass 11 个成员槽全部 0 容量构造）；
② pMem 非空时**不再改 +0xD（保持 0）**——外部缓冲接管不计自分配；
③ +0xD 仅在 _new 成功路径置 1（operator new 失败返 0 也不改标志——与
   batch 833 的「先置 1 再验数组空」不同版本，本条是后置型）；
④ 调用方（HouseClass::HouseClass）构造后立即覆盖虚表 0x7E9E24 + 补
   +0x10/+0x14——本函数是基类层构造，派生字段由调用方补齐（编译产物形态）；
⑤ 与孪生 0x510640 逐字节同构仅虚表不同（0x7E9E44 vs 0x7EA5C4）——同一
   模板两份编译实例，+0x38 槽用 0x7EA5C4 表、+0x50 起用 0x7E9E44 表；
⑥ 23 处调用点中 21 处集中在 HouseClass 家族（FUN_004f5190 11 + ctor 11），
   构造序列完全一致（每 0x18B 一个成员容器）——HouseClass 成员容器批量
   初始化惯用。
