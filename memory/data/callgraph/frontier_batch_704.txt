=== 语义 ===

**面向对齐扫描器（推断名，建筑域）**——__thiscall 2 栈参（参1=
方向/坐标+标志复合推断，参2 未直接读——[esp+0x40] 为参1 高字节
标志）ret 8：① Type+0x16BE 标志门控（关 → 直接返回）；② 循环
次数 = clamp([Type+0x5B8]>>8, 1, …)（sar 8 最小 1）；③ 以
this 为中心遍历 8 方向（0x89F688 方向表）邻居格：0x5657A0 查
格 → 0x47C520 GetBuilding 取建筑；④ 建筑 Type+0x16BF 标志 +
虚表槽 0x38 与 this 同类型比较 → GetFacing（0x4C93D0）结果
>>12 半定向 and 3 与参1 低 2 位比较——★面向匹配；⑤ 匹配后
分支：参1 高字节标志非零 → FlashbangWarheadAt（0x48A620）+
[0x8871E0]+0xFA8 参数 + 虚表槽 0x16C 七参链；标志零 → 虚表槽
0xF8；⑥ 循环次数用尽收尾。

★面向对齐：8 方向邻居建筑的同类型 + 面向匹配 + 闪光弹/参数
处理——建筑域武器/装饰对齐推断（炮塔朝向扫描）。
