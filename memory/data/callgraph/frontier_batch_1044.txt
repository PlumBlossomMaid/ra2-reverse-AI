      第二遍 (1,0,str,-1,buf,len,0,0) 实际转换；

  ④ esi 步进 4（指针数组）直到 [esi]==0；
  ⑤ 返回 0 成功 / -1 失败（长度 0 或 malloc/转换失败短路）。
