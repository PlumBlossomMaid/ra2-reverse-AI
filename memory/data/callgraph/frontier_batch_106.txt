================================================================================
0x42D470  双 word 写入/坐标对构造（24 callers，21B）
================================================================================
机器码（全 21B，ret 8 = 2 栈参）：
    mov dx, [esp+8]           ; ★ arg2（word）
    mov eax, ecx              ; this/输出（CellStruct*）
    mov cx, [esp+4]           ; ★ arg1（word）
    mov [eax], cx             ; out->X = arg1
    mov [eax+2], dx           ; out->Y = arg2
    ret 8

语义：**把两个 16 位整数值打包写入输出结构的前 4 字节**——`CellStruct(X,Y)`
的「按值填充」形态（或 point/coord 对构造器）。ret 8 表示 __stdcall 2 栈参
（或 __thiscall + 1 栈参，视调用方约定），输出指针走 ecx。

紧邻 0x42D490（0xC8B 邻域，同族展开成员）：参数==8 时走 MapClass 特殊路径
（[0x87F7E8]=MapClass::Instance → 0x5657A0 取 +0x116 → [0x8B413C] 表 →
[edx+0x28] 读值写出）；否则用 **`[0x89F688]`（★方向偏移表，RMG 阶段数据已
多次引用的全局）按参数索引做叠加**（`cx = [edx] + word[0x89F688 + eax*4]`）——
即「坐标 + 方向表偏移」的寻址族。

⚠️ partial：宿主类不确定（CellStruct/Point2D 推断）、0x89F688 方向表语义
（batch RMG 侧已见同名全局，本条是 engine 侧消费者之一）。

================================================================================
0x41C380  3D 距离 → 整数（24 callers，0x31B）
================================================================================
机器码（全 0x31B）：
    fild [ecx+8]              ; st: z
    fild [ecx+4]              ; st: y, z
    fild [ecx]                ; st: x, y, z
    sub esp, 8
    fld st(0) / fmul st(1)    ; x*x
    fld st(2) / fmul st(3)    ; y*y
    faddp st(1)               ; x² + y²
    fld st(3) / fmul st(4)    ; z*z
    faddp st(1)               ; x²+y²+z²
    fstp qword [esp]          ; ★ 和存成 double 参数
    fstp st(0)×3
    call 0x4CAC40             ; ★ 平方根 helper
    add esp, 8
    jmp 0x7C5F00              ; ★ _ftol → int（尾部跳转）

语义：**`(int)sqrt(x²+y²+z²)`——三点间 3D 距离取整**。输入是坐标结构（+0/+4/+8
三个 int），输出整数距离。0x4CAC40 前 0x30 实读确认是平方根类 helper（fcom
[0x7E1748] 阈值 + fmul [0x7E4900] 系数，疑 FastSqrt 系），尾跳 `jmp
0x7C5F00(_ftol)` 是 MSVC6 尾调用优化。

★跨批次连接：0x7C5F00 = _ftol（batch 083/092/093/096 同族 x87 向零截断）；
调用方含距离判定场景（弹药/索敌范围），与 batch「威胁评估」系统同理论域但为
总线几何工具。

⚠️ partial：0x4CAC40 的确切实现（FastSqrt 系数与阈值未对齐）、输入结构精确布局
（疑 CoordStruct）与返回语义（int 距离 or 平方数未逐一回查调用点）。

================================================================================
0x6C9850  链表节点析构（24 callers，0x31B）
================================================================================
机器码（全 0x31B）：
    mov esi, ecx                      ; this
    xor edi, edi
    mov eax, [esi+4]                  ; ★ this->+4（前向指针）
    mov [esi], 0x7E61F0               ; ★ 安装虚表 0x7E61F0
    cmp eax, edi / je skip1
    mov ecx, [esi+8]                  ; ★ this->+8（后向指针）
    mov [eax+8], ecx                  ; 前向->+8 = 后向
  skip1:
    mov ecx, [esi+8]
    cmp ecx, edi / je skip2
    mov eax, [esi+4]
    mov edx, [ecx]                    ; 后向->虚表
    push eax
    call [edx+4]                      ; ★ 虚表槽 +4（设定前向/通知）
  skip2:
    mov [esi+8], edi                  ; +8 = NULL
    mov [esi+4], edi                  ; +4 = NULL
    ret

语义：**双向链表节点析构**——先把节点接回链表（前向->后向贯通），再以后向节点的
虚表槽 +4 做一次挂接通知（把 this 从链上摘除），最后两根指针置 NULL。为
「登记册/链表」基建族的析构侧（batch 088/089/091/104 同族，0x407450 摘除 +
本条析构 = 完整生命周期）。

★跨批次连接：虚表安装（0x7E61F0）与 batch 092（0x42FCB0 装 0x7E38D0）、
batch 104（双向链表摘除 0x407450）同属容器基建；next/prev 双指针布局与
0x407450 完全一致（可互推同类）。

⚠️ partial：0x7E61F0 虚表类归属、虚表槽 +4 的方法身份。
