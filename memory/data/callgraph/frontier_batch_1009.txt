★语义：**MSVC6 CRT wcstok（宽字符分词器）**——cdecl 2 参：
① 入口取 _getptd()（batch 008 已登记）；参1 为 NULL 时用
   ptd->+0x1C（per-thread 上次 token 指针）续扫；
② 在 string 中找 control 里出现的字符（双循环：外层推进 string、
   内层扫 control）；
③ 命中后原地把该字符清 0（`and word [ecx],0`）；
④ ptd->+0x1C 记下次起点（命中字符后一格）；
⑤ 返回 `P != ecx ? P : 0`——有推进（找到 token）返 token 起点，
   无推进返 0（NULL）。

★原版怪癖（照抄）：
  ① ★per-thread 状态在 ptd+0x1C（非静态全局）——多线程各自独立；
  ② 返回判定用 `sub + neg + sbb + and` 惯用（不是 cmp/je）；
  ③ 分隔符不是跳过而是**原地清 0**（破坏性分词，与 strtok 同）；
  ④ 双循环结构（两个几乎同构的"扫 control"内层循环，第一轮找
     token 边界、第二轮找分隔符清零点）——Westwood/MSVC 复制粘贴；
  ⑤ 宽字符一律 +2 字节步进（inc ecx/inc ecx，不 lea）。

★依赖链实锤（本批 disasm + TSV 交叉）：
