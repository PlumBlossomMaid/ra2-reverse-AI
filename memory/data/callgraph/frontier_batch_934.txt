一、语义（完整汇编逐段核对 + 黄金 14 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码逐段确认）：
  · 调用约定：thiscall 变体 + 1 栈参（ret 4）：
    - ecx = 矩形结构指针 this（[this+0] 低16=x、[this+4] 低16=y、
      [this+8]=w int32、[this+0xC]=h int32）
    - dl = flagA（0x5A7257 存 [esp+0xb]，0x5A73BF 读 [esp+0x13]）
    - 栈参 1 = flagB（0x5A73D4 读 [esp+0x24]，只用低字节）
  · 四角菱形判定（0x5A7262-0x5A7377）：
    角0=(x,y)、角1=(x+w-1,y)、角2=(x,y+h-1)、角3=(x+w-1,y+h-1)。
    每角四判据（判据顺序固定，有符号）：
      X+Y <= W → fail（[0xABED04]）；X-Y >= W → fail；
      Y-X >= W → fail；X+Y > W+2H → fail（[0xABED08]）。
    ★角坐标 16 位截断：角1/3 的 X、角2/3 的 Y 先 32 位 lea 求值再 movsx
    截断回 16（0x5A72AD/0x5A72F5/0x5A733A——与 0x5A76E0 batch 932 同构）。
  · 全矩形扫描（★对比 76E0 的 3×3+边带，这里是整个 w×h 矩形）：
    外层 cy 从 raw_y 起、条件 cy < h+raw_y；内层 cx 从 raw_x 起、条件
    cx < w+raw_x（0x5A7386/0x5A7392，jge 退出）。★h<=0 直接成功返 1
    （0x5A738A jge 0x5A741E——golden h-zero gc=0 实证）；★w<=0 内层空
    （0x5A7395 jge 0x5A740D——golden w-zero gc=0 实证，四角仍判）。
  · 每格：GetCellAt(0x5657A0)（thiscall ecx=0x87F7E8）→ tile=[cell+0x38]
    → 5 谓词链按序（0x5A73B6-0x5A73FD）：
      a. 0x4866D0（tile ∈ [paved, +0xf)，[0xABBEC8]）：过 →
         flagA!=0 → 继续（0x5A73C7 jmp）；flagA==0 → 整体 fail
      b. 0x4866F0（tile ∈ [paved4, +4)，[0xABBEC4]）：过 →
         flagB!=0 → 继续；==0 → 整体 fail
      c. 0x486380（tile==0xFFFF || tile==0）：过 → 继续
      d. 0x486650（tile ∈ [misc, +0xE)，[0xAA10A4]）：过 → 继续
      e. 0x486670（tile ∈ [pavet, +0x10)，[0xABC2B0]）：过 → 继续；
         全失败 → 整体 fail
  · 返回 al：全过 1（0x5A7421）/任一判据或谓词链失败 0（0x5A742D）。
    返回 EAX 低字节有实际语义（与 76E0/6C10 的"EAX 无意义"不同——本条
    是判定函数，调用方 0x5A5B50/0x5A6D80/0x5A7070 用 al 分支）。

★谓词窗口宽度（2026-10-19 dump 实锤，五谓词宽度各不相同）：
  0x4866D0：mov ecx,[0xABBEC8]; cmp; jl 返0; add ecx,0xf; cmp; jge 返0
    → [paved, paved+0xf)，★宽度 0xf 非 0x10
  0x4866F0：mov ecx,[0xABBEC4]; jl 返0; add ecx,4; cmp; jge 返0
    → [paved4, paved4+4)。[0xABBEC4] 新全局（PavedRoads-4，batch 934
    首次登记）
  0x486380：cmp eax,0xFFFF; je 返1; test eax,eax; je 返1; xor 返0
    → tile==0xFFFF || tile==0
  0x486650：同构 [misc, misc+0xE)，[0xAA10A4]
  0x486670：同构 [pavet, pavet+0x10)，[0xABC2B0]

★原版怪癖（golden 实证，C++ 侧逐条复刻）：
  ① 双前置谓词门控：0x4866D0/0x4866F0 通过后还要检查 flagA/flagB，
     flag 为 0 时**整体失败**（不是跳过该格）——flagA-zero/flagB-zero
     gc=1 实证首格即 fail（其余 5 格未访问）。
  ② 谓词链序与 76E0 边带（670→380→650）不同：7250 是
     6D0 → 6F0 → 380 → 650 → 670，前两个带 flag 门控。
  ③ 扫描范围是整矩形；h<=0 / w<=0 时四角仍判、扫描区空。
  ④ 角 1/3、2/3 的加宽坐标先 32 位求值再 movsx 截断回 16 位。
  ⑤ 谓词/GetCellAt 全是有符号比较（jl/jge），tile 按有符号 int32 读。
  ⑥ [0xABBEC4] 与 [0xABBEC8]（PavedRoads）相邻，窗口 [11,15) 恰在
     [15,30) 左侧——golden flagB 用例用 tile=12 精确定位该窗口。
