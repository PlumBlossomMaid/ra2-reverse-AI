一、链语义（disasm 全 90B + 依赖交叉 + 分派宿主三向核对，
0x7CAC66-0x7CACBF）
--------------------------------------------------------------
签名（推断）：cdecl 5 参（param1=元素索引 param2=容器对象
param3=param4=未用 param5=外层键 [ebp+0x18]），返回命中项
指针 / 0（无命中）。

主体（0x7CAC66-0x7CACBF）：
007cac66  push ebp/mov ebp,esp/push ecx/and dword[ebp-4],0
007cac6e  push ebx/mov ebx,[ebp+0xc]          ; ebx = param2 容器对象
007cac72  push esi/push edi
007cac74  mov eax,[ebx+0x10]                  ; ★★[obj+0x10] 外层数组
007cac77  cmp dword[eax+8],0                  ; [数组+8] 元素数
007cac7b  mov esi,[eax+0xc]                   ; [数组+0xC] 指针表
007cac7e  jbe 0x7cacb5                        ; ★空 → 返 0
; → 外层循环（0x7CAC80）：
007cac80  mov edi,[esi]                       ; edi = 外层项
007cac82  mov ecx,[ebp+0x18]                  ; ecx = param5 外层键
007cac85  mov eax,[edi]                       ; [项] 名字符串
007cac87  cmp eax,ecx/je 0x7cac9e             ; ★指针相等快速命中
007cac8b  add ecx,8/add eax,8                 ; ★键比较加 8 偏移
                                              ;   （条目前 8B 元数据）
007cac93  call 0x7cda90                       ; ★★TSV:632 CRT strcmp
                                              ;   对齐优化版（batch
                                              ;   192——dword 分块）
007cac98  pop ecx/test eax,eax/pop ecx
007cac9c  jne 0x7caca4                        ; 不等 → 下一项
; → 命中（0x7CAC9E）：
007cac9e  test byte[edi+0x14],1               ; ★★[项+0x14]&1 门控
007caca2  je 0x7cacbc                         ; 标志 0 → 返回该项
007caca4  inc dword[ebp-4]                    ; 计数++
007caca7  mov eax,[ebx+0x10]
007cacaa  mov ecx,[ebp-4]/add esi,4
007cacb0  cmp ecx,[eax+8]/jb 0x7cac80         ; 外层循环
007cacb5  xor eax,eax/pop edi/esi/ebx/leave/ret ; ★无命中返 0
007cacbc  mov eax,edi/jmp 0x7cacb7            ; ★返回命中项指针

★语义：**MSVC6 CRT 双层命名键查找器第三件（推断名——batch
1107/1118 同模板最短变体）**——cdecl 5 参：
  ① [obj+0x10] 外层数组按 param5 字符串键遍历匹配（[edi]
     指针相等快速命中 / strcmp 0x7CDA90 慢路径加 8 跳前
     缀）；
  ② 命中项 [edi+0x14]&1 == 0 才返回该项指针（本件独有
     &1 门控——单层外层查找，无内层二次匹配，90B 最短）；
  ③ 无命中返回 0（无 errno/哨兵）。
  = 双层命名键查找器三件套（0x7CADB9 312B / 0x7CACC0
  249B / 0x7CAC66 90B）中的首个分派变体（单层版）。

★调用点（探针 E8 实测 1 处 0x7CAB59）：宿主 0x7CAB40-0x7CAB7D
  分派器（三向分支：`mov ecx,[obj+0x10]; mov ecx,[ecx+4];
  test cl,1/jne → test cl,2 → 分别调 0x7CAC66 / 0x7CACC0 /
  0x7CADB9`——三件套按容器标志位分派，0x7CAC66 为 cl&1==
  0 且 cl&2==0 组合的默认/首件）。

★E8 被调者：0x7CDA90（★★TSV:632 CRT strcmp 对齐优化版
  ✓已登记——batch 192，dword 分块无 locale 快路径）——
  **唯一函数依赖，已登记**。

★原版怪癖（照抄）：
  ① 三件套最短版：无内层查找无 [esi+4] 数组访问——与
     0x7CADB9/0x7CACC0 的「外层+内层双 strcmp」不同，本
     件仅外层单遍历；
  ② [项+0x14]&1 门控（0x7CAC9E）vs 孪生 0x7CACC0 的
     &3 门控（0x7CAD97）——位掩码不同（1 vs 3），三件
     套各有差异；
  ③ 键比较加 8 偏移（[项] 名字符串指针 +8 才是串首——
     条目前 8B 元数据）与两孪生一致（模板共性）；
  ④ 指针相等快速命中 + strcmp 慢路径双轨（字符串实习
     化优化）与两孪生一致；
  ⑤ push ecx 局部槽 [ebp-4] 作外层计数（and 清 0 初始
     化）——最小栈帧无 [ebp-0xC] 内层计数（本件无内层）；
  ⑥ 返回 0/项指针双出口：xor eax,eax 独立路径 + mov
     eax,edi 跳转合并，带 ebx 恢复（三件套收尾一致）。
