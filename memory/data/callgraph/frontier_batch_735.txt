=== 语义 ===

**宽字符串类 operator+=（扩容追加版，推断名）**——thiscall 1 栈
参 ret 4（栈参 1=源宽串对象指针，ecx=this）：① 取源内部指针
[eax]（空源 → 全局兜底空串 [0x887734]——batch 112 实锤的「空串
兜底」惯用，空源或兜底空都直接返回 this 不做修改）；② 计算总长
= wcslen(源) + 1（'\0'） + wcslen(旧串)（若旧串非空）；③
operator new 分配总长×4 字节新缓冲 → this->[0] = 新缓冲；④ 若旧
串非空 wcscpy 拷入旧串（否则写宽 NUL 0——空旧串分支）；⑤
wcscat 追加源串到缓冲尾（★核心追加操作）；⑥ delete 释放旧缓
冲；⑦ 返回 this。
★语义统一：宽字符串类 operator= 家族（batch 097 0x7B66D0 + batch
125 0x7B6720 + batch 134 0x7B7600 + batch 143 0x7B6880 + batch
156 0x7B68E0）的**追加变体**——operator= 替换整串，本条 operator+=
在旧串后拼接源串并整体重新分配（两段 wcslen + 一次 wcscpy +
一次 wcscat + 一次 delete 的完整扩容链）。

=== 原版怪癖（照抄） ===

① 空源兜底 [0x887734]（源对象内部指针为 NULL 时用全局空串——
batch 112/151/156 同款惯用，空源/兜底空都静默返回 this）；
② 两段 wcslen（源先算+1，旧串存在才加——长度分步累加非一次定
   长）；
③ 总长 ×4（wchar_t 4 字节——宽串缓冲字节数）；
④ 旧串空分支写宽 NUL（mov word[eax],0——空旧串特殊处理，避免
   wcscpy NULL 源）；
⑤ wcscat 是「追加核心」（先拷贝旧串再拼源——两操作分离而非单
   次拼接 API）；
⑥ delete 旧缓冲放最后（新缓冲完全就绪才释放旧——异常安全弱，
   顺序敏感）；
⑦ 返回 eax=ebx（返回 this——operator+= 链式调用约定）；
⑧ ret 4 单栈参（源对象指针——宽串家族惯例）；
⑨ 无自赋值保护（源==this 时先取 [eax] 旧指针后 new 新缓冲——
   自追加语义推断 [eax] 旧指针仍可用因 new 在 wcscpy 前）。
