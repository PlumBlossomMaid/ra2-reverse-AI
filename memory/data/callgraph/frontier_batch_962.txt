一、链语义（disasm 全段复核 + golden 21 用例实证）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7CD680 = MSVCRT _strnicmp（不
区分大小写定长比较）——cdecl 3 栈参 (s1, s2, count)，返回比较三态
{-1,0,+1}（逐字节，仅 'A'-'Z' 转小写后无符号比较）。
  机器码（0x7CD680-0x7CD77E，257B 全段）：
    push ebp/push edi/push esi/push ebx
    ecx=[ebp+0x10]=count → or ecx,ecx → je 0x7CD77A（★count==0 → 返 0）
    esi=[ebp+8]=s1 / edi=[ebp+0xC]=s2
    lea eax,[0xB78298] / cmp [eax+8],0 → jne 0x7CD6F1（★慢路径 locale）
    快路径（0x7CD6A3，C locale [0xB782A0]==0）：
      bh=0x41('A') / bl=0x5A('Z') / dh=0x20
      循环（0x7CD6AC）：
        ah=[esi] → or ah,ah → mov al,[edi] → je 收尾（ah==0）
        → or al,al → je 收尾（al==0）
        inc esi / inc edi
        cmp ah,bh / jb → cmp ah,bl / ja → add ah,dh
          （★仅 [0x41,0x5A] 内字符 +0x20 转小写）
        cmp al,bh / jb → cmp al,bl / ja → add al,dh（s2 同）
        cmp ah,al → jne 0x7CD6DF（★ecx=-1 → jb 返回 -1 / neg → 1）
        dec ecx → jne 循环（count 限制）
      收尾（0x7CD6D5，任一 NUL 或 count 耗尽）：
        xor ecx,ecx → cmp ah,al → je 0x7CD77A（相等返 0）
        → mov ecx,-1 → jb 0x7CD77A（★ah<al → s1<s2 → -1）
        → neg ecx → +1（s1>s2）
    0x7CD77A: mov eax,ecx / pop 族 / leave / ret
  慢路径（0x7CD6F1，[0xB782A0]!=0）：进临界区 [0xB78BA4] + 调锁家族
  0x7CD9F5 + 逐字符调 tolower 内核 0x7CB063（batch 244/958 归档镜像）。

★原版怪癖（golden 实证，照抄）：
  ① count==0 直接返回 0（不读 s1/s2——空指针安全）；
  ② 任一字符串到 NUL 即提前终止（不继续到 count 超限）；NUL 早退时
     ah/al 未转小写（转小写在 inc 之后），但 NUL=0 与任何非 0 字节
     比较结果不受是否转小写影响（0x00 恒小于一切，'A'-'Z' 恒大于 0）；
  ③ 仅 'A'-'Z'（0x41-0x5A）内字符 +0x20 转小写参与比较——'@'(0x40)
     下界不转、'`'(0x60) 与 'z'(0x7A) 上界不转（golden 针对性两用例
     实证：@ vs ` → -1、z vs { → -1）、非 ASCII（0x80+）原样不转；
  ④ 返回三态 {-1,0,+1} 非原始差值（jne 分支 mov ecx,-1 → jb -1 /
     neg +1；收尾 xor ecx,ecx → je 0 / jb -1 / neg +1）；
  ⑤ ★慢路径（[0xB782A0]!=0，locale 非 C）依赖锁家族 0x7CD9F5 +
     tolower 内核 0x7CB063——本批只复刻 C locale 快路径。
