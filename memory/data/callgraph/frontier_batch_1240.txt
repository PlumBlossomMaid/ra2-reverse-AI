★字节对解码器家族（10 件——0x7C6B70/0x7C6C79/0x7C6D40/
0x7C6DD6/0x7C6E94/0x7C6F2E/0x7C6FC8/0x7C70C4/0x7C7174/

公共头（0x7C6B70 为标本，198-265B）：
007c6b70  push ebp/mov ebp,esp/add esp,-0x14
007c6b7b  shl dword ptr [ebp+0x1c],1    ; 参7 ×2
007c6b7e  mov eax,[ebp+0x1c] / shl eax,2 ; ×4 → [ebp-0xc]
007c6b87  mov esi,[ebp+0xc]             ; 参2 = 目标指针
007c6b8a  mov eax,[ebp+0x18] / mul [ebp+0x14]  ; 参6×参5
007c6b90  mov [ebp-0x14],eax
007c6b93  add eax,esi / mov [ebp-4],eax ; 源+偏移
007c6b98  mov edi,[ebp+0x10] / mov [ebp-8],edi
007c6ba6  mov bh,[eax+esi] / mov bl,[esi] / inc esi
007c6bac  test bh,0x80                   ; 高位判定
★家族差异（移位/判定位）：
  0x7C6B70/0x7C6C79（同体双份）/0x7C6FC8：shl[+0x1c],1 +
    shl eax,2 + test bh,0x80
  0x7C70C4：shl[+0x1c],1 + shl eax,1 + test bh,0x80（js 分支）
  0x7C6D40/0x7C6E94/0x7C6F2E：shl eax,1 + cmp bh,0xff +
    shl ebx,3/4/3
  0x7C6DD6/0x7C726A：shl eax,2 + cmp bh,0xff
  0x7C7174：shl eax,3 + cmp bh,0xff
★语义：**RLE/平面解码器（推断名——源+行距偏移 + 字节对
  (bh,bl) 解压 + 位/字节判定分派）**。7 参（目标/源/行距/
  尺寸…），mul 行距 + shl 元素宽变体。⚠️partial：头段定性
  （家族形态确定，完整循环/分派分支未逐条追踪——死代码无
  运行观测）。

★对象字段访问器/初始化器（5 件）：
0x7C6270（60B）：mov word [eax+0x22],0 / [eax+0x20],7 /
  mov dword [eax+0x14],0 / [eax+0x10],0 / [eax+0x36],0 /
  [eax+0x34],7 / [eax+0x28],0 / [eax+0x24],0 → leave/ret
  ★字段初始化器（推断名——8 字段清零/置 7 两态）。
0x7C6730（34B）：mov word [eax+0x22],0 / [eax+0x14],0 /
  [eax+0x36],0 / [eax+0x28],0 → leave/ret
  ★同族精简版（缺 +0x20/+0x34/+0x10/+0x24 写入）。
0x7C60C0（271B）：mov eax,[ebp+0x8c] / or [ebp+0x88] /
  mov [ebp+0x74],eax → 字符串扫描（mov al,[esi]/test al）
  → 查表 [ebp+0x50]/[ebp+0x40] 双表
  ★对象字段聚合 + 表驱动字符串匹配（推断名）。⚠️partial。
0x7C62AC（871B）：mov [ebx+0x10],0/[ebx+0x24],0 → cmp word
  [ebx+0x38],0x10 → je 时 shr eax,1 → mov esi,[ebx]/edi,
  [ebx+4] → cmp word [ebx+0x3a],2 分支
  ★对象字段 + 尺寸判定分派（推断名，0x38=类型/0x3A=子型）。
  ⚠️partial：871B 大函数仅头段。
0x7C6752（950B）：mov cx,[ebx+0x38]/dx,[ebx+0x3a] → cmp

  ★对象字段类型分派（推断名，8/0x10 主型 + 1/2 子型）。
  ⚠️partial：950B 大函数仅头段。

★算术例程（4 件）：
0x7C3D60（326B）：push ecx → mov eax,[esp+0x1c]/ecx,
  [esp+0x18]/edx,[esp+0x14] → lea ebp,[eax+eax]（×2）→
  imul ecx,ebp → lea eax,[edx+ecx*4]（元素×4 索引）→
  cmp edx,eax / jae 结束 → 循环
  ★索引数组填充（推断名——元素宽 4 索引 + 行距倍增）。
0x7C4260（317B）：同 0x7C3D60 但 lea eax,[edx+ecx*2]
  （元素宽 2 变体）。
0x7C5BC0（466B）：pushfd/cld → mov [ebp-8],0 → 三参空检查
  （[ebp+8]/[ebp+0xc]/[ebp+0x10] je 0x7C5D87）→ mov dl,0x80
  → cmp ecx,0 位循环
  ★三参位处理例程（推断名——空检查 + 位掩码循环）。
0x7C5DB0（206B）：mov esi,[esi]/edi,[edi]/eax,[eax]/ebx,
  [ebx]（四指针解引）→ add eax,esi / add ebx,edi → shld
  ecx,esi,1 / shld edx,eax,1 → sub [ebp+0x18] ×2 → dec ×2
  ★大数/位运算（推断名——shld 双精度移位 + 加减）。
  与 0x7C5BC0 同区（0x7C5Bxx 数学例程族）。

★边界/负值判定（1 件）：
0x7C5E7E（96B）：mov ebx,[ebp+8] → mov esi,[ebx] → add
  edi,[ebx] / sub edi,[ebp+0x18] → neg esi → dec edi →
  test edi,esi / jl → mov [ebx],0 或 sub [ebx],edi
  ★指针边界钳制（推断名——[目标]=初值，越界清零/回退）。
  两组（[ebp+8]/[ebp+0xc] 各一次）。

★CPUID/特性探测（1 件）：
0x7C6072（70B）：pushfd → mov [ebp-2],0 → pushfd/pop eax

  → pushfd/pop eax → xor eax,ebx → je 0x7C60AE（不支持）
  ★CPU 特性探测（推断名——ID 标志位翻转检测）。
  （batch 1238 已见 0x7C6064 rdtsc，此为其邻接特性检测。）

★nibble 解码（1 件）：
