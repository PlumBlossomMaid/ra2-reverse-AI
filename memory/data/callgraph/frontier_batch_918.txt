一、函数体全读（73B，disasm 0x402600 0x50 全量）

回值=尾跳目标返回值。
机器码（73B 全读）：
  前置: push esi → mov esi,ecx（★this）→ mov eax,[esi+0xd4]（★★
    this+0xD4 = 接口/父类虚表指针）→ call [eax+0x28]（★★虚表槽

    0x40263d（★bit0=0 → 跳过主操作，直接尾跳）
  主操作: mov ecx,[esi+0xa4] → and ecx,0xfffffffe（★★清 bit0）→
    mov [esi+0xa4],ecx → mov edx,[esi+0xd4] → mov ecx,esi → call
    [edx+0x14]（★★虚表槽 0x14——主操作）→ mov eax,[esi+0xa4] →
    or al,4（★★置 bit2）→ mov [esi+0xa4],eax
  尾跳: 0x40263d: mov edx,[esi+0xd4] → mov ecx,esi → pop esi →
    jmp [edx+0x2c]（★★虚表槽 0x2C——tail-call 收尾，返回值即本函
    数返回值）
语义：**标志位门控接口三段转发器（推断名）**——thiscall 无栈参：①

  时清 bit0 → 虚表槽 0x14 主操作 → 置 bit2；③ 虚表槽 0x2C 尾跳收
  尾（tail-call——不额外 ret，直接透传返回）。★★典型「pending 标志
  位驱动的一次性操作」模式：bit0=待处理、bit2=已处理/已调度。
