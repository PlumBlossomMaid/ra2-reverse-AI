================================================================================
★ 模块归属：0x7B46xx–0x7B67xx 是一整个字符串类（本批把它拼齐）
================================================================================
此前零散取证的函数，本批确认是**同一个字符串类**的成员：

| 地址 | 角色 | 扇入 |
|---|---|---|
| `0x7B4620` | 默认构造（清指针字段） | 71 |
| `0x7B4630` | 赋值 `operator=`（NULL 安全） | 81 |
| `0x7B46F0` | 析构（delete + 置 NULL） | 163 |
| `0x7B4710` | 比较（返回布尔） | — |
| `0x7B6760` | 析构孪生 | 95 |
| `0x7B6780` | `operator==`（NULL 安全） | — |

它们的共性：都经 `ecx`（this）访问 `+0x00` 的 char* 字段，operator new/delete
一律走 `0x7C8E17`/`0x7C8B3D`。这是**单指针字段的引用语义字符串类**——
`this->[0x00]` 直接存 `char*`，无 SSO/无长度缓存，是最朴素的 MFC 之前形态。
扇入合计约 400+，是引擎里用得最重的字符串类之一。

================================================================================
0x007B4620  默认构造（清指针字段）
================================================================================
71 callers。全部 7 字节：

    007b4620  mov eax, ecx
    007b4622  mov dword ptr [eax], 0
    007b4628  ret

即「把 this->[0] 置 NULL」的默认构造（成员初始化 `str = nullptr`）。

================================================================================
0x007B4630  赋值 operator=（NULL 安全）
================================================================================
81 callers。反汇编全部 0x5C 字节：

    007b4630  push ebx / push esi
    007b4632  mov esi, [esp+0xc]           ; 源串
    007b4636  mov ebx, ecx                 ; this
    007b463b  mov dword ptr [ebx], 0       ; this->str = NULL
    007b4641  je 0x7b4650                  ; 源 NULL → 分配 1 字节空串
    007b4643  mov edi, esi
    007b4645  or ecx, -1 / xor eax, eax
    007b464a  repne scasb                  ; strlen(source)
    007b464c  not ecx                      ; ecx = strlen+1
    007b4655  push ecx
    007b4656  call 0x7c8e17                ; operator new
    007b465b  add esp, 4
    007b465e  mov [ebx], eax               ; this->str = 新缓冲
    007b4660  test esi, esi
    007b4662  mov byte ptr [eax], 0        ; 缓冲[0]=0（空串兜底）
    007b4665  je 0x7b4686                  ; 源 NULL → 完成
    ; （否则再来一次 strlen，然后 rep movsd + rep movsb 拷贝内容）

要点：**NULL 源不崩**——分配 1 字节、写 '\0'，得到空串。这是「赋空 =
赋空串」而非「赋空 = 置 NULL」的语义，与 0x7B4620 默认构造（置 NULL）
区分。**紧邻的 0x7B4690 是它的孪生**（开头 `mov [ebx],0; or ecx,-1;
repne scasb` 同形，未做归一化比对）。

================================================================================
0x0050B6F0  HouseClass::IsControlledByCurrentPlayer
================================================================================
79 callers（符号名 symbol_source=USER_DEFINED，YRpp 覆盖，按推断名标注）。
反汇编全部 0x34 字节：

    0050b6f0  mov eax, [0xa8b238]          ; 全局标志
    0050b6f5  test eax, eax
    0050b6f7  jne 0x50b716                 ; 置位 → 走比较路径
    0050b6f9  mov al, [ecx+0x1ec]          ; this->field_0x1EC
    0050b6ff  test al, al / jne 0x50b710   ; 为 1 → 返 1
    0050b703  mov al, [ecx+0x1ed]          ; this->field_0x1ED
    0050b709  test al, al / jne 0x50b710   ; 为 1 → 返 1
    0050b70d  xor eax, eax / ret           ; 都 0 → 返 0
    0050b710  mov eax, 1 / ret
    0050b716  mov edx, [0xa83d4c]          ; 全局当前玩家指针
    0050b71c  xor eax, eax
    0050b71e  cmp ecx, edx                 ; this == 当前玩家 ?
    0050b720  sete al                      ; 返 (this == current)
    0050b723  ret

语义：**判定本 House 是否由当前玩家控制**。两条路径：
① 全局 `[0xA8B238]` 未置位（单机/非观察者模式）→ 查两个标志字节
   `+0x1EC`/`+0x1ED`（应为 IsHumanPlayer / IsObserver 之类）；
② `[0xA8B238]` 置位 → 直接比较 `this` 与全局当前玩家指针 `[0xA83D4C]`。
紧邻的 `0x50B730` 是近孪生（标志字节判断顺序略不同）。

⚠️ 保留边界：`+0x1EC`/`+0x1ED` 两个标志的具体含义、`[0xA8B238]`
（单机/观察者开关）与 `[0xA83D4C]`（当前玩家）的写入点均未实锤。
