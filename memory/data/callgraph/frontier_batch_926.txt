一、语义（210B 全读 + emu 黄金闭环）
------------------------------------------------
真义（黄金实证 + 机器码逐段确认）：
  ① dx = p2.x-p1.x ; dy = p2.y-p1.y（movsx word 带符号读 int16）
  ② 若 dx==0: a = π/2（[0x7E2820] 快速路径，跳过 Atan 调用）
     否则:     a = Atan(-(double)dy/(double)dx)  // 0x4CADE0 4097 项 LUT
               if (dx < 0) a += π                  // [0x7E44D0]
  ③ r = |a - arg|（fsub qword [esp+0x18] + fabs）
  ④ while (r >= 2π) r -= 2π                      // mod 2π（[0x7E3CC0]）
  ⑤ if (r > π) r = 2π - r                        // 折叠到 [0,π]
  ⑥ 返回 Random() * kInvUintMax * 2.0 + 1.5 * r
     // [0x7ED898]=1/(2^32-1) × [0x7ED790]=2.0 + [0x7ED798]=1.5×r
  全程 RC=chop（原版 x87 全局向零截断——MXCSR toward-zero 复刻）。

三、C++ 模型（code/rewrite/rmg/dead_code_jitter.{h,cpp}）
------------------------------------------------
签名：double DeadCodeAngleJitter(Randomizer& rng, int16 ax/ay/bx/by,
  double arg)。
实现链：dx/dy int32（p2-p1 方向）→ dx==0 快路 π/2 / Atan(-dy/dx)
（fast_math 已有模型，0x4CADE0 4097 项 LUT）+ dx<0 加 π →
|a-arg| → mod 2π 循环 → >π 折叠 → j = Random()*kInvUintMax*2.0
+ 1.5*r。
★浮点环境坑：原版 x87 全局 RC=chop，C++ SSE 默认 round-to-nearest
——与 batch 924/925 同修法（MXCSR _MM_ROUND_TOWARD_ZERO 全程包裹
+ volatile 防重排）；非 x86_64 降级同数学语义（主对拍平台为 x64）。

五、怪癖照抄（C++ 模型内已固化 + 单测锁定）
------------------------------------------
① dx==0 走 π/2 快路不调 Atan（省一次 LUT 查表，且 -dy/0 会是 inf）；
② Atan 参数是 -(double)dy/(double)dx（先取负再除，非 atan2）；
③ dx<0 加 π 修正象限（atan LUT 只覆盖 -π/2..π/2）；
④ mod 2π 用 while 循环 fsub（非 fmod——逐次 chop 舍入）；
⑤ r>π 折叠 2π-r 把角差归一到 [0,π]；
⑥ 随机项 = Random()*kInvUintMax*2.0（幅度 2.0，非 1.0）；
⑦ 权重 1.5*r（角度差线性放大 1.5 倍）；
⑧ j 链全程 RC=chop（MXCSR toward-zero 复刻）；
⑨ ret 0x10 三栈参（第三参 double 8B 占两个 dword 槽）。
