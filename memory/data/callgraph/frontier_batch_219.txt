0x408070  位标志测试（8 callers，全 0x07 读完）
================================================================================
机器码（全 0x07，body=7）：
    mov eax,[ecx+0xC]   ; ★ 读 this->+0xC
    and eax,1           ; ★ 取 bit0
    ret
  紧邻 0x408080（同区第二成员）:
    push esi / mov esi,ecx / push 0x50 / push edx / lea eax,[esi+0xA4]
    push eax ...        ; ★ 三参调用（+0xA4 子对象）

语义：**位标志测试（0x408xxx 区）**——返回 this->+0xC 的 bit0
（`and eax,1`）——布尔位读取器。7 字节极简。
★0x40xxxx 区（batch 207 的 0x40BD00 缓冲容器构造、batch 216 的
0x4115F0 邻域）——对象字段管理端；紧邻 0x408080 是三参调用函数
（+0xA4 子对象）。

⚠️ partial：+0xC bit0 语义、宿主类、紧邻 0x408080 身份。

0x4B4D50  可选对象槽 8 调用（8 callers，全 0x0D 读完）
================================================================================
机器码（全 0x0D，body=13）：
    mov eax,[ecx]          ; ★ this->+0（可选对象指针）
    test eax,eax / je 0x4B4D5C   ; ★ 为空 → 直接返回
    mov ecx,[eax] / push eax
    call [ecx+8]           ; ★ 虚表槽 8（对象方法调用）
  0x4B4D5C:
    ret
  紧邻 0x4B4D60（同族第二份，逐字节相同）:
    mov eax,[ecx] / test eax / je 0x4B4D6C / mov ecx,[eax] / push eax
    call [ecx+8] / ret     ; ★ 完全同码副本

语义：**可选对象槽 8 调用（0x4B4Dxx 区）**——this->+0 非空时调其虚表
槽 8（委托/通知推断）；为空静默跳过。紧邻 0x4B4D60 是**逐字节相同的
第二份**（两份副本——编译器/链接器重复实例化）。
★**空指针门闩 + 槽 8**：与 batch 205 的 0x48ACE0（恒返 -15 桩）不同
（本条第 8 字节处 je 跳过的空检查是有效委托而非桩）。
★0x4Bxxxx 区（batch 216 的 0x4B4D50 邻域）——对象委托端。

⚠️ partial：+0 对象身份、虚表槽 8 语义、双份副本的实例化来源。

================================================================================
0x631D10  子对象槽 0x10 转发（8 callers，全 0x20 读完）
================================================================================
机器码（全 0x20，body=32）：
    mov ecx,[ecx+4]        ; ★ this->+4 子对象
    test ecx,ecx / je 0x631D29   ; ★ 为空 → 直接返参数 1
    mov edx,[esp+8] / mov eax,[ecx]
    push edx / mov edx,[esp+8] / push edx   ; ★ 连续压 2 参（转发）
    call [eax+0x10]        ; ★ 虚表槽 0x10
    ret 8                  ; ★ 2 参清理
  0x631D29:
    mov eax,[esp+8] / ret 8   ; ★ 子对象空 → 返参数 1
  紧邻 0x631D30（同族第二份）:
    mov ecx,[ecx+4] / test ecx / je 0x631D3C
    mov eax,[ecx] / jmp [eax+4]   ; ★ 尾调用虚表槽 4
    xor eax,eax / ret

语义：**子对象槽 0x10 转发（0x631xxx 区，batch 210 的 0x630310 同区）**——
this->+4 子对象非空时把调用方 2 参转给其虚表槽 0x10（ret 8 清 2 参）；
为空直接返参数 1（透传）。紧邻 0x631D30 是同族第二份（尾调用虚表槽 4
——另一转发变体）。
★**空对象透传**（转发 vs 透传双路径）——与 batch 198 的 0x541370
（双标志闸门转发）同思路但更简（单空检查无标志）。
★0x63xxxx 区（batch 210 的 0x630310 表面工厂、batch 215 的 0x635120
容器清理器同区）——容器/表面管理端。

⚠️ partial：+4 子对象身份、虚表槽 0x10/4 语义、透传参数 1 的调用方契约、
紧邻 0x631D30 完整行为。
