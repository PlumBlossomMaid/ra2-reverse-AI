一、链语义（disasm 全 23B 复核）
------------------------------------------------
0x7CB9B8(23B) = MSVC6 CRT 宽字符数值解析包装（_wtoi/_wcstol 族，
0x7C-0x7D 静态 CRT 区）——cdecl 3 栈参，固定压 0 作 flags 转调主体：
  push 0                         ; ★第 4 参 flags=0（最先压入 → 栈高址）
  push [esp+0x10] ×3            ; ★第 1/2/3 参转发（arg1/arg2/arg3）
  call 0x7CB9CF                 ; ★★主体：宽字符前缀扫描 + 符号/进制
                                ;   状态解析
  add esp,0x10                   ; cdecl 弹 16B（4 参）
  ret
  等价：return 0x7CB9CF(arg1, arg2, arg3, 0)

被调 0x7CB9CF（前段 64B 复核）：
  push ebp/mov ebp,esp/push ecx/and [ebp-4],0
  push ebx/push esi/push edi
  mov edi,[ebp+8]（★第 1 参=宽串指针）
  mov si,word[edi]/add edi,2（★读 u16 前缀字符）
  循环：push 8/push esi（si 零扩展 u16）/call 0x7D3920（★★字符分类查
    表——batch 048/244 同 0x7D 段设施）/test eax/je 0x7CB9F8
    （★命中）→ mov si,word[edi]/inc edi ×2（★跳过一宽字符）→ jmp
  0x7CB9F8: cmp si,0x2d（'-'）/jne 0x7CBA04 → or [ebp+0x14],2（★★
    flags 第 4 参 |=2 符号位）→ jmp 0x7CBA0A → cmp si,0x2b（'+'）/
    jne 0x7CBA0F → mov si,word[edi]/inc edi ×2（★跳过符号）→ 后续进
    制/数字/精度扫描（未读完）
★语义：**宽字符数值解析包装**——0x7CB9B8 固定压 flags=0 调主体
0x7CB9CF；主体 = _wtoi/_wcstol 家族宽版前缀解析：逐宽字符查
0x7D3920（字符分类，8=digit 掩码推断）跳过前导分类字符、识别
'-'/'+' 符号置 flags bit1、继续进制/数字/精度扫描（batch 489
_wcstod 双字版同模板）。
★原版怪癖（batch 489 已录同模板，照抄）：
  ① flags 第 4 参由调用方初始化（本包装固定 0）；
  ② 符号 '-' 置 flags|2（bit1）、'+' 不置但同样跳过；
  ③ 宽字符 2B 步进（inc edi ×2）+ mov si 零扩展；
  ④ 字符分类走 0x7D3920 查表（非手写 ASCII 比较——locale 感知）。

★依赖链实锤（本批 disasm + TSV 交叉）：
  ① 0x7CB9CF = 宽字符数值解析主体（紧邻后函数，本批入口交叉）——
     batch 489 _wcstod 双字版同模板推断；
  ② 0x7D3920 = 字符分类查表设施（batch 048/244 同 0x7D 段）；
  ③ flags/符号位（bit1）——batch 489/244 数值解析族交叉。
