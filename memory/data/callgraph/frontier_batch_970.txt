一、链语义（disasm 全段复核）
------------------------------------------------
0x7CA75B(49B) = MSVC6 CRT FILE 关闭（0x7C-0x7D 静态 CRT 区）——
cdecl 1 栈参（FILE* 流槽），_IOSTRG 分支短路 + 流锁三步骤：
  push esi / mov esi,[esp+8]        ; ★参数=FILE* 流槽
  push edi / or edi,0xFFFFFFFF      ; ★返回值预置 -1 EOF
  test byte ptr [esi+0xC],0x40      ; ★★流槽+0xC 标志位测试 _IOSTRG
  je 0x7CA770                       ; 未置位 → 标准关闭流程
  and dword ptr [esi+0xC],0         ; ★字符串流分支：直接清标志字
  jmp 0x7CA787                      ; ★★跳过全部解锁流程（未进锁）
  0x7CA770: push esi / call 0x7CB3F9   ; ★★流锁 Enter（batch 966 归档）
  push esi / call 0x7CA78C             ; ★★关闭内核（返回 edi）
  push esi / call 0x7CB44B             ; ★★流锁 Leave（batch 961 归档）
  add esp,0xC
  0x7CA787: mov eax,edi / pop 族 / ret

被调 0x7CA78C（关闭内核，前 40B 复核）：
  push esi / mov esi,[esp+8] / push edi / or edi,0xFFFFFFFF
  test byte ptr [esi+0xC],0x83       ; ★标志 0x83（_IOERR|_IOFLRTN|...）
  je 0x7CA7CF / push esi
  call 0x7CB1F9                      ; ★★FILE 缓冲 flush（batch 046 域）
  push esi / mov edi,eax
  call 0x7D2B54                      ; ★★FILE 底层 close 设施
  push [esi+0x10]
  call 0x7D2A74                      ; ★★FILE 缓冲释放设施
  add esp,0xC ...
  （后续未读——batch 226 partial 标注）

★语义：**FILE 关闭（fclose 家族）**——`流槽+0xC` 带 `_IOSTRG`(0x40)
位（内存/字符串流，无底层 OS 句柄）则**只清标志字、返回 -1、不进锁**；
否则标准三步：流锁 Enter(0x7CB3F9) → 关闭内核(0x7CA78C，flush+close
+缓冲释放，返回值透传) → 流锁 Leave(0x7CB44B)。
★原版怪癖（batch 226 已录，照抄）：`_IOSTRG` 分支**直接返回 -1（EOF）
且完全不解锁**——不解锁安全（该分支没进临界区），但**返回值恒为失败**
（即使字符串流语义上"关闭成功"）——易被"顺手修成正确"的怪癖。
★调用方（batch 226 已录）：含 **0x5DC170（woldata.key 解密公式，
QWEN.md 实锤 YR 正版校验全链）**——该链需临时打开数据文件，fclose
出现吻合；0x53E770（1156B 候选 TOP）与 0x48E0B0 为文件/资源 I/O 侧。

★依赖链实锤（本批 disasm + TSV 交叉）：
  ① 0x7CB3F9/0x7CB44B = 流锁 Enter/Leave——batch 966/961 已归档
     crt_runtime_verified（[0x87BF50,0x87C1B0] 锁数组 → 0x7CD9F5/
     0x7CDA56；区间外 [0x7E11E8]/[0x7E11EC] IAT），0x7CA75B 三步骤
     调用现场交叉；
  ② 0x7CA78C = FILE 关闭内核——0x7CB1F9（缓冲 flush，batch 046 流
     槽标志域）+ 0x7D2B54/0x7D2A74（FILE 底层 close/缓冲释放设施，
     0x7D 段 CRT）；
  ③ 流槽 +0xC 标志字：0x10 _IOFLRTN/0x20 _IOERROR/0x80 EOF/0x40
