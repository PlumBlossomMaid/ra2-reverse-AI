一、链语义（disasm 全 266B + 月份表取证，0x7D52B8-0x7D53C1）
--------------------------------------------------------------
签名（实测）：cdecl 1 参（param1 = time_t* @[esp+4]），
返回分解结构指针（TLS 缓冲 [edi+0x40] 或默认 [0xB783B0]）。

★常量（代码内联 + PE 取证）：
  0x7861F80 = 126230400 = 1461 天（4 年含闰）秒数
  0x1E13380 = 31536000  = 365 天秒数
  0x1E28500 = 31622400  = 366 天秒数（闰年）
  0x15180   = 86400     = 1 天秒数
  0xE10     = 3600      = 1 小时秒数
  0x3C      = 60        = 1 分钟秒数
  [0x87D580] = 平年累计月天数表 {−1,30,59,90,120,151,181,
               212,243,273,304,334}（PE dword 实锤）
  [0x87D5B4] = 闰年累计月天数表 {−1,30,58,89,119,150,180,
               211,242,272,303,333}（PE dword 实锤）

★语义：**MSVC6 CRT 32 位 time_t 分解器（推断名——localtime/
gmtime 类）**——cdecl 1 参 time_t*：
  ① 调 0x7D140B（batch 008 per-thread CRT TLS/错误态初始化
     ）取 TLS 基址；负时间戳直接返回 0；
  ② TLS 缓冲 [edi+0x40] 懒分配（malloc 0x24），未分配时用
     默认目标 [0xB783B0]；
  ③ 公历分解：÷1461 天（4 年周期含闰）得年 → 逐级减 365/
     366 天年调整 → ÷86400 得年内日 → 月表扫描定位月（
     [0x87D580] 平年/[0x87D5B4] 闰年累计表）→ ÷3600 得时
     → ÷60 得分 → 余秒；
  ④ 输出结构字段：+0 秒 / +4 分 / +8 时 / +0xC 月内日 /
     +0x10 月 / +0x14 年(+1900) / +0x18 日余 / +0x1C 年内日
     / +0x20 0；
  ⑤ 返回结构指针（TLS 缓冲或 [0xB783B0]）。

★调用点（探针 E8 实测 3 处）：0x7CD300/0x7CD330/0x7CD345
  同宿主 0x7CD2E0 区：①[0x87CA60] 时区偏移修正 → call →
  0x7D4FAB 二次转换（[0x87CA64] 门控）→ [0x87CA68] 偏移再
  修正 → 二次 call → [esi+0x20]=1（★夏令时/本地标记）；
  ②溢出路径（时间戳超 0x7FFC0B7F）→ 直接 call → 0x7D4FAB
  → [0x87CA68] 修正。宿主语义 = CRT localtime 包装（UTC
  修正 + 本地时区 + DST 标记）。

★E8 被调者：0x7D140B（batch 008 per-thread CRT TLS/错误态
  初始化，18 callers——本批 0x7D52C3 交叉）+ 0x7C9430
  （batch 063 malloc，TLS 缓冲懒分配）。

★原版怪癖（照抄）：
  ① 负时间戳直接返回 0 且不写任何字段（无错误码）；
  ② TLS 缓冲 [edi+0x40] 懒分配（首次 malloc 0x24），未分
     配时用默认 [0xB783B0] 兜底——两目标并存；
  ③ 年计算 lea edx,[eax*4+0x46]：4 年周期×4 + 70（1900
     纪元偏移）——非闰年分支直接减两遍 365 天；
  ④ 闰年标记 ebx=1 时用 [0x87D580] 平年表？反汇编显示非
     闰走 0x87D5B4——★表选择与直觉相反需注意（0x7D5352
     mov edi,0x87D5B4 在 test ebx,ebx jne 之后 = 非闰走闰

  ⑤ 月表扫描 lea ebx,[edi+4] 从第 2 项起逐项比对（首项
