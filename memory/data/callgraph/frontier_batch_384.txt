② 0x0048A8D0 —— 角度换算（实读常量 π/2）（推断名，253B，ret 0x14）
================================================================================
**常量实测**（`.qwen/tmp/_read_dbl.py` 直读 PE 字节，非猜值）：
```
0x7E2800 = 0.0        （double，raw 0000000000000000）
0x7E2808 = 128.0      （double，raw 0000000000006040）
0x7E2810 ≈ -0.0982    （double，raw 575e9f982d2219bf）

```
机器码（要点）：5 个栈参（`ret 0x14`）+ `cl`（字节，存 `bl`）+ `edx` 两寄存器参。
```
0048a8d0  sub esp,8 / **lea eax,[esp+0x14]**（★取栈参地址）/ push 族
0048a8f8  **call 0x48A9D0**（★同域子函数，5 参 + cl/edx）→ test al / **je 0x48a9c1**（返回 0）
0048a905  **test bl,bl / je 0x48a939**（★bl 门控两条路径）
 ; 路径 A（bl != 0）：
0048a909  **fld qword [esp+0x24] / fsub [0x7E2820]（−π/2）/ fmul [0x7E2818]（× -10430.06004）
          / call 0x7C5F00（★CRT _ftol）**
0048a91e  **mov word [esp+0x20], ax**（★★**只存 16 位**）
          mov ecx,[esp+0x20]（★按 **dword 读回**）/ **mov [eax],ecx**（★写 32 位到
          *(栈参5)）→ mov al,1 / **ret 0x14**
 ; 路径 B（bl == 0）：先以"参数+1、cl=0"再调 0x48A9D0，然后
0048a954  fld [esp+0x10] / **fcomp [esp+0x24]** / fld [esp+0x24] / fnstsw ax / **test ah,1**
          → 分支：
0048a995  （比较成立）**fsub [0x7E2820] / fmul [0x7E2818] / _ftol** → 存 16 位 → 返回 1
0048a967  （不成立）**fchs**（★取负）/ fsub [0x7E2820] / fmul [0x7E2818] / _ftol → 存 16 位 → 返回 1
0048a9c1  出口：xor al,al / ret 0x14（返回 0）
```
**语义（推断名）**：**角度换算/归一化**——`x → (x − π/2) × (−10430.06004)` 取
`_ftol`（**向零截断**），**只保留低 16 位**后写进 `*(栈参5)`；`bl` 决定走"直接换算"
还是"先递归求另一个角度再比较、必要时 `fchs` 取负"。**数值口径**：`x = π/2 → 0`；
`x = 0 → +16383.5`（= π/2 × 10430.06）；即**常量把 π/2 映到 2^14 = 16384 量级的
"16 位整圆"刻度**（65536/2π = 10430.378 与之相差 3.05e-5，**不相等**）。
★原版怪癖（照抄）：① **算完只 `mov word [esp+0x20], ax`（16 位），随后
`mov ecx,[esp+0x20]` 按 dword 读回并 `mov [eax],ecx` 写 32 位**——**写出值的
高 16 位不是本次计算结果**（来自该栈槽原内容，⚠️ 槽位来源未逐帧核对，仅登记
现象：**16 位截断 + dword 写回**）；② **`fchs` 手工处理负角**（未用 `atan2`/取模）；
③ **`_ftol` 向零截断**（与 QWEN.md 硬性规范 4 一致：此点确认用 `_ftol`，非
ties-to-even、非 round-half-away）；④ 常量 **π/2** 与 **−10430.06004** 成对使用、
`fsub` 在前 `fmul` 在后（运算次序钉死）；⑤ 三条 `ret 0x14` 各写一遍收尾；
⑥ **参数同时走 `cl`(字节)/`edx` 与 5 个栈参**（混用寄存器与栈传参）。
★跨批次连接：`_ftol @0x7C5F00`（QWEN.md 已实锤"`_ftol` 快路径比对
`[0x822D80]` 控制字缓存 0x0E7F"）+ 0x48A8D0 与 0x48A9D0 构成**同域配对**
（后者未登记，列为候选）。
⚠️ partial：宿主/用途（**朝向？炮塔角？地图角？——未读 callers，不猜**；
`bl` 门控与"参数+1 再比较"的语义未定）、常量 **−10430.06004 的精确归一化口径**
（**已实测数值**，是否为 65536/2π 的某种取整未证）、子函数 `0x48A9D0` 语义
