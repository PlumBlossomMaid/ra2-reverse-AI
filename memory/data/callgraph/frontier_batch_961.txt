一、链语义（disasm 全 47B 复核）
------------------------------------------------
0x7CB44B(47B) = MSVC6 CRT 流锁 Leave（0x7C-0x7D 静态 CRT 区）——
cdecl 1 栈参（锁指针），按是否落在内部锁数组区间分两路：
  mov eax,[esp+4]（★锁指针参）
  mov ecx,0x87BF50（★★锁数组下界）
  cmp eax,ecx → jb 0x7CB46F（<下界 → 走 IAT 路径）
  cmp eax,0x87C1B0 → ja 0x7CB46F（>上界 → 走 IAT 路径）
  ★★区间 [0x87BF50, 0x87C1B0] = 608B = 19 × 32B 锁数组
    （MSVC6 _locktable 形态：每锁 32B = 占用/等待/事件/类型）

  add eax,0x1C（★锁编号 = 索引 + 0x1C——与 0x7CB3F9 Enter
    的 0x1C 基偏移对称）
  push eax → call 0x7CDA56（★★锁家族——batch 244 推断 CRT
    临界区/流锁包装，_pick_945 留桩边界项）→ pop ecx → ret
  0x7CB46F（区间外）：add eax,0x20（★p+0x20）→ push eax →
    call [0x7E11EC]（★★IAT 导入槽——batch 279/292 同 .rdata
    槽区 [0x7E11E8]/[0x7E11EC] 成对锁槽）→ ret
  ★★语义：流锁释放分发——内部锁数组指针 → 编号 → 0x7CDA56
  （锁 Leave 内核）；外部对象指针 → p+0x20 → IAT 槽（Enter/
  Leave 通用回调）。与 0x7CB3F9（流锁 Enter，对称对）构成
  Enter/Leave 双入口。

★可观测行为总结：1 参 cdecl 双路径锁释放（区间内编号 →
