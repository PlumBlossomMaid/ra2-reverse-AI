0x7B48D0  窄串 operator=（释放旧值）（12 callers，0x50 未读完）
================================================================================
机器码还原（前 0x50）——与 batch 134 的宽串 0x7B7600（释放旧值版）**同构**：
    mov eax, [ecx]                  ; ★ this->[0]（旧串指针）
    test eax / je 跳过
    push eax / call 0x7C8B3D        ; ★ CRT::_delete 释放旧（batch 001/096）
  跳过:
    mov esi, [esp+0x10]             ; ★ 源参数字符串
    mov [ecx], 0                    ; 先置 NULL
    test esi / je 空源
    repne scasb 求 strlen（edi=源）   ; ★ 源长度
    jmp 定长
  空源:
    mov ecx, 1
  定长:
    push ecx / call 0x7C8E17        ; ★ CRT::_new（len+1，batch 001）
    mov [ecx], eax / mov byte [eax], 0
    test esi / je 收尾
    ...（rep movsb 拷贝——strlen 后用 rep movsd/movsb）

语义：**窄字符串类 operator=（释放旧值 + 重新分配）**——与 batch 134 的宽串
0x7B7600 **同构（窄串版）**：_delete 旧 → strlen 定长 → _new(len+1) → 拷贝
（rep movsb，窄串 1 字节）。窄串 operator= 家族（batch 090 已登记）的释放
旧值变体。

★跨批次连接：batch 134（0x7B7600 宽串同构）+ batch 090（窄串 operator= 族）
+ _delete/_new 三件套——宽窄串释放旧值版对称。

⚠️ partial：拷贝段（rep movsb 之后）未读完、宿主类名（StringClass 推断）。

0x792BE0  UI 控件查找文本链（12 callers，0x50 未读完）
================================================================================
机器码还原（前 0x50）：
    mov edi, ecx                    ; this
    mov ebx, edx                    ; 参数字符串
    mov ecx, 0xC4                   ; ★ 常量 0xC4（控件 ID?）
    call 0x775940                   ; ★（0x775940 取对话框/控件）
    mov esi, eax
    test esi / je 收尾
    mov edx, [0xB77DC8] / or edx, edi

    mov ecx, ebx
    call 0x7B71B0                   ; ★ 宽串 length（batch 128 实锤）
    test eax / jbe 收尾
    push 0x5B2 / push esi
    call [0x7E14A8]                 ; ★ GetDlgItem（batch 099 实锤）
    mov ecx, ebx
    call 0x7B7140                   ; ★ 宽串 getter（batch 112 实锤）
    push eax ...
    ; ★（GetDlgItem(对话框, 0x5B2) 取控件 → 取参数字符串 → 设文本）

语义：**UI 控件查找 + 文本设置链**——0x775940 取对话框（常量 0xC4 相关）、
[0xB77DC8] 全局置位、GetDlgItem(0x5B2) 取控件、宽串 length/getter（0x7B71B0/
0x7B7140）取参数文本——batch 110/141 的「GetDlgItem 取控件 → 填文本」链的
又一实例（批量引用已登记的 UI 家族工具）。

★跨批次连接：batch 099（GetDlgItem 0x7E14A8）+ batch 128/112（宽串 length/
getter）+ [0xB77DC8] 全局——UI 控件文本链跨批咬合。

⚠️ partial：0x775940 身份、0xC4 常量语义、[0xB77DC8] 全局、设文本动作后半。

0x5F1C30  虚调用三参版（batch 119 闭合，12 callers，0x1B 全读完）
================================================================================
机器码（全 0x1B）：
    mov eax, [ecx+0x3C]             ; ★ +0x3C 门卫
    test eax / jne 继续
    xor eax / ret 8                 ; ★ 空 → 返 0
  继续:
    mov edx, [esp+8]                ; 参数 1
    mov ecx, [ecx+0x38]             ; ★ +0x38 服对象
    push edx / mov edx, [esp+8]     ; 参数 2
    mov eax, [ecx] / push edx
    call [eax+0x10]                 ; ★ 虚表槽 +0x10（两参调用）
    ret 8

语义：**batch 119 登记的 0x5F1BF0（虚调用重试包装器）的三参版兄弟**——batch
119 文档当时标注「紧邻 0x5F1C30 是同族三参版（虚表槽 +0x10）」，本批补登：
+0x3C 门卫 → +0x38 服对象虚表槽 +0x10 两参调用。0x5F1BF0 = 虚表槽 +8 四参 +
失败计数 ++；本条 = 虚表槽 +0x10 两参（无计数）。

★跨批次连接：batch 119（0x5F1BF0 同族闭合）+ 虚表槽调用族——0x5F1xxx
区的「服对象虚调用」包装家族第二成员。

⚠️ partial：虚表槽 +0x10 方法身份、+0x3C/+0x38 字段语义（沿用 batch 119）。
