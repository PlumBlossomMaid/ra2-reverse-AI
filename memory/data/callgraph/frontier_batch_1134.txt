★语义：**MSVC6 CRT asctime（推断名——tm 结构格式化为
"Www Mmm dd hh:mm:ss yyyy\n"）**——cdecl 1 参 const tm*：
  ① 0x7D140B 取 TLS 基址 → [esi+0x38] 缓冲懒分配（malloc
     0x1A=26 字节，失败回退静态 0xB783DC）；
  ② 星期表 [0x7F9948]（tm_wday×3）+ 月表 [0x7F995F]
     （tm_mon×3）各写 3 字节（错位 4——第 3 字节空格槽）；
  ③ 0x7D58C8 数值转串逐字段：tm_mday/tm_hour/tm_min/tm_sec
     （冒号分隔）+ tm_year 世纪（idiv 100 + 19）+ 十位个位；
  ④ 换行 + NUL 终止，返回缓冲基址。
  = asctime 标准实现（TLS 缓冲 + 星期/月名表 + 逐字段格式化
  ）。

  （CRT 时间格式化调用端——asctime/ctime 分发宿主）。
