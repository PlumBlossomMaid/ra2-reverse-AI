一、链语义（disasm 全 86B + 全局分布 + 五调用点归属，
0x7DBC9A-0x7DBCEF）
--------------------------------------------------------------
签名（推断）：cdecl 1 参（[ebp+8]=标志字节 cl），按位选
择 FPU 常量/状态输出到 [ebp-8]（double 槽）或 [ebp+8]
（int 槽）。

主体（0x7DBC9A-0x7DBCEF）：
007dbc9a  push ebp/mov ebp,esp/push ecx/push ecx   ; 局部 8B
007dbc9f  mov cl,[ebp+8]                 ; ★cl = 标志字节
; → bit0（0x7DBCA2）：fld [0x87D704] → fistp [ebp+8]
007dbca2  test cl,1/je 0x7dbcb1          ; ★★bit0 → [0x87D704] 80 位
                                          ;   控制字 → fistp 转 int
                                          ;   存参槽
007dbca7  fld [0x87d704]/fistp dword[ebp+8]/wait
; → bit3（0x7DBCB1）：
007dbcb1  test cl,8/je 0x7dbcc6          ; ★★bit3 → fnstsw ax 状态字
                                          ;   + [0x87D704] → double 槽
007dbcb6  wait/fnstsw ax
007dbcb9  fld [0x87d704]/fstp qword[ebp-8]/wait
; → bit4（0x7DBCC6）：
007dbcc6  test cl,0x10/je 0x7dbcd5       ; ★★bit4 → [0x87D710] →
                                          ;   double 槽
007dbccb  fld [0x87d710]/fstp qword[ebp-8]/wait
; → bit2（0x7DBCD5）：
007dbcd5  test cl,4/je 0x7dbce3          ; ★★bit2 → fldz/fld1/fdivrp
                                          ;   （1/0 = inf 怪异计算）
007dbcda  fldz/fld1/fdivrp st(1)/fstp st(0)/wait
; → bit5（0x7DBCE3）：
007dbce3  test cl,0x20/je 0x7dbcee       ; ★★bit5 → fldpi → double 槽
007dbce8  fldpi/fstp qword[ebp-8]/wait
007dbcee  leave/ret

★语义：**MSVC6 CRT FPU 控制字常量选择器（推断名——batch
192 0x7DBC77 _controlfp 的邻件）**——cdecl 1 参：
  ① cl 标志位逐位分派（互斥位测试链）：
     bit0 → [0x87D704]（x87 控制字全局）fistp 转 int 存参
     槽；
     bit3 → fnstsw 状态字 + [0x87D704] → double 槽；
     bit4 → [0x87D710]（另一 FPU 状态全局）→ double 槽；
     bit2 → fldz/fld1/fdivrp（1/0 → inf 的怪异求值）；
     bit5 → fldpi → double 槽；
  ② 纯 x87 指令操作（fld/fistp/fnstsw/fldpi），零 E8 调
     用。
  = _controlfp/_statusfp 支持层——按调用者标志位提取对
  应 FPU 控制字/状态常量（五个调用点全在 0x7DBxxx 域）。

★调用点（探针 E8 实测 5 处）：0x7DB95B/0x7DB975/0x7DB997/
0x7DBB2A/0x7DBB41——全在 0x7DBxxx（FPE 包装域——batch
192 0x7DBC77 _controlfp、batch 1141 0x7DB54E FPE 检查包
装器同区）——按各自标志位取值。

★E8 被调者：**零子调用**（全 86B 纯 x87 fld/fistp/fnstsw/
fldpi 操作）。全局：[0x87D704]（2 处引用 0x7DBCA9/0x7DBCBB
本函数内）+ [0x87D710]（1 处 0x7DBC CD 本函数内）——x87
控制字/状态字存储区，与 batch 1141 [0x87D700] FPE 门控全
局同连续区（0x87D700-0x87D71C FPE 状态结构族）。

★原版怪癖（照抄）：
  ① cl 五位分派用独立 test/je 链（非查表非位扫描）——
     互斥位测试逐条硬编码；
  ② bit0 路径 fistp 存 [ebp+8]（int 参槽复用）而 bit3/4/5
     存 [ebp-8]（double 局部）——两槽分用；
  ③ bit2 路径 fldz/fld1/fdivrp st(1)（1÷0 → +inf 经 x87
     +inf 语义）后 fstp st(0) 清理——怪异计算照抄（无实
     际用途痕迹）；
  ④ bit3 先 fnstsw ax 后 fld [0x87D704]——状态字 + 控制
     字双读；
  ⑤ 每分支后 wait 收尾（FPU 同步）——x87 序列化惯用；
  ⑥ [0x87D704]/[0x87D710] 均为本函数内引用（唯一消费点
     ——专用 FPU 状态全局）。
