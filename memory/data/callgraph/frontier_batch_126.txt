0x7CAF30  CRT::strchr（16 callers）
================================================================================
身份实锤：YRpp CRT.h:58-59
    static char *__cdecl strchr(const char *Str, int Val)
        { JMP_STD(0x7CAF30); }
地址 + __cdecl 两参（Str/Val）+ 返回 char* 三证吻合。

机器码还原（全 0x83）：

    mov al, [esp+8]                ; ★ Val（目标字节）
    mov ebx, eax / shl eax, 8      ; 高字节填充 Val
    mov edx, [esp+8]               ; Str
    test edx, 3 / je 对齐路径      ; ★ 非 4 对齐 → 逐字节路径
  逐字节:
    mov cl, [edx] / inc edx
    cmp cl, bl / je 命中            ; 找到 → 返回（edx-1）
    test cl, cl / je 未命中         ; '\0' → 返 0
    test edx, 3 / jne 逐字节
  对齐路径:
    or ebx, eax / shl ebx, 0x10 / or ebx, eax   ; ★ 4 字节填满 Val
    mov ecx, [edx] / mov edi, 0x7EFEFEFF         ; ★ SWAR 魔数
    ; ★ 经典 haszero 技巧：逐 dword 检查是否含目标字节或 '\0'
    lea / xor 0x1010100 / and ... / jne 慢路
    ...（eax 内测 4 字节哪一字节命中 → 返回精确地址）

语义：**标准 CRT 字节查找（strchr）**——非对齐时逐字节、对齐后 4 字节 SWAR
优化（0x7EFEFEFF 魔数 = haszero/hasvalue 惯用法），找到返回指针、未找到返回
NULL。0x7C-0x7D 静态 CRT 层（项目既有实证 ra2_code_region_layout_crt_provenance）
的字符串查找成员。

★跨批次连接：0x7C-0x7D CRT 层字符串家族再添一员（此前 strcmpi/wcsncpy/
wcscmp/wcslen 已登记）——查找/比较/拷贝三类齐；SWAR 魔数 0x7EFEFEFF 是
MSVC6 标准实现指纹。

⚠️ partial：无（全读完）；末段 4 字节内定位的精确位移逻辑未逐字节展开。

0x7CA45F  CRT::wcscat（16 callers）
================================================================================
身份实锤：YRpp CRT.h:24-25
    static wchar_t *__cdecl wcscat(wchar_t *Dest, const wchar_t *Source)
        { JMP_STD(0x7CA45F); }
地址 + __cdecl 两参（Dest/Source）+ 返回 Dest 三证吻合。

机器码还原（全 0x2A，42B）：
    mov eax, [esp+4]               ; Dest
    mov ecx, eax
    loop1: cmp word [eax], 0 / je 找到尾   ; ★ 宽串找 '\0'（2B 步进）
    inc eax×2 / jne loop1
  找到尾:
    mov edx, [esp+8]               ; Source
    loop2: mov si, [edx] / mov [ecx], si    ; ★ 2B 拷贝
    inc ecx×2 / inc edx×2
    test si / jne loop2            ; ★ 连 '\0' 一起拷完
    ret

语义：**标准 CRT 宽字符拼接（wcscat）**——先找到 Dest 的空终止符，再把 Source
逐 wchar_t（含终止符）拷到其后。紧邻 0x7CA489（= CRT::wcscpy，batch 097 已
实锤）——wcscat 是 wcscpy 加上「先找尾」的组合。

★跨批次连接：宽字符三件套（wcscpy/wcscmp/wcslen，batch 097/098/110）再添
wcscat——拷贝家族补齐；batch 072/085/090 窄串族的宽串镜像继续扩展。

⚠️ partial：无（全 0x2A 读完）。
