五、原版怪癖（照抄）
-------------------
① ★★★[esp+8] 读调用方栈残留：sub esp,0x10 + push esi 后 [esp+8] 是
   sub 分配的局部槽，函数体从未写入——mov ecx,[esp+8] 实际读的是调用方
   call 前该栈位置的残留内容（调用方栈帧/更早压入值），写入对象 +0xC；
   值与调用点现场环境相关（非确定性）——**未初始化读取怪癖**；
② 双 32 位压栈拼 double：调用方先压 +0x3CC(高字) 再压 +0x3C8(低字)，
   小端栈上低地址=低字，fld qword 正好读满 8 字节（x87 无 uint32 转换
   指令的 MSVC6 传 double 惯用形态——与 RMG scaled_random 的 fild qword
   同族思路）；
③ _ftol 结果写两槽（+0x10/+0x14 同值）——记录结构 4 槽 {帧戳, 残留,
   结果, 结果}；
④ fst qword[esi] 把缩放值存回 this+0（double 结果字段）后再 _ftol——
   FPU 栈上先存后取；
⑤ 双标志门控语义：+0x18（已标记/占用推断）非 0 → 直接记录覆盖；+0x18
   ==0 且 +0x19==0 → 跳过；+0x19 非 0 → 记录——与 0x4A51D0「皆 0 才返 1
   空闲」互补（0x4A51D0 判空、本函数置占用）；
⑥ 记录中途置 +0x18=1、收尾清 +0x19=0（+0x19 是待记录请求位推断）；
⑦ 调用点条件判定「宿主+0x114 == 对象+0x5E0」/ 三字节门控 +0x6E0..0x6E2
   / 虚表槽 0x274 返 1 跳过——各宿主自己的前置条件，非本函数内。
