签名（确认）：thiscall 0 参（ecx=this），无返回值（析构
副作用）。对象布局：+0 = vtable 0x7FA498、+4 = 句柄/指针

★语义：**MSVC6 CRT LocalFree 析构体（推断名——vtable
0x7FA498 对象族析构）**——thiscall 0 参析构：
  ① vtable 复位 0x7FA498（对象 +0 写回）；
  ② this->+8 子对象非 NULL → 调其虚表槽 8（1 参 thiscall
     释放子对象）；
  ③ this->+0xC 非 NULL → LocalFree（IAT [0x7E1340]，释放
     LocalAlloc 分配的指针）。
  = CRT/C++ 对象析构的标准形态（写回 vtable + 虚表槽释放
  子对象 + Win32 LocalFree 释放成员）。

★vtable 0x7FA498 三写点（探针 imm32 命中 0x7DCDD4/
  0x7DCE29/0x7DCE43——全在 0x7DCE 族内）：
  ① 0x7DCDD4（构造器 0x7DCDC5 内，ret 0xC = thiscall 3
     栈参）：and [esi+0xC],0 / mov [esi+4],eax / mov
     [esi],0x7FA498 / mov [esi+8],eax / cmp byte[esp+0x10],
     0 / je / mov ecx,[eax] / push eax / call dword[ecx+4]
     （★构造路径调子对象虚表槽 4）→ mov eax,esi / pop esi
     / ret 0xC；
  ② 0x7DCE29（拷贝构造器 0x7DCE0E 内，ret 4 = thiscall 1
     参）：mov [esi+4],ecx / mov [esi],0x7FA498 / mov
     [esi+8],eax / test eax,eax / je / mov ecx,[eax] /
     push eax / call dword[ecx+4]（★拷贝路径同样调虚表槽
     4）→ pop esi / ret 4；
  ③ 0x7DCE43（本批析构体——析构路径调**虚表槽 8**）。
  → 构造/拷贝构造走槽 4、析构走槽 8（attach/detach 语义
  双槽分派，推断为 AddRef/Release 类引用计数——未确认不
  臆断）。
