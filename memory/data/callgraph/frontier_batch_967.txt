真义（黄金实证 + 机器码全段确认）：0x7C8DF0 = MSVCRT strrchr（反向
字符查找）——cdecl 2 栈参 (s, c)，返回 s 中**最后一次**出现字符 c
的指针、未找到返 0；★c==0 返终止 NUL 指针（标准 strrchr 语义）。
纯内存操作，无子调用无全局引用——全程可真身模拟。
  机器码（0x7C8DF0-0x7C8E16，39B）：
    push ebp / mov ebp,esp / push edi
    mov edi,[ebp+8]=s
    xor eax,eax（AL=0）→ or ecx,-1 → repne scasb（★正扫 NUL）
    inc ecx → neg ecx（★ECX = 串长含 NUL = len+1——SCASB 相等命中
      时也先执行后递减，故 inc/neg 得 len+1）
    dec edi（★指向 NUL 处）
    mov al,[ebp+0xC]=c（★只取低 8 位）
    std（★方向标志=递减）
    repne scasb（★反向从 NUL 处倒找 c，共 len+1 个位置）
    inc edi（★校正：REPNE 停止时 EDI 已越位）
    cmp [edi],al → je 0x7C8E11（命中返指针）
    xor eax,eax（未命中返 0）
    0x7C8E11: mov eax,edi
    cld（★恢复 DF）→ pop edi → leave → ret

★原版怪癖（golden 实证，照抄）：
  ① 反向扫描覆盖 [len..0] 共 len+1 位置（含 NUL 与 s[0]）——ECX 正
     扫 NUL 后 inc/neg 得 len+1，反扫恰好走完 NUL 到 s[0] 全程；
  ② 收尾 cmp 在未命中（ECX 耗尽）时把 s[0] 再比一次——s[0]==c 仍返
     &s[0]（反向最后检查位），反证返回指针确为 c（golden s="ba"
     c='a' 未走此支但 s[0] 命中路径实证）；
  ③ c 只取低 8 位（高位忽略——golden 0x1FF 与 0xFF 等价实证）；
  ④ c==0 时 NUL 处即命中返终止 NUL 指针（含空串→&s[0]）；
  ⑤ std/cld 配对（cdecl 约定 DF 返回时 clear）；
  ⑥ or ecx,-1 编码（非 mov ecx,-1）。
