★语义：**CRT 浮点指数格式化器（推断名——%e 家族）**——cdecl 4
参（参1=目标缓冲，参2=长度，参3=浮点源结构，参4=前缀标志）：
  ① 参4!=0 → 0x7CEF29 转换辅助（参2>0 标志 + 负号偏移）；
  ② 源首 '-' → 写负号并越过；参2>0 → 填充字符 [0x87C7A0]
     （目标+1 后移一字节）；
  ③ strcpy（0x7D4BF0）拼接常量串 0x7F9898（参4==0 时起点为
     目标+参2）；参3参数不越界 → 写 'E' 指数标记；
  ④ [源+0xC] 首字节=='0' → 零值直接返回；
  ⑤ 指数 = [源+4]-1，负号处理 → 逐位手写：>=100 → idiv 100 百
     位 + 余数、>=10 → idiv 10 十位 + 余数、个位 add 0x30；
  ⑥ 返回目标缓冲。

★原版怪癖（照抄）：
  ① 填充字符走全局 [0x87C7A0]（可配置填充——默认 0x20 空格）；

  ③ 'E' 指数标记只在参3参数引用非空时写（[ebp+0x10]==0 跳过

  ⑥ 指数 -1 后负数补 '-'（dec 后 jns/neg）。
