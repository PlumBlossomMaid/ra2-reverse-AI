一、函数体全读（386B，disasm 0x7C81DB 0x190 全量）
------------------------------------------------
参数契约（cdecl 3 栈参 ret）：[ebp+8]=输入压缩串（esi）、[ebp+0xC]=
输出缓冲（edi）、[ebp+0x10]=输入长度（edx——用于末端计算）。
机器码（386B 全读，逐段要点）：
  序言: push ebp → mov ebp,esp → add esp,-0x14 → push ebx/ecx/edx/
    edi/esi → mov edi,[ebp+0xc]（★输出）→ mov esi,[ebp+8]（★输入）
    → mov edx,[ebp+0x10]（★长度）→ mov al,[esi] → or al,al → je
    0x7c82af（★★首字节 0 → 走第二段——输入为空或特殊开头）→ mov
    [ebp-4],edi → add edx,edi → mov [ebp-0xc],edx（★输出末端=输出+
    长度）→ cld → 主循环 0x7c8204: mov eax,[ebp-0xc] → sub eax,edi
    → je 0x7c8257（★末尾）→ mov [ebp-8],eax → lodsb（★读控制字
    节）→ or al,al → js 0x7c823b（★bit7 集 → 分档）
  字面量回拷（非负控制字节）: mov ah,al → and ah,0xf → mov cl,al →
    shr cl,4 → add ecx,3（★★长度 = (al>>4)+3——batch 916 编码端
    sub bl,3/shl 4 共轭）→ cmp ecx,[ebp-8] → jbe 0x7c8230 → mov
    ecx,[ebp-8]（★长度钳制到剩余）→ lodsb（★偏移）→ mov esi,edi →
    sub esi,eax（★源=目标-偏移）→ rep movsb（★★回拷——LZ 类）
  分档（bit7 集）: 0x7c823b: test al,0x40 → jne 0x7c825e（★bit6 →
    特殊）→ cmp al,0x80 → je 0x7c8257（★★0x80=结束标记！）→ mov
    cl,al → and ecx,0x3f（★bit6/bit7 都 0 的区间 → 短字面量）→
    cmp ecx,[ebp-8] → jbe → rep movsb → 0x7c825e: mov cl,al → and
    ecx,0x3f → add ecx,3 → cmp al,0xfe → jne 0x7c8281（★★0xFE=填
    充标记）→ sub eax,eax → lodsw（★填充长度）→ mov ecx,eax →
    lodsb（★填充字节）→ rep stosb（★★填充：一个字节重复写 N 次）
    → 0x7c8281: cmp al,0xff → jne 0x7c828b（★★0xFF=长回拷标记）→
    sub eax,eax → lodsw（★长度）→ mov ecx,eax → 0x7c828b: lodsw
    （★偏移）→ add eax,[ebp-4]（★源=输出基址+偏移）→ rep movsb
    （★长回拷）→ 循环
  收尾 0x7c8257: mov eax,edi → sub eax,[ebp-4]（★返回输出量）→
    jmp 0x7c82a3（★统一出口）→ 0x7c835b: pop 族 → leave → ret
  第二段（首字节 0）: 0x7c82af: lodsb（★跳过首 0）→ 同款主循环
    0x7c82bb 全段重复（字面量/0x80 结束/0xFE 填充/0xFF 长回拷/短
    字面量——与第一段逐字节同构）
  尾部: 0x7c8362: jmp dword[0x7e1300]（★IAT 跳板——后续函数）
语义：**Format80 解码器（推断名）**——cdecl 3 栈参（输入/输出/长度）
  ：按控制字节分档解码：① 非负字节（无 bit7）= 字面量回拷（长度
  (al>>4)+3、偏移下一字节、rep movsb）；② 0x80 = 结束标记；③ bit6
  集分档：0xFE = 填充（长度 word + 填充字节 rep stosb）、0xFF = 长
  回拷（长度 word + 偏移 word + rep movsb）、其余 and 0x3f = 短字
  面量；④ 返回解码输出量（edi - 基址）。★★与 batch 916 编码端
  0x551E50（0x81 头/0x80 终止/三级长度编码）构成 Format80 编解码对
  ——本批=解码端（QA.64 前瞻匹配 不对应，编码端在 0x55 区、解码端
