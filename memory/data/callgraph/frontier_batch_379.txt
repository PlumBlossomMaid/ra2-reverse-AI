**语义（推断名）**：**链式哈希表插入**——`插入(this, key, value)`：① 若表非空，
经**全局哈希函数指针 `[0xAC1B18]`** 求哈希，用 **`(1 << [0xAC1B0C]) − 1` 掩码**定位桶
（`[0xAC1B00]`），沿 **`+0x204` 链**比对节点首 dword（**key**）；② **命中**则把
栈参2 写进节点 `+0x24` 并返回 1；③ **未命中**则 `operator new`（`0x7C8E17`）建节点
（`0x7B66C0` 构造 + `0x623340` 子构造 + `0x623610` 灌栈缓冲），**头插到桶**
（`[esi+0x204] = 旧头`），**元素数 `[0xAC1B04]++`**，再算
**装载因子 = 元素数 / 容量（`fidiv [0xAC1B08]`）**并与**阈值 `[0xAC1B28]`** 比较，
**越阈即调 `0x624FC0` 扩容/重哈希**；④ 插入后**再查一遍**拿到节点（`lea ebp,[eax+4]`），
清理栈缓冲（`operator delete` + `0x623460` 逐项释放 + `0x624480`），
最后把栈参2 写进节点 `+0x20` 返回 1。
