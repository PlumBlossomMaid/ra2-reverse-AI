   = MSVC6 静态 CRT（ra2_code_region_layout_crt_provenance）；
   0xFF 前导检测 + errno EILSEQ + locale 双路径为 CRT
   MBCS 转换标准形态。
2. 依赖：0x7CC653（紧邻转换核心）+ 0x7D1690（errno 槽）
   + [0xB782A0]/[0x87C79C] 全局——重写 gamemd 时用等价
   运行时（mbtowc/_mbstowcs）代替。
3. gamemd_replication_discipline：CRT 多字节转换设施，
   重写时用等价运行时代替，逐字节复刻无意义——按商业
   库纪律归档，不写 C++ 模型不做 golden。
