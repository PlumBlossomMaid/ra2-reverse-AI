0x4093B0  全局函数指针 trampoline（18 callers，0x10 全读完）
================================================================================
机器码（全 0x10）：
    mov eax, [0x87E848]             ; ★ 读全局函数指针 [0x87E848]
    test eax / je 返 0
    jmp eax                         ; ★ 非空 → 尾跳执行
  返 0:
    xor eax, eax / xor edx, edx / ret

语义：**「读 [0x87E848] 的函数指针，非空则尾跳执行」的 trampoline**——
batch 111 登记的 0x407170（标志/定点族）里 `call 0x4093B0` 正是走这里——
当时标注「0x4093B0（★函数指针 [0x87E848] trampoline）」，本批正式立案。
18 个调用方共用这一个「可替换回调」（引擎挂钩点：其他代码改 [0x87E848]
即可全局换行为，无需 patch 各调用点）。

★跨批次连接：batch 111 引用闭合（0x407170 → 本条）；[0x87E848] 与 batch 102
（[0xABFD34] 函数指针钩子）、batch 105（[0xAA0430] 计数）同属「全局函数指针

0x7B47F0  窄串比较（18 callers）
================================================================================
机器码（全 0x63 实读）：
    mov eax, [ecx]                  ; ★ this->[0]（串指针，NULL 兜底语义）
    mov esi, [esp+8]                ; ★ 参数字符串
    test eax / jne 继续
    test esi / jne 继续
    xor al / ret 4                   ; 双 NULL → 相等（true）
  继续:
    test eax / je 收尾1
    test esi / je 收尾1
    mov dl, [eax] / mov bl, [esi]    ; ★ 逐字节比较
    loop: cmp dl, bl / jne 收尾2
    test dl / je 收尾1               ; 遇 '\0' → 相等
    mov dl, [eax+1] / mov bl, [esi+1]
    cmp / jne 收尾2                  ; ★ 2 字节展开
    add eax, 2 / add esi, 2 / loop
  收尾2:
    sbb eax, eax / sbb eax, -1
    test eax / setne al / ret 4      ; ★ 返回「是否相等」（bool）
  收尾1:
    mov al, 1 / ret 4

语义：**窄字符串类的比较成员（strcmp 语义 → bool）**——this->[0] 与参数字符串
逐字节比较（2 字节展开、遇 '\0' 判等），返回相等布尔。★NULL 语义：双 NULL
返相等、单 NULL 走 1 分支——与 batch 085/088/090 窄串族「NULL≡空串」设计
一致。★原版怪癖：收尾2 用 `sbb/setne` 把 strcmp 差值归一成 bool，而非直接
返回差值——调用方只关心是否相等。

★跨批次连接：窄串族（batch 059/062/072/085/086/088/090）比较方向的新成员；
与 batch 093（CRT::strcmpi 0x7C8D20）不同——这是引擎自写窄串比较（大小写
敏感），CRT 版是大小写不敏感——两套并存。

⚠️ partial：宿主类（StringClass 推断，batch 085 命名）、[esp+8] 参数的确切
类型（const char* vs 同族对象）。

0x77D940  GameMode 门禁变体（18 callers，0x2F 全读完）
================================================================================
机器码（全 0x2F）：
    cmp [0xA8B238], 4 / je 继续      ; ★ GameMode == 4（SessionClass::Instance）
    xor al / ret                     ; 否则 false
  继续:
    mov eax, [0xB76B24]              ; ★ 第一标志（[0xB76B24]）
    test eax / jne 返 1              ; 非零 → true
    mov eax, [0xB76B30] / shr eax, 8 / and al, 1   ; ★ bit8
    test eax / jne 返 1              ; [0xB76B30] bit8 → true
    xor al / ret                     ; 否则 false
  返 1: mov al, 1 / ret

语义：**「GameMode==4 且（[0xB76B24] 非空 或 [0xB76B30] bit8）」的变体门禁**。
与 batch 113 登记的 0x77D970（GameMode==4 且 [0xB76B30] bit8）同族：本变体多
一个 [0xB76B24] 早退条件（任一成立即 true）。两函数共享 [0xA8B238]（GameMode）
与 [0xB76B30]，是同一 UI 状态闸的两个判断入口。

★跨批次连接：[0xA8B238] = SessionClass::Instance/GameMode（batch 098/099/113
同全局第四消费）；[0xB76B30] bit8 与 batch 113（0x77D970）互证。

⚠️ partial：[0xB76B24] 标志身份（vs [0xB76B30] 的 bit8 语义差异未实锤）、
GameMode==4 含义。
