一、链语义（disasm 全 101B + 依赖交叉 + 宿主导航常量，
0x7CF64C-0x7CF6B0）
--------------------------------------------------------------
签名（推断）：cdecl 1 参（[ebp+8]=double），返回 eax：
2 = 整数且 ÷2 仍整数 / 1 = 整数且 ÷2 非整数 / 0 = 非整数
或 NaN/Inf 域。

★语义：**MSVC6 CRT x87 double 整数判定助手（推断名）**——
cdecl 1 参：
  ① classifier（0x7D930F batch 012）al&0x90 排除 NaN/Inf 域
     → 返 0；
  ② frndint 取整后比对（x 有小数部分）→ 返 0；
  ③ x/2.0 再取整比对：x/2 仍整数 → 返 2（偶数），否则返
     1（奇数）。
  = x87 整数判定惯用（分类闸 + 两次 frndint 恒等检查），宿
  主 0x7CF5EF 同浮点域（0x7CF5C0 区 fcomp [0x7E2800]=0.0、
  fldz 空值路径——_ftol/浮点打印前导判定域）。

★调用点（探针 E8 实测 1 处 0x7CF5EF）：宿主 0x7CF5C0-0x7CF647
  （双分支：jbe 取 [0x87d550] / fcomp 0.0 判零 / cmp [ebp+0xC],
  ecx = INT64 高半零判 → call 0x7CF64C → 结果回接）——大整
  数/浮点转换域（INT64 双半比较 + classifier 前置）。

★E8 被调者：0x7D930F（★★batch 012 IEEE-754 classifier——

  18B 纯取整；0x7D8EF5 起为邻接 copysign/QNaN 静默包装

★原版怪癖（照抄）：
  ① classifier 返回 al 后 `test al,0x90`——0x90 = 0x10|0x80
     仅测两比特（NaN/Inf 域掩码），非全码测试；

     分离——两条收尾不合并。
