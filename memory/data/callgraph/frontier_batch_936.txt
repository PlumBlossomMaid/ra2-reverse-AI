一、语义（完整汇编逐段核对 + 黄金 8 用例闭环）
------------------------------------------------
真义（黄金实证 + 机器码逐段确认）：
  · 调用约定：ret 0（无栈参，0x5A76D4 c3），纯寄存器传参：
    - ecx = 输出矩形指针（4×int32，写入 {minX, minY, w, h}）
    - edx = 输入对象指针（[edx+4] = 元素数组 dword 首址、[edx+0x10]
      = 元素个数 n）
    元素布局：每元素 4B = {short X @+0, short Y @+2}（低 16 = X、高 16
    = Y）。
  · 主循环（0x5A7658-0x5A76AC，★从数组末尾往前遍历）：
    16 位变量初值：di=minX=999(0x3E7)、bx=minY=999（0x5A7655 mov bx,di
    拷贝初值）、ax=maxX=0（0x5A7643 xor ax,ax）、bp=maxY=0（0x5A7651
    xor bp,bp）。
    每元素（0x5A7669-0x5A7695）：
      X = 元素 dword 低 16（0x5A766D mov edx,[edx]; cmp dx,di）
      Y = 高 16（0x5A767B mov si,word ptr [esp+0x1A]）
      cmp dx,di; jge 跳过 → minX = min(minX,X)（直接 16 位有符号比较）
      cmp si,bx; jge 跳过 → minY = min(minY,Y)
      cmp dx,ax; jle 跳过 → maxX = max(maxX,X)
      cmp si,bp; jle 跳过 → maxY = max(maxY,Y)
    指针 -= 4、计数--，jne 0x5A7669 循环（0x5A76A0-0x5A76AC）。
  · 输出段（0x5A76AE-0x5A76CB）：
      movsx 把 16 位 min/max 符号扩展成 32 位：
      out[0] = (s32)minX
      out[1] = (s32)minY
      out[2] = (s32)maxX - (s32)minX + 1   （0x5A76B6 sub; 0x5A76BD inc）
      out[3] = (s32)maxY - (s32)minY + 1
      eax = ecx（输出矩形首址，0x5A76B4 mov eax,ecx）。
  · RNG 不参与；无 GetCellAt / 谓词依赖——纯数组扫描。

★原版怪癖（golden 实证，C++ 侧逐条复刻）：
  ① min 初值 999、max 初值 0：空数组（n==0）→ 0x5A7658 js 直接跳输出
     → {999, 999, 0-999+1=-998, 0-999+1=-998} 哨兵（golden empty）。
  ② 全负坐标时 max 保持初值 0（-1 > 0 为假，jle 跳过更新）——max 不是
     「真实最大值」：golden allneg {(-1,-1),(-2,-2)} → {-2,-2,3,3}
     （maxX/maxY 恒 0）。
  ③ X/Y 各自独立扫描：元素布局 {short X, short Y} 4B（低 16 X 高 16
     Y），读取后各自参与 16 位有符号比较。
  ④ 从数组末尾往前遍历（lea edx,[edx+esi*4] 指向 arr[n-1]），顺序不
     影响 min/max。
  ⑤ 输出 w/h = max-min+1（含端点），16→32 用 movsx 符号扩展——负坐标
     参与 32 位差值。

三、C++ 模型（code/rewrite/rmg/dead_code_7640.{h,cpp}）
------------------------------------------------
签名：void DeadCode7640(const DeadCode7640Context& ctx, int32_t out[4])。
ctx 携带 world / count。world 抽象输入数组读取（Element(i) 返回 dword：
低 16 X、高 16 Y——与原版 mov edx,[edx] 读元素一致）。实现要点：
16 位变量初值（min=999/max=0）→ 倒序遍历所有元素做四个 16 位有符号
min/max 更新 → movsx 符号扩展输出 {minX, minY, max-min+1, max-min+1}。
无失败路径（返回 void）。
