一、语义（全段反汇编逐条核对 + golden 16 行闭环）
------------------------------------------------
真义（机器码全 56B 确认，disasm.py 0x5A1E10 0x38）：
  · 调用约定：**thiscall 无栈参 ret 0**——ecx=this（mov esi,ecx），
    读 this->[0x3C]（dword，mov eax,[esi+0x3c]）。
  · 门禁：cmp eax,4 / je 0x5A1E20；cmp eax,3 / jne 0x5A1E46
    —— [this+0x3C] == 4 || == 3 才执行编排，否则零调用直接返回。
  · 命中编排（0x5A1E20-0x5A1E41 五连调，固定顺序）：
      ① call 0x58EBC0       （无参 ret 0——ecx 残留无契约）
      ② call 0x58EF10       （无参 ret 0）
      ③ mov ecx,esi; call 0x5A19E0（thiscall ecx=this，ret 0）
      ④ push -1; push 0; mov ecx,0x87F7E8; call 0x578E60
         —— RepaintAll(Instance, 0, -1)：thiscall+2 栈参 ret 8，
         参数1=0（[esp+4]）、参数2=-1（[esp+8]）
         （★★push -1 实锤形态——与活代码 0x598D73 同款 owner=-1）
      ⑤ mov ecx,esi; call 0x5A17F0（thiscall ecx=this，ret 0）
  · ★★零取数点：门禁本身不调 Randomizer；五个子调用本批全部打桩
    （C3=ret / C2 08 00=ret 8）+ hook 各入口记录调用序列与实参。

公式（golden 16 行实证）：
  if (this->[0x3C] == 4 || this->[0x3C] == 3) {
    Sub58EBC0(); Sub58EF10(); Sub5A19E0();
    RepaintAll(0, -1);   // 实参形态 push -1; push 0
    Sub5A17F0();
  }

★与 0x58C4A0 族的差异：
  ① **编排门禁**——不是取数循环，是五个子调用的固定顺序编排；
  ② **门禁双值判断**（==4||==3，0x58C4A0 族是类型字段比对）；
  ③ **RepaintAll 实参**（参数1=0、参数2=-1——owner=-1 活代码同款）。
