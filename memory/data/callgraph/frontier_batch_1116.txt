一、链语义（disasm 全 256B + 宿主锁交叉，0x7CC309-0x7CC408）
--------------------------------------------------------------
签名（实测）：cdecl 3 参（param1=dst 宽字符缓冲 @[ebp+8]、
param2=src 多字节串 @[ebp+0xC]、param3=limit @[ebp+0x10]），
返回转换宽字符数 / 长度查询 / -1 失败。

★调用点宿主锁（探针交叉）：0x7CC2E5 宿主 0x7CC2xx 区调
  0x7CD9F5（CRT region lock Enter，TSV:238 已登记）+ 0x7CDA56
  （CRT region lock Leave，TSV:239 已登记）——★★铁证：本函
  数是 CRT 线程安全流/串设施的一部分。

★语义：**MSVC6 CRT mbstowcs（多字节串→宽字符）**——cdecl
3 参：
  ① dst==NULL → 长度查询：窄模式 _strlen（0x7D15A0），宽
     模式槽调用查长；失败 errno=0x2A（42=EILSEQ）返回 -1；
  ② dst!=NULL 且 limit>0：[0xB782A0]==0 窄模式 → 逐字节
     movzx 扩为宽字直译（单字节代码页 1:1 映射）直到 NUL/
     limit；[0xB782A0]!=0 宽模式 → 槽调用（6 参：locale/
     9/-1/src/dst/limit）→ 失败经 [0x7E1200] 'z'（0x7A）边
     界判定决定回退 DBCS 扫描（[0x87C590] ctype 表 2B/项
     0x80 lead-byte 位）→ 槽二次调用 → 仍失败 EILSEQ -1；
  ③ 成功返回宽字符数（槽返回值 -1 修正）。
  mbstowcs 标准行为完备（EILSEQ/-1/长度查询/NUL 终止）。

★原版怪癖（照抄）：
  ① [0xB782A0] 模式全局分双路径：窄模式（单字节代码页）纯
     movzx 扩字直译；宽模式（DBCS）走槽调用——同一函数两套
     语义，模式由全局静态决定；[0xB782A0] 29 处引用全 CRT

  ⑥ errno 0x2A=42=EILSEQ 写 [eax]（0x7D168E 结果指针）——

四、关键方法论修正：0x7E1xxx 槽表静态值不可作调用目标语义证据
----------------------------------------------------------------
★反汇编 [0x7E11C4] 槽目标 0x40F9A8（本批取证）：
  0040f9a8  nop×8（对齐填充）
  0040f9b0  fld qword[0x7E1EC8] / fmul qword[0x7E1720] /
            fstp qword[0x887548] / ret
  0040f9d0  fld qword[0x7E1EC8] / fmul qword[0x7E1728] /
            fstp qword[0x887520] / ret
  0040f9f0  fld qword[0x7E1EC8] / ...（同模式继续）
  = **MSVC6 CRT 浮点常量初始化器族**（每函数把常量×系数→
  全局，0.4KB 内同模式函数集群）——不是 Westwood thiscall
  对象方法！
★矛盾点：batch 1115 记录 0x7DC5DC/0x7DC4C9 用 **8 参**调用
  [0x7E11C4]；本批 0x7CC309 用 **6 参**调用 [0x7E11C4]；而
  槽静态值 0x40F9A8 是 0 参浮点常量初始化器——调用约定互
  相矛盾 → ★★[0x7E1xxx] 槽表 PE 静态值不是真实调用目标，
  槽表运行时被改写（CRT 启动/引擎初始化时填入真函数指针）。
★影响：batch 1111/1115 以槽静态值（0x7E1338→0x410FCE 等）
  判定「Westwood thiscall 对象方法分派」推断存疑——0x410FCE
  处字节 `ff ff 00 00` 非有效指令头，后续反汇编可能 misalign
  （数据被误当代码）。判据应改为：①对象方法形态须看调用
  点现场的 push 约定/返回处理，②槽静态值只作参考不作证据。
★处置：本批登记此修正；batch 1111/1115 已归档行暂不改写
  （保留原文并交后续复核批统一修正），但后续批次不得引用
  槽静态值断言调用目标语义。
