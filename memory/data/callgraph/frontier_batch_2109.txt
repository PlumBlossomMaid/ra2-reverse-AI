## 原版怪癖（照抄）

1. a 路**删除后重取数组基址**（mov edi,[0xb04dac]）——左移删除会改变 [0xb04dac] 内容但基址不变，重取为冗余防漂移；
2. a/c 路同款过期窗口惯用法：`[0xa8ed84]-时间戳 < 阈值 ? 阈值-差值 : 原值`，归 0 即到期——但两路字段对不同（+0x24/+0x2c vs +0x30/+0x38）；
3. b 路双跳表选色：`mov cl,[eax+0x660374] / jmp [ecx*4+0x660364]`——类型码经索引表映射到跳表（非连续 case 压缩）；
4. b 路 0x4355b0 三参调用（0xff/0x80 组合）取色，"分支1"路径用 `or cl,0xff` 直接造值不调 0x4355b0；
5. b 路第一套三字节（[esp+0x14..0x16]）全 0 时**整跳主体**（色值 0 = 不注册）；
6. b 路与 2108 b 主体逐段同构、仅第二段槽号 0x90 vs 0x44——同族两注册器；
7. c 路存活判定 `jg`（窗口>0 跳）vs a 路 `jne`（窗口≠0 跳）——a 路窗口为负也删，c 路窗口必须恰 0 才调度（细微差异需照抄）。
