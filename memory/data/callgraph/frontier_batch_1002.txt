一、链语义（disasm 全段复核 + batch 841 交叉）
------------------------------------------------
0x7CB19C(47B) = MSVC6 CRT 流锁保护的流操作包装（flush 内核版，
0x7C-0x7D 静态 CRT 区）——cdecl 1 栈参（FILE* 流槽）：
  push esi / mov esi,[esp+8]       ; ★参数=FILE* 流槽
  test esi,esi / jne 0x7CB1AE      ; ★空指针 → 独立路径
  push esi / call 0x7CB25E         ; ★★空指针处理路径（[0xB79BE0]/
                                   ;   [0xB78BC4] 全局遍历清理推断）
  pop ecx / pop esi / ret
  0x7CB1AE: push edi / push esi
  call 0x7CB3F9                    ; ★★流锁 Enter（batch 966 归档）
  push esi / call 0x7CB1CB         ; ★★内核操作（flush 内核）
  push esi / mov edi,eax           ; ★edi=内核结果
  call 0x7CB44B                    ; ★★流锁 Leave（batch 961 归档）
  add esp,0xC / mov eax,edi / pop 族 / ret
内核 0x7CB1CB（0x40 复核）：
  push esi / mov esi,[esp+8]       ; ★流槽
  push esi / call 0x7CB1F9         ; ★★flushbuf 底层（batch 049 已登

                                   ;   关闭内核同款被调）

  or eax,0xFFFFFFFF                ; ★flush 失败 → -1
  pop esi / ret
  0x7CB1E0: test byte [esi+0xD],0x40（★流槽+0xD 标志 0x40）/ je
  0x7CB1F5（★无 0x40 → 返 0）
  push [esi+0x10]（★流槽+0x10=OS 句柄 fd——batch 226 流槽布局）/
  call 0x7D30D1（★fd 操作未登记）→ neg eax / pop ecx / pop esi /
  sbb eax,eax（★★neg/sbb 惯用——fd 操作结果 0/-1）
  0x7CB1F5: xor eax,eax / pop esi / ret

①空流槽走 0x7CB25E 独立路径（非直接返 0/非锁包裹）；②非空则「流锁
