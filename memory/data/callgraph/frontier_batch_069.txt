**判据**：`add eax,eax`（×2）+ `mov word [eax],0`（word 级 NUL）+
`0x7CA405`(wcslen)/`0x7CA489`(wcscpy) —— 全部是**宽字符**操作。

★ **引擎有两个并存的字符串类**：
- 窄：`0x7B46xx`（batch 062，char、operator new 长度×1）
- 宽：`0x7B66xx`（本条，wchar_t、长度×2）
0x7B66D0 是宽字符串类的 operator=（NULL 安全：源 NULL 分配 1 宽字符空串）。
紧邻的 0x7B6760（batch 061 的 delete+null 析构）很可能就是它的析构——
**0x7B66xx 宽字符串类与 0x7B46xx 窄字符串类物理相邻**。

0x0065D460  链表节点递归析构（虚表 0x7F094C）
================================================================================
53 callers。全部 0x1C 字节：

    0065d460  mov eax, ecx                  ; this
    0065d462  mov ecx, [eax+4]              ; this->[4] = next
    0065d465  mov dword [eax], 0x7f094c     ; ★ 设虚表 0x7F094C
    0065d46b  test ecx, ecx
    0065d46d  je 0x65d47b                   ; next==NULL → 返回
    0065d46f  mov dword [eax+4], 0          ; this->[4] = 0
    0065d476  mov eax, [ecx]                ; next->vtable
    0065d478  jmp dword ptr [eax+8]         ; ★ 尾调 next->vtable->[8]()
    0065d47b  ret

即「设自身虚表 → 若 next 非空则递归调 next 的删除析构（vtable+8 是
scalar deleting destructor 槽）」——**析构整条链的递归析构**（尾调用，
MSVC `virtual ~Node(int)` 沿链递归的形态）。

紧邻的 `0x65D480` 是链插入/替换：`inc [edi+4]`（next 的引用计数+1）+
删除旧节点 + 设新节点。`+0x04` 既是链下节又是引用计数——**侵入式引用计数
链表节点**。
