一、链语义（disasm 全段复核 + golden 10 用例实证）
------------------------------------------------
真义（黄金实证 + 机器码全段确认）：0x7CA45F = MSVCRT wcscat（宽字符
串连接）——cdecl 2 栈参 (dst, src)，把 src 追加到 dst 的终止 NUL 处
（覆盖 NUL、src 的 NUL 收尾），返回 dst。纯内存操作，无子调用无全局
引用——全程可真身模拟。
  机器码（0x7CA45F-0x7CA488，42B）：
    eax=[esp+4]=dst / ecx=dst
    cmp word [eax],0 → je 0x7CA473（dst 空串快路径，跳过扫描）
  找 NUL 循环（0x7CA46B）：
    inc ecx ×2 / cmp word [ecx],0 / jne——ecx 停在 dst 终止 NUL
  复制循环（0x7CA478）：
    si=*(u16*)edx（src）→ *(u16*)ecx=si（写 dst）
    inc ecx ×2 / inc edx ×2 / test si,si / jne——src 到 NUL 即停
    （NUL 已先写入再测停）
  pop esi / ret（eax 恒为入口 dst 原值 → 返回 dst）

★原版怪癖（golden 实证，照抄）：
  ① 找 NUL 用 16 位比较（宽字符），指针步进 inc ×2；
  ② dst[0]==0 快路径跳过扫描直接复制（语义等价，省一轮循环）；
  ③ src 的 NUL 被复制进 dst（标准 wcscat 语义：dst 终止 NUL 被覆盖、
     src 终止 NUL 收尾；src 空时只写一个 NUL）；
  ④ 无 dst 容量检查（调用者保证空间）；
  ⑤ 返回 eax = 入口 dst（非终止位置）。
