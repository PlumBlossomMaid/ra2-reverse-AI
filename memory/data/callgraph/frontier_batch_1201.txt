★语义：**MSVC6 CRT __freebuf FILE 缓冲释放器（标准
__freebuf）**——cdecl 1 参：
  ① _flag 双检：先 `test al,0x83`（流标志 _IOREAD|
     _IOWRT|_IORW——非流直接返回），再 `test al,8`
     （_IOMYBUF 自有缓冲标志——非自有直接返回）；
  ② 命中 → free(_base)（0x7C93E8）+ `and word,0xfbf7`
     清 _IOMYBUF(0x8) 与 0x800 位；
  ③ 复位 _ptr/_base/_cnt 三字段（FILE+0/+8/+4 = 0）。
  = FILE 自有缓冲释放原语（fclose/fflush 尾部调用）。

★调用点（探针 E8 实测 1 处 0x7CA7A4）：宿主 0x7CA7xx
  （fclose 类流程）：push esi/call 0x7cb1f9（★flush——
  batch 1113 fwrite 链同款 0x7CB1F9）/push esi/mov
  edi,eax/call 0x7D2B54（★本批 __freebuf）→ push [esi+
  0x10]/call 0x7d2a74（★后续 fd 关闭段）/add esp,0xc/
  test eax,eax/jge 0x7ca7bd——flush 后释自有缓冲、再关
  底层句柄的 fclose 展开链。

★E8 被调者（1 个）：**0x7C93E8（★★TSV:234 semantics_

★全局：无（纯 FILE 结构操作）。

★原版怪癖（照抄）：
  ① _flag 双段检测（先 test al,0x83 流标志、再 test
     al,8 _IOMYBUF）——标准 __freebuf 的 MSVC6 展开形态
     （非 _IOMYBUF 即不释放——fclose 前 flush 仍可直关
     fd）；
  ② `and word[esi+0xc],0xfbf7` 清 0x0808 **两位**（
     _IOMYBUF 0x8 + 0x800 未知位）——不只清 mybuf；
  ③ 复位三字段用 xor eax,eax 后三次 mov [esi+N],eax
     （同值复用）——编译器寄存器调度；
  ④ pop ecx 清 free 1 参（cdecl）在复位**之前**——清理
     与字段复位乱序（照抄）；

     ——判定失败静默返回；

     流三标志合并——非流对象（如未初始化 FILE）直接跳过。
